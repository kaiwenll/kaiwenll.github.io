## 第一部分 · 知识地图（先建立整体逻辑）

省情看似是散点，其实是「一块地 → 一群人 → 一份产业 → 一套省内文件」的链条，而山东岗位的命题重心明显落在链条末端：

```
元层        怎么考：B 型高教综合 / C 型职教教基，省情为公共基础；真题已出现「济南市市情」
   ↓        S50 时效与未收录清单；真题形态见《第一个月每日知识点讲义》M01—M07
地理层      名称·简称·省会 → 区位 → 地形气候 → 面积人口民族 → 16 市 → 山川海河
   ↓        S01 名称 / S02 区位 / S03 地形气候 / S04 面积人口 / S05—S07 行政区划 / S08 水系
历史文化层  建制沿革 → 史前先秦 → 齐鲁名人 → 稷下学宫 · 齐鲁文化
   ↓        S09 建制 / S10—S12 沿革 / S13—S17 名人 / S18 稷下学宫与文化谱系
经济科技层  经济总量与农业 → 工业品牌 → 新旧动能转换 → 自贸区 · 自主创新示范区 · 交通
   ↓        S19—S21 经济 / S22 未收录的 2025 报告数据 / S23 区域战略 / S24 科教 / S25 交通 / S26 资源
文旅层      世界遗产与 5A → 名山数字 → 十大文旅品牌 → 名城戏曲鲁菜 → 16 市特产 → 山东之最
   ↓        S27—S34
时政省情层  黄河战略 → 半岛城市群 → 部省共建职教高地 → 省域现代体系新模式 → 送分题原理
   ↓        S34—S40
省内文件层  山东省职业教育条例 → 实施方案 → 基本工作规范（2025）
```

**七层对应的真题分布**：省内文件层与地理层的 16 市、行政区划命中率最高（「济南市市情」为原题，「服务滨州当地建设」为滨州职业学院 2024 论述题）；历史文化层常以「《孟子》」「六艺」「黄炎培」等小题出现在选择题里；经济与文旅层多为数字型选择题；时政省情层几乎每卷都出现在选择或论述的升华部分。**省内文件为什么是山东岗位的送分题**，见第七部分导语与 S40 专门拆解。

**一条通用答题主线**（后面每个考点都能套）：
`是什么（定义／原文数字）→ 在哪（地理或文件位置）→ 为什么重要（对山东的意义）→ 怎么落到岗位（高职教师／学校／专业）→ 升华（黄河战略、教育强省、技能型社会）`

## 第二部分 · 地理区位与行政区划（S01—S08）

这一部分全是选择题的硬数字：名称、简称、省会、面积、人口、16 市名单。B 型卷公共基础与 C 型卷常识题都从这里取点，特点是「记住就得分、记混就丢分」，必须逐条闭卷默写。

### S01 · 山东名称、简称、省会与「齐鲁」★

**【必背原文】** 山东，最初作为一个地理概念，主要指崤山、华山或太行山以东的黄河流域广大地区；**因居太行山以东而得名，简称「鲁」，省会济南**。先秦时期隶属齐国、鲁国，故而别名**齐鲁**。首先将齐、鲁联系起来的是孔子，但这里的「齐鲁」仍然是国家概念，到战国后期「齐鲁」才真正组成一个词，成为含有统一文化特点的地域概念；**最早把「齐鲁」作为统一地域概念使用的应该是荀子**。战国时称崤山、函谷关或太行山以东地区为「山东」或「关东」，这是广义上的山东；秦朝统一后，「山东」一词开始有广义和狭义之分，狭义上的山东已与今天山东的地理范围大致相当。（省情常识 p2；省情汇总 p1）

**【要点拆解】**

| 要素 | 原文落点 | 易错点 |
| --- | --- | --- |
| 得名 | 居太行山以东 | 不是「泰山以东」 |
| 简称 | 鲁 | 不是「齐」 |
| 省会 | 济南 | 明初设山东布政使司治济南府，此后济南一直为省会（省情常识 p5） |
| 别名 | 齐鲁 | 先秦为齐国、鲁国两个国家概念，战国后期才成统一地域概念 |
| 关键人物 | 荀子最早把「齐鲁」作为统一地域概念使用 | 常被误答成孔子 |

1. 「山东」作为**行政区划名称开始于金代**（金代改京东东路、京东西路为山东东路、山东西路，是历史上第一次把「山东」作为行政区划名称），**清初设置山东省**，「山东」才成为本省的专名（省情汇总 p1；省情常识 p4）。
2. 广义「山东」与狭义「山东」的分界在秦统一后，选择题常问「山东一词作为行政区划名称始于何时」，答案是金代。
3. 「齐鲁」从国家概念到地域概念的转折点是战国后期，人物是荀子，两处都是高频填空点。
4. 山东素有「膏壤千里」之称，也是「礼仪之邦」（鲁国）、「冠带衣履天下」（齐国）等表述的出处（省情常识 p3）。

**【答题框架/落点】** 填空「山东简称＿＿、省会＿＿」直接写鲁、济南；简答「「齐鲁」含义的演变」按「两个国家 → 孔子首次连称 → 战国后期成地域概念 → 荀子最早统一使用」四步写。

**【易混辨析】** 「山东」得名于太行山以东，不是泰山以东；「齐鲁」在先秦是**齐国与鲁国两个诸侯国**，不是一开始就指山东这块地域；「金代始作行政区划名称」与「清初设山东省成为专名」是两个时间节点，不可合并。

**【真题锚点】** 济南幼儿师范高等专科学校 2024（2024.1.20）选择题含「济南市市情」，本条为市情前置知识；济南工程职业技术学院 2023 选择「得天下英才而教育之三乐也出自《孟子》」属同板块文化常识；命题角度：填空「最早把齐鲁作为统一地域概念使用的是＿＿」。

**【出处】** 省情常识 p2、p4、p5；省情汇总 p1。

### S02 · 地理区位与经纬度、毗邻省份 ★

**【必背原文】** 山东地处**华东沿海、黄河下游、京杭大运河中北段，是华东地区的最北端省份**；位于中国东部沿海、黄河下游，北纬 34°22.9″—38°24.01″、东经 114°47.5″—122°42.3″之间。境域包括**半岛和内陆两部分**：山东半岛突出于渤海、黄海之中，东与朝鲜半岛、日本列岛隔海相望，北与辽东半岛相对、庙岛群岛纵列其间（是渤海与黄海之自然分界线，拱卫天津和北京）；西部内陆自北而南与**河北、河南、安徽、江苏**四省接壤。全境南北最长约 420 多公里，东西最宽约 700 多公里。（省情常识 p2、p6；省情汇总 p5）

**【要点拆解】**

| 维度 | 原文要点 |
| --- | --- |
| 大区位 | 华东沿海、黄河下游、京杭大运河中北段，华东最北端省份 |
| 海域 | 渤海、黄海；半岛三面环海 |
| 半岛相对关系 | 北与辽东半岛相对，东与朝鲜半岛、日本列岛隔海相望 |
| 陆上邻省 | 河北、河南、安徽、江苏（自北而南四省） |
| 跨度 | 南北最长约 420 多公里，东西最宽约 700 多公里 |

1. 「华东地区最北端省份」是本条最易被忽略的定位句，凡问「山东在华东的位置」必写。
2. 陆上邻省是**四个**（河北、河南、安徽、江苏），不是五个；顺序自北而南，选择题常把「山东与山东接壤」类干扰项混入。
3. 庙岛群岛是渤海与黄海的自然分界线，同时「拱卫京畿」，属地理＋时政双用素材。
4. 山东半岛突出于渤海、黄海之中，与「三面环海」（省情汇总 p5）呼应，海岸线数据见 S08。

**【答题框架/落点】** 简答「简述山东地理区位」按「大区位 → 经纬度 → 半岛与内陆两部分 → 海域 → 邻省 → 跨度」六层；选择题按上表关键词直接选。

**【易混辨析】** 「华东最北端」不等于「华北」；「隔海相望」的对象是朝鲜半岛、日本列岛，「相对」的对象是辽东半岛；「接壤四省」与「隔海相望」是两组不同关系，不可混答。

**【真题锚点】** 济南幼儿师范高等专科学校 2024 选择含「济南市市情」；命题角度：选择「下列不与山东陆上接壤的省份是」，或填空「山东是＿＿地区的最北端省份」。

**【出处】** 省情常识 p2、p6；省情汇总 p5。

### S03 · 地形地貌与气候 ★

**【必背原文】** 境内**中部山地突起，西南、西北低洼平坦，东部缓丘起伏**，形成以山地丘陵为骨架、平原盆地交错环列其间的地形大势。**泰山雄踞中部，主峰海拔 1545 米，为全省最高点**；**黄河三角洲一般海拔 2 米～10 米，为全省陆地最低处**。境内地貌复杂，大体可分为中山、低山、丘陵、台地、盆地、山前平原、黄河冲积扇、黄河平原、黄河三角洲等 **9 个基本地貌类型**；平原面积占全省面积 **65.56%**，丘陵占 **15.39%**，山地占 **14.59%**，台地占 **4.46%**。山东的气候属**暖温带季风气候类型**，降水集中、雨热同季、春秋短暂、冬夏较长，热量条件可满足农作物一年两作的需要。（省情常识 p6；省情汇总 p5）

**【要点拆解】**

| 项目 | 数据／表述 | 备注 |
| --- | --- | --- |
| 地势大势 | 中部高、西南西北低平、东部缓丘 | 十六字口诀「中突、西平、东缓」 |
| 最高点 | 泰山主峰 1545 米 | 全省最高点 |
| 最低处 | 黄河三角洲 2～10 米 | 全省陆地最低处 |
| 9 类地貌 | 中山·低山·丘陵·台地·盆地·山前平原·黄河冲积扇·黄河平原·黄河三角洲 | 数字题 |
| 四类占比 | 平原 65.56%、丘陵 15.39%、山地 14.59%、台地 4.46% | 四类合计 100% |
| 气候 | 暖温带季风气候 | 雨热同季、一年两作 |

1. 地形以**山地丘陵为骨架**，但面积占比最大的是**平原（65.56%）**，这两句常被混成一句考：「骨架」讲结构，「占比」讲面积，务必分清。
2. 9 类地貌与四类占比是两组不同数字，前者是类型数，后者是面积构成。
3. 「暖温带季风气候」是固定表述，改成「温带大陆性季风气候」即错；「一年两作」是热量条件的落点。
4. 山东有「北方落叶果树的王国」「粮棉油之库，水果水产之乡」之称（省情常识 p2、p10），可与农业条目联动。

**【答题框架/落点】** 简答「山东地形地貌特征」按「地势大势 → 最高最低 → 9 类地貌 → 四类占比 → 气候」五层；数字题按上表填。

**【易混辨析】** 「山地丘陵为骨架」≠「山地面积最大」；「暖温带季风气候」≠「亚热带季风气候」；泰山 1545 米是**全省最高点**，不要与蒙山 1156 米、崂山 1132.7 米（S28）混淆。

**【真题锚点】** 命题角度：选择「山东面积占比最大的地貌类型是」，或填空「泰山主峰海拔＿＿米，为全省最高点」；日照工业学校 2023 选择含「教育法规和时政」，地理常识属同板块公共基础。

**【出处】** 省情常识 p6；省情汇总 p5。

### S04 · 总面积、人口与民族 ☆

**【必背原文】** 山东**总面积 15.8 万平方公里，约占中国总面积的 1.64%**；是**中国的经济第三大省、人口第二大省、中国温带水果之乡**，国内生产总值稳居全国第三名，约占中国 GDP 总量的 1/9。2022 年年末**常住人口 10162.79 万人，排名全国第二**；其中 0—14 岁人口占 17.86%，15—64 岁人口占 65.42%，65 岁及以上人口占 16.72%；全省城镇人口 6559.48 万人，**常住人口城镇化率 64.54%**。**山东省 56 个民族齐全**，主体民族为汉族，少数民族散居、杂居，其中**回族人口占比最大**。（省情常识 p2、p10；省情汇总 p2）

**【要点拆解】**

| 数字 | 对应考点 |
| --- | --- |
| 15.8 万平方公里 / 1.64% | 总面积、占全国比重 |
| 经济第三 / 人口第二 / GDP 约 1/9 | 三个「全国位次」 |
| 10162.79 万人（2022 年末） | 常住人口，全国第二 |
| 64.54% | 常住人口城镇化率 |
| 56 个民族齐全 | 民族构成，回族占比最大 |

1. 「经济第三大省、人口第二大省」是两句不同位次，题干常互换设错；GDP 约占全国 1/9 是配套比例。
2. 人口数据标注为「2022 年年末」，属资料包标注年份的统计值，答题须带年份，不可写成当年最新数据。
3. 三个年龄段占比（17.86%、65.42%、16.72%）与城镇化率 64.54% 是选择题数字库，按「少—中—老—城镇」四组记。
4. 「56 个民族齐全、回族占比最大」是民族状况的固定答案，注意不是「少数民族人口最多的省」。

**【答题框架/落点】** 数字题按上表填；简答「山东人口民族概况」按「总量与位次 → 年龄结构 → 城镇化 → 民族构成」四层，每个数字带资料包标注年份。

**【易混辨析】** 「人口第二大省」≠「面积第二大省」（山东面积约 15.8 万平方公里，临沂才是省内面积最大的市，见 S32）；「常住人口城镇化率」≠「户籍人口城镇化率」；回族是**少数民族中占比最大**，不是全省人口最多。

**【真题锚点】** 命题角度：选择「山东省常住人口居全国第几位」，或填空「山东省总面积约＿＿万平方公里」；济南幼儿师范高等专科学校 2024 选择含「济南市市情」，本条为市情背景数据。

**【出处】** 省情常识 p2、p10；省情汇总 p2。

### S09 · 建制沿革：「山东」从地理概念到行政专名 ★

**【必背原文】** 战国时称**崤山、函谷关或太行山以东**地区为「山东」或「关东」，这是广义上的山东；**秦朝统一后，「山东」一词开始有了广义和狭义之分**，狭义上的山东已与今天山东的地理范围大致相当。**「山东」一词作为行政区划名称，开始于金代**（金代改京东东路、京东西路为**山东东路、山东西路**，是历史上第一次把「山东」这个古老的地理区域作为行政区划名称）；金末设「山东行省」，后又设「东平行省」，为行省制度的开端。**清初设置山东省，「山东」才成为本省的专名**。（省情汇总 p1；省情常识 p4）

**【要点拆解】**

| 阶段 | 关键表述 |
| --- | --- |
| 战国 | 「山东／关东」＝崤山、函谷关或太行山以东，广义地理概念 |
| 秦统一后 | 分广义、狭义，狭义已接近今天山东范围 |
| 金代 | 设山东东路、山东西路，**首次成为行政区划名称** |
| 金末 | 「山东行省」「东平行省」，行省制度开端 |
| 清初 | 设置山东省，成为本省专名 |

1. 四个阶段对应四句不同判断，选择题最爱问「山东作为行政区划名称始于何时」，答案是**金代**，不是秦、不是清。
2. 元代沿袭行省制度，先后设东平行省、济南行省、山东淮南楚州行省、益都行省、山东行省等（省情常识 p4），属沿革细节，○ 档认得即可。
3. 明代设**山东布政使司，治济南府，此后济南一直为山东省会**；下辖 **6 府 15 州 89 县**，6 府为济南、东昌、兖州、青州、登州、莱州（省情常识 p5）。
4. 清代将地方一级政区一律改称省，除沿用明代 13 省外又新置 5 省，共 **18 省**（省情常识 p5）。

**【答题框架/落点】** 简答「「山东」名称的演变」按「战国广义 → 秦分广狭 → 金代行政区划 → 清初专名」四步；填空直接写「金代」「清初」。

**【易混辨析】** 「金代始作行政区划名称」≠「清初成为本省专名」；「广义山东」（太行山以东广大地区）≠「狭义山东」（今山东范围）；「山东行省」（金末）与「山东省」（清初）不是同一建制。

**【真题锚点】** 山东开放大学 2023 选择「礼已具备法的性质是在哪个朝代」属同类朝代辨析题；命题角度：选择「「山东」作为行政区划名称最早始于」，或填空「清初设置＿＿，山东才成为本省专名」。

**【出处】** 省情汇总 p1；省情常识 p2、p4、p5。

### S10 · 史前与先秦：沂源人、文化谱系与齐鲁建国 ★

**【必背原文】** 目前发现最早的山东人是**「沂源人」**，可以把山东的历史上推到**四五十万年以前**；沂源猿人化石是山东发现的年代最早的古人类化石，也是整个黄河中下游平原最早的古人类化石。山东石器时代文明包括**距今 8500 年—7500 年的后李文化、距今 7300 年—6100 年前的北辛文化、公元前 4300 年—前 2500 年的大汶口文化与龙山文化、公元前 1900—前 1600 年的岳石文化**。商朝建立以前，山东是商族活动的中心，商前期**五次迁都，有三次在山东境内**。周灭商后实行分封制，**公元前 11 世纪，周武王将大臣姜尚和胞弟周公旦分封在这里，建立了齐、鲁两个大国**。（省情常识 p2；省情汇总 p1）

**【要点拆解】**

| 序列 | 文化／事件 | 时间 |
| --- | --- | --- |
| 1 | 沂源人 | 四五十万年前 |
| 2 | 后李文化 | 距今 8500—7500 年 |
| 3 | 北辛文化 | 距今 7300—6100 年 |
| 4 | 大汶口文化、龙山文化 | 公元前 4300—前 2500 年 |
| 5 | 岳石文化 | 公元前 1900—前 1600 年 |

1. 文化谱系是「后李 → 北辛 → 大汶口 → 龙山 → 岳石」一脉相承，省情常识 p17 明确其为「在文化传统演变上一脉相承又相对独立的文化谱系」。
2. **龙山文化**因 1928 年首次发现于济南东郊龙山镇（章丘龙山镇城子崖）而得名，以**磨光黑陶**为特征（省情常识 p24、省情汇总 p14），是「山东之最」常考点。
3. 先秦两件大事：**公元前 594 年鲁国「初税亩」**，表明鲁国已出现封建生产关系的萌芽；**公元前 481 年齐国田常杀齐简公「专齐之政」**，齐国成为当时中国最早出现的一个封建大国；秦灭六国时**齐国是最后被灭的一个诸侯国**（省情常识 p3）。
4. 齐国定都临淄，「通商工之业，便鱼盐之利」，有「冠带衣履天下」之誉；鲁国都于曲阜，为「礼仪之邦」（省情常识 p3）。

**【答题框架/落点】** 简答「山东史前文化谱系」按上表五个文化依次写；选择「齐鲁建国于何时、分封者是谁」写公元前 11 世纪、周武王分封姜尚（齐）与周公旦（鲁）。

**【易混辨析】** 「沂源人」是**最早的山东人**（四五十万年前），不要与「龙山文化」（新石器时代晚期）混成同一时期；「初税亩」（鲁国，前 594）与「田常专齐之政」（齐国，前 481）是两件不同事件；「齐国最后被灭」指秦灭六国顺序，不是春秋争霸顺序。

**【真题锚点】** 济南工程职业技术学院 2023 选择「得天下英才而教育之三乐也出自《孟子》」「黄炎培中华职业学校校训敬业乐群」属同板块文化常识；命题角度：填空「山东石器时代文明中距今 8500—7500 年的是＿＿文化」。

**【出处】** 省情常识 p2、p3、p17、p24；省情汇总 p1、p14。

### S11 · 秦汉至明清沿革要点 ☆

**【必背原文】** 秦并天下分天下为 **36 郡**，其中在山东地区设置**齐郡、东郡、薛郡、琅邪郡**；汉武帝**元封五年（公元前 106 年）**划分天下为**十三州**，其中在山东地区设置北部的**青州**和南部的**兖州、徐州**，一直延续到西晋时期。山东素有**「膏壤千里」**的美誉，秦汉以来成为中国的经济中心，是汉代**「丝绸之路」的重要源头**，**临淄、定陶、亢父（今济宁）是全国三大纺织中心**。明代山东布政使司下辖 **6 府 15 州 89 县**；**洪武二十六年（1393 年）**山东耕地面积 7240 余万亩，是北宋时期的 2.4 倍，居全国第三位；**1421 年永乐皇帝迁都北京**以后，京杭大运河沿线的济宁和临清因漕运而繁荣。（省情常识 p3、p5）

### S12 · 近现代沿革：开埠、五四、解放与平原省 ○

**【必背原文】** **1860 年代，烟台成为山东第一个开放口岸**；**1895 年**甲午战争中日军攻占威海，北洋海军全军覆没；**1898 年**青岛和威海分别租借给德国和英国，德国修筑**胶济铁路（1905 年）**与**津浦铁路北段（1911 年）**；**1914 年**日军从德国手中夺取青岛，**1922 年华盛顿会议后归还中国**；**1928 年**山东省撤销道这一级，省直辖 107 个县；**1930 年**国民政府从英国手中收回威海。五四运动以后山东成立早期共产主义小组，**1921 年王尽美、邓恩铭参加中国共产党第一次全国代表大会**，山东成为全国建党最早的省份之一。**1949 年 6 月 2 日**解放军进驻青岛，**1949 年 8 月 18 日长山列岛解放，山东省至此全部解放**。（省情常识 p5、p20）

### S13 · 孔子：儒家学派创始人与世界十大文化名人之首 ★

**【必背原文】** **孔子（公元前 551 年—公元前 479 年），名丘，字仲尼，春秋末年鲁国（今曲阜）人**，是我国古代伟大的思想家、教育家，**儒家学派的创始人，被列为「世界十大文化名人」之首**。孔子开创了私人讲学的风气，被后世尊为「文圣」「至圣」「至圣先师」「万世师表」；曾受业于老子，带领部分弟子**周游列国十四年**，晚年修订**六经，即《诗》《书》《礼》《乐》《易》《春秋》**。其弟子及再传弟子把孔子及其弟子的言行语录和思想记录整理成儒家经典**《论语》**。（省情汇总 p1；省情常识 p17、p29）

**【要点拆解】**

| 项目 | 原文落点 |
| --- | --- |
| 生卒 | 前 551—前 479（省情常识 p17 具体到 9 月 28 日—4 月 11 日） |
| 籍贯 | 春秋末年鲁国陬邑（今山东曲阜） |
| 身份 | 思想家、教育家、儒家学派创始人 |
| 尊号 | 文圣、至圣、万世师表、世界十大文化名人之首 |
| 著述 | 修订六经；言行辑为《论语》 |

1. 「**开创私人讲学风气**」是孔子在教育史上的核心贡献，与「学在官府」相对，教育类简答题常考。
2. 六经是《诗》《书》《礼》《乐》《易》《春秋》，**《论语》不是孔子亲著**，是弟子及再传弟子记录的言行汇编，选择题常在此设错。
3. 省情常识 p29 另记孔子哲学思想提倡「仁义」「礼乐」「德治教化」「君以民为体」，可作论述引用。
4. 曲阜「三孔」（孔府、孔庙、孔林）为世界文化遗产（S27），与孔子条目联动。

**【答题框架/落点】** 简答「孔子的教育贡献」按「开创私人讲学 → 有教无类、因材施教（省情常识 p18 教育理念语境）→ 修订六经 → 《论语》与儒家传承 → 世界影响」五层；填空直接写生卒、籍贯、尊号。

**【易混辨析】** 孔子是**儒家**创始人，墨子是**墨家**创始人（S15），二者并称先秦「显学」；「至圣」是孔子，「亚圣」是孟子（S14），「复圣」是颜回，「宗圣」是曾子；「六经」不含《论语》。

**【真题锚点】** 日照工业学校 2023 判断「孔子教育思想」为原题；济南工程职业技术学院 2023 选择「得天下英才而教育之三乐也出自《孟子》」属同板块；命题角度：填空「孔子被列为＿＿之首」。

**【出处】** 省情汇总 p1；省情常识 p17、p18、p29。

### S14 · 孟子、曾子与「孔孟」「宗圣」★

**【必背原文】** **孟子（约公元前 372 年—前 289 年），名轲，邹国（今邹城）人**，提出**「民为贵，社稷次之，君为轻」**，主张实行**「仁政」**，提倡**「富贵不能淫，贫贱不能移，威武不能屈」**；继承并发展了孔子的学说，因此被称为**「亚圣」**，后人把孔子与孟子并称为**「孔孟」**。孟子把道德规范概括为**仁、义、礼、智**，把人伦关系概括为**「父子有亲，君臣有义，夫妇有别，长幼有序，朋友有信」**五伦，其**「性善论」**与荀子的「性恶论」相对。**曾子（前 505—前 435），名参，字子舆，春秋末年鲁国南武城人（今山东嘉祥）**，主张以孝恕忠信为核心的儒家思想，著《大学》《孝经》《曾子十篇》，被后世尊奉为**「宗圣」**。（省情汇总 p2；省情常识 p18、p19）

**【要点拆解】**

| 人物 | 籍贯 | 核心主张／尊号 |
| --- | --- | --- |
| 孟子 | 邹国（今邹城） | 民贵君轻、仁政、性善论、亚圣 |
| 曾子 | 鲁国南武城（今嘉祥） | 孝恕忠信、慎独、宗圣、《大学》《孝经》 |
| 颜回 | 曲阜（省情常识 p29） | 复圣，孔子得意弟子 |

1. 「民为贵，社稷次之，君为轻」是孟子最著名的命题，凡「儒家民本思想」简答必引。
2. 孟子代表作《孟子》属**语录体散文集**，由孟子及其弟子共同编写完成；常考篇目《鱼我所欲也》《得道多助，失道寡助》《生于忧患，死于安乐》《寡人之于国也》（省情常识 p18）。
3. 「四德」仁义礼智与「五伦」是两组不同清单，四德中以仁义最为重要，基础是孝、悌。
4. **「慎独」**出自曾子「内省、慎独的修养观」（省情常识 p19），与《师德与教育法规知识点讲义》E09「教师职业道德修养·慎独」是同一概念，可跨篇作答。

**【答题框架/落点】** 简答「孟子的教育／政治思想」按「民贵君轻 → 仁政 → 性善论 → 四德五伦 → 亚圣与孔孟」五层；论述「齐鲁文化中的师德资源」可把曾子慎独接到教师职业道德修养（E09）。

**【易混辨析】** 「亚圣」是孟子，「复圣」是颜回，「宗圣」是曾子，「至圣」是孔子，四个尊号不能互换；「性善论」（孟子）与「性恶论」（荀子）相对；「邹国（今邹城）」不是「鲁国（今曲阜）」。

**【真题锚点】** 日照工业学校 2023 判断「孔子教育思想」；济南工程职业技术学院 2023 选择「得天下英才而教育之三乐也出自《孟子》」为原题；命题角度：填空「提出民为贵、社稷次之、君为轻的是＿＿」。

**【出处】** 省情汇总 p2；省情常识 p18、p19、p29。

### S15 · 墨子、鲁班、孙武孙膑、扁鹊 ★

**【必背原文】** **墨子**是战国初期鲁国出现的杰出平民思想家，反对掠夺战争，主张**「兼爱」「非攻」**，提倡节俭、反对浪费，所创**墨家学派**与儒家并称**「显学」**（省情汇总 p2）；墨子是中国历史上唯一一个农民出身的哲学家，提出「兼爱」「非攻」「尚贤」「尚同」「天志」「明鬼」「非命」「非乐」「节葬」「节用」等观点，以兼爱为核心、以节用尚贤为支点（省情常识 p18）。**鲁班**，本姓公输，名般，春秋战国之际著名能工巧匠和发明家，因是鲁国人、「般」与「班」同音而称鲁班，成为中国古代能工巧匠的代表。**孙武**著**《孙子兵法》十三篇**，被誉为「兵学圣典」，置于《武经七书》之首；**孙膑**为孙武后人，兵家代表人物，著**《孙膑兵法》**，**1972 年在临沂银雀山汉墓中发现该书竹简**。**扁鹊**，姓秦名越人，齐国卢（今长清西南）人，最早提出**「望、闻、问、切」**诊断方法，创造脉学理论，医学著作**《难经》**为中医四大经典之一。（省情汇总 p2、p3；省情常识 p19）

**【要点拆解】**

| 人物 | 核心标签 | 易考点 |
| --- | --- | --- |
| 墨子 | 兼爱、非攻、显学、平民思想家 | 与儒家并称显学 |
| 鲁班 | 公输般、能工巧匠代表 | 与「班墨学院」品牌呼应（S48） |
| 孙武 | 《孙子兵法》十三篇、兵学圣典 | 兵圣、百世兵家之师 |
| 孙膑 | 《孙膑兵法》、1972 银雀山汉墓竹简 | 田忌赛马 |
| 扁鹊 | 望闻问切、《难经》、切脉治病先驱 | 反对「信巫不信医」 |

1. 「班墨学院」之名即合**鲁班（班）与墨子（墨）**两位山东工匠／思想家，是山东省职教出海国际品牌（S48），本条为其文化来源。
2. 「1972 年临沂银雀山汉墓竹简」是《孙膑兵法》重见天日的标志性事件，属数字＋地点双考点。
3. 扁鹊强调**疾病以预防为主**，反对「信巫不信医」，可作健康教育类论述素材。
4. 孙武故里有东营广饶说（省情常识 p27「东营是古代大军事家孙武的故里」），与 S33 山东之最联动。

**【答题框架/落点】** 连线题按上表一一对应；简答「齐鲁科技与工匠传统」按「鲁班（巧匠）→ 墨子（《墨经》科技思想）→ 扁鹊（医学）→ 孙武孙膑（兵学）」四层，可升华到「大国工匠、能工巧匠」（E53）。

**【易混辨析】** 孙武著《孙子兵法》、孙膑著《孙膑兵法》，二者不是同一人、同一书；「显学」指墨家与儒家并称，不含道家；「望闻问切」是扁鹊四诊法，不要与《难经》书名混答。

**【真题锚点】** 济南工程职业技术学院 2023 选择「中医望闻问切摸脉是动脉」为原题；命题角度：填空「1972 年在临沂＿＿汉墓发现《孙膑兵法》竹简」，或选择「主张兼爱非攻的是」。

**【出处】** 省情汇总 p2、p3；省情常识 p18、p19、p27。

### S16 · 管仲、齐桓公、晏婴、范蠡与稷下学宫 ☆

**【必背原文】** **管仲**改革使齐国一跃成为当时最强盛的国家，为**齐桓公**的霸业奠定基础，被誉为**「法家先驱」「圣人之师」「华夏第一相」**；「管鲍之交」出其事迹，**「仓廪实而知礼节，衣食足而知荣辱」**出自《管子》。姜尚封齐后采取**「通工商之业，便鱼盐之利」**政策，鼓励发展工商业。**「陶朱公」范蠡**，春秋后期山东出现的成功商人代表，本名范蠡，曾辅佐越王勾践灭吴，后弃官经商，司马迁《史记·货殖列传》称其**「十九年之中，三致千金」**，「陶朱公」成为巨商大贾的代名词；范蠡助越灭吴后辗转至陶（曹国陶丘，「天下之中」）定居经商，被后人尊为**「商祖」**。战国时期齐国还创建了**世界上第一所官方举办、私家主持的高等学府——稷下学宫**。（省情汇总 p2；省情常识 p2、p3）

**【要点拆解】**

| 人物／机构 | 标签 |
| --- | --- |
| 管仲 | 法家先驱、圣人之师、华夏第一相；仓廪实而知礼节 |
| 齐桓公 | 春秋五霸之首、春秋第一霸主 |
| 晏婴、鲍叔牙 | 齐国名臣，管鲍之交 |
| 范蠡（陶朱公） | 三致千金、商祖、陶丘「天下之中」 |
| 稷下学宫 | 世界第一所官方举办、私家主持的高等学府 |

1. 「稷下学宫」的定语「**官方举办、私家主持**」是必背关键词，漏一个字即失分；它常被称作世界最早的高等学府／官办智库，可作教育史论述素材。
2. 「通工商之业，便鱼盐之利」是齐国经济政策原文，与鲁国「礼仪之邦」形成齐鲁文化对照。
3. 「仓廪实而知礼节，衣食足而知荣辱」可作「经济基础与道德建设」论述引句，与《新时代职业道德建设实施纲要》（E19）联动。
4. 齐国「冠带衣履天下」、曹国陶丘「天下之中」，与 S11 三大纺织中心、S08 运河商埠共同构成山东重商传统。

**【答题框架/落点】** 连线题按上表；简答「齐国为何能称霸」按「姜尚通商工之业 → 管仲改革 → 齐桓公霸业 → 稷下学宫聚贤」四层；论述「齐鲁文化的经济与教育传统」可引稷下学宫。

**【易混辨析】** 「春秋五霸之首／春秋第一霸主」是齐桓公，不是齐国最后被灭（那是战国末）；「商祖」是范蠡，「华夏第一相」是管仲；稷下学宫是**齐国**创建，不是鲁国，也不是孔子创办的私学。

**【真题锚点】** 命题角度：填空「世界上第一所官方举办、私家主持的高等学府是＿＿」，或选择「仓廪实而知礼节出自」；山东商业职业技术学院 2023 校名含「商业」，可作校情类论述背景，不作事实引用。

**【出处】** 省情汇总 p2；省情常识 p2、p3。

### S17 · 文学艺术与科技名人速查表 ☆

**【必背原文】** 资料包《山东省情省况汇总》第二节「齐鲁名人」与《山东省情省况常识考点》第七节「文化状况」收录下列人物与成果：**贾思勰**（山东青州人，北魏末期）著**《齐民要术》，中国现存最早的一部完整的农书，被誉为「中国古代农业百科全书」**；**王叔和**（高平，今邹城）著**《脉经》，我国医学史上第一部脉学专著**；**刘勰**（南朝）著**《文心雕龙》，我国第一部系统的文学批评理论专著**；**王羲之**（琅琊临沂人）被尊**「书圣」**，行书**《兰亭序》**为「天下第一行书」；**展子虔**（隋，渤海今阳信西南）**《游春图》**是迄今我国保存最早的山水画；**颜真卿**（唐，祖籍琅琊临沂）行书**《祭侄文稿》**为「天下第二行书」；**钱乙**（北宋，东平人）**《小儿药证直诀》**，被尊**「儿科医圣」**；**张择端**（北宋，琅琊东武今诸城）**《清明上河图》**（全长 552 厘米、宽 25.5 厘米）；**李清照**（济南人，号易安居士，婉约派代表）与**辛弃疾**（济南历城人，号稼轩，豪放派，与苏轼并称「苏辛」）合称**「济南二安」**；**蒲松龄**（淄川人，号柳泉居士）著文言短篇小说集**《聊斋志异》**；**孔尚任**（曲阜人，孔子第 64 代孙）著**《桃花扇》**，与《长生殿》作者洪昇并称**「南洪北孔」**；**王懿荣**（清代烟台人）为**甲骨文之父**。（省情汇总 p3、p4；省情常识 p19）

**【要点拆解】**

| 类别 | 人物 · 成果 · 称号 |
| --- | --- |
| 农学 | 氾胜之《氾胜之书》；贾思勰《齐民要术》；王祯《农书》 |
| 医学 | 王叔和《脉经》；钱乙《小儿药证直诀》儿科医圣；扁鹊《难经》 |
| 文论书画 | 刘勰《文心雕龙》；王羲之《兰亭序》；展子虔《游春图》；颜真卿《祭侄文稿》；张择端《清明上河图》 |
| 文学 | 李清照、辛弃疾「济南二安」；蒲松龄《聊斋志异》；孔尚任《桃花扇》；王士祯「一代诗坛盟主」；张养浩《山坡羊·潼关怀古》 |
| 文字 | 王懿荣，甲骨文之父 |

1. 「最」字系列最易考：《齐民要术》**中国现存最早最完整农书**、《脉经》**第一部脉学专著**、《文心雕龙》**第一部系统文学批评理论专著**、《游春图》**最早山水画**、《兰亭序》**天下第一行书**、《祭侄文稿》**天下第二行书**。
2. 「济南二安」＝李清照（易安）＋辛弃疾（幼安），因二人字号皆带「安」且均为济南人，选择题常问「二安指谁」。
3. 中国古代**四大农书**：《氾胜之书》、贾思勰《齐民要术》、王祯《农书》、徐光启《农政全书》（省情常识 p34），其中前三部作者均为山东人。
4. 本条 ☆ 档：按「人—书—称号」三元组记忆即可，不展开文学赏析。

**【答题框架/落点】** 连线题按表对应；简答「山东古代科技文化贡献」按「农学 → 医学 → 文论书画 → 文学」四类各举一例。

**【易混辨析】** 「天下第一行书」《兰亭序》（王羲之）≠「天下第二行书」《祭侄文稿》（颜真卿）；「孔孟」是孔子孟子，「南洪北孔」的「孔」是孔尚任；「济南二安」不含王士祯；甲骨文之父是王懿荣，不是刘鹗。

**【真题锚点】** 山东开放大学 2023 选择「六艺包括以下哪几个」属同类文化常识；命题角度：选择「《齐民要术》的作者是」，或填空「『济南二安』指＿＿和＿＿」。

**【出处】** 省情汇总 p3、p4；省情常识 p19、p34。

### S18 · 稷下学宫与齐鲁文化谱系（论述升华句）☆

**【必背原文】** 齐鲁文化的渊源应追溯到距今 5000 年以前聚居在齐鲁之地的古老民族**东夷族**；在齐鲁之地上，不仅存在着从 **8000 年前的后李文化到北辛、大汶口文化，再到龙山文化直至距今 4000 年左右的岳石文化**这样一个在文化传统演变上**一脉相承又相对独立**的文化谱系，而且发现了距今 5000 年左右众多的城堡遗址和图像文字、陶文以及蛋壳黑陶。战国时期**儒学实际上已经占据了鲁国、齐国两个国家，实现了儒学齐鲁化**；秦汉时期董仲舒吸收齐国和鲁国的新思想形成新儒学体系，儒学从此由**「齐鲁之学」发展到「独尊儒术」**。山东是**儒家文化发源地**，儒家思想创立人有济宁曲阜的孔子、济宁邹城的孟子，墨家思想创始人枣庄滕州的墨子、军事家孙子等；**战国时期齐国创建了世界上第一所官方举办、私家主持的高等学府——稷下学宫**。（省情常识 p17、p2；省情汇总 p1）

**【要点拆解】**

| 层 | 内容 |
| --- | --- |
| 族源 | 东夷族，距今 5000 年以前 |
| 文化谱系 | 后李 → 北辛 → 大汶口 → 龙山 → 岳石，一脉相承又相对独立 |
| 思想 | 儒学齐鲁化 → 董仲舒新儒学 → 独尊儒术 |
| 教育 | 稷下学宫，世界第一所官方举办、私家主持的高等学府 |
| 发源地 | 儒家文化发源地；孔孟墨孙皆出齐鲁 |

1. 本条主要用途是**论述题的升华段**：从「齐鲁文化发源地」接到「教育家精神」（E21—E23）、「立德树人」（E53），形成地方文化＋教师使命的答题链。
2. 「一脉相承又相对独立」是文化谱系的固定评价，不可改成「完全独立」或「外来传入」。
3. 「儒学齐鲁化 → 齐鲁之学 → 独尊儒术」是三步演进，人物是董仲舒，选择题常问「谁把儒学推向独尊」。
4. 山东素称**「一山一水一圣人」**（S29）、「礼仪之邦」、「孔孟之乡」，三句都是文化定位句，可互换作开头。

**【答题框架/落点】** 论述「结合齐鲁文化谈高职教师的文化使命」按「文化谱系 → 儒家发源地与稷下学宫 → 尊师重教传统 → 教育家精神与立德树人 → 落到山东高职教师」五层；选择、填空按上表关键词。

**【易混辨析】** 「东夷族」是族源，不是「龙山文化」；「稷下学宫」是官办私持的高等学府，不是孔子私学；「儒学齐鲁化」在战国，「独尊儒术」在秦汉，两个阶段不可合并。

**【真题锚点】** 济南幼儿师范高等专科学校 2024 选择含「济南市市情」；日照工业学校 2023 判断「孔子教育思想」；命题角度：论述「齐鲁文化中的尊师重教传统对新时代教师的启示」。

**【出处】** 省情常识 p2、p17；省情汇总 p1。

## 第四部分 · 经济、产业与科技教育（S19—S26）

省情经济题几乎全是数字题，而数字必须带**资料包标注的年份**：资料包给出的最新经济总量是 **2022 年**的统计值，2025 年省政府工作报告数据未收录。本部分把「有哪些数字、这些数字出自哪一年、哪些数字根本没有」一次说清。

### S19 · 经济总体：全国第三、约占 1/9 与 2022 年 GDP ★

**【必背原文】** 山东是**中国经济最发达的省份之一、经济实力最强的省份之一**，**2007 年以来经济总量稳居全国第三位（次于广东、江苏）**；**2022 年，全省实现地区生产总值 87435.1 亿元，按不变价格计算，比上年增长 3.9%**。资料包《山东省情省况常识考点》第一节另记：山东省是**中国的经济第三大省、人口第二大省、中国温带水果之乡**，国内生产总值稳居全国第三名，**约占中国 GDP 总量的 1/9**。（省情常识 p13、p2）

**【要点拆解】**

| 数字 | 含义 | 年份／口径 |
| --- | --- | --- |
| 全国第三 | 经济总量位次，次于广东、江苏 | 2007 年以来 |
| 87435.1 亿元 | 全省地区生产总值 | 2022 年 |
| 3.9% | 按不变价格计算比上年增长 | 2022 年 |
| 约 1/9 | 占中国 GDP 总量比重 | 资料包标注口径 |

1. 「稳居全国第三」与「约占全国 1/9」是同一地位的两面表述，都属资料包原文，论述题可连用。
2. **87435.1 亿元必须带「2022 年」**，写成「2025 年 GDP」即与资料包不符；「按不变价格计算」也不能漏，增长率口径是「不变价」。
3. 「经济第三大省、人口第二大省」两句位次不同，选择题常互换设错（见 S04）。
4. 本条与 S20 农业「农业增加值长期稳居中国各省第一位」、S21 工业「总产值及增加值居各省前三位」共同构成山东经济地位的三句判断。

**【答题框架/落点】** 数字题按上表填并带年份；简答「山东经济地位」按「总量位次 → 占全国比重 → 农业位次 → 工业位次」四句写。

**【易混辨析】** 「地区生产总值 87435.1 亿元」是 2022 年值，不是资料包标注为 2025 年的数据；「增长 3.9%」是**不变价**增速，不是名义增速；「经济第三」与「人口第二」不冲突，一个是经济、一个是人口。

**【真题锚点】** 济南幼儿师范高等专科学校 2024 选择含「济南市市情」；命题角度：填空「2022 年山东省实现地区生产总值＿＿亿元」，或选择「山东省经济总量稳居全国第几位」。

**【出处】** 省情常识 p2、p13。

### S20 · 农业：「粮棉油之库、水果水产之乡」与十强产业 ☆

**【必背原文】** 山东**耕地率属全国最高省份，是中国的农业大省，农业增加值长期稳居中国各省第一位**；素有**「粮棉油之库」「水果水产之乡」**之称。粮食作物种植分夏、秋两季：夏粮主要是**冬小麦**，秋粮主要是玉米、地瓜、大豆、水稻、谷子、高粱和小杂粮；**小麦、玉米、地瓜是山东的三大主要粮食作物**，**花生是重要的油料作物**。山东有「**北方落叶果树的王国**」之称，各种果树 90 种、分属 16 科 34 属；烟台苹果、莱阳梨、肥城桃、乐陵金丝小枣、枣庄石榴、大泽山葡萄以及章丘大葱、莱芜生姜、潍坊萝卜等是久负盛名的特产。资料包《山东省情省况常识考点》p13 另列「**十强产业**」词目，但未在已核对页给出完整清单，**具体十强产业名称需回查资料原文，本文不作补写**。（省情常识 p13、p10；省情汇总 p5）

**【要点拆解】**

| 项目 | 原文落点 |
| --- | --- |
| 农业位次 | 耕地率全国最高，农业增加值长期稳居各省第一 |
| 称号 | 粮棉油之库、水果水产之乡、北方落叶果树王国 |
| 三大粮食作物 | 小麦、玉米、地瓜 |
| 油料作物 | 花生 |
| 生物资源 | 植物 3100 余种、野生经济植物 645 种、树木 600 多种 |

1. 「农业增加值第一」与「经济总量第三」是不同指标，选择题常把两者混成一句问「山东 agricultural 居第几」。
2. 三大粮食作物是**小麦、玉米、地瓜**，不含水稻、大豆；花生是油料作物，不在三大粮食之列。
3. 「十强产业」词目出现在 p13，但资料包本页未列完整清单，按「不凭空发明」原则只记词目、不补名称；若考题涉及具体清单，需回查原文或另行补充。

**【答题框架/落点】** 简答「山东农业概况」按「位次 → 两个称号 → 三大粮食作物与油料 → 果树与特产」四层；数字题按上表填。

### S21 · 工业、「群象经济」与山东品牌 ☆

**【必背原文】** 山东工业发达，**工业总产值及工业增加值居中国各省前三位**，特别是大型企业较多，号称**「群象经济」**；由于山东是中国重要的粮棉油肉蛋奶产地，轻工业特别是**纺织和食品工业**相当发达；重工业企业发展迅速，重点工矿业企业有**齐鲁石化、山东电力、山东钢铁、山东海化、胜利油田、兖矿集团、中国铝业山东铝厂、南山集团、晨鸣纸业**等。山东省著名品牌有**海尔、张裕、齐鲁石化、青岛啤酒、海信、双星、澳柯玛、鲁能、浪潮、中国重汽、山东黄金、歌尔声学、万华、如意、太阳纸业、金锣**等。战国时齐国即号称「冠带衣履天下」，**临淄、定陶、亢父（今济宁）是汉代三大纺织中心**（见 S11）。（省情常识 p13、p3；省情汇总 p2）

**【要点拆解】**

| 类别 | 代表 |
| --- | --- |
| 经济形态 | 群象经济（大型企业多） |
| 轻工业 | 纺织、食品 |
| 重工矿 | 齐鲁石化、胜利油田、兖矿集团、山东钢铁、山东海化 |
| 消费品牌 | 海尔、海信、青岛啤酒、张裕、澳柯玛、双星 |
| 装备与材料 | 中国重汽、浪潮、山东黄金、万华、太阳纸业 |

1. 「群象经济」是山东工业结构的专有概括，与「中小企业为主」的省份形成对照，选择题常问「群象经济指什么」。
2. 汉代三大纺织中心（临淄、定陶、亢父）与现代纺织食品工业构成历史—现实呼应，可作论述素材。
3. 品牌清单属 ○ 档：认得「海尔、海信、青岛啤酒、张裕、浪潮、中国重汽」等为山东品牌即可，不要求全默。
4. 青岛另有「中国品牌之都」「世界啤酒之城」「中国帆船之都」之称（省情常识 p25），与品牌条目联动。

**【答题框架/落点】** 简答「山东工业特征」按「总产值位次 → 群象经济 → 轻重工业结构 → 代表企业与品牌」四层；选择题按上表归类。

**【易混辨析】** 「群象经济」讲企业规模结构，不是「产业集群」；「工业总产值前三位」与「经济总量第三位」是不同指标；「张裕」是葡萄酒品牌（烟台，1894 年开办，见 S33），不是啤酒品牌。

**【真题锚点】** 东营职业学院 2023 材料「农业产业学院建设意义」可延伸到产教融合与山东产业；命题角度：选择「下列不属于山东著名品牌的是」，或填空「山东大型企业较多，号称＿＿经济」。

**【出处】** 省情常识 p3、p13、p25；省情汇总 p2。

### S25 · 交通、资源与「山东之最」数字族 ○

**【必背原文】** 山东**世界遗产 4 处**：**泰山、曲阜「三孔」（文化遗产）、齐长城、京杭大运河（山东段）**。**国家 5A 级景区**包括崂山风景区、刘公岛、龙口南山景区、蓬莱阁、台儿庄、泰山、趵突泉、蒙山景区、曲阜三孔、潍坊青州古城、威海华夏城、东营黄河口生态旅游区、临沂萤火虫水洞·地下大峡谷旅游区、济宁市微山湖旅游区、青岛市奥帆海洋文化旅游区。**鲁菜**：起源于淄博市博山区，是中国传统八大菜系中**唯一的自发型菜系**，历史最悠久、技法最丰富、难度最高、最见功力。

### S27 · 黄河流域生态保护和高质量发展战略 ☆

**【必背原文】** 资料包在省情与职教政策中把黄河战略列为山东重大国家战略之一，与「新旧动能转换、海洋强省、乡村振兴」并列；职教必背 p87 将职业教育与黄河流域高质量发展相衔接。

**【要点拆解】**
1. 战略定位：生态优先、绿色发展，统筹生态保护与高质量发展。
2. 山东角色：黄河入海口在东营，东营黄河口生态旅游区为 5A 景区（见 S26）。
3. 职教落点：沿黄地区产业转型需要技术技能人才，高职专业设置可对接绿色低碳、现代农业、高端化工。

### S41 · 《山东省职业教育条例》总览与施行日期 ★★★

**【必背原文】** 资料包收录的《山东省职业教育条例》为**山东省地方性法规**，**2024 年 5 月 1 日起施行**（资料包标注）。第一条立法目的：「为了推动职业教育高质量发展，提高劳动者素质和技术技能水平，促进就业创业，建设教育强省、人力资源强省和技能型社会，推进新时代社会主义现代化强省建设，根据《中华人民共和国职业教育法》等法律、行政法规，结合本省实际，制定本条例」。第三条：「职业教育必须坚持中国共产党的领导，坚持社会主义办学方向，贯彻国家的教育方针，坚持立德树人、德技并修，坚持产教融合、校企合作，坚持面向市场、促进就业，坚持面向实践、强化能力……」

**【要点拆解】**
1. 性质：地方性法规（省人大及其常委会制定），效力低于法律、行政法规，高于省政府规章。
2. 施行：2024.5.1——与上位法《职业教育法》（2022.5.1 修订施行）相差近两年，是两个不同的时间点。
3. 立法目的关键词：高质量发展、劳动者素质、技术技能水平、就业创业、教育强省、人力资源强省、技能型社会。
4. 第三条「六个坚持」：党的领导、社会主义办学方向、教育方针、立德树人德技并修、产教融合校企合作、面向市场促进就业、面向实践强化能力。

**【答题框架/落点】**：问「《山东省职业教育条例》何时施行」答 2024.5.1；问「立法目的」按第一条关键词串写；简答「职业教育坚持哪些原则」按第三条逐条写。

**【易混辨析】**：**《职业教育法》（国家法律，2022.5.1）vs《山东省职业教育条例》（地方性法规，2024.5.1）**——层级与日期都不同，是必考配对；**地方性法规（省人大）vs 地方政府规章（省政府）**——制定机关不同，效力不同。

**【真题锚点】** 滨州职院 2024 考「职业教育法」相关；命题角度：选择「山东省职业教育条例施行时间」。

### S42 · 条例：体系构成、政府职责与办学主体 ★★

**【必背原文】** 第十二条「职业教育包括**职业学校教育和职业培训**」。第十三条「**中等职业学校教育是现代职业教育体系的基础**，由高级中等教育层次的中等职业学校（含技工学校）实施，培养技术技能人才，并为高等教育输送具有扎实技术技能基础和合格文化基础的生源」。第十五条要求县级以上人民政府制定职业教育发展专项规划，建立健全「政府统筹、行业企业积极举办、社会力量深度参与」的格局。第十六条「鼓励支持企业发挥重要办学主体作用」。

**【要点拆解】**
1. 两类：职业学校教育 + 职业培训。
2. 基础地位：中等职业学校教育是现代职教体系的基础（不是高等职教）。
3. 政府职责：统筹规划、专项规划、行业企业参与。
4. 企业定位：「重要办学主体」——不是「辅助力量」。

**【答题框架/落点】**：简答「山东条例如何界定职业教育范围」答两类；论述「如何破解校热企冷」引第十六条「企业是重要办学主体」+ S31 的四要素激励。

**【易混辨析】**：**中等职教（体系基础）vs 高等职教（主体层次）**——条例明确中等是基础；**职业学校教育 vs 职业培训**——学历教育与非学历培训两类。

**【真题锚点】** 命题角度：选择「现代职业教育体系的基础」答中等职业学校教育。

**【出处】** 职教条例 p3—4。

### S43 · 条例：贯通培养、横向融通与考试招生 ★★

**【必背原文】** 第十九条：「推动不同层次职业教育**纵向贯通**，构建**中等职业教育、专科层次职业教育、本科层次职业教育、专业学位研究生教育相衔接**的人才培养体系」。第二十条：「推动不同类型教育**横向融通**，推动中等职业学校与普通高级中学、高等职业学校与应用型普通本科高等学校**课程互选、资源共享、学习成果互认**」。第二十一条：「完善**文化素质与职业技能相结合**的职业教育考试招生制度，科学确定职业技能考试成绩在录取中所占权重」。第十八条：符合条件的中等职业学校可与专科层次高职合作实施专科层次职业教育。

**【要点拆解】**
1. 纵向贯通四层：中职→专科→本科→专业学位研究生。
2. 横向融通两条线：中职↔普高、高职↔应用型本科；三个机制：课程互选、资源共享、学习成果互认。
3. 职教高考：文化素质 + 职业技能，技能成绩占一定权重。

**【答题框架/落点】**：简答「山东条例如何构建现代职教体系」按纵向贯通 + 横向融通 + 考试招生三段写；论述可接「职教高考打通升学通道」。

**【易混辨析】**：**纵向贯通（层次衔接）vs 横向融通（类型融通）**——一个上下、一个左右；**「专业学位研究生教育」是贯通体系的一环，别漏写**。

**【真题锚点】** 滨州职院 2024「一体两翼五重点」与体系建设相关；命题角度：多选「纵向贯通包括哪些层次」。

**【出处】** 职教条例 p4—5。

### S44 · 条例：专业设置、终身培训与学徒制 ★★

**【必背原文】** 第二十三条：省教育行政部门会同有关部门引导职业学校「根据国家规定，按照市场需求、就业形势设置并**动态调整专业**」，组织制定具有地方特色的专业教学指导方案、课程标准、岗位实习标准。第二十四条：建立面向全体劳动者的**终身职业技能培训制度**，开展普惠性、均等化的职业技能培训服务。第二十五条：企业承担职工职业培训主体责任，按规定提取和使用职工教育经费。第二十六条：「推行**中国特色学徒制**，支持企业设立学徒岗位，与职业学校、职业培训机构开展合作，对新招用职工、在岗职工和转岗职工进行学徒培训。」

**【要点拆解】**
1. 专业设置依据：市场需求 + 就业形势，动态调整。
2. 三层标准：专业教学指导方案、课程标准、岗位实习标准（地方特色）。
3. 培训制度：终身职业技能培训，普惠性、均等化。
4. 学徒制三类对象：新招用职工、在岗职工、转岗职工。

**【答题框架/落点】**：专任教师岗答「专业如何动态优化」引第二十三条；简答「中国特色学徒制在山东条例中的规定」答第二十六条三点。

**【易混辨析】**：**中国特色学徒制（企业设学徒岗位）vs 现代学徒制（校企联合培养）**——表述侧重不同，山东条例用「中国特色学徒制」；**动态调整专业（事前适应）vs 专业教学标准（事中规范）**——不同环节。

**【真题锚点】** 命题角度：选择「学徒制培训对象不包括」用「在校生」做干扰。

**【出处】** 职教条例 p5—6。

### S45 · 条例：立德树人、五育并举与数字化改造 ★★

**【必背原文】** 第二十八条：「职业学校应当落实**立德树人**根本任务，加强校风学风、师德师风建设，营造良好学习环境」。第二十九条：「构建**德智体美劳全面培养**的教育体系，完善**全员全过程全方位**育人机制」。第三十二条：「充分利用**大数据、人工智能、区块链**等新兴技术，优化专业课程内容，系统化改造课程体系，打造数字化、智能化课程教学资源平台」。

**【要点拆解】**
1. 根本任务：立德树人；两个抓手：校风学风、师德师风。
2. 五育：德智体美劳；三全育人：全员、全过程、全方位。
3. 数字化三项技术：大数据、人工智能、区块链；三个动作：优化内容、改造体系、打造平台。

**【答题框架/落点】**：论述「高职教师如何落实立德树人」按「师德师风→课程思政→五育并举→三全育人→数字化赋能」五层；这是专任教师岗最可能出的论述方向。

**【易混辨析】**：**五育并举（德智体美劳）vs 三全育人（全员全过程全方位）**——前者是内容结构，后者是育人机制；**立德树人（根本任务）vs 德技并修（职教特色）**——一个总任务、一个职教表达。

**【真题锚点】** 滨州职院 2024「教育家精神」「职业教育活动周口号」；命题角度：简答「职业学校如何落实立德树人」。

**【出处】** 职教条例 p6—7。

### S46 · 条例：教师队伍、双师型与继续教育 ★★★（专任教师岗核心）

**【必背原文】** 第三十三条：完善职业教育教师培养体系，鼓励设立专门的职业教育师范院校，支持有条件的高等学校举办职业技术师范教育。第三十四条：「按照国家和本省制定的教职工配备标准，配齐合格的教职工，建立与行业企业联合培养具备**理论教学和实践教学能力**的「**双师型**」教师机制，优化专兼职教师结构，建设高素质教师队伍」。第三十五条：「专业课教师（含实习指导教师）应当具有一定年限的**相应工作经历或者实践经验**，达到相应的技术技能水平」。第三十六条：「职业学校应当落实教师继续教育制度，专业课教师**到行业企业培训的学分一般应当占其继续教育总学分的百分之五十以上**」。第三十七条：加强职业教育教研队伍建设，统筹配备专职教研员，支持聘请优秀教师担任兼职教研员。

**【要点拆解】**

| 条款 | 对象 | 硬性要求 |
| --- | --- | --- |
| 第 33 条 | 培养体系 | 鼓励设职教师范院校、办职业技术师范教育 |
| 第 34 条 | 全体教师 | 双师型机制、专兼职结构优化 |
| 第 35 条 | 专业课教师（含实习指导） | 一定年限工作经历/实践经验 |
| 第 36 条 | 专业课教师继续教育 | 企业培训学分≥总学分 50% |
| 第 37 条 | 教研队伍 | 专职教研员 + 兼职优秀教师 |

**【答题框架/落点】**：这是专任教师岗最贴合的一组条文，简答题直接按条款顺序写；论述「如何成为双师型教师」答「企业实践→技能等级→课程改造→指导学生竞赛→教研结合」；面试也可引用第 35、36 条表决心。

**【易混辨析】**：**「双师型」教师（理论+实践双能力）vs 兼职教师（来自行业企业）**——前者是能力结构，后者是来源身份；**50% 是企业培训学分占比，不是课时占比，也不是全体教师要求**——对象与口径都要看清。

**【真题锚点】** 多校真题反复考「双师型」（K12）；命题角度：选择「专业课教师企业培训学分占比」答 50% 以上。

**【出处】** 职教条例 p7—8。

### S47 · 《山东省深化新时代职业教育教师队伍建设改革实施方案》★★★

**【必背原文】** 文件为山东省深化新时代职业教育教师队伍建设改革的省级实施方案（5 页），围绕师德师风、双师素质、教师培养培训、评价激励等方面部署，直接对应「专任教师」岗位的政策语境。**具体条款与数字以资料包原文为准，本讲义不代替原文。**

**【要点拆解】**
1. 层级：省级实施方案，落实国家《关于深化新时代职业教育教师队伍建设改革的意见》类部署。

**【真题锚点】** 命题角度：填空「山东省深化新时代职业教育教师队伍建设的省级文件」答本方案名称。

### S48 · 《山东省职业院校基本工作规范》（2025 年 1 月 10 日）★★★

**【必背原文】** 资料包收录《1 山东省职业院校基本工作规范》（2025 年 1 月 10 日，12 页），是山东省内职业院校办学与教学管理的基本规范文件，内容涉及学校管理、教学运行、教师职责、学生管理等基本工作要求。
