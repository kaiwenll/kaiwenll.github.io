本系列第三篇《第一个月学习内容详解》讲的是「每天做什么」，本篇讲的是**「每天要掌握的知识点本身」**——把 30 天里出现的每一个考点展开成可以直接背、可以直接往答题纸上写的内容。两篇配套使用：先看本篇搞懂知识，再按执行表安排做题和自测。

## 第一部分 · 知识地图（先建立整体逻辑）

零散背 65 个考点效率极低。它们其实是一条从宏观到微观的链条，理解这条链，答题时就能自动调取：

```
定位层  职业教育是什么、地位如何、坚持什么方向
   ↓    K01 地位 / K02 七大坚持 / K03 三大转变 / K04 三件大事
体系层  国家要建成什么样的体系、用什么抓手
   ↓    K05 一体两翼五重点 / K06 体系建设改革 / K07 双高 / K08 四链 / K09 四合 / K10 五金 / K11 101计划
融合层  体系怎么落地——教育与产业如何结合
   ↓    K13 产教融合 / K14 工学结合 / K15 校企合作 / K19 学徒制 / K22 现场工程师 / K40 产业学院·岗课赛证
教学层  落到课堂——教什么、怎么教、怎么评价
   ↓    K17 三教改革 / K18 教育数字化 / K21 1+X / K20 职教高考 / K32 学分银行 / K57 课程思政 / K48—K53 五育
教师层  谁来教——专任教师岗的身份题
   ↓    K12 双师型 / K41 教育家精神 / K55 十项准则 / K56 师德师风 / K61—K65 四有·四引·四统一·六下功夫
学生层  教给谁、如何管理、如何成长
   ↓    K34 就业 / K38 师生关系 / K54 学生管理规定 / K53 资助政策 / K23 职业本科
时政层  大背景——所有论述题的「升华句」从这里取
        K43 教育强国六力 / K44 教育强国纲要 / K45 教科人 / K46 教育现代化2035 / K47 新质生产力 / K42 AI与教育
```

**六个模块对应的真题分布**：融合层与体系层命中率最高（8/10 份卷），教师层与教学层次之，时政层几乎每卷都出现在选择或论述的升华部分。这解释了为什么第 2、3 周要花最多时间。

**一条通用答题主线**（后面每个考点都能套）：
`是什么（定义/内涵）→ 为什么（背景/意义）→ 有什么问题（现状）→ 怎么办（措施，落到教师或院校）→ 升华（教育强国 / 新质生产力 / 技能型社会）`

## 第二部分 · 第 1 周（11.18—11.24）定盘与元知识

第 1 周不背具体考点，任务是把「考什么、怎么考」搞清楚。这些是方法性知识，但直接决定后面三周的精力分配。

### D1 · 11.18｜M01 考试形态判定

**知识要点**

1. 山东高职专任教师岗**没有统一考纲**，自主招聘至少两种形态：
   - **B 型（高教综合）**：公基 + 高等教育学 + 高等教育心理学 + 高校师德 + 教育法规 + 时政 + 省情。2026 实例：山东旅游职业学院。
   - **C 型（职教 + 教基）**：公基 + 职业教育基础 + 教育学 + 心理学。2026 实例：临沂城市职业学院、山东商业职业技术学院。
2. 判定依据只有一条——公告里「笔试内容」的**原文表述**：出现「高等教育学、高等教育心理学」归 B 型；出现「职业教育基础知识、教育学、心理学」归 C 型。
3. 两型的公共科目完全重合，差别只在专业科，因此可以同时准备、双线并行。

**易错**：不要按「学校名字像本科还是高职」来猜。同一省份不同年份、同校不同岗位都可能换卷。

### D2 · 11.19｜M02 公告信息提取、M03 岗位属性

**知识要点**

1. 必抄四项：岗位代码、笔试内容原文、笔试占比、报名与资格条件。
2. 用人形式两种：**人员控制总量备案制**（山东高职多数）与**省属事业编制**（少数）。影响的是编制待遇，不影响笔试内容。
3. 同校专任教师岗 / 辅导员岗 / 管理岗常使用不同试卷，看岗位代码区分。辅导员岗常加考综合写作与案例分析，专任教师岗更偏专业科与教学理论。

**M04 公基考情**：公基是两型共同科目，但拉不开差距；资料包《公基笔记说明》里含高职公基考情分析，用来决定投入上限，不要一上来就扎进 6000 题。

### D3—D4 · 11.20—11.21｜M05 真题题型结构

10 份山东真题（2023—2024，考生回忆版）拆出的结构规律：

| 结构类型 | 代表院校 | 特征 |
| --- | --- | --- |
| 客观 + 简答 + 论述 | 山东商业职院 2023 | 单选 30 + 多选 15，简答 4×5，论述 2 题；**全部围绕职教政策** |
| 客观 + 材料 + 案例 + 大作文 | 东营职院 2023 | 材料 2×10、案例 10、倡议书、40 分作文「如何做好高职院校教育教学工作」 |
| 教育基础 + 写作 | 日照工业学校 2023 | 人物思想、教育词源、教学过程特点，末题 800 字「职教如何突围」 |
| 高教 + 心理学 + 公基 + 时政 | 青岛工程职院 2023 | 选择覆盖四板块，简答考双高、人才培养模式、实习基地 |
| 公基 + 教综 + 学术写作 | 济南工程职院 2023 | 桑代克、布卢姆、韦纳、自我效能感；写作谈蔡元培学术自由 |

**核心结论**：写作几乎必考且分值高（40 分作文、倡议书、考察报告、800 字议论文），只背知识点不练笔会直接丢分。

把每份卷的每个考点归入六类，统计出现次数，得到优先级：

| 板块 | 出现 | 代表考点 |

| 教育学与心理学基础 | 6/10 | 杜威、陶行知、桑代克、韦纳归因、负迁移、自我效能感、教学过程特点 |

**M07 使用规则**：频次 ≥ 3 的考点一律标 ★，进入本月必背清单；频次 1—2 的标 ☆；未出现但属于主干体系的标 ○ 保底。

### D6 · 11.23｜M08 65 考点知识地图

即本文「第一部分」的六层链条。当天任务不是背，而是**在目录上给每个考点标注层级 + 优先级 + 真题归属**，形成一张索引表。这样做的好处是：后面每背一个考点，都知道它在体系中的位置，简答论述时能自动联想相邻考点。

**M09 背诵标准**：★ = 闭卷写 5 条以上；☆ = 含义 + 3 条；○ = 认得、能选、能当素材。月末逐条对照。

### D7 · 11.24｜K01 职业教育地位、K02 七大坚持 ★

#### K01 职业教育地位（p6—7）★

**定义（必背原文）**：为了培养高素质技术技能人才，使受教育者具备从事某种职业或者实现职业发展所需要的职业道德、科学文化与专业知识、技术技能等职业综合素质和行动能力而实施的教育，**包括职业学校教育和职业培训**。

**类型定位（必背三句）**：职业教育是**与普通教育具有同等重要地位的教育类型**，是国民教育体系和人力资源开发的重要组成部分，是培养多样化人才、传承技术技能、促进就业创业的重要途径。

**要点拆解**

1. 关键词是「**类型**」不是「层次」——职业教育不是次等教育，不是普通教育的压缩版。
2. 与普通教育的区别：更重实践技能培养、与市场需求紧密相连；社会发展既需要学术型人才，也需要大量技术型人才。
3. 优化类型定位的三条路径：统筹职业教育、高等教育、继续教育协同创新；推进职普融通、产教融合、科教融汇；培育更多技术技能人才。
4. **改革必要性四条**：① 经济社会发展对高技能人才需求激增（新兴产业、产业升级）；② 提升人才培养质量与就业竞争力（破解理论实践脱节）；③ 服务现代产业体系的结构性支撑；④ 破除「次等教育」的社会认知瓶颈。
5. 教师落点：帮助学生树立专业自信（行业趋势、校友事迹、市场分析）、因材施教、做中学、项目教学与技能竞赛、企业实习、职业指导与心理辅导。

**答题框架**：定义 → 类型定位三句 → 为什么不是次等教育 → 改革四条必要性 → 教师怎么做。

**真题锚点**：山东商业职院 2023 简答「职业教育体系是什么」；滨州职院 2024 多选「培养多样化人才、传承技术技能、促进就业创业」。

#### K02 职业教育七大坚持（p8—10）★

**必背原文（七条）**：坚持中国共产党的领导；坚持社会主义办学方向，贯彻国家的教育方针；坚持立德树人、德技并修；坚持产教融合、校企合作；坚持面向市场、促进就业；坚持面向实践、强化能力；坚持面向人人、因材施教。

**要点拆解**

1. 出自**新修订《职业教育法》**，是法定要求，不是一般倡议。
2. 记忆分组：前两条讲**方向与领导**，中间两条讲**育人路径**（立德树人 + 产教融合），后三条讲**三个面向**（市场、实践、人人）。
3. 高职教师贯彻的落点：把「培养什么人、怎样培养人、为谁培养人」贯穿教学全过程；培育劳模精神、劳动精神、工匠精神；参与校企合作与企业实践；课程设置对接市场需求；强化实训实习；关注个体差异；依法治教。
4. 意义：提高技能人才社会地位和待遇，形成劳动光荣、技能宝贵、创造伟大的时代风尚。

**易混**：七条里的「德技并修」与后文「五育并举」不同——前者是职教育人原则（德育 + 技能），后者是全面发展教育的五育结构。

**真题锚点**：滨州职院 2024 考「四个全面、五位一体」等政治常识，同一板块常与七大坚持混考。

## 第三部分 · 第 2 周（11.25—12.1）体系与改革（本月最重）

### D8 · 11.25｜K03 三大转变、K04 三件大事、K05 一体两翼五重点 ★

#### K03 职业教育发展三大转变（p10）☆

经过 **5—10 年**左右，职业教育基本完成三个转变：
1. 由**政府举办为主** → 政府统筹管理、社会多元办学的格局转变；
2. 由**追求规模扩张** → 提高质量转变；
3. 由**参照普通教育办学模式** → 企业社会参与、专业特色鲜明的类型教育转变。

配套记忆：「两个加强」= 加强职业道德教育、加强职业技能培训；「三个转变」的另一版本表述（题库答案）= 转变办学思想、转变办学机制、转变办学模式。**两种表述都记，考试按题干选**。

#### K04 职业教育三件大事（p10—11）☆

1. 建设一批**办学能力高水平、产教融合高质量**的高等职业学校和专业群，引导学校由「基础好、条件好」转向「服务好、支撑好」；重点服务地方产业、区域战略、一体两翼、高品质民生、边境职业教育、职教出海。
2. 推动职业教育「**走出去**」：研制职教出海标准规范，分类分层打造高质量品牌项目。
3. 办好**世界职业技术教育发展大会**：颁布世界职业教育大奖、组建世界职业教育联盟、举办世界职业技术教育展览，将全国职业院校技能大赛升级为世界职业院校技能大赛。

#### K05 一体两翼五重点（p11—13）★★★

**背景（必背）**：2022 年 12 月，中共中央办公厅、国务院办公厅印发《关于深化现代职业教育体系建设改革的意见》，提出新阶段职业教育改革「一体、两翼、五重点」重大举措。

**一体**：探索**省域现代职业教育体系建设新模式**，是改革的**基座**。围绕国家区域发展规划和重大战略，选择有迫切需要、条件基础和改革探索意愿的省份，在产教融合、职普融通等方面改革突破，以点上突破带动面上高质量发展，形成可复制可推广的经验。

> **易错（高频失分点）**：一体不是「建设现代职业教育体系」这个泛称，而是「**探索省域**现代职业教育体系建设**新模式**」。写论述时漏掉「省域」「新模式」会被判概念不准。

**两翼**：改革的**载体**。
- **市域产教联合体**：以产业园区为基础，支持省级政府打造兼具人才培养、创新创业、促进产业经济高质量发展功能的联合体；成立政府、企业、学校、科研机构等多方参与的理事会，**实体化运作**，集聚资金、技术、人才、政策等要素。
- **行业产教融合共同体**：优先选择重点行业和重点领域，支持龙头企业和高水平高校、职业学校牵头，组建学校、科研机构、上下游企业共同参与的**跨区域**共同体；开展委托培养、订单培养、学徒制培养，面向企业员工开展岗前/岗位培训和继续教育，建设技术创新中心。

**五重点**：围绕职业教育自立自强的五项重点工作。
1. **提升职业学校关键办学能力**——组建国家级核心能力建设专家团队，打造核心课程、优质教材、教师团队、实践项目，遴选专业教学资源库、在线精品课程、虚拟仿真实训基地，做强智慧教育平台；制定新一轮高职「双高计划」遴选方案与中职「双优计划」实施意见。
2. **建设「双师型」教师队伍**——依托头部企业和高水平大学建设国家级培养培训基地，推进「双师型」教师认定，实施职业院校教师素质提高计划、名校长名师（名匠）培育计划，以固定岗与流动岗结合吸引行家里手任教。
3. **建设开放型区域产教融合实践中心**——政府搭台、多元参与、市场驱动，分类建设公共实践中心、企业实践中心、学校实践中心，集实践教学、社会培训、真实生产、技术服务于一体。
4. **拓展学生成长成才通道**——建立符合职教规律的考试招生制度，因地制宜制定职教高考方案，扩大应用型本科在职教高考中的招生规模；推进中职—高职（3+2）、中职—职业本科（3+4）、高职专科—职业本科（3+2）贯通培养；完善专升本办法，推进职普融通。
5. **创新国际交流与合作机制**——办好世界职业技术教育发展大会和世界职业院校技能大赛，推动成立世界职业技术教育发展联盟；「教随产出、产教同行」，推广「中文+职业技能」项目，服务国际产能合作与中国企业走出去。

**答题框架**：出处（2022.12《意见》）→ 一体（基座）→ 两翼（载体，两个分别展开）→ 五重点（逐条 + 每条一句措施）→ 与本校/本岗位结合。

**真题锚点**：滨州职院 2024 简答「一体两翼五重点」原题；青岛工程职院 2023「职业教育如何进行专业建设与改革」可用五重点作答。

### D9 · 11.26｜K06 体系建设改革、K07 双高计划 ★

#### K06 现代职业教育体系建设改革（p13—14）★

**供给侧结构性改革主线**：坚持以人为本、能力为重、质量为要、守正创新，建立健全多形式衔接、多通道成长、可持续发展的梯度职业教育和培训体系；坚持**以教促产、以产助教、产教融合、产学合作**，延伸教育链、服务产业链、支撑供应链、打造人才链、提升价值链；构建央地互动、区域联动，政府、行业、企业、学校协同的发展机制。

**完善体系三条措施**：
1. 深入推进「一体两翼」格局（省域新模式 + 高水平市域产教联合体 + 高效能行业产教融合共同体）。
2. 持续提升**关键办学能力**：实施职业学校达标工程；打造对接产业链创新链的优势专业、高阶性创新性挑战度的精品课程、启智润心的高质量教材、高水平实验实习实训基地；以教育家精神、工匠精神引领高素质「双师型」教师队伍；以信息技术、数字技术、人工智能全面赋能专业、课程、教学和评价。
3. 推动**职普横向融通、纵向贯通**：职业教育不是具体教育阶段而是教育类型，要形成包容畅通的学生成长成才通道。

**关键办学能力四条（p44，另一视角）**：提升现代治理能力、提升人才培养质量（核心）、提升科技服务实力（补「散弱虚」短板）、提升国际化水平。

**答题落点**：问「如何提高关键办学能力」用四条；问「如何完善体系」用三条；两者不要混用。

#### K07 双高计划 / 新双高 / 第二期（p15—16）★

1. **双高计划**：即「高水平高职学校和高水平专业建设计划」，集中力量建设一批引领改革、支撑发展、中国特色、世界水平的高职学校和专业群，打造技术技能人才培养高地和技术技能创新服务平台。**五年一个周期、有进有出**，被称为「高职双一流」。
2. **新双高**：指**办学质量高水平 + 产教融合高质量**。前者要求教育教学、师资队伍、实践教学达到高标准，优化课程结构、更新教学内容、强化实践环节、关注个性化发展；后者要求与行业企业紧密合作，共同开发课程、编写教材、建设实训基地，提供真实职业环境。
3. **第二期双高计划（2025—2029 年）**：集中力量建设 **60 所左右**高水平高职学校和 **160 个左右**高水平专业群，系统推进专业、课程、教材、教师、实训基地等教学关键要素改革，形成可复制可借鉴的经验，培养大国工匠、能工巧匠、高技能人才。

**易混**：双高 ≠ 新双高。前者是项目名，后者是新阶段的质量标准表述。资料中 222 页政策汇编 p61 收录的是第二期（2025—2029 年）文件。

**真题锚点**：青岛工程职院 2023 简答「双高计划」原题。

**四链 = 教育链、人才链、产业链、创新链**。以立德树人为根本、高质量发展为目标，深化育人方式、办学模式、管理体制、保障机制改革，探索四链联动，构建职普融通、产教融合、科教融汇的体系，服务新质生产力。

院校怎么做（三条主线）：① 以**产业链**为导向重塑**教育链**——建立专业设置「正负面清单」，撤并过剩专业，改造升级智能制造、数字经济相关专业，前瞻布局新材料、新能源、人工智能等新专业；② 深化校企协同育人；③ 打通成果转化，让**创新链**成果快速应用于**产业链**。

### D11 · 11.28｜K12 双师型教师 ★（详见 D21 教师层，本日先掌握定义与占比）

**必背定义（p22）**：贯彻党的教育方针，热爱职业教育事业，具有良好思想政治素质和师德素养，落实立德树人根本任务，遵循职业教育规律和技术技能人才成长规律，**具备相应的理论教学和实践教学能力**，紧跟产业发展趋势和行业人才需求，具有企业相关工作经历或积极深入企业和生产服务一线进行岗位实践，能把新技术、新工艺、新规范融入教学的**复合型人才**。

**三个硬指标/关键词**：① 理论教学 + 实践教学「双能力」；② 企业工作经历或一线岗位实践；③ 理解所教专业（群）与产业的关系。
**数字**：职业院校教师教学创新团队中「双师型」教师占比**不低于 50%**；专业课教师中双师型占比超过一半。

**提升培养能力三条（p22—23）**：构建政府统筹管理、行业企业和院校深度融合的教师队伍建设机制，健全中高职教师培养培训体系；打通校企人员双向流动渠道；建立「双师型」教师资格准入、聘用考核制度，畅通职业发展通道。

**真题锚点**：山东商业职院 2023 论述「双师型教师队伍应该具备的素质与能力」原题；滨州职院 2024 单选「兼职教师占全体教师比例」。

### D13 · 11.30｜K13 产教融合 ★（本月最可能出论述的考点）

**含义（p23）**：职业学校根据所设专业积极开办专业产业，把产业与教学密切结合、相互支持相互促进，把学校办成集人才培养、科学研究、科技服务于一体的产业性经营实体，形成学校与企业浑然一体的办学模式。核心表述：**以教促产、以产助教、产教融合、产学合作**，延伸教育链、服务产业链、支撑供应链、打造人才链、提升价值链。

**产教融合共同体**：产业界、教育界和政府共同构建的合作共享组织体系（与「两翼」直接对应，见 K05）。

**如何深化（三条，p24）**
1. **优化职业教育供给结构**：形成紧密对接产业链、创新链的专业体系；推进部省共建职业教育创新发展高地；深化东西部协作；启动技能型社会职业教育体系建设地方试点。
2. **构建多元办学格局**：政府统筹管理、行业企业积极举办、社会力量深度参与；健全国有资产评估、产权流转、权益分配、干部人事管理，鼓励企业依法参与举办职业教育，鼓励校企共建基础设施与实训基地。
3. **协同推进产教深度融合**：各级政府将产教融合列入经济社会发展规划；建设产教融合试点城市、标杆行业、产教融合型企业。

**重要意义（三层，p24—25）**：人才培养（真实产业环境、缩短岗位适应期）、产业发展（人才储备、定制培养、科技成果转化）、国家层面（优化教育结构、支撑制造强国与产业升级）。

**现存问题（p25，论述题加分项）**：① 校企合作深度不足——「校热企冷」、合作形式单一（多停留在实习、兼职授课）、稳定性差；② 政策落实不到位——配套细则不完善、执行力度不够、受益面窄（偏向大型企业国企）。

**七种深入发展模式（p30—32，了解级）**：可从「共建实训基地、订单培养、技术服务、战略联盟、科技资源共享、技术开发、技术创新服务平台」角度记忆，不必逐条死背。

**万能五段式**：含义 → 载体（市域产教联合体 / 行业产教融合共同体）→ 问题（校热企冷、合而不深）→ 措施（专业跟产业走、共建产业学院、订单培养、实训基地、企业导师）→ 意义/升华。

**真题锚点**：滨州职院 2024 论述「产教融合」；青岛工程职院 2023 论述「如何深化产教融合」；东营职院 2023 材料「农业产业学院建设意义」。

### D14 · 12.1｜K14 工学结合、K15 校企合作、K16 三大精神 ☆

#### K14 工学结合（p32—33）
**含义**：把学校学习与企业实践结合，理论联系实际，促使学生工学相长，成为高素质技能型人才；既符合国际职业教育普遍规律，又具中国特色。
**主要形式**：半工半读、工学交替、勤工俭学、订单培养、工程导向、任务驱动、岗位见习。
**教学特征（六条）**：模块化教学内容呈开放性与职业性；教学做合一、任务驱动、案例式；「双证」融通的理论与实践教学；学校（教室）与企业（实训基地）一体化；「双师型」教师与外聘行业专家为主体、兼职教师占较大比例；真实职业体验与职业道德教育。

#### K15 校企合作（p33）
**含义**：学校与企业双主体协同育人，通过共同育人、合作研究、共建机构、共享资源，形成产教融合、校企合作、工学结合、知行合一的共同育人机制。
**意义（三方）**：学校——了解科技发展避免知识滞后、及时调整人才培养方案、共建实训基地、共同研发提高科研能力；学生——了解岗位要求制定职业规划、增加工作经验与就业能力；企业——联合培养降低人力资源成本、资源共享提高运营效率。

#### K16 三大精神（p33—34）★
| 精神 | 核心内涵 |
| --- | --- |
| **劳模精神** | 爱岗敬业、争创一流，艰苦奋斗、勇于创新，淡泊名利、甘于奉献 |
| **劳动精神** | 崇尚劳动、热爱劳动、辛勤劳动、诚实劳动 |
| **工匠精神** | 敬业、精益求精、严谨细致、积极创新；对自己产品精雕细琢、精益求精，是职业道德、职业能力、职业品质的体现 |

**内在关系（必背）**：**劳动精神是根基**（离开劳动创造，劳模精神与工匠精神就是无源之水、无本之木）；**劳模精神与工匠精神是劳动精神向更高水平的发展、更高层次的升华**；三者是以爱国主义为核心的民族精神和以改革创新为核心的时代精神的生动体现。

**工匠精神四层展开（p34—38）**：执着专注、精益求精、一丝不苟、追求卓越。

**易混**：三大精神（劳模/劳动/工匠）≠ 教育家精神（六内涵）≠ 职教「三种教育类型」（职教/高教/继教）。

**真题锚点**：东营职院 2023 作文材料含「工匠精神」；山东服装职院 2023 简答「积极奉献社会的内涵」可用劳模精神作答。

## 第四部分 · 第 3 周（12.2—12.8）教学、证书、人物与教师

### D15 · 12.2｜K17 三教改革、K18 教育数字化、K19 中国特色学徒制 ★

#### K17 三教改革（p39—40）★
**含义（必背）**：**教师、教材、教法**改革。目标是打造一支德技精湛的教师队伍、建设一批内容形式精良的教材、形成一套精准施教的教法。

| 改革维度 | 核心措施 |
| --- | --- |
| **教师** | 组建高水平、结构化教学创新团队（多人共上一门课）；建设高素质双师型队伍（专业课教师中双师型超过一半）；安排专业教师到企业顶岗实践；聘请行业企业专业人才和能工巧匠任兼职教师；完善考核评价；校企共建双师型培养培训基地 |
| **教材** | 制定高职教材标准、严把教学标准关；校企「双元」合作开发国家规划教材并配套信息化资源；**每 3 年修订 1 次**，及时将新工艺、新规范充实进教材，实现**书证融通** |
| **教法** | 以校企合作、育训结合为切入点，抓实验、实训、实习三个关键环节；推行启发式、讨论式教学与项目化、模块化课程；改革考试方法，重综合运用与解决实际问题能力；运用大数据、人工智能、虚拟工厂等现代信息技术 |

**易混**：三教**改革**（教师·教材·教法）≠ 三教**协同**（职业教育·高等教育·继续教育，K26）。这是选择题高频陷阱。

**答题落点**：问「如何推进三教改革」按教师/教材/教法三层各写 2—3 条，最后落到「以教师改革为核心、以学生发展为中心、教法改革不能脱离课程教材教师学生」三条原则（题库标准答案）。

#### K18 教育数字化（p40—43）☆
**含义**：我国开辟教育发展新赛道、塑造教育发展新优势的重要突破口。目标是构建虚实结合、更具沉浸性的职业教育新样态，数据驱动的精准新路径，人机结合的智能化新范式；营造「人人可学、时时可学、处处可学」的智慧学习环境，引领理念、思想、方法、实践变革，重塑职业教育新生态。
**数字化战略行动**：2022 年起国务院、教育部实施「国家教育数字化战略行动」，明确「强化需求牵引，深化融合、创新赋能、应用驱动，积极发展『互联网+教育』，加快推进教育数字转型和智能升级」。
**答题落点**：专业/课程/教学/评价四方面赋能（与 K06 关键办学能力呼应）。

#### K19 中国特色学徒制（p43）★
**必背定义**：引导企业按岗位总量的一定比例设立**学徒岗位**，鼓励和支持有技术技能人才培养能力的企业（特别是产教融合型企业）与职业学校、职业培训机构合作，对新招用职工、在岗职工、转岗职工进行学徒培训，或与职业学校联合招收学生，以**工学结合**方式进行学徒培养；有关企业可按规定享受补贴；联合招收学生的**应当签订学徒培养协议**。
**记忆点**：岗位比例 + 三类对象（新招用/在岗/转岗）+ 工学结合 + 补贴 + 培养协议。
**真题锚点**：滨州职院 2024 单选「中国特色学徒制、岗课赛证」。

### D16 · 12.3｜K20 职教高考、K21 1+X 证书、K22 现场工程师 ☆

#### K20 职教高考（p44）
**含义**：高等职业学校采取「**文化素质 + 职业技能**」相结合的考核方式招收学生。
**配套**：扩大应用型本科在职教高考中的招生规模；各省因地制宜制定方案；与 K05 五重点之四「拓展成长成才通道」联动。

#### K21 1+X 证书制度（p45—46）★
**定义**：「1」为**学历证书**，「X」为**若干职业技能等级证书**。学历证书全面反映学校人才培养质量，在国家人力资源开发中起基础性作用；职业技能等级证书是毕业生、社会成员职业技能水平的凭证，反映职业活动和个人职业生涯发展所需的综合能力。
**作用四条**：提升学生职业技能、强化综合素质、提高就业竞争力、增强人才培养与产业需求的契合度（通过产教融合引导学生考取与需求紧密相关的证书，缓解结构性就业矛盾）。
**配套概念**：**书证融通**（K17 教材改革）、**学分银行**（K32）、学习成果认定积累转换。
**真题锚点**：主观题高频「谈一谈你对 1+X 证书的理解」（题库第 9 题）。

#### K22 现场工程师（p46）○
在生产、工程、管理、服务等**一线岗位**，能够以科学技术创造性解决工作现场技术应用问题的**应用型、复合型技能人才**。「现场」指从事产品生产、制造或提供生产服务的场所，含基本生产车间作业场所及实验室、生产供应环节等辅助部门作业场所。
**配套**：教育部等五部门「职业教育现场工程师专项培养计划」。

### D17 · 12.4｜K23 职业本科、K24 职教出海、K25 鲁班工坊 ☆

#### K23 职业本科教育（p46—48）
**定义**：本科层次职业教育，是国家在高等职业教育中开展的本科层次职业教育，不同于普通本科、专科层次职业教育和研究生层次职业教育，主要培养**高层次、高技能的应用技术型人才**。
**机遇**：为学生提供更大发展空间（已纳入学士学位授予体系）；为社会提供有力人才供给（破解「专科高职培养的能力不够用、普通本科培养的学术型人才不管用」）。
**挑战**：顶层制度体系尚不完善（标准体系、财政投入机制待建）；职业本科学校内涵建设亟待强化（规模扩张期、优质校少、国家平台未开放）。
**对策四条**：完善制度标准体系；定位准确凸显职教特色（切忌办成综合性大学）；探索经验模式、打造发展范式；提升社会服务能力（参与共同体与联合体建设、参与技术研发与成果转化）。
**易错**：职业本科 **不是**普通本科的翻版，也**不是**高职专科的简单升格，须坚守产教融合核心理念与类型定位。

#### K24 职教出海（p48—49）
**含义**：从「借船出海」转向「随船出海」「带船出海」，由优质教育资源「请进来」转向主动「走出去」，为世界其他国家培养输送人才，服务国际产能合作。
**四条路径**：产教融合、教随产出（海外基地对接走出去企业需求）；以国际合作项目为抓手构建国际化工作格局；「中文 + 职业技能」融合；在「引进来」「走出去」中完善职教体系。
**关联**：K04 三件大事之二、K05 五重点之五。

#### K25 鲁班工坊（p49—50）○
天津原创并率先实践的中外人文交流知名品牌，是中国职业教育国际化发展的重大创新成果。以鲁班的「大国工匠」形象为依托，在泰国、印度、印尼等国设立，采用学历教育与职业培训方式把天津国家现代职业教育改革创新示范区的优秀技术和职业文化输出，为共建「一带一路」提供技术服务与人才支持。
**「天津方案」三层**：授人以渔助海外青年成才；辐射带动中国职教方案名扬海外（标准、装备、方案全球推广）；助力企业国际产教融合促共赢。

### D18 · 12.5｜K26 三教协同、K27 三融发展、K28 高质量发展 ★

#### K26 三教协同（p51）☆
**内涵**：党的二十大报告提出「**统筹职业教育、高等教育、继续教育协同创新**」。三类教育是教育链接就业的枢纽组合，既有边界也有交叉，核心与难点集中在终身学习体系的沟通衔接；从「不同」走向「协同」，优势互补、交叉融合，建设高质量教育体系、支撑教育强国。
**易混（本月最大陷阱）**：K17 三教**改革** = 教师、教材、教法；K26 三教**协同** = 职教、高教、继教。题干出现「统筹」「协同创新」「终身学习」就是后者。

#### K27 三融发展（p51—53）★★
| 概念 | 内涵 |
| --- | --- |
| **职普融通** | 职业教育与普通教育两种类型相互沟通、相互衔接，既各成体系又融合发展，实现教育资源共享、贯通、互认；让不同禀赋的学生多次选择、多样化成才；有助于扭转社会偏见、消解职普分流焦虑 |
| **产教融合** | 见 K13；核心是教育链与产业链对接，「以教促产、以产助教」 |
| **科教融汇** | 深入实施科教兴国战略的重要抓手，融合汇聚科技与教育力量，服务国家科技自立自强；通过技术研发过程与人才培养环节交融贯通，促进科技创新、产业体系与人才培养体系深度融合；是优化职业教育类型定位的**新方向** |

**三融改革指导思想（题库标准答案，必背）**：以**提升职业学校关键能力为基础**，以**深化产教融合为重点**，以**推动职普融通为关键**，以**科教融汇为新方向**；统筹职业教育、高等教育、继续教育协同创新，有序有效推进现代职业教育体系建设改革。
**记忆口诀**：基础—能力、重点—产教、关键—职普、新方向—科教。

#### K28 高质量发展（p53）☆
**内涵**：高质量发展是全面建设社会主义现代化国家的**首要任务**；完整、准确、全面贯彻新发展理念，加快构建以国内大循环为主体、国内国际双循环相互促进的新发展格局。
**推进职教高质量发展五条**：① 强化类型特色（巩固类型定位、纵向贯通、横向融通）；② 完善产教融合办学体制；③ 创新校企合作办学机制；④ 深化教育教学改革（双师型队伍、教学模式与方法、教学内容与教材、质量保证体系）；⑤ 打造中国特色职业教育品牌。

**真题锚点**：滨州职院 2024 论述「职业院校如何做好科教融汇，服务滨州当地建设」——用 K27 科教融汇 + K13 产教融合 + 本地产业三层作答。

### D20 · 12.7｜K31 黄炎培职业教育思想体系 ★

**体系六部分（必背框架）**：作用与地位、目的、办学方针、教学原则、职业道德教育、评价。

| 部分 | 内容 |
| --- | --- |
| **作用** | 「谋个性之发展」「为个人谋生之准备」「为个人服务社会之准备」「为国家及世界增进生产力之准备」；提高国民职业素养，解决生计问题 |

### D21 · 12.8｜K41 教育家精神、K55 教师职业道德、K56 师德师风 ★★

#### K41 教育家精神（p69—73）★★★
**背景**：2023 年 9 月，第三十九个教师节前夕，习近平总书记致信全国优秀教师代表，**首次提出并阐述中国特有的教育家精神**。

**六内涵（必背，逐字）**
1. 心有大我、至诚报国的**理想信念**（信念之维）
2. 言为士则、行为世范的**道德情操**（道德之维）
3. 启智润心、因材施教的**育人智慧**（学识之维）
4. 勤学笃行、求是创新的**躬耕态度**（态度之维）
5. 乐教爱生、甘于奉献的**仁爱之心**（情感之维）
6. 胸怀天下、以文化人的**弘道追求**（境界之维）

**记忆口诀**：理想信念—道德情操—育人智慧—躬耕态度—仁爱之心—弘道追求；对应「信、德、智、态、情、境」六个维度。

**高校教师如何践行（三条，题库答案）**：以师德师风学习为先导，铸牢从教信念之基；以专业能力培养为核心，夯实从教素养之本；以教育实践训练为底色。

**升华句（论述万能）**：教师是立教之本、兴教之源；不应把教育仅看作谋生职业，而应牢记「为党育人、为国育才」使命，把「小我」融入国家繁荣富强的「大我」。

**真题锚点**：滨州职院 2024 简答「教育家精神的时代内涵」原题。

#### K56 师德师风（p103—104）★
**两个「第一/根本标准」**：把**立德树人的成效**作为检验学校一切工作的**根本标准**；把**师德师风**作为评价教师队伍素质的**第一标准**；将社会主义核心价值观贯穿师德师风建设全过程。
**基本原则四条**：坚持正确方向、坚持尊重规律、坚持聚焦重点、坚持继承创新。
**总体目标**：经过 **5 年左右**努力，基本建立完备的师德师风建设制度体系和有效长效机制；形成教师安心、热心、舒心、静心从教的环境。
**师德底线**：自重、自省、自警、自励。
**破五唯**：唯分数、唯升学、唯文凭、唯论文、唯帽子（注意：资料 p104 一处写「唯分数、唯文凭、唯职称、唯论文、唯帽子」，另一处按中央原文为「唯分数、唯升学、唯文凭、唯论文、唯帽子」；**考试以中央原文五唯为准**，答题可写「等」规避版本差异）。
