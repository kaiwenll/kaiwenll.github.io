## 第二部分 · 师德理论基础（E01—E10）

这一部分回答「师德是什么、从哪来、由哪些要素构成」，是全篇唯一偏学理的板块，B 型卷简答与 C 型卷辨析题常从这里出小题。

### E01 · 道德概述：起源、内涵、本质、特点、功能、发展规律 ☆

**【必背原文】** 马克思主义认为，道德起源于人类社会的早期劳动；道德是由一定社会的经济关系所决定的特殊意识形态，是以善恶评价为标准、依靠社会舆论、传统习惯和内心信念所维持的，调整人们之间以及个人与社会、人与自然之间关系的行为规范的总和。道德的功能有认识功能、教育功能、调节功能。道德发展的规律：社会经济关系决定道德的发展；道德演变的总趋势是不断进步；道德的发展是变革与继承的统一；社会变革是道德发展的动力。

**【要点拆解】**

1. 内涵四层：由经济关系决定；以善恶为评价标准；靠行为习惯、社会舆论、内心信念调节；调整个人与个人、个人与集体、个人与社会的关系。
2. 本质两层：一般本质（与政治、法律、哲学同属社会意识形态）；特殊本质（非制度化、非权利、内化的规范调节方式，是一种实践精神）。
3. 特点四个：特殊的规范性、独特的多层次性、广泛的社会性、更大的稳定性。
4. 功能三个：认识功能（明确行为方向）、教育功能（教化善恶）、调节功能（指导纠正行为、协调关系）。
5. 道德与法律的区别：道德不靠权力强制开路，靠舆论、习惯、信念；法律靠国家强制力。这是「礼已具备法的性质」「法官除了法律无别的上司」一类选择题的判断底座。

**【答题框架/落点】** 问「道德的内涵/特点/功能」按上面 4／4／3 分条默写；问「道德与法的关系」用「强制方式不同、调整范围不同、二者相互支撑」三层收束。

**【易混辨析】** 道德的「特殊本质」不等于「一般本质」：前者讲道德区别于其他意识形态的**特殊规范方式**，后者只讲它是社会意识形态之一。另注意「调节功能」是道德最主要的功能，不要把「认识功能」写成核心。

**【真题锚点】** 山东开放大学 2023 单选「礼已具备法的性质是在哪个朝代」「『法官除了法律无别的上司』说明法具有什么」，考的是法与道德的分界；日照工业学校 2023 选择含「教育法规」板块，同层可混考。

**【出处】** 高校师德 p6—p9。

### E02 · 教师职业道德的含义与构成 ★

**【必背原文】** 职业道德，是指从事一定职业的人们在职业生活中所应遵循的道德规范以及与之相适应的道德观念、情操和品质。教师职业道德是教师在从事教育劳动时所应遵循的行为规范和必备的品德的总和，是调节教师与他人、与社会、与集体、与学生等的职业工作关系时所必须遵守的基本道德规范和行为准则，以及在此基础上所表现出来的道德观念、情操和品质；它是一般社会道德在教师职业中的特殊体现。教师职业道德主要由教师职业理想、教师职业责任、教师职业态度、教师职业纪律、教师职业技能、教师职业良心、教师职业作风和教师职业荣誉等因素构成。

**【要点拆解】**

| 要素 | 落点 |
| --- | --- |
| 职业理想 | 忠诚人民教育事业、树立崇高职业理想 |
| 职业责任 | 尽职尽责、教书育人 |
| 职业态度 | 爱岗敬业、乐于奉献 |
| 职业纪律 | 遵守法纪、依法执教 |
| 职业技能 | 扎实基本功、刻苦钻研业务 |
| 职业良心 | 内在的道德责任感与自我评价能力 |
| 职业作风 | 严于律己、以身作则 |
| 职业荣誉 | 社会对教师道德行为的公认评价 |

1. 定义三句话缺一不可：「行为规范和必备品德的总和」「调节四种职业关系」「一般社会道德在教师职业中的特殊体现」。
2. 构成八因素建议按「理想—责任—态度—纪律—技能—良心—作风—荣誉」顺序背，正好覆盖师德全部考点。
3. 「教书育人」是教师在履行教育义务活动中最主要、最基本的道德责任，也是教师道德实践中的根本范畴。

**【答题框架/落点】** 名词解释先给定义三句，再列八因素；简答「教师职业道德由哪些因素构成」直接默八因素并各配一句解释。

**【易混辨析】** 「教师职业道德」与「师德师风」不是同一层：前者是**规范与品德的体系**（学理概念），后者是**队伍建设的第一标准与工作口径**（政策概念，见 E14）。另「职业道德」是属概念，「教师职业道德」是种概念，答定义时不能只写属概念。

**【真题锚点】** 山东服装职业学院 2023 论述「职业院校如何开展学生道德教育」可用八因素反推教师端；命题角度：名词解释「教师职业道德」在 B 型卷高频。

**【出处】** 高校师德 p9、p19。

### E03 · 教师职业道德的五大特征 ★

**【必背原文】** 教师职业道德的特征：鲜明的继承性、强烈的责任性、独特的示范性、严格的标准性、影响的广泛性和深远性。

**【要点拆解】**

1. 鲜明的继承性：师德是从长期教书育人实践中总结提炼出来的，世世代代调整师生、同行、上下级、家长关系的最一般经验，可跨时代沿用。
2. 强烈的责任性：是教师自觉积极职业态度形成的基础，对教育教学起导向、动力、保证作用。
3. 独特的示范性：以身作则、为人师表是教师职业道德**区别于其他职业道德的明显标志**；扬雄「师者，人之模范也」，夸美纽斯「教师的义务是用自己的榜样来教导学生」，乌申斯基「教师个人的范例，对于青年人的心灵，是任何东西都不能代替的阳光」。
4. 严格的标准性：比其他职业道德有更高、更全面的内容要求，要求崇高的精神境界与高尚道德品质。
5. 影响的广泛性（不仅影响在校学生，还经学生、家长影响整个社会）与深远性（关系学生人格塑造、社会前途未来）。

**【答题框架/落点】** 五条按「继承—责任—示范—标准—广泛深远」默写；论述题把「示范性」展开到「学高为师、身正为范」与教师言行雅正。

**【易混辨析】** 五大「特征」与 E04 的「原则」不同：特征是师德**表现出来的属性**，原则是处理利益关系时**应遵循的准则**。另「示范性」是区别标志，不要错写成「严格的标准性」。

**【真题锚点】** 济南工程职业技术学院 2023 写作「蔡元培学术自由」、滨州职业学院 2024 下午场简答「教育家精神的时代内涵」，都要用「示范性」作教师端论据；命题角度：多选「下列属于教师职业道德特征的是」。

**【出处】** 高校师德 p11—p12。

### E04 · 教师职业道德的基本原则与教育人道主义 ★

**【必背原文】** 教师职业道德基本原则是教师在教育职业活动中正确处理各种利益关系时所应遵循的最根本的指导准则，是一定社会或阶级对教师在职业活动中提出的最根本的道德要求，指明教师职业实践中道德行为的总方向，统帅整个教师职业道德体系，是衡量和判断教师行为善恶的最高道德标准。我国教师职业道德的基本原则是**忠于人民教育事业**；教师职业道德的重要原则是**教育人道主义**。

**【要点拆解】**

1. 基本原则的四层理解：区别于其他类型职业道德的标志；指明道德行为总方向；是师德理论与实践的概括总结；是调整个人与他人、个人与社会关系的根本指导原则。
2. 忠于人民教育事业：把青少年一代培养成为有理想、有道德、有文化、有纪律、适应社会发展需要的一代新人；是我国教育社会主义性质的必然要求，是衡量教育工作者个人行为和品质的**最高道德标准**。
3. 教育人道主义：社会主义人道主义在教育领域、教育过程中的具体化、「职业化」；要求教育者与受教育者都从社会主义人道主义原则出发，尊重对方作为人的价值与尊严，教育者以完美人格要求自己、以人道原则协调关系。
4. 原则的作用三个：指导作用、统帅作用、裁决作用。
5. 原则确立的依据三条：反映一定社会经济关系和阶级利益的根本要求；符合一般社会道德原则的基本要求；反映教师职业活动的特点。

**【答题框架/落点】** 问「基本原则是什么」答「忠于人民教育事业」并给四层理解；问「原则的作用」答指导／统帅／裁决三条；问「确立依据」答三条。

**【易混辨析】** 「基本原则」只有一条（忠于人民教育事业），「重要原则」是教育人道主义，二者不是并列关系；另「作用」（指导／统帅／裁决）与「要求」（树立无产阶级世界观人生观价值观、树立崇高理想信念、具备良好专业能力素质、具有顽强意志和崇高精神境界）是两组不同答案，不要混用。

**【真题锚点】** 命题角度：简答「我国教师职业道德的基本原则及其依据」，B 型高教综合卷常见。

**【出处】** 高校师德 p14—p15。

### E05 · 教师职业道德原则的要求与教师伦理学定位 ☆

**【必背原文】** 教师职业道德原则的要求：树立无产阶级的世界观、人生观和价值观；树立崇高的理想、信念和价值目标；具备良好的专业能力素质；具有顽强的意志和崇高的精神境界。教师伦理学是把教师职业道德作为研究对象的学科，围绕道德起源、道德本质、师德原则、师德范畴、师德修养、师德评价六块展开。

**【要点拆解】**

1. 四条要求对应「方向—目标—本领—境界」，可与 E03 的示范性、严格标准性互相印证。
2. 教师伦理学的知识框架＝本篇第二部分全部内容，写「教师伦理学研究对象」时按六块列举即可。
3. 「教书育人，忠诚于人民的教育事业，是教师职业道德的灵魂，它统帅、制约着师德的一切行为规范和范畴」，这句可作论述题的收束句。
4. 师德评价的最高标准是「人的全面和自由的发展」；一般标准是善恶标准；具体标准分政治方向、业务知识方法、道德行为三方面。

**【答题框架/落点】** 论述「试论教师职业道德修养的学理基础」：道德概述 → 师德原则 → 师德范畴 → 修养与评价，逐层点题。

**【易混辨析】** 教师伦理学（学科）≠ 教师职业道德（规范体系）≠ 师德师风（建设工作），三者是「研究／规范／实践」的关系。

**【真题锚点】** 命题角度：名词解释「教师伦理学」、辨析「师德就是教师伦理学」，属于 B 型卷教育学理论小题。

**【出处】** 高校师德 p15、p19、p28。

### E06 · 教师职业道德五大范畴 ★

**【必背原文】** 教师职业道德的主要范畴：教师义务、教师良心、教师公正、教师荣誉、教师人格。

**【要点拆解】**

| 范畴 | 核心内容 | 作用/要点 |
| --- | --- | --- |
| 教师义务 | 提高思想政治觉悟和教育教学业务水平；尽职尽责教书育人；创设良好内部教育环境 | 最主要、最基本的道德责任是教书育人 |
| 教师良心 | 对学生、家长、同事、社会、学校、职业履行义务中形成的特殊道德责任感和自我评价能力 | 特点：公正性、综合性、稳定性、内隐性、广泛性 |
| 教师公正 | 在教育教学中公平合理地对待和评价每一个学生 | 内容：坚持真理、秉公办事、奖罚分明 |
| 教师荣誉 | 社会对教师道德行为的公认的客观评价和教师对自己行为价值的自我意识 | 内容：光荣的角色称号、无私的职业特性、崇高的人格形象 |
| 教师人格 | 教师作为特定社会角色表现出的道德面貌与特征 | 特质：人格与师格的统一、较高的格位水平；师表美含表美、道美、风格美 |

1. 教师良心的培养措施：对教育工作高度负责的精神、高尚的师德品质、知耻心自尊心自爱心。
2. 教师公正的作用：调动每个学生学习积极性、形成公正无私品德、利于教师威信形成、形成良好教育教学环境。
3. 教师人格修养策略「取法乎上」，尺度是确立教师人格修养的审美尺度、进行师表美建设。

**【答题框架/落点】** 问「师德范畴有哪些」先列五个，再各写含义＋内容两条；问「教师公正」单拆时按含义—内容—作用三段答。

**【易混辨析】** 「范畴」与 E02「构成八因素」不同：范畴是伦理学提炼的**五组核心概念**（义务、良心、公正、荣誉、人格），构成是师德的**八个要素**（理想、责任、态度、纪律、技能、良心、作风、荣誉）。两者只有「良心」「荣誉」重合，选择题常在此设混项。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」的反向考点即教师公正与尊重学生人格；命题角度：多选「教师良心／教师公正的内容」。

**【出处】** 高校师德 p12—p14。

### E07 · 教师职业道德的发展历程 ○

**【必背原文】** 教师职业道德的发展分先秦时期、封建社会、社会主义社会三个阶段。孔子要求教师「学而不厌，诲人不倦」，主张因材施教、「其身正，不令而行；其身不正，虽令不从」；韩愈提出「师者，所以传道授业解惑也」「弟子不必不如师，师不必贤于弟子」；陶行知认为「做教师的人，必须天天学习，天天接受再教育」。

**【要点拆解】**

1. 先秦：孔子（启发、因材施教、以身作则）、孟子（「得天下英才而教育之」、「教育必以正」）、墨子（「兼相爱、交相利」、「以身戴行」、「有道者劝以教人」为大善）、荀子（「师术有四，而博习不与焉」）。
2. 封建：董仲舒「化民成性」、朱熹「修身」「接物」「教人有序」、王守仁「致良知」「知行合一」、康有为与蔡元培重师德品行。
3. 社会主义：教师职业道德成为社会主义道德体系的重要组成部分，增添崭新内容。
4. 记忆钩子：先秦讲「榜样与启发」，封建讲「修身与课程」，社会主义讲「为人民服务」。

**【答题框架/落点】** 写作题谈「古今师德传承」按三阶段各取一人一句，收束到「教育家精神是中华优秀师道传统的创造性转化」。

**【易混辨析】** 「师者，所以传道授业解惑也」出自韩愈，不是孔子；「有教无类」才是孔子。真题常把人物与主张交叉设错。

**【真题锚点】** 日照工业学校 2023 选择「人物的教育理念思想」「孔子教育思想」、济南工程职业技术学院 2023 选择「得天下英才而教育之三乐也出自《孟子》」，均属本层。

**【出处】** 高校师德 p10—p11；高频速记 p33。

### E08 · 高等学校教师职业道德规范六条及与中小学规范对比 ★

**【必背原文】** 2011 年 12 月 23 日，教育部、中国教科文卫体工会全国委员会颁布《高等学校教师职业道德规范》，这是继 2008 年教育部、中国教科文卫体工会重新修订和印发《中小学教师职业道德规范》之后，首次制订印发《高等学校教师职业道德规范》。它从**爱国守法、敬业爱生、教书育人、严谨治学、服务社会、为人师表**六个方面，对高校教师职业责任、道德原则及职业行为提出了要求。

**【要点拆解】**

| 高校规范六条 | 关键禁止性表述 |
| --- | --- |
| 爱国守法 | 不得有损害国家利益和不利于学生健康成长的言行 |
| 敬业爱生 | 不得损害学生和学校的合法权益 |
| 教书育人 | 不拒绝学生的合理要求；不得从事影响教育教学工作的兼职 |
| 严谨治学 | 坚决抵制学术失范和学术不端行为 |
| 服务社会 | 坚决反对滥用学术资源和学术影响 |
| 为人师表 | 自觉抵制有损教师职业声誉的行为 |

1. 六条顺序记忆：「守法—爱生—育人—治学—服务—师表」，前三条对「国／生／教」，后三条对「学／社会／自身」。
2. 高校规范独有的两条是「严谨治学」「服务社会」，这是高校职能（科学研究、社会服务）在师德上的体现。
3. 爱国守法是基本道德要求；教书育人是教师的天职、核心工作；为人师表是教师职业的内在要求。
4. 为人师表的六个「不失」：拒腐防变不失节、恪尽职守不失职、言行一致不失信、公正无私不失衡、宽以待人不失度、处变不惊不失态。

**【答题框架/落点】** 问「高校师德规范内容」默六条并各带一句禁止性表述；问「与中小学规范的区别」按颁布时间、适用对象、条目侧重、职能映射四点答。

**【易混辨析】** 高校规范六条 ≠ 新时代高校教师职业行为十项准则（E11）：前者是 2011 年《规范》，六条、偏倡导；后者是 2018 年《准则》，十条、条条带「不得」、偏底线。另《中小学教师职业道德规范》六条的具体条目资料包未完整收录，仅收录「2008 年重新修订印发」这一事实及与高校规范的先后关系，六条具体原文需另行补充，答题不得凭记忆外推为资料原文。

**【真题锚点】** 山东服装职业学院 2023 简答「积极奉献社会的内涵」与高校规范第五条「服务社会」、十项准则第十条「积极奉献社会」同板块；命题角度：多选「下列属于高校教师职业道德规范的是」。

**【出处】** 高校师德 p16—p18；师德考点 p7；高频速记 p14—p15；职教必背 p102—p103。

### E09 · 教师职业道德修养：概念、任务、策略、慎独 ★

**【必背原文】** 教师职业道德修养是将教师职业道德要求转化为自己的信念并付诸行动的活动，简说是一种自我锻炼、自我改造、自我陶冶、自我教育的过程。修养的根本途径是**理论与实践相结合**。教师职业道德修养的最高层次是**「慎独」**，「慎独」最早出自儒家经典《礼记·中庸》。

**【要点拆解】**

1. 任务四项：提高教师道德认识（前提）、陶冶教师道德情感（正义感、自豪感、荣誉感、幸福感）、磨炼教师道德意志、养成良好的教师职业道德行为习惯（最终目的和归宿）。
2. 策略六项：加强学习，坚持继承与创新相结合；勤于实践磨炼，坚持知与行相结合；树立榜样，虚心向他人学习；确立可行目标，坚持不懈努力；学会反思，坚持自律与他律的结合；努力做到「慎独」。
3. 他律与自律：他律是道德形成的初级阶段、是自律的前提和基础；自律是师德修养最有效的形式和最高境界、是他律的发展和升华；师德修养重在自律。
4. 内省：孔子「君子求诸己，小人求诸人」，要求教师经常对自己的思想和行为进行自省并及时纠正。
5. 意义三条：有利于做好教育工作造就新一代人才、有利于教师道德品质完善、有利于弘扬社会主义风尚。

**【答题框架/落点】** 问「如何提高师德修养」按六条策略答；问「修养的任务」按认识—情感—意志—行为习惯四段答；论述可收束到「慎独」与「知行合一」。

**【易混辨析】** 「修养的任务」是**知、情、意、行**四个内部环节，「修养的策略」是**六条外部方法**，两组答案不能互换；「最高层次／最高境界」是慎独，不是自律（自律是「最有效的形式和最高境界」的另一种表述，答题按资料原文区分使用）。

**【真题锚点】** 命题角度：简答「教师职业道德修养的途径」「什么是慎独」，与滨州职业学院 2024「教育家精神的时代内涵」同属教师发展板块。

**【出处】** 高校师德 p24—p27。

### E10 · 教师职业道德评价 ☆

**【必背原文】** 教师职业道德评价是指教师自己、他人或社会，根据社会主义的教师职业道德准则、规范和科学的标准，在系统广泛地搜集各方面信息、充分占有资料的基础上，运用现代技术手段，对教师的职业道德意识、道德情感、道德意志和道德行为进行考察和价值判断。评价标准分善恶标准（一般标准）、具体标准、最高标准（人的全面和自由的发展）。

**【要点拆解】**

1. 评价原则四个：客观性原则、科学性原则、教育性原则、民主性原则。
2. 评价方法五个：自我评价法、学生评价法、社会评价法、加减评分法、模糊综合评判法。
3. 评价基本要求四组结合：肯定评价与否定评价相结合（以肯定评价为主）、动态评价与静态评价相结合、单项评价与综合评价相结合（以综合评价为主）、定量评价与定性评价相结合（以定性评价为主）。
4. 评价目的：探索掌握教师职业道德形成和发展的客观规律，有效指导教师提高职业道德素质、完善职业道德品质。
5. 评价价值三条：维护实现师德规范、促进师德素质形成发展、优化教育教学行为。

**【答题框架/落点】** 名词解释按定义＋三标准；简答「评价原则／方法／基本要求」分别按 4／5／4 分组默写，注意把「三个为主」写出来。

**【易混辨析】** 「评价标准」（善恶／具体／最高）≠「评价原则」（客观／科学／教育／民主）≠「评价方法」（五种），三组词都以「评价」开头，是选择题最高频的混项来源。另「教育性原则」的宗旨是「教育是评价的基础，评价过程是教育过程」。

**【真题锚点】** 命题角度：多选「教师职业道德评价的方法包括」，常与 E09 修养策略混考。

**【出处】** 高校师德 p27—p32。

## 第三部分 · 师德规范与师德师风（E11—E20）

### E11 · 新时代高校教师职业行为十项准则（十条原文）★★★

**【必背原文】** 一、坚定政治方向。坚持以习近平新时代中国特色社会主义思想为指导，拥护中国共产党的领导，贯彻党的教育方针；不得在教育教学活动中及其他场合有损害党中央权威、违背党的路线方针政策的言行。二、自觉爱国守法。忠于祖国，忠于人民，恪守宪法原则，遵守法律法规，依法履行教师职责；不得损害国家利益、社会公共利益，或违背社会公序良俗。三、传播优秀文化。带头践行社会主义核心价值观，弘扬真善美，传递正能量；不得通过课堂、论坛、讲座、信息网络及其他渠道发表、转发错误观点，或编造散布虚假信息、不良信息。四、潜心教书育人。落实立德树人根本任务，遵循教育规律和学生成长规律，因材施教，教学相长；不得违反教学纪律，敷衍教学，或擅自从事影响教育教学本职工作的兼职兼薪行为。五、关心爱护学生。严慈相济，诲人不倦，真心关爱学生，严格要求学生，做学生良师益友；不得要求学生从事与教学、科研、社会服务无关的事宜。六、坚持言行雅正。为人师表，以身作则，举止文明，作风正派，自重自爱；不得与学生发生任何不正当关系，严禁任何形式的猥亵、性骚扰行为。七、遵守学术规范。严谨治学，力戒浮躁，潜心问道，勇于探索，坚守学术良知，反对学术不端；不得抄袭剽窃、篡改侵吞他人学术成果，或滥用学术资源和学术影响。八、秉持公平诚信。坚持原则，处事公道，光明磊落，为人正直；不得在招生、考试、推优、保研、就业及绩效考核、岗位聘用、职称评聘、评优评奖等工作中徇私舞弊、弄虚作假。九、坚守廉洁自律。严于律己，清廉从教；不得索要、收受学生及家长财物，不得参加由学生及家长付费的宴请、旅游、娱乐休闲等活动，或利用家长资源谋取私利。十、积极奉献社会。履行社会责任，贡献聪明才智，树立正确义利观；不得假公济私，擅自利用学校名义或校名、校徽、专利、场所等资源谋取个人利益。

**【要点拆解】**

1. 制定目的（必背导语）：进一步增强教师的责任感、使命感、荣誉感，规范职业行为，明确师德底线，引导广大教师努力成为有理想信念、有道德情操、有扎实学识、有仁爱之心的好老师，着力培养德智体美劳全面发展的社会主义建设者和接班人。
2. 十条结构：每条都是「正面要求＋『不得』底线」两段式，答题时**必须把「不得」写出来**，只写前半句会被判答案不完整。
3. 记忆分组：一—三讲**方向与守法**（政治、爱国、文化），四—六讲**育人与师生**（教学、关爱、言行），七—九讲**学术与廉洁**（学术、公平、廉洁），十讲**社会与义利**。
4. 与「四有」的对应：准则导语把「四有好老师」写进制定目的，答「如何践行准则」可回扣 E24。
5. 高频单条：第六条「严禁任何形式的猥亵、性骚扰行为」、第八条「招生、考试、推优、保研、就业及绩效考核、岗位聘用、职称评聘、评优评奖」的列举、第十条「校名、校徽、专利、场所」的列举，都是多选原文题的取材点。

**【答题框架/落点】** 简答「十项准则」按十条顺序默写，每条写「标题＋正面句＋不得句」；案例题先用准则条款给行为定性，再写处理依据（E16）。

**【易混辨析】** 十项准则（2018 年、十条、底线式、带「不得」）≠ 高等学校教师职业道德规范（2011 年、六条、倡导式、无逐条「不得」）≠ 中小学教师职业道德规范（2008 年修订）。三者名称都含「教师职业/职业道德规范」，务必按年份与条数区分。

**【真题锚点】** 山东服装职业学院 2023 简答「积极奉献社会的内涵」即第十条原题；滨州职业学院 2024 下午场简答「教育家精神的时代内涵」与本条同属滨州卷教师板块；命题角度：案例「教师收受家长礼品／与学生发生不正当关系／抄袭成果」要求指出违反哪条准则。

**【出处】** 师德考点 p6—p7、p17；高频速记 p12—p14；职教必背 p101—p102。

### E12 · 十项准则的「不得」红线归类 ★

**【必背原文】** 十项准则每条后半句均为师德底线，资料包将其概括为「明确师德底线」，并要求各地各校「制定具体化的教师职业行为负面清单及失范行为处理办法」。

**【要点拆解】**

| 红线类型 | 对应条款 | 典型失范表现 |
| --- | --- | --- |
| 政治与言论 | 一、三 | 损害党中央权威、发表转发错误观点、编造散布虚假信息 |
| 国家利益与公序良俗 | 二 | 损害国家利益、社会公共利益，违背社会公序良俗 |
| 教学纪律 | 四、五 | 敷衍教学、擅自兼职兼薪、要求学生从事与教学科研社会服务无关事宜 |
| 师生关系 | 六 | 与学生发生不正当关系、猥亵、性骚扰 |
| 学术与公平 | 七、八 | 抄袭剽窃、篡改侵吞、招生考试推优保研就业评聘中徇私舞弊 |
| 廉洁与义利 | 九、十 | 收受财物、参加家长付费宴请旅游娱乐、假公济私、擅用学校资源谋私利 |

1. 「负面清单」是把十项准则的「不得」细化为本校可操作条款，属于准则学习贯彻的第二步（见 E13）。
2. 案例题答题顺序：先定性（违反第几条）→ 再引「不得」原文 → 再写处理（E16 一票否决／零容忍）→ 最后写整改与长效机制。
3. 第六条用「严禁」而非「不得」，是十条中唯一使用「严禁」的表述，属高频填空点。

**【答题框架/落点】** 材料分析题先按上表把行为归到红线类型，再逐条对应准则序号，避免只写道德评价不引条款。

**【易混辨析】** 「师德底线」（E15 的自重、自省、自警、自励）是**个人修养口径**，十项准则的「不得」是**制度红线口径**，问「师德底线是什么」答前者，问「准则禁止什么」答后者。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」与第六条、第五条同属案例题素材；命题角度：给一段教师行为描述，要求「指出违反了十项准则的哪一条」。

**【出处】** 师德考点 p6—p7、p16；高频速记 p12—p14。

### E13 · 十项准则的学习贯彻与「一票否决」 ☆

**【必背原文】** 各地各校要立即行动，结合落实师德师风建设长效机制，开展准则的学习贯彻；结合本地区、本学校实际进行细化，制定具体化的教师职业行为负面清单及失范行为处理办法。要把好教师入口关，在教师招聘、引进时组织开展准则的宣讲，确保每位新入职教师知准则、守底线；要将准则要求体现在教师聘用、聘任合同中，明确有关责任；要强化考核，在教师年度考核、职称评聘、推优评先、表彰奖励等工作中必须进行师德考核，实行师德失范**「一票否决」**；对于发生准则中禁止行为的，要态度坚决，一查到底，依法依规严肃惩处，绝不姑息。

**【要点拆解】**

1. 四步贯彻：立即部署学习贯彻 → 制定负面清单与处理办法 → 落实到教师管理具体工作（入口关、聘用合同、考核）→ 坚决查处违规行为。
2. 三个「必须进」：进招聘宣讲、进聘用（聘任）合同、进年度考核与职称评聘推优评先。
3. 「一票否决」的落点：年度考核、职称评聘、推优评先、表彰奖励。
4. 与《弘扬教育家精神加强新时代高素质专业化教师队伍建设的意见》（2024 年 8 月 6 日）衔接：师德表现作为教师资格准入、招聘引进、职称评聘、导师遴选、评优奖励、项目申报等的**首要要求**。

**【答题框架/落点】** 问「如何把准则落到实处」按四步＋三个「必须进」答；问「一票否决用在哪」直接列四类考核事项。

**【易混辨析】** 「一票否决」（考核环节）≠「零容忍」（查处环节，E16）≠「第一标准」（评价定位，E14）：三者分别对应「怎么用结果」「怎么查行为」「怎么定地位」。

**【真题锚点】** 命题角度：简答「如何在教师管理工作中落实十项准则」，与滨州职业学院 2024 卷教师发展主题相邻。

**【出处】** 师德考点 p16、p11；政策汇编 p7（教育家精神铸魂强师行动）。

### E14 · 师德师风第一标准与四项基本原则 ★

**【必背原文】** 要把**立德树人的成效作为检验学校一切工作的根本标准**，把**师德师风作为评价教师队伍素质的第一标准**，将社会主义核心价值观贯穿师德师风建设全过程。新时代师德师风建设基本原则：坚持正确方向、坚持尊重规律、坚持聚焦重点、坚持继承创新。《关于加强和改进新时代师德师风建设的意见》2019 年 11 月 15 日颁布。

**【要点拆解】**

1. 两个「标准」必须成对背：根本标准（立德树人成效，检验学校一切工作）＋第一标准（师德师风，评价教师队伍素质）。
2. 四原则按「方向—规律—重点—继承」记，注意没有「坚持依法治教」这一条，不要与教育现代化基本原则（E55）混。
3. 《意见》的六大块：总体要求、加强教师队伍思想政治工作、大力提升教师职业道德素养、将师德师风建设要求贯穿教师管理全过程、着力营造全社会尊师重教氛围、推进师德师风建设任务落到实处。
4. 提升师德素养的路径：突出课堂育德、突出规则立德、突出典型树德、突出文化养德（见《意见》第 7—12 条）。
5. 责任主体：各地各校把师德师风建设作为教师队伍建设首要任务，夯实学校主体责任，压实学校主要负责人**第一责任人**责任。

**【答题框架/落点】** 简答「新时代师德师风建设的基本原则」默四条；论述「如何看待师德师风建设」用「两个标准＋四原则＋三个突出＋责任主体」组织。

**【易混辨析】** 「根本标准」（立德树人）与「第一标准」（师德师风）是真题最爱互换的陷阱；另「第一责任人」是学校主要负责人（师德建设），与 E16「党委书记和校长抓师德同责」表述同源但不完全同词，按题干选。

**【真题锚点】** 山东服装职业学院 2023 论述「职业院校如何开展学生道德教育」、滨州职业学院 2024 下午场「教育家精神的时代内涵」，升华句都用「师德师风第一标准」。

**【出处】** 师德考点 p2、p17—p19；高频速记 p15—p16。

### E15 · 师德师风总体目标、师德底线与五个「唯」 ★

**【必背原文】** 新时代师德师风建设总体目标：经过 **5 年左右**努力，基本建立起完备的师德师风建设制度体系和有效的师德师风建设长效机制；教师思想政治素质和职业道德水平全面提升，教师敬业立学、崇德尚美呈现新风貌；教师权益保障体系基本建立，教师安心、热心、舒心、静心从教的良好环境基本形成，师道尊严进一步提振；全社会对教师职业认同度加深，教师政治地位、社会地位、职业地位显著提高，尊师重教蔚然成风。师德底线：**自重、自省、自警、自励**。五个「唯」：唯分数、唯文凭、唯职称、唯论文、唯帽子。

**【要点拆解】**

1. 目标周期「5 年左右」是数字题；「四心」＝安心、热心、舒心、静心；「三地位」＝政治地位、社会地位、职业地位。
2. 师德底线八个字「自重、自省、自警、自励」常作填空；与 E12 的制度红线区分。
3. 五个「唯」在师德师风口径是「唯分数、唯文凭、唯职称、唯论文、唯帽子」；在《深化新时代教育评价改革总体方案》与「坚决克服 5 个唯」口径里是「唯分数、唯升学、唯文凭、唯论文、唯帽子」——**第二项不同**，见易混辨析。
4. 弘扬高尚师德六句：以德立身、以德立学、以德施教、以德育德（四个以德）＋四个相统一（E18）＋争做「四有」好老师＋做「四个引路人」。

**【答题框架/落点】** 问「总体目标」按「周期＋制度体系＋四新风貌＋四心环境＋三地位＋尊师重教」分层默写；问「师德底线」只答八个字。

**【易混辨析】** 五个「唯」两版：师德师风版第二项是「唯职称」，教育评价改革版第二项是「唯升学」。资料包两处都出现，考试按题干出处选，不能自己合并成六个。另「5 年左右」是师德师风目标周期，不要与《职业教育必背考点》里「3 至 5 年」高素质教师队伍建设目标混淆。

**【真题锚点】** 滨州职业学院 2024 单选含「四个全面、五位一体」等政治常识，同一板块常与「5 唯」「九个坚持」混考；命题角度：填空「师德底线是自重、自省、＿＿、＿＿」。

**【出处】** 师德考点 p2—p3；高频速记 p15—p16、p47；职教必背 p103—p104。

### E16 · 师德失范行为处理与「零容忍」 ★

**【必背原文】** 《教育部关于高校教师师德失范行为处理的指导意见》：各高校要严格落实师德建设主体责任，建立完善党委统一领导、党政齐抓共管、牵头部门明确、院（系）具体落实、教师自我约束的工作机制；**党委书记和校长抓师德同责，是师德建设第一责任人**。高校教师要自觉加强师德修养，严格遵守师德规范，严以律己，为人师表，把教书育人和自我修养结合起来，坚持以德立身、以德立学、以德施教、以德育德。《弘扬教育家精神加强新时代高素质专业化教师队伍建设的意见》明确「坚持师德违规**『零容忍』**」：依规依纪依法查处师德违规行为，对群众反映强烈、社会影响恶劣的严重师德违规行为，从严从重给予处理处分；落实教职员工准入查询和从业禁止制度；坚持失责必问、问责必严。

**【要点拆解】**

1. 处理工作机制五句：党委统一领导、党政齐抓共管、牵头部门明确、院（系）具体落实、教师自我约束。
2. 责任主体：高校是师德建设的责任主体，主要负责人是师德建设的第一责任人；党委书记和校长抓师德同责。
3. 处理链条：受理举报 → 调查核实 → 依规依纪依法处理处分 → 通报警示 → 典型案例强化警示教育。
4. 配套制度：教职员工准入查询、从业禁止、师德失范「一票否决」（E13）。
5. 师德建设长效机制的六个抓手（见《意见》）：师德教育、师德宣传、健全师德考核、强化师德监督、注重师德激励、严格师德惩处。

**【答题框架/落点】** 案例题按「定性 → 援引准则条款 → 处理主体与程序 → 长效机制」四段写；简答「高校如何加强师德建设」用六个抓手。

**【易混辨析】** 「一票否决」是考核结果的使用，「零容忍」是查处的态度，「第一责任人」是责任分配，「同责」强调书记与校长并列——四词各有所指，不可互相替换。另「师德失范行为处理」与《教师法》第三十七条「行政处分或者解聘」是政策与法律两个层级，案例题若问「法律依据」要回到 E39。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」、论述「职业院校如何开展学生道德教育」，可延伸到师德失范处理；命题角度：案例「某教师学术不端被举报，学校应如何处理」。

**【出处】** 师德考点 p19—p20、p23、p11、p16；政策汇编 p7。

### E17 · 「破五唯」与教育评价改革 ☆

**【必背原文】** 要深化教育体制改革，健全立德树人落实机制，扭转不科学的教育评价导向，坚决克服**唯分数、唯升学、唯文凭、唯论文、唯帽子**的顽瘴痼疾，从根本上解决教育评价指挥棒问题。《深化新时代教育评价改革总体方案》2020 年 10 月由中共中央、国务院印发，要求改进结果性评价、强化过程性评价、探索增值性评价、健全综合性评价。

**【要点拆解】**

1. 五类改革对象：改革党委和政府教育工作评价、改革学校评价、改进教师评价、改革学生评价、改革用人评价。
2. 教师评价要点：坚持把师德师风作为第一标准、突出教育教学实绩、强化一线学生工作、改进高校教师科研评价、推进人才称号回归学术性荣誉性。
3. 「四个评价」：改进结果评价、强化过程评价、探索增值评价、健全综合评价。
4. 高职院校落点：破除「唯文凭、唯论文、唯帽子、唯身份、唯奖项」，把师德师风、工匠精神、技术技能水平和教育教学实绩作为职称评聘主要依据（见山东实施方案，对应另一篇 S46）。

**【答题框架/落点】** 论述「如何扭转不科学的教育评价导向」按「五唯表现 → 四类评价 → 五类改革 → 职教特色落点」组织。

**【易混辨析】** 「破五唯」（唯分数、唯升学、唯文凭、唯论文、唯帽子）与 E15 师德师风口径的「5 唯」（唯分数、唯文凭、唯职称、唯论文、唯帽子）第二项不同，这是本篇最容易被出题人利用的组内差异。

**【真题锚点】** 济南工程职业技术学院 2023 简答「高等学校教育公平的基本主张」、山东开放大学 2023 论述「对教育目的基本精神的理解」，均可引教育评价改革作措施段。

**【出处】** 高频速记 p47；职教必背 p112—p113；山东实施方案 p4（对应省情篇 S46）。

### E18 · 弘扬高尚师德：四个以德与四个相统一 ★

**【必背原文】** 弘扬高尚师德：健全师德建设长效机制，推动师德建设常态化长效化，创新师德教育，完善师德规范，引导广大教师**以德立身、以德立学、以德施教、以德育德**，坚持**教书与育人相统一、言传与身教相统一、潜心问道与关注社会相统一、学术自由与学术规范相统一**，争做「四有」好教师，全心全意做学生锤炼品格、学习知识、创新思维、奉献祖国的引路人。

**【要点拆解】**

1. 四个以德：立身、立学、施教、育德，按「自身—学问—教学—育人」递进。
2. 四个相统一逐条落点：教书育人相统一（思政课教师核心职业要求，课堂教学是主导环节）；言传身教相统一（人格素质要求，以身作则）；潜心问道与关注社会相统一（专业素养要求，用「四个正确认识」引导学生）；学术自由与学术规范相统一（政治素养要求，保证研究方向）。
3. 四个相统一出自 2016 年 12 月全国高校思想政治工作会议，是「四个引路人」之外另一组高频「四」。
4. 与课程思政衔接：所有课程都有育人功能，所有教师都负育人职责，专业课要上出「思政味」、与思政课同向同行。

**【答题框架/落点】** 问「四个相统一」默四条并各配一句落点；写作题谈「学术自由与学术规范」用第四条＋蔡元培「思想自由、兼容并包」的辨析收束。

**【易混辨析】** 「四个相统一」（师德建设口径）≠「四个引路人」（教师角色口径，E25）≠「四个回归」（回归常识、本分、初心、梦想）≠「四个服务」（教育方针口径）。四组都叫「四」，看题干问的是「师德」「角色」「本科教育」还是「办学方向」。

**【真题锚点】** 济南工程职业技术学院 2023 写作「材料关于学术自由蔡元培，谈理解及对高等学校改革的启示」直接对应第四条；山东商业职业技术学院 2023 简答「课程思政建设的内容」与四个相统一同源。

**【出处】** 师德考点 p3、p7；高频速记 p16、p42—p43；政策汇编 p8、p17（高校思政工作会议讲话）。

### E19 · 新时代职业道德建设实施纲要（2025 年 4 月 21 日）○

**【必背原文】** 《新时代职业道德建设实施纲要》（2025 年 04 月 21 日）总体要求：牢固树立符合中国特色社会主义发展要求、体现新时代特点的职业道德规范，提升职业道德建设科学化、规范化、制度化水平，引导各行业各领域弘扬新风正气，以优良行风带民风、促社风。职业道德基本规范的主要内容：爱岗敬业、诚实守信、办事公道、热情服务、奉献社会。

**【要点拆解】**

1. 三结合原则：坚持继承传统与创新发展相结合、坚持全面推进与分类指导相结合、坚持积极倡导与有效治理相结合。
2. 三大任务块：加强职业道德规范建设、深化职业道德教育、切实加强组织领导。
3. 职业道德基本规范五条：爱岗敬业、诚实守信、办事公道、热情服务、奉献社会（与 E02 教师职业道德八因素不是同一套）。
4. 学校落点：结合基础教育、职业教育、高等教育不同特点，通过课程设置、职业体验、专业培训加强学生职业道德教育，引导学生树立正确劳动观、职业观、就业观。

**【答题框架/落点】** 作为论述题的时代背景句使用，主体答案仍回到十项准则与师德师风第一标准。

**【易混辨析】** 职业道德基本规范（爱岗敬业、诚实守信、办事公道、热情服务、奉献社会）≠ 高校教师职业道德规范六条（E08）≠ 十项准则十条（E11）；三组分别是「各行各业」「高校教师」「新时代教师行为底线」。

**【真题锚点】** 命题角度：选择「新时代职业道德基本规范的内容」，属 2026 新政新增小题；「热情服务、奉献社会」可与十项准则第十条混考。

**【出处】** 师德考点 p13、p15。

### E20 · 教学与科研相统一、经师与人师 ☆

**【必背原文】** 培养人才是大学的第一使命，是大学的根和本；教学侧重于言传，科研侧重于身教，教学与科研如鸟之双翼、车之两轮，是一对需要平衡的辩证关系。「经师」指教师要精通专业知识、成为学术典范；「人师」指教师要涵养德行、润己泽人；教师要努力做精于「传道授业解惑」的「经师」和「人师」的统一者。

**【要点拆解】**

1. 洪堡提出「教学与科研相统一」原则，成为现代大学的基本标志；教学与科研相结合是高等学校普遍实行的教学原则和办学方针。
2. 科研对人才培养的作用：面向未知世界、探索未知知识、解决真实问题，拓展学生素质结构、提升人才培养质量。
3. 经师与人师统一的两条路径：以「经师」之「才」促「人师」之「德」（学高为师），以「人师」之「德」帅「经师」之「才」（身正为范）；「经师易求，人师难得」。
4. 平衡教学与科研三条：以科研为基础实现教学科研一体化；科研是提高教学质量的关键；要围绕教学搞科研（科研是源，教学是流）。

**【答题框架/落点】** 写作题「如何理解高校教师的教学与科研」按「洪堡原则 → 辩证关系 → 两条统一路径 → 三条平衡措施」组织。

**【易混辨析】** 「经师与人师」讲**教师个体**的才德统一；「教书与育人相统一」（E18）讲**职业行为**的两个侧面；「四个引路人」讲**对学生的四个角色**，三者常被合成一道多选题，需按「教师／行为／学生」区分。

**【真题锚点】** 济南工程职业技术学院 2023 写作「蔡元培学术自由与高等学校改革」、山东政法学院 2022 论述「从工作岗位谈对一段话的理解」，均可引经师人师；命题角度：简答「如何做经师和人师的统一者」。

**【出处】** 师德考点 p4、p7—p9；职教必背 p107—p110。

### E21 · 教育家精神六内涵 ★★★

**【必背原文】** 2023 年 9 月，在第三十九个教师节前夕，习近平总书记致信全国优秀教师代表，首次提出并阐述了中国特有的教育家精神，六个内涵为：**心有大我、至诚报国的理想信念；言为士则、行为世范的道德情操；启智润心、因材施教的育人智慧；勤学笃行、求是创新的躬耕态度；乐教爱生、甘于奉献的仁爱之心；胸怀天下、以文化人的弘道追求**。

**【要点拆解】**

1. 六条按「理想信念—道德情操—育人智慧—躬耕态度—仁爱之心—弘道追求」顺序背，前两条讲「方向与德行」，中间两条讲「智慧与态度」，后两条讲「情感与境界」。
2. 六个维度（E22）一一对应：信念之维、德行之维、学识之维、态度之维、情感之维、境界之维。
3. 首次提出时间与场合：2023 年 9 月、第三十九个教师节前夕、致信全国优秀教师代表；资料包另注「2025 年是第四十一个教师节」。
4. 践行路径三条：以师德师风学习为先导，铸牢从教信念之基；以专业能力培养为核心，夯实从教素养之本；以教育实践训练为底色，扎下从教立身之根。
5. 记忆锚：每条都是「四字＋四字」的对偶结构，写错一个字即失分，必须逐字默写。

**【答题框架/落点】** 简答「教育家精神的时代内涵」（滨州职院 2024 原题）按六条逐条写「原句＋一句维度解释」；论述再补「四大坚持」（E23）与教师个人、学校制度两层落点。

**【易混辨析】** 教育家精神（六内涵，面向教师）≠ 三大精神（劳模精神、劳动精神、工匠精神，面向劳动者）≠ 四有好老师（四项，面向好老师标准）。另「心有大我、至诚报国」不可写成「心有大我、至诚报效」，「弘道追求」不可写成「宏道追求」。

**【真题锚点】** 滨州职业学院 2024 下午场简答「教育家精神的时代内涵」原题；山东幼儿师范高等专科学校 2024 论述「新时代中国教育应培养什么样的人」可用六内涵作教师端论据。

**【出处】** 师德考点 p1—p2、p10；高频速记 p7—p12；职教必背 K41（p78 附近）。

### E22 · 教育家精神六个维度与逐条阐释 ★

**【必背原文】** 心有大我、至诚报国的理想信念体现了教育家精神的**信念之维**；言为士则、行为世范的道德情操体现了**德行之维**；启智润心、因材施教的育人智慧体现了**学识之维**；勤学笃行、求是创新的躬耕态度体现了**态度之维**；乐教爱生、甘于奉献的仁爱之心体现了**情感之维**；胸怀天下、以文化人的弘道追求体现了**境界之维**。

**【要点拆解】**

| 内涵 | 维度 | 阐释关键词 |
| --- | --- | --- |
| 心有大我、至诚报国 | 信念之维 | 家国天下、「大我」与「小我」、为党育人为国育才、意识形态阵地 |
| 言为士则、行为世范 | 德行之维 | 以身示范、以身作则、社会风气与道德的影响者塑造者 |
| 启智润心、因材施教 | 学识之维 | 教育机智、创造性运用教育规律、激发内在潜能、春风化雨润物无声 |
| 勤学笃行、求是创新 | 态度之维 | 学习型社会、终身学习、知行合一、应对大数据人工智能对「知识权威」的挑战 |
| 乐教爱生、甘于奉献 | 情感之维 | 唯有热爱可抵岁月漫长、保持教育的温度与教学活力 |
| 胸怀天下、以文化人 | 境界之维 | 天下为公、人类命运共同体、坚定文化自信、弘扬全人类共同价值 |

1. 六维度是「以文化人」式的分维命名，答论述时每条配 1—2 个关键词即可，不必整段背。
2. 信念之维的核心句：教师不应仅仅把教育看作谋生的职业，应把「小我」凝聚升华为国家繁荣富强的「大我」。
3. 态度之维的时代背景句：大数据、人工智能、云计算、虚拟现实等新一代信息技术快速发展，教师「知识权威」角色面临前所未有的挑战。

**【答题框架/落点】** 论述「高校教师如何践行教育家精神」：六条内涵＋六维度＋三条践行路径＋落到课堂教学、科学研究、社会实践各环节。

**【易混辨析】** 「维度」是对六内涵的**学理命名**（信念／德行／学识／态度／情感／境界），不是另一套六条；若题干问「六个内涵」答原句，问「从哪几个维度理解」答六个之维。

**【真题锚点】** 滨州职业学院 2024 下午场简答「教育家精神的时代内涵」可加六维度提分；命题角度：论述「结合人工智能时代谈勤学笃行、求是创新」。

**【出处】** 师德考点 p1—p2；高频速记 p10—p12。

### E23 · 弘扬教育家精神四大坚持与高素质专业化教师队伍目标 ★

**【必背原文】** 弘扬教育家精神的**四大坚持**：坚持教育家精神铸魂强师（引导广大教师坚定心有大我、至诚报国的理想信念，陶冶言为士则、行为世范的道德情操，涵养启智润心、因材施教的育人智慧，秉持勤学笃行、求是创新的躬耕态度，勤修乐教爱生、甘于奉献的仁爱之心，树立胸怀天下、以文化人的弘道追求，践行教师群体共同价值追求）；坚持教育家精神培育涵养（融入教师培养、发展，构建日常浸润、项目赋能、平台支撑的教师发展良好生态）；坚持教育家精神弘扬践行（贯穿教师课堂教学、科学研究、社会实践等各环节，筑牢践行主阵地）；坚持教育家精神引领激励（建立完善教师标准体系，纳入教师管理评价全过程）。

**【要点拆解】**

1. 四大坚持的动词：铸魂强师 → 培育涵养 → 弘扬践行 → 引领激励，按「立魂—养成—落地—制度」递进。
2. 《中共中央国务院关于弘扬教育家精神加强新时代高素质专业化教师队伍建设的意见》**出台时间 2024 年 8 月 6 日**，目的：大力弘扬教育家精神，加强新时代高素质专业化教师队伍建设，进一步营造尊师重教良好氛围。
3. 队伍总目标：打造一支**师德高尚、业务精湛、结构合理、充满活力**的高素质专业化教师队伍。
4. 具体目标双时点：经过 **3 至 5 年**努力，教育家精神得到大力弘扬，尊师重教社会氛围更加浓厚；到 **2035 年**，教育家精神成为广大教师的自觉追求，实现教师队伍治理体系和治理能力现代化，数字化赋能教师发展成为常态，教师成为最受社会尊重和令人羡慕的职业之一。
5. 思政与师德要求纳入教师聘用合同；师德表现作为教师资格准入、招聘引进、职称评聘、导师遴选、评优奖励、项目申报等的首要要求；师德违规「零容忍」。

**【答题框架/落点】** 简答「如何弘扬教育家精神」默四大坚持；论述「如何建设高素质专业化教师队伍」按「总目标＋双时点＋四大坚持＋零容忍」组织。

**【易混辨析】** 「四大坚持」（弘扬路径）≠「四个相统一」（师德行为）≠「四个引路人」（教师角色）；「3 至 5 年」是队伍建设目标周期，「5 年左右」是师德师风建设目标周期（E15），两者不是同一文件。

**【真题锚点】** 滨州职业学院 2024 下午场简答「教育家精神的时代内涵」可延伸考四大坚持；命题角度：简答「弘扬教育家精神的四大坚持」。

**【出处】** 师德考点 p2、p9—p13；高频速记 p12；政策汇编 p7。

### E24 · 四有好老师 ★

**【必背原文】** **有理想信念、有道德情操、有扎实学识、有仁爱之心**。2014 年 9 月 9 日，习近平总书记在同北京师范大学师生代表座谈时发表重要讲话，就「怎样才能成为好老师」首次提出这一精准回答；此后在建设教育强国集体学习中提出「坚定理想信念、陶冶道德情操、涵养扎实学识、勤修仁爱之心」，是对「四有」好老师的新阐释和新发展。

**【要点拆解】**

1. 四条各自的育人导向：有理想信念＝实现中国梦的思想基础、思想育人导向；有道德情操＝教书育人的前提条件、道德育人导向；有扎实学识＝对教师的起码要求、知识育人导向；有仁爱之心＝教师从事职业所需、和谐育人导向。
2. 四个新动词：坚定、陶冶、涵养、勤修，分别对应理想信念、道德情操、扎实学识、仁爱之心，是 2026 新政高频填空点。
3. 经典句：「学生往往可以原谅老师严厉刻板，但不能原谅老师学识浅薄」；「捧着一颗心来，不带半根草去」；「教育是一门『仁而爱人』的事业，爱是教育的灵魂，没有爱就没有教育」。
4. 落点：十项准则的制定目的就是「引导广大教师努力成为有理想信念、有道德情操、有扎实学识、有仁爱之心的好老师」，E11 与 E24 可互相引用。

**【答题框架/落点】** 名词解释默四条；简答「如何成为四有好老师」按四条各配「导向＋一句经典＋教师做法」；论述收束到「经师与人师统一者」「大先生」。

**【易混辨析】** 四有好老师（四项标准，2014 年北师大）≠ 四个引路人（四个角色，E25）≠ 四点希望（面向青年学生，E27）≠ 四个相统一（师德行为，E18）。「四有」的第三项是「扎实学识」，资料包有的页面写「扎实知识」，按「四有」标准表述用「扎实学识」。

**【真题锚点】** 山东政法学院 2022 论述「培养什么样的人，理想信念，四个自信」、济南幼儿师范高等专科学校 2024 论述「新时代中国教育应培养什么样的人」，教师端论据均可用四有；命题角度：填空「坚定理想信念、＿＿道德情操、＿＿扎实学识、＿＿仁爱之心」。

**【出处】** 师德考点 p3；高频速记 p41；职教必背 p113—p114；政策汇编 p155—p158（北师大座谈讲话）。

### E25 · 四个引路人 ★

**【必背原文】** 广大教师要做学生**锤炼品格的引路人**，做学生**学习知识的引路人**，做学生**创新思维的引路人**，做学生**奉献祖国的引路人**。

**【要点拆解】**

1. 四个角色按「品格—知识—创新—祖国」记，分别对应德育、智育、创新教育、爱国主义教育。
2. 逐条落点：锤炼品格＝培养健全人格和良好道德品质、传承中华优秀传统文化、教师自身以身作則；学习知识＝深厚学识功底、教会学习方法、激发学习兴趣、扮演引导者帮助者参与者；创新思维＝鼓励敢于创新甚至犯错、接纳学生新观点、敢于让学生超越自己；奉献祖国＝激发爱国情怀、树立远大理想、致力民族复兴。
3. 与高校规范「教书育人」条、十项准则第四条「潜心教书育人」互为表里。

**【答题框架/落点】** 简答「四个引路人」默四条＋各一句落点；论述可接「四有」→「四引」→「四统一」形成教师形象三段论。

**【易混辨析】** 「四个引路人」的对象是**学生**、落点是**教师角色**；「四点希望」（E27）的对象也是**青年学生**但内容是爱国／励志／求真／力行，是**对学生的要求**不是对教师的角色描述，二者极易混。

**【真题锚点】** 山东政法学院 2022 论述「从工作岗位看，对一段话的理解，大约是培养什么样的人、理想信念、四个自信」，与四个引路人同板块；命题角度：多选「四个引路人包括」。

**【出处】** 师德考点 p3、p7；高频速记 p41；职教必背 p114—p115。

### E26 · 四个相统一（师德建设口径）★

**【必背原文】** 坚持**教书与育人相统一、言传与身教相统一、潜心问道与关注社会相统一、学术自由与学术规范相统一**。引导广大教师以德立身、以德立学、以德施教，不断加强师德师风建设，广大教师才能更好地完成塑造灵魂、塑造生命、塑造新人的时代使命。

**【要点拆解】**

1. 四条逐条定位：教书育人相统一＝对思政课教师的核心职业要求，课堂教学是主导环节；言传身教相统一＝人格素质要求，先深入学习真正理解坚定信仰马克思主义；潜心问道与关注社会相统一＝专业素养要求，用「四个正确认识」引导学生；学术自由与学术规范相统一＝政治素养要求，保证马克思主义理论研究和思想政治教育的正确方向。
2. 四个正确认识：正确认识世界和中国发展大势、中国特色和国际比较、时代责任和历史使命、远大抱负和脚踏实地。
3. 出处：2016 年 12 月 7 日全国高校思想政治工作会议；同时是 E18「弘扬高尚师德」的组成句。

**【答题框架/落点】** 简答默四条；论述「如何加强师德师风建设」把四条与「四个以德」合用。

**【易混辨析】** 本条与 E18 内容同源，差别在 E18 侧重「弘扬高尚师德」的完整表述，E26 侧重四条各自的**修养定位**（核心职业要求／人格素质／专业素养／政治素养）；另资料包《职教必背》p116 给出另一种「政治素养与道德品质的统一、知识传授与价值引领的统一、个人成长与国家利益的统一、理论学习与实践活动的统一」的概括表述，两种表述都记，**考试按题干选**，不得混写成八条。

**【真题锚点】** 济南工程职业技术学院 2023 写作「蔡元培学术自由」直接对应第四条；山东商业职业技术学院 2023 简答「课程思政建设的内容」可用「教书与育人相统一」。

**【出处】** 高频速记 p16、p42—p43；职教必背 p116—p117；政策汇编 p8、p17。

### E27 · 四点希望与六个下功夫（易混重点）★★

**【必背原文】** **四点希望**（五四青年节前夕北京大学师生座谈，面向全国青年）：一是要爱国，忠于祖国，忠于人民；二是要励志，立鸿鹄志，做奋斗者；三是要求真，求真学问，练真本领；四是要力行，知行合一，做实干家。**六个下功夫**（《全国教育大会》）：要在坚定理想信念上下功夫；要在厚植爱国主义情怀上下功夫；要在加强品德修养上下功夫；要在增长知识见识上下功夫；要在培养奋斗精神上下功夫；要在增强综合素质上下功夫。

**【要点拆解】**

1. 六个下功夫逐条关键词：坚定理想信念（共产主义远大理想、中国特色社会主义共同理想、四个自信）、厚植爱国主义情怀（听党话跟党走、扎根人民奉献国家）、加强品德修养（社会主义核心价值观、大爱大德大情怀）、增长知识见识（求真理悟道理明事理）、培养奋斗精神（刚健有为、自强不息）、增强综合素质（含健康第一、美育、劳动精神三个子要求）。
2. 「增强综合素质」条内含三个「要」：树立健康第一的教育理念开齐开足体育课；全面加强和改进学校美育，坚持以美育人、以文化人；在学生中弘扬劳动精神，懂得劳动最光荣、最崇高、最伟大、最美丽。
3. 两组都是「四／六」数字题，出题人常把「四点希望」混进「六个下功夫」的选项。

**【答题框架/落点】** 问「六个下功夫」按六条默并带上「增强综合素质」的三个子要求；问「对青年提出的四点希望」只答爱国／励志／求真／力行。

**【易混辨析】** 四点希望＝**对青年学生**的四条要求（爱国、励志、求真、力行）；六个下功夫＝**教育工作的六个着力点**（理想信念、爱国情怀、品德修养、知识见识、奋斗精神、综合素质）；四个引路人＝**教师角色**；四有好老师＝**教师标准**。四组「四／六」务必按「对象＋数字＋内容」三要素区分。

**【真题锚点】** 山东政法学院 2022 论述「培养什么样的人，理想信念，四个自信」与六个下功夫第一条同源；日照工业学校 2023 判断「孔子教育思想」「德育原则」属同板块；命题角度：多选「下列属于六个下功夫的是」。

**【出处】** 高频速记 p41—p42、p48；职教必背 p115、p117—p118。

### E28 · 思政课教师「六要」、思政队伍数字与心理健康「四位一体」☆

**【必背原文】** 建设一支**政治强、情怀深、思维新、视野广、自律严、人格正**的思政课教师队伍。思政课教师「六要」：政治要强、情怀要深、思维要新、视野要广、自律要严、人格要正。办好思想政治理论课关键在教师，关键在发挥教师的积极性、主动性、创造性；思政课的本质是讲道理，把道理讲深、讲透、讲活；推动思政课改革创新要不断增强思想性、理论性和亲和力、针对性，坚持「八个相统一」（政治性和学理性、价值性和知识性、建设性和批判性、理论性和实践性、统一性和多样性、主导性和主体性、灌输性和启发性、显性教育和隐性教育相统一）。

**【要点拆解】**

| 数字考点 | 内容 |
| --- | --- |
| 师生比 1:350 | 高校按不低于 1:350 核定专职思政课教师岗位 |
| 每生每年 40 元／30 元 | 本科院校不低于 40 元、专科院校不低于 30 元提取思政课教师专项经费 |
| 心理健康「四位一体」 | 健康教育、监测预警、咨询服务、干预处置的学生心理健康工作体系 |
| 心理健康队伍 | 以专职教师为骨干，专兼结合、专业互补、相对稳定、素质较高 |

1. 思政课「六要」与教师队伍建设「六字标准」（政治强、情怀深、思维新、视野广、自律严、人格正）是同一组内容的表述变体，都可背。
2. 「八个相统一」是思政课改革创新的方法论，与 E26「四个相统一」不同，数字不同、对象不同。
3. 心理健康工作体系在《教育强国建设规划纲要》中的表述：普及心理健康教育，建立全国学生心理健康监测预警系统，分学段完善服务工作机制（见 E57）。

**【答题框架/落点】** 填空「1:350」「40 元／30 元」按上表；简答「思政课教师六要」默六条；案例「学生心理危机」用四位一体作答。

**【易混辨析】** 「六要」（思政课教师）≠「六个下功夫」（教育工作）≠「四有」（好老师）≠「八个相统一」（思政课教学方法）≠「四个相统一」（师德）；40 元是本科、30 元是专科，勿颠倒。

**【真题锚点】** 山东政法学院 2022 简答「思政金课的理解」直接对应本条；命题角度：填空「高校专职思政课教师岗位师生比不低于 1:＿＿」。

**【出处】** 师德考点 p5、p8；政策汇编 p160—p161（思政课教师座谈会讲话）；高频速记 p42。

## 第五部分 · 教育法律法规（E29—E45）

本部分条文一律以资料包《教育法律法规核心考点》收录的现行文本为准。命题以「权利义务」「施行日期」「法律责任」「数字期限」四类为主，务必逐字记。

### E29 · 中华人民共和国教育法（总则与基本制度）★

**【必背原文】** 《中华人民共和国教育法》1995 年 3 月 18 日第八届全国人民代表大会第三次会议通过，根据 2009 年 8 月 27 日、2015 年 12 月 27 日、2021 年 4 月 29 日三次修正；**自 1995 年 9 月 1 日起施行**。第五条：教育必须为社会主义现代化建设服务、为人民服务，必须与生产劳动和社会实践相结合，培养德智体美劳全面发展的社会主义建设者和接班人。第六条：教育应当坚持立德树人，对受教育者加强社会主义核心价值观教育，增强受教育者的社会责任感、创新精神和实践能力。第八条：教育活动必须符合国家和社会公共利益；国家实行教育与宗教相分离。第九条：中华人民共和国公民有受教育的权利和义务，公民不分民族、种族、性别、职业、财产状况、宗教信仰等，依法享有平等的受教育机会。

**【要点拆解】**

| 条款 | 必记内容 |
| --- | --- |
| 第十七条 | 国家实行学前教育、初等教育、中等教育、高等教育的学校教育制度 |
| 第十九条 | 国家实行九年制义务教育制度 |
| 第二十条 | 国家实行职业教育制度和成人教育制度 |
| 第二十一条 | 国家实行国家教育考试制度 |
| 第二十二条 | 国家实行学业证书制度 |
| 第二十三条 | 国家实行学位制度 |
| 第二十五条 | 国家实行教育督导制度和学校及其他教育机构教育评估制度 |

1. 《教育法》是我国教育工作的**根本大法**，是依法治教的根本大法，标志我国教育工作进入全面依法治教的新阶段。
2. 教育方针三句：为社会主义现代化建设服务、为人民服务、与生产劳动和社会实践相结合，落点是培养德智体美劳全面发展的社会主义建设者和接班人。
3. 教育与宗教相分离、任何组织和个人不得利用宗教进行妨碍国家教育制度的活动，是高频判断点。
4. 设立学校四项基本条件：有组织机构和章程；有合格的教师；有符合规定标准的教学场所及设施、设备等；有必备的办学资金和稳定的经费来源。

**【答题框架/落点】** 问「教育基本制度」按上表七项默；问「教育方针」答第五条原文；论述「依法治教」以《教育法》为根本大法起笔。

**【易混辨析】** 资料包「政策汇编第三篇」收录的是早期《教育法》文本（第五条为「德、智、体等方面」、条文号与现行版不同），「法规核心」收录的是 2021 年三次修正后的现行文本（第五条为「德智体美劳」）。**答题一律用现行版**；若题干问「1995 年版第五条」，才用早期表述。

**【真题锚点】** 山东开放大学 2023 论述「对教育目的基本精神的理解」即第五条；日照工业学校 2023 选择含「教育法规」；山东商业职业技术学院 2023 简答「新职教法对人才培养的目标与要求」可回扣教育方针。

**【出处】** 法规核心 p1—p2；政策汇编 p169—p175（早期版本，供版本辨析）。

### E30 · 教育法：学校的权利与义务 ★

**【必背原文】** 第二十九条 学校及其他教育机构行使下列权利：（一）按照章程自主管理；（二）组织实施教育教学活动；（三）招收学生或者其他受教育者；（四）对受教育者进行学籍管理，实施奖励或者处分；（五）对受教育者颁发相应的学业证书；（六）聘任教师及其他职工，实施奖励或者处分；（七）管理、使用本单位的设施和经费；（八）拒绝任何组织和个人对教育教学活动的非法干涉；（九）法律、法规规定的其他权利。第三十条 学校及其他教育机构应当履行下列义务：（一）遵守法律、法规；（二）贯彻国家的教育方针，执行国家教育教学标准，保证教育教学质量；（三）维护受教育者、教师及其他职工的合法权益；（四）以适当方式为受教育者及其监护人了解受教育者的学业成绩及其他有关情况提供便利；（五）遵照国家有关规定收取费用并公开收费项目；（六）依法接受监督。

**【要点拆解】**

1. 权利 9 条、义务 6 条，数字要记牢；记忆口诀「权利：章、教、招、籍、证、聘、财、拒、其他」。
2. 学校具备法人条件的，自批准设立或者登记注册之日起取得法人资格（第三十二条）。
3. 学校权利中的「拒绝非法干涉」与「自主管理」是公办高职「办学自主权」的法律源头，可与山东省职业教育条例第二十八条（另一篇 S39）串联。
4. 义务中「公开收费项目」「依法接受监督」是案例题常考的两条。

**【答题框架/落点】** 简答「学校的权利和义务」分两栏默；案例「学校违规收费／拒绝公开信息」定位到义务第（五）（六）项。

**【易混辨析】** 「学校权利」≠「教师权利」（E36）≠「学生权利」（E31/E43）：三者的第一条都涉及教育教学活动，但主体不同；「对受教育者进行学籍管理、实施奖励或者处分」是**学校**权利，不是教师权利。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」的对照面即学校义务；命题角度：多选「下列属于学校及其他教育机构权利的是」。

**【出处】** 法规核心 p2—p3；政策汇编 p171（早期版本第二十八、二十九条）。

### E31 · 教育法：受教育者的权利与义务 ★

**【必背原文】** 第四十三条 受教育者享有下列权利：（一）参加教育教学计划安排的各种活动，使用教育教学设施、设备、图书资料；（二）按照国家有关规定获得奖学金、贷学金、助学金；（三）在学业成绩和品行上获得公正评价，完成规定的学业后获得相应的学业证书、学位证书；（四）对学校给予的处分不服向有关部门提出申诉，对学校、教师侵犯其人身权、财产权等合法权益，提出申诉或者依法提起诉讼；（五）法律、法规规定的其他权利。第四十四条 受教育者应当履行下列义务：（一）遵守法律、法规；（二）遵守学生行为规范，尊敬师长，养成良好的思想品德和行为习惯；（三）努力学习，完成规定的学习任务；（四）遵守所在学校或者其他教育机构的管理制度。

**【要点拆解】**

1. 权利 5 条、义务 4 条；权利第（四）项含两条救济路径：对处分不服→申诉；对人身权财产权受侵害→申诉或依法提起诉讼。
2. 第三十七条：受教育者在入学、升学、就业等方面依法享有平等权利；第三十八条：国家、社会对家庭经济困难的儿童、少年、青年提供各种形式的资助；第四十一条：从业人员有依法接受职业培训和继续教育的权利和义务。
3. 第四十条：国家、社会、家庭、学校及其他教育机构应当为有违法犯罪行为的有违法行为的未成年人接受教育创造条件——这是《预防未成年人犯罪法》在《教育法》里的接口（见 E45）。

**【答题框架/落点】** 案例「教师侵犯学生权利」按「定性（人身权／财产权／受教育权）→ 引第四十三条 → 救济路径 → 教师法第三十七条责任」四段写。

**【易混辨析】** 教育法第四十三条（受教育者权利，5 条）≠《普通高等学校学生管理规定》学生权利（7 条，E43）：后者更细，含社会实践、创新创业、参与学校管理、知情权参与权表达权监督权等，考试按题干问的是「教育法」还是「学生管理规定」选。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」原题；济南工程职业技术学院 2023 简答「高等学校教育公平的基本主张」可用第三十七条。

**【出处】** 法规核心 p4；政策汇编 p172（早期版本第四十二、四十三条）。

### E32 · 教育法：教师条款与法律责任 ★

**【必背原文】** 第三十三条 教师享有法律规定的权利，履行法律规定的义务，忠诚于人民的教育事业。第三十四条 国家保护教师的合法权益，改善教师的工作条件和生活条件，提高教师的社会地位；教师的工资报酬、福利待遇，依照法律、法规的规定办理。第三十五条 国家实行**教师资格、职务、聘任制度**，通过考核、奖励、培养和培训，提高教师素质，加强教师队伍建设。第八十一条 违反本法规定，侵犯教师、受教育者、学校或者其他教育机构的合法权益，造成损失、损害的，应当依法承担**民事责任**。

**【要点拆解】**

1. 法律责任章高频条款：不按预算核拨教育经费→限期核拨、情节严重给予行政处分；扰乱教育教学秩序、破坏校舍场地财产→公安机关治安管理处罚、构成犯罪追究刑事责任；明知校舍或教育教学设施有危险而不采取措施造成人员伤亡或重大财产损失→**追究刑事责任**；违规举办学校→撤销、没收违法所得、行政处分；违规颁发学位学历证书→宣布证书无效、责令收回或没收、情节严重取消颁发资格。
2. 冒名顶替入学资格（第七十七条）：停止参加相关国家教育考试**二年以上五年以下**；与他人串通允许他人冒用本人身份的，停止参加相关国家教育考试**一年以上三年以下**；入学资格被顶替权利受侵害的，可以请求恢复其入学资格。
3. 考试作弊（第七十九条）：取消相关考试资格或成绩；情节严重的责令停止参加相关国家教育考试**一年以上三年以下**；五类作弊行为（非法获取试题答案、携带使用作弊器材资料、抄袭他人答案、让他人代替自己参加考试、其他不正当手段）。

**【答题框架/落点】** 案例「校舍危房致伤亡」「冒名顶替上学」「考试作弊」分别定位第七十三、七十七、七十九条并写出处理档次。

**【易混辨析】** 「行政处分」（对内部人员）≠「行政处罚」（对行政相对人）≠「民事责任」（赔偿损失）≠「刑事责任」（构成犯罪）；另「二年以上五年以下」是盗用冒用他人身份顶替者，「一年以上三年以下」是允许他人冒用本人身份者和考试作弊情节严重者，三个数字不能互换。

**【真题锚点】** 山东开放大学 2023 单选「礼已具备法的性质」「法的性质」属法理板块；命题角度：案例「顶替他人取得入学资格如何处理」。

**【出处】** 法规核心 p3、p5—p7。

### E33 · 中华人民共和国高等教育法（总则、基本制度、设立与组织）★

**【必背原文】** 1998 年 8 月 29 日第九届全国人民代表大会常务委员会第四次会议通过，根据 2015 年 12 月 27 日、2018 年 12 月 29 日两次修正；**自 1999 年 1 月 1 日起施行**。第二条：本法所称高等教育，是指在完成高级中等教育基础上实施的教育。第五条：高等教育的任务是培养具有社会责任感、创新精神和实践能力的高级专门人才，发展科学技术文化，促进社会主义现代化建设。第十一条：高等学校应当面向社会，依法自主办学，实行民主管理。第三十九条：国家举办的高等学校实行**中国共产党高等学校基层委员会领导下的校长负责制**。第六十八条：本法所称高等学校是指大学、独立设置的学院和高等专科学校，其中包括**高等职业学校和成人高等学校**。

**【要点拆解】**

1. 高等学历教育分为专科教育、本科教育和研究生教育；专科基本修业年限**二至三年**，本科**四至五年**，硕士研究生**二至三年**，博士研究生**三至四年**。
2. 设立审批（第二十九条）：实施本科及以上教育的高等学校由国务院教育行政部门审批；实施专科教育的高等学校由省、自治区、直辖市人民政府审批，报国务院教育行政部门备案；其他高等教育机构由省级教育行政部门审批。
3. 高等学校自批准设立之日起取得法人资格，校长为法定代表人；校长全面负责教学、科学研究和其他行政管理工作，六项职权含「聘任与解聘教师以及内部其他工作人员，对学生进行学籍管理并实施奖励或者处分」。
4. 学术委员会五项职责：审议学科专业与教学科研计划、评定教学科研成果、调查处理学术纠纷、调查认定学术不端行为、审议其他学术事项。
5. 高等学校通过以教师为主体的教职工代表大会等组织形式，依法保障教职工参与民主管理和监督。

**【答题框架/落点】** 简答「高等学校的办学自主权」按第三十二至三十八条列：招生方案、设置调整学科专业、制定教学计划选编教材、开展科研技术开发社会服务、开展境外交流合作、确定内部机构与人员配备、管理使用财产。

**【易混辨析】** 「党委领导下的校长负责制」（高教法第三十九条，公办高校）与「校长为法定代表人」（第三十条）不矛盾：前者是领导体制，后者是民事主体代表。另高等职业学校**属于**高等教育法所称高等学校，这是高职岗位常考的判断题。

**【真题锚点】** 青岛工程职业学院 2023 选择覆盖「高等教育学」板块；济南工程职业技术学院 2023 论述「高等学校毕业生体制的改革趋势」与高教法学生、就业条款相关。

**【出处】** 法规核心 p7—p12；政策汇编 p176—p180（含修正说明）。

### E34 · 高等教育法：教师资格、职务、聘任与学生条款 ☆

**【必背原文】** 第四十六条 高等学校实行教师资格制度：中国公民凡遵守宪法和法律，热爱教育事业，具有良好的思想品德，具备**研究生或者大学本科毕业学历**，有相应的教育教学能力，经认定合格，可以取得高等学校教师资格；不具备研究生或者大学本科毕业学历的公民，学有所长，通过国家教师资格考试，经认定合格，也可以取得高等学校教师资格。第四十七条 高等学校教师职务设**助教、讲师、副教授、教授**。第四十八条 高等学校实行教师聘任制，遵循双方平等自愿的原则，由高等学校校长与受聘教师签订聘任合同。

**【要点拆解】**

1. 第五十三条至第五十九条（学生）：学生应遵守法律法规、学生行为规范和学校管理制度；按国家规定缴纳学费，家庭经济困难的可申请补助或减免；国家设立奖学金、勤工助学基金和贷学金；学生课余可参加社会服务和勤工助学活动但不得影响学业任务完成；可在校内组织学生团体；思想品德合格、在规定修业年限内学完规定课程成绩合格或修满相应学分，准予毕业；高校应为毕业生、结业生提供就业指导和服务。
2. 第五十一条：高校应为教师参加培训、开展科学研究和进行学术交流提供便利条件；应对教师、管理人员和教学辅助人员的思想政治表现、职业道德、业务水平和工作实绩进行考核，考核结果作为聘任或解聘、晋升、奖励或处分的依据。
3. 学位：学位分为学士、硕士和博士（第二十二条）；学位制度衔接 E41《学位法》。

**【答题框架/落点】** 问「高校教师职务有哪些」答助教、讲师、副教授、教授四级；问「高校教师资格学历门槛」答研究生或大学本科毕业学历＋学有所长的考试通道。

**【易混辨析】** 高教法第四十六条「研究生或者大学本科毕业学历」与教师法第十一条第（五）项「取得高等学校教师资格，应当具备研究生或者大学本科毕业学历」一致；不要与中小学各层级学历门槛（E38）串用。

**【真题锚点】** 青岛工程职业学院 2023 简答「高职人才培养模式的基本特征」、济南工程职业技术学院 2023 简答「高等学校教育公平的基本主张」属同板块；命题角度：填空「高校教师职务设＿＿、＿＿、＿＿、＿＿」。

**【出处】** 法规核心 p11—p12；政策汇编 p180—p181。

### E35 · 中华人民共和国教师法（总则与教师定义）★

**【必背原文】** 《中华人民共和国教师法》**自 1994 年 1 月 1 日起施行**。第二条：本法适用于在各级各类学校和其他教育机构中专门从事教育教学工作的教师。第三条：教师是履行教育教学职责的**专业人员**，承担教书育人，培养社会主义事业建设者和接班人、提高民族素质的使命；教师应当忠诚于人民的教育事业。第四条：各级人民政府应当采取措施，加强教师的思想政治教育和业务培训，改善教师的工作条件和生活条件，保障教师的合法权益，提高教师的社会地位；全社会都应当尊重教师。第六条：每年**九月十日**为教师节。

**【要点拆解】**

1. 「专业人员」是教师法对教师身份的法定定性，名词解释必写；与「公务员」「自由职业者」相区别。
2. 第五条：国务院教育行政部门主管全国的教师工作。
3. 第四十条用语含义：各级各类学校指实施学前教育、普通初等教育、普通中等教育、职业教育、普通高等教育以及特殊教育、成人教育的学校；中小学教师指幼儿园、特殊教育机构、普通中小学、成人初等中等教育机构、职业中学以及其他教育机构的教师。
4. 第四十三条附则施行日期 1994 年 1 月 1 日，与教育法 1995 年 9 月 1 日、高教法 1999 年 1 月 1 日构成三个必记日期。

**【答题框架/落点】** 名词解释「教师」按第三条整句默＋「专业人员」定性；简答「教师法的适用对象」按第二条。

**【易混辨析】** 教师节（9 月 10 日，教师法第六条）≠ 第三十九个教师节（2023 年，教育家精神提出时间）≠ 建国后第一个教师节（1985 年，资料包未收录，需另行补充）；资料包只明确「9 月 10 日」与「2023 年是第三十九个教师节、2025 年是第四十一个教师节」。

**【真题锚点】** 山东政法学院 2022 论述「从工作岗位看，对一段话的理解」涉及教师身份；命题角度：判断「教师是履行教育教学职责的专业人员」。

**【出处】** 法规核心 p12—p13、p16。

### E36 · 教师法：教师权利六条 ★

**【必背原文】** 第七条 教师享有下列权利：（一）**进行教育教学活动，开展教育教学改革和实验**；（二）**从事科学研究、学术交流，参加专业的学术团体，在学术活动中充分发表意见**；（三）**指导学生的学习和发展，评定学生的品行和学业成绩**；（四）**按时获取工资报酬，享受国家规定的福利待遇以及寒暑假期的带薪休假**；（五）**对学校教育教学、管理工作和教育行政部门的工作提出意见和建议，通过教职工代表大会或者其他形式，参与学校的民主管理**；（六）**参加进修或者其他方式的培训**。

**【要点拆解】**

1. 六条权利可归为「教学权、科研权、评价权、报酬权、参与管理权、进修培训权」六个词，答题先写词再展开原文。
2. 第九条履职保障四项：提供符合国家安全标准的教育教学设施和设备；提供必需的图书、资料及其他教育教学用品；对教师在教育教学、科学研究中的创造性工作给以鼓励和帮助；支持教师制止有害于学生的行为或其他侵犯学生合法权益的行为。
3. 教师权利与 E37 教师义务是一一对应的两面，常合并考「教师的权利与义务」。

**【答题框架/落点】** 简答「教师享有哪些权利」默六条；案例「学校拖欠工资／阻止教师参加培训／拒绝教师参与民主管理」分别定位第（四）（六）（五）项。

**【易混辨析】** 「评定学生的品行和学业成绩」是教师权利（评价权），「对学生进行学籍管理、实施奖励或者处分」是学校权利（教育法第二十九条），主体不同；「参与学校的民主管理」通过教职工代表大会，不是「决定学校重大事项」。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」的反向即教师权利边界；命题角度：多选「下列属于教师法规定教师权利的是」。

**【出处】** 法规核心 p12—p13。

### E37 · 教师法：教师义务六条与履职保障 ★

**【必背原文】** 第八条 教师应当履行下列义务：（一）遵守宪法、法律和职业道德，为人师表；（二）贯彻国家的教育方针，遵守规章制度，执行学校的教学计划，履行教师聘约，完成教育教学工作任务；（三）对学生进行宪法所确定的基本原则的教育和爱国主义、民族团结的教育，法制教育以及思想品德、文化、科学技术教育，组织、带领学生开展有益的社会活动；（四）关心、爱护全体学生，尊重学生人格，促进学生在品德、智力、体质等方面全面发展；（五）制止有害于学生的行为或者其他侵犯学生合法权益的行为，批评和抵制有害于学生健康成长的现象；（六）不断提高思想政治觉悟和教育教学业务水平。

**【要点拆解】**

1. 六条义务按「守法—施教—育人—爱生—保护—提高」记；「尊重学生人格」是案例题最高频的落点。
2. 第九条四项履职保障见 E36；第二十二条考核内容：政治思想、业务水平、工作态度和工作成绩；第二十三条考核应客观、公正、准确，充分听取教师本人、其他教师以及学生的意见；第二十四条教师考核结果是受聘任教、晋升工资、实施奖惩的依据。
3. 义务与十项准则的呼应：第（一）项对应准则一、二；第（四）（五）项对应准则五、六；第（六）项对应准则四、七。

**【答题框架/落点】** 案例「教师体罚学生／侮辱学生人格」按「违反教师法第八条第四项＋第三十七条＋十项准则第五条」三层定性。

**【易混辨析】** 教师义务六条（教师法第八条）≠ 受教育者义务四条（教育法第四十四条，E31）；「关心、爱护全体学生，尊重学生人格」是**教师义务**，「尊敬师长，养成良好的思想品德和行为习惯」是**学生义务**。

**【真题锚点】** 山东服装职业学院 2023 论述「职业院校如何开展学生道德教育」、材料分析「侵犯了学生的什么权利」，均可用第八条；命题角度：简答「教师应当履行哪些义务」。

**【出处】** 法规核心 p13。

### E38 · 教师法：资格、学历门槛与聘任 ☆

**【必背原文】** 第十条 国家实行**教师资格制度**；中国公民凡遵守宪法和法律，热爱教育事业，具有良好的思想品德，具备本法规定的学历或者经国家教师资格考试合格，有教育教学能力，经认定合格的，可以取得教师资格。第十一条学历门槛：（一）幼儿园教师资格：幼儿师范学校毕业及其以上学历；（二）小学教师资格：中等师范学校毕业及其以上学历；（三）初级中学教师、初级职业学校文化专业课教师资格：高等师范专科学校或者其他大学专科毕业及其以上学历；（四）高级中学教师资格和中等专业学校、技工学校、职业高中文化课、专业课教师资格：高等师范院校本科或者其他大学本科毕业及其以上学历；（五）**高等学校教师资格：研究生或者大学本科毕业学历**；（六）成人教育教师资格：按成人教育的层次、类别分别具备高等、中等学校毕业及其以上学历。

**【要点拆解】**

1. 第十四条：受到**剥夺政治权利**或者**故意犯罪受到有期徒刑以上刑事处罚**的，不能取得教师资格；已经取得教师资格的，**丧失教师资格**。
2. 第十三条认定权限：中小学教师资格由县级以上地方人民政府教育行政部门认定；中等专业学校、技工学校的教师资格由县级以上地方人民政府教育行政部门组织有关主管部门认定；普通高等学校的教师资格由国务院或者省、自治区、直辖市教育行政部门或者由其委托的学校认定。
3. 第十六条国家实行教师职务制度；第十七条学校和其他教育机构应当逐步实行**教师聘任制**。
4. 第四章培养培训：各级人民政府和有关部门办好师范教育；教育行政部门、学校主管部门和学校制定教师培训规划；国家机关、企业事业单位和其他社会组织应为教师的社会调查和社会实践提供方便。

**【答题框架/落点】** 问「哪些人不能取得教师资格／丧失教师资格」答第十四条两句；问「认定权限」按三类学校分层答。

**【易混辨析】** 「不能取得」与「丧失」是第十四条的两段，前者针对未取得者、后者针对已取得者；另「高等师范院校本科或者其他大学本科毕业」是**高中／中职文化课专业课**门槛，不是高校教师门槛，高校教师是「研究生或者大学本科毕业学历」（E34 同）。

**【真题锚点】** 日照工业学校 2023 选择「教育法规和时政」含资格制度；命题角度：判断「受到剥夺政治权利的人已经取得教师资格的，丧失教师资格」。

**【出处】** 法规核心 p13—p14。

### E39 · 教师法：待遇、法律责任与教师申诉 ★

**【必背原文】** 第二十五条 教师的平均工资水平应当**不低于或者高于国家公务员的平均工资水平**，并逐步提高；建立正常晋级增薪制度。第三十五条 侮辱、殴打教师的，根据不同情况分别给予行政处分或者行政处罚；造成损害的责令赔偿损失；情节严重构成犯罪的依法追究刑事责任。第三十七条 教师有下列情形之一的，由所在学校、其他教育机构或者教育行政部门给予**行政处分或者解聘**：（一）故意不完成教育教学任务给教育教学工作造成损失的；（二）**体罚学生，经教育不改的**；（三）**品行不良、侮辱学生，影响恶劣的**。第三十九条 教师对学校或者其他教育机构侵犯其合法权益的，或者对学校或者其他教育机构作出的处理不服的，可以向教育行政部门提出申诉，教育行政部门应当在接到申诉的**三十日内**作出处理。

**【要点拆解】**

1. 待遇章要点：中小学教师和职业学校教师享受教龄津贴和其他津贴；教师医疗同当地国家公务员享受同等待遇，定期身体健康检查；教师退休或退职后享受国家规定的退休或退职待遇。
2. 第三十六条：对依法提出申诉、控告、检举的教师进行打击报复的，由所在单位或者上级机关责令改正；情节严重的可以给予行政处分。
3. 第三十八条：地方人民政府违反本法规定拖欠教师工资或者侵犯教师其他合法权益的，应当责令其限期改正。
4. 第七章奖励：教师在教育教学、培养人才、科学研究、教学改革、学校建设、社会服务、勤工俭学等方面成绩优异的，由所在学校予以表彰、奖励。

**【答题框架/落点】** 案例「教师体罚学生」按第三十七条第一款第（二）项＋「经教育不改」要件＋教育法第四十三条学生权利三段写；问「教师申诉期限」答三十日。

**【易混辨析】** 教师申诉「三十日」（教师法第三十九条，自然日）≠ 学生申诉「10 日内提出书面申诉、15 日内复查结论、15 日内向省级教育行政部门申诉、30 个工作日内处理」（E44）；「行政处分或者解聘」（教师法第三十七条）与「师德失范一票否决」（E13）分属法律与政策两个层级。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」的法律责任落点即第三十七条；命题角度：填空「教育行政部门应当在接到教师申诉的＿＿日内作出处理」。

**【出处】** 法规核心 p15—p16。

### E40 · 中华人民共和国职业教育法 ★

**【必背原文】** 新修订《中华人民共和国职业教育法》自 **2022 年 5 月 1 日**起施行。职业教育是**与普通教育具有同等重要地位的教育类型**，是国民教育体系和人力资源开发的重要组成部分，是培养多样化人才、传承技术技能、促进就业创业的重要途径。职业教育七大坚持：坚持中国共产党的领导；坚持社会主义办学方向，贯彻国家的教育方针；坚持立德树人、德技并修；坚持产教融合、校企合作；坚持面向市场、促进就业；坚持面向实践、强化能力；坚持面向人人、因材施教。

**【要点拆解】**

1. 七大坚持出自新修订《职业教育法》，是**法定要求**，不是一般倡议；分组记忆：前两条讲方向与领导，中间两条讲育人路径（立德树人＋产教融合），后三条讲三个面向（市场、实践、人人）。
2. 类型定位三句：与普通教育具有同等重要地位的教育类型／国民教育体系和人力资源开发的重要组成部分／培养多样化人才、传承技术技能、促进就业创业的重要途径。
3. 职业学校学生在升学、就业、职业发展等方面与同层次普通学校学生享有平等机会；用人单位不得设置妨碍职业学校毕业生平等就业和公平竞争的报考、录用、聘用条件。
4. 山东省职业教育条例第三条（另一篇 S36）完整照录七大坚持并加「弘扬社会主义核心价值观、培育劳模精神劳动精神工匠精神」，可作为「法—条例」对照的答题素材。

**【答题框架/落点】** 简答「新职教法对人才培养的目标与要求」（山东商业职院 2023 原题）按「类型定位三句＋七大坚持＋平等机会」组织；论述「职业教育不是次等教育」用类型定位＋七大坚持。

**【易混辨析】** 七大坚持（职教法，七条）≠ 教育方针（教育法第五条）≠ 师德师风四原则（E14）；另「德技并修」是职教育人原则，「五育并举」是全面发展教育结构，不要混。

**【真题锚点】** 山东商业职业技术学院 2023 简答「职业教育体系是什么」「新职教法对人才培养的目标与要求」；滨州职业学院 2024 多选「职业学校学生在升学就业职业发展」「培养多样化人才，传承技术技能，促进就业创业」。

**【出处】** 职教必背 K01（p6—p7）、K02（p8—p10）；山东省职业教育条例 p1（另一篇 S36）；真题（山东商业职院 2023、滨州职院 2024）。

### E41 · 中华人民共和国学位法 ☆

**【必背原文】** 《中华人民共和国学位法》2024 年 4 月 26 日第十四届全国人民代表大会常务委员会第九次会议通过，**2025 年 1 月 1 日起施行**，《中华人民共和国学位条例》同时废止。第二条：国家实行学位制度，学位分为**学士、硕士、博士**，包括学术学位、专业学位等类型，按照学科门类、专业学位类别等授予。第三条：学位工作坚持中国共产党的领导，全面贯彻国家的教育方针，践行社会主义核心价值观，落实立德树人根本任务，遵循教育规律，坚持公平、公正、公开，坚持**学术自由与学术规范相统一**。

**【要点拆解】**

1. 体制：国务院设立学位委员会领导全国学位工作，每届任期**五年**；国务院学位委员会设主任委员一人、副主任委员和委员若干人；省、自治区、直辖市人民政府设立省级学位委员会。
2. 学位评定委员会组成人员应为**不少于九人的单数**，主席由学位授予单位主要行政负责人担任；审议重大事项会议应有全体组成人员的**三分之二以上**出席，决议由全体组成人员**过半数**通过。
3. 学位授予资格审批：学士学位授予资格由省级学位委员会审批报国务院学位委员会备案；硕士学位授予资格由省级学位委员会组织审核报国务院学位委员会审批；博士学位授予资格由国务院教育行政部门组织审核报国务院学位委员会审批；审批单位自受理申请之日起**九十日内**作出决议，公示期不少于**十个工作日**。
4. 答辩委员会：硕士学位答辩委员会不少于**三人**，博士学位答辩委员会不少于**五人**（其中学位授予单位以外的专家不少于二人），决议由全体组成人员**三分之二以上**通过；学术复核、复核决定均自受理之日起**三十日内**作出。

**【答题框架/落点】** 数字题按上表记；简答「学位类型」答学士、硕士、博士＋学术学位、专业学位。

**【易混辨析】** 《学位法》（2025.1.1 施行）已取代《学位条例》，答题若题干写「学位条例」应按资料包说明「同时废止」；另「三分之二以上出席／过半数通过」（学位评定委员会）与「三分之二以上通过」（答辩委员会）是两个不同比例。

**【真题锚点】** 命题角度：选择「《学位法》施行时间」「学位评定委员会人数要求」，属 2026 新政新增小题。

**【出处】** 法规核心 p16—p20。

### E42 · 中华人民共和国爱国主义教育法 ☆

**【必背原文】** 《中华人民共和国爱国主义教育法》**自 2024 年 1 月 1 日起施行**。第三条：爱国主义教育应当高举中国特色社会主义伟大旗帜，坚持爱国和爱党、爱社会主义相统一，以维护国家统一和民族团结为着力点，把全面建成社会主义现代化强国、实现中华民族伟大复兴作为鲜明主题。第五条：爱国主义教育应当坚持思想引领、文化涵育，教育引导、实践养成，主题鲜明、融入日常，因地制宜、注重实效。第十五条：国家将爱国主义教育纳入国民教育体系，各级各类学校应当将爱国主义教育贯穿学校教育全过程，办好、讲好思想政治理论课，并将爱国主义教育内容融入各类学科和教材中。

**【要点拆解】**

1. 主要内容九项（第六条）：马克思列宁主义、毛泽东思想、邓小平理论、「三个代表」重要思想、科学发展观、习近平新时代中国特色社会主义思想；中国共产党史、新中国史、改革开放史、社会主义发展史、中华民族发展史；中国特色社会主义制度与党带领人民团结奋斗的重大成就、历史经验和生动实践；中华优秀传统文化、革命文化、社会主义先进文化；国旗、国歌、国徽等国家象征和标志；祖国的壮美河山和历史文化遗产；宪法和法律，国家统一和民族团结、国家安全和国防等方面的意识和观念；英雄烈士和先进模范人物的事迹及体现的民族精神、时代精神；其他富有爱国主义精神的内容。
2. 第十条：每年 **10 月 1 日**中华人民共和国国庆日，国家和社会各方面举行多种形式的庆祝活动，集中开展爱国主义教育。
3. 第三十七条禁止行为：侮辱国旗、国歌、国徽；歪曲、丑化、亵渎、否定英雄烈士事迹和精神；宣扬、美化、否认侵略战争、侵略行为和屠杀惨案；侵占、破坏、污损爱国主义教育设施等。
4. 第二十三条：国家采取措施开展历史文化教育和「一国两制」实践教育，增强中国香港特别行政区同胞、中国澳门特别行政区同胞的爱国精神，自觉维护国家主权、统一和领土完整。

**【答题框架/落点】** 简答「爱国主义教育的主要内容」按九项分组默；案例「污损国旗／诋毁英烈」定位第三十七条、第三十八条。

**【易混辨析】** 《爱国主义教育法》（法律，2024.1.1 施行）≠《新时代爱国主义教育实施纲要》（政策文件，政策汇编目录收录）；前者是法、后者是纲要，问「法律规定」答前者。

**【真题锚点】** 山东政法学院 2022 简答「党的百年奋斗的历史意义」、滨州职业学院 2024 选择「四个全面、五位一体」属时政板块；命题角度：填空「爱国主义教育法自＿＿年＿＿月＿＿日起施行」。

**【出处】** 法规核心 p20—p24；政策汇编 p1（目录含《新时代爱国主义教育实施纲要》）。

### E43 · 普通高等学校学生管理规定：学生权利七条 ★

**【必背原文】** 学生在校期间依法享有下列权利：（一）参加学校教育教学计划安排的各项活动，使用学校提供的教育教学资源；（二）参加社会实践、志愿服务、勤工助学、文娱体育及科技文化创新等活动，获得就业创业指导和服务；（三）申请奖学金、助学金及助学贷款；（四）在思想品德、学业成绩等方面获得科学、公正评价，完成学校规定学业后获得相应的学历证书、学位证书；（五）在校内组织、参加学生团体，以适当方式参与学校管理，对学校与学生权益相关事务享有**知情权、参与权、表达权和监督权**；（六）对学校给予的处理或者处分有异议，向学校、教育行政部门提出申诉，对学校、教职员工侵犯其人身权、财产权等合法权益的行为，提出申诉或者依法提起诉讼；（七）法律、法规及学校章程规定的其他权利。

**【要点拆解】**

1. 七条权利，比教育法第四十三条多出「社会实践与就业创业指导服务」「校内组织学生团体、参与学校管理、四项权利」「创新创业档案与学分」等高校专属内容。
2. 学生实行**自我管理、自我服务、自我教育、自我监督**（「四自」）；考核分为**考试和考查**两种；对通过补考、重修获得的成绩应当予以标注。
3. 入学资格：因故不能按期入学应向学校请假，未请假或请假逾期的，除因不可抗力等正当事由外，视为放弃入学资格；审查发现新生录取通知、考生信息等证明材料与本人实际情况不符或有其他违反国家招生考试规定情形的，取消入学资格。
4. 转学六类禁止情形：入学未满一学期或者毕业前一年的；高考成绩低于拟转入学校相关专业同一生源地相应年份录取成绩的；由低学历层次转为高学历层次的；以定向就业招生录取的；研究生拟转入学校、专业的录取控制标准高于其所在学校、专业的；无正当转学理由的。
5. 退学六类情形：学业成绩未达要求或未在学习年限内完成学业；休学保留学籍期满未提出复学申请或复查不合格；经指定医院诊断患有疾病或意外伤残不能继续在校学习；未经批准连续**两周**未参加学校规定的教学活动；超过规定期限未注册又未履行暂缓注册手续；学校规定的其他情形。应征参加中国人民解放军（含中国人民武装警察部队）的，学校保留其入学资格或学籍至退役后 **2 年**。

**【答题框架/落点】** 简答「学生在校期间依法享有的权利」默七条；案例「取消入学资格／退学／转专业」按对应条款写。

**【易混辨析】** 「不得转专业」（以特殊招生形式录取、国家有相关规定或录取前与学校有明确约定的）与「不得转学六情形」是两组不同清单；「结业证书」（修完教学计划规定内容但未达毕业要求）≠「肄业证书」（对退学学生发给）≠「写实性学习证明」。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」；济南工程职业技术学院 2023 论述「高等学校毕业生体制的改革趋势」；日照工业学校 2023 简答「新型师生关系特点」属同板块。

**【出处】** 高频速记 p23—p27；职教必背 p97—p101；政策汇编 p1（目录「学生管理类」p29 起）。

### E44 · 普通高等学校学生管理规定：处分五种与申诉五个时限 ★

**【必背原文】** 对有违反法律法规、本规定以及学校纪律行为的学生，学校应当给予批评教育，并可视情节轻重，给予如下纪律处分：（一）**警告**；（二）**严重警告**；（三）**记过**；（四）**留校察看**；（五）**开除学籍**。学校给予学生处分，应当坚持教育与惩戒相结合，做到**证据充分、依据明确、定性准确、程序正当、处分适当**。除开除学籍处分以外，给予学生处分一般应当设置 **6 到 12 个月**期限，到期按学校规定程序予以解除。

**【要点拆解】**

| 时限 | 内容 |
| --- | --- |
| 10 日内 | 学生对处理或处分决定有异议，向学校学生申诉处理委员会提出书面申诉 |
| 15 日内 | 学生申诉处理委员会接到书面申诉之日起作出复查结论并告知申诉人 |
| 延长 15 日 | 情况复杂不能在规定限期内作出结论，经学校负责人批准可延长 |
| 15 日内 | 学生对复查决定有异议，向学校所在地省级教育行政部门提出书面申诉 |
| 30 个工作日内 | 省级教育行政部门接到学生书面申诉之日起对申诉人的问题给予处理并作出决定 |

1. 处分决定书五项内容：学生基本信息；作出处分的事实和证据；处分的种类、依据、期限；申诉的途径和期限；其他必要内容。
2. 对学生作出取消入学资格、取消学籍、退学、开除学籍或者其他涉及学生重大利益的处理或处分决定的，应当提交**校长办公会或者校长授权的专门会议**研究决定，并应当事先进行**合法性审查**。
3. 送达：处理、处分决定以及处分告知书等应直接送达学生本人，学生拒绝签收的可以留置方式送达。
4. 学校应当坚持教育与宗教相分离原则，任何组织和个人不得在学校进行宗教活动。

**【答题框架/落点】** 案例「处分程序是否正当」按「五适当＋决定书五项＋重大处分合法性审查＋送达＋申诉时限」逐项核对；数字题按上表默五个时限。

**【易混辨析】** 五个时限的单位不同：前三个「日」、最后一个「**工作日**」（30 个工作日）；资料包原注「5 个时间需辨析清楚，易混淆」。另「申诉复查 15 日」与「向省级教育行政部门申诉 15 日」是两段不同起算点。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」可延伸到处分与申诉；命题角度：填空「省级教育行政部门应当在接到学生书面申诉之日起＿＿个工作日内作出决定」。

**【出处】** 高频速记 p26—p27；职教必背 p100—p101。

### E45 · 资料包未收录全文的法规与命题角度 ○

4. 命题角度二：案例「学生在实习期间受伤如何赔偿」，答题可写「依据《民法典》与教育部《学生伤害事故处理办法》等有关规定处理，并落实实习责任保险与三方协议」，不引具体条文号。

## 第六部分 · 制度层：权利义务、资格聘任、申诉与法律责任（E46—E50）

### E46 · 教师·学生·学校三方权利义务总对照 ★

**【必背原文】** 资料包按主体分列三方条款：学校依《教育法》享有「按照章程自主管理、组织实施教育教学活动」等权利并承担「遵守法律法规、贯彻国家教育方针、维护受教育者和教师合法权益」等义务（见 E30）；受教育者依《教育法》第四十三条享有「参加教育教学计划安排的各项活动，使用教育教学设施、设备、图书资料」等权利，依第四十四条承担「遵守法律法规、遵守学生行为规范、努力学习」等义务（见 E31），高校学生另在《普通高等学校学生管理规定》中列七项权利（见 E43）；教师依《教师法》第七条享有六项权利、依第八条承担六项义务（见 E36、E37）。三方出自不同法律、不同条款组，命题人常把不同主体的条款混排让考生判断归属。

**【要点拆解】**

| 主体 | 权利出处 | 义务出处 | 最易考的一条 |
| --- | --- | --- | --- |
| 学校 | 《教育法》关于学校权利的规定（E30） | 《教育法》关于学校义务的规定（E30） | 按照章程自主管理、拒绝非法干涉教育教学活动 |
| 教师 | 《教师法》第七条六项（E36） | 《教师法》第八条六项（E37） | 进行教育教学活动，开展教育教学改革和实验 |
| 受教育者／学生 | 《教育法》第四十三条（E31）、《普通高等学校学生管理规定》七项权利（E43） | 《教育法》第四十四条、学生管理规定 | 参加教育教学计划安排的各项活动、使用教育教学资源 |

1. 三方关系是「学校组织实施—教师施教—学生受教」，权利与义务一一对应：一方的义务常是另一方的权利，例如学校「提供符合标准的教学设施」对应学生「使用教育教学资源」。
2. 主体先定、法再定、条款最后定：案例题第一步永远是判断问的是学校、教师还是学生，第二步才调对应法律。
3. 学生管理规定是《教育法》受教育者条款在高校场景的细化，七项权利比第四十三条多出「社会实践与就业创业指导服务」「校内组织学生团体、参与学校管理」「知情权、参与权、表达权、监督权」等高校专属内容（见 E43）。
4. 教师权利义务只认《教师法》第七、八条，不要把《教育法》里「教师享有法律规定的权利」这句原则性表述当成具体条款。

**【答题框架/落点】** 案例「某主体被侵犯了什么权利」按「定主体 → 定法律 → 默条款 → 对照事实」四步写；简答「学校／教师／学生各有哪些权利义务」分三栏对照，宁可少写一条也不要串到别的主体栏里。

**【易混辨析】** 权利可以放弃、义务必须履行，命题常把「可以参加……活动」与「应当遵守……规范」混选；「受教育者」是《教育法》用语，「学生」是《普通高等学校学生管理规定》用语，指同一群体但权利清单长短不同；「学校按照章程自主管理」是权利而非义务，且以「遵守法律法规」为前提，不等于不受约束。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」即从受教育者权利清单取点；命题角度：选择「下列属于《教师法》第七条教师权利而非学校权利的是」，或「下列属于学生义务而非学生权利的是」。

**【出处】** 法规核心 p1—p24（收录范围）；高频速记 p23—p27；职教必背 p97—p101（本条为对照整理，条文原文见 E30、E31、E36、E37、E43）。

### E47 · 教师权利六条与义务六条对照速记 ★

**【必背原文】** 《教师法》第七条教师享有下列权利：（一）进行教育教学活动，开展教育教学改革和实验；（二）从事科学研究、学术交流，参加专业的学术团体，在学术活动中充分发表意见；（三）指导学生的学习和发展，评定学生的品行和学业成绩；（四）按时获取工资报酬，享受国家规定的福利待遇以及寒暑假期的带薪休假；（五）对学校教育教学、管理工作和教育行政部门的工作提出意见和建议，通过教职工代表大会或者其他形式，参与学校的民主管理；（六）参加进修或者其他方式的培训。《教师法》第八条教师应当履行下列义务：（一）遵守宪法、法律和职业道德，为人师表；（二）贯彻国家的教育方针，遵守规章制度，执行学校的教学计划，履行教师聘约，完成教育教学工作任务；（三）对学生进行宪法所确定的基本原则的教育和爱国主义、民族团结的教育，法制教育以及思想品德、文化、科学技术教育，组织、带领学生开展有益的社会活动；（四）关心、爱护全体学生，尊重学生人格，促进学生在品德、智力、体质等方面全面发展；（五）制止有害于学生的行为或者其他侵犯学生合法权益的行为，批评和抵制有害于学生健康成长的现象；（六）不断提高思想政治觉悟和教育教学业务水平。（两条原文见 E36、E37）

**【要点拆解】**

| 序 | 权利（第七条，关键词） | 义务（第八条，关键词） |
| --- | --- | --- |
| 1 | 教育教学、改革实验 | 守法、守职业道德、为人师表 |
| 2 | 科研、学术交流、发表意见 | 贯彻方针、执行教学计划、履行聘约 |
| 3 | 指导学生、评定品行与成绩 | 进行思想品德与法制教育、组织社会活动 |
| 4 | 获取工资报酬、福利、带薪寒暑假 | 关心爱护全体学生、尊重人格 |
| 5 | 提出意见建议、参与民主管理 | 制止有害于学生的行为、批评抵制不良现象 |
| 6 | 参加进修与培训 | 不断提高思想政治觉悟与业务水平 |

1. 六条对六条，编号不是逐条对应，但可以按「教—研—评—酬—管—学」串权利，按「守—教—育—爱—护—进」串义务，闭卷默写不易漏条。
2. 「评定学生的品行和学业成绩」是权利也是专业自主权的体现，不能答成「义务」；「不断提高业务水平」是义务，与权利栏「参加进修培训」互为表里但归属不同。
3. 「制止有害于学生的行为」是作为义务，遇到不作为型案例（教师对欺凌视而不见）就落这一条。
4. 「履行教师聘约」把义务与聘任制度（E48）接在一起，是论述「为什么教师要签聘约」的法条依据。

**【答题框架/落点】** 简答「教师的权利与义务」按上表两列各默六条；案例「教师某行为是否合法」先判是行使权利还是未履行义务，再引对应条款；论述「如何依法执教」把义务六条展开成六个分论点。

**【易混辨析】** 最易错的是把「参与学校民主管理」写成义务、把「不断提高业务水平」写成权利；另「带薪寒暑假」是第四项权利的完整表述，选择题常漏「带薪」二字；「关心爱护全体学生」的落点是「全体」，写成「关心优秀学生」即错。

**【真题锚点】** 日照工业学校 2023 选择含「教育法规和时政」；山东商业职业技术学院 2023、滨州职业学院 2024 涉及教师职责类题型；命题角度：填空「教师对学校教育教学、管理工作提出意见和建议，通过＿＿＿＿或者其他形式参与学校民主管理」。

**【出处】** 法规核心 p1—p24（收录范围）；高频速记 p23—p27；职教必背 p101—p103（两条原文见 E36、E37）。

### E48 · 教师资格制度与聘任制度 ☆

**【必背原文】** 《教师法》确立国家实行教师资格制度：中国公民凡遵守宪法和法律，热爱教育事业，具有良好的思想品德，具备本法规定的学历或者经国家教师资格考试合格，有教育教学能力，经认定合格的，可以取得教师资格（资格条件见 E38）。学校和其他教育机构应当逐步实行教师聘任制，教师的聘任应当遵循双方地位平等的原则，由学校和教师签订聘任合同，明确规定双方的权利、义务和责任（聘任原则见 E38、E39）。资料包另在《关于全面深化新时代教师队伍建设改革的意见》相关要点中收录「完善国家教师资格制度，建立完善符合教育行业特点的教师招聘制度，严把教师入口关」「充分落实高校用人自主权，政府各有关部门不统一组织高校人员聘用考试，简化进人程序」（师德考点 p12、p21）。

**【要点拆解】**

| 环节 | 核心问题 | 依据与落点 |
| --- | --- | --- |
| 资格 | 能不能当教师（准入） | 国籍、守法、品德、学历或考试合格、教育教学能力、认定合格，见 E38 |
| 招聘 | 能不能进这所学校（入口） | 符合教育行业特点的招聘制度，严把入口关 |
| 聘任 | 以什么身份上岗（岗位） | 双方平等、签订聘任合同、明确权利义务责任 |
| 考核与职称 | 上岗后怎么评价 | 突出教育教学实绩，克服唯论文、唯帽子、唯职称、唯学历、唯奖项（见 E17） |

1. 「资格」是国家对个人的准入认定，「聘任」是学校与教师之间的岗位合同关系，二者先后不同、主体不同，案例题常把「没有教师资格」与「未签聘约」混为一谈。
2. 高校用人自主权的落点是「不统一组织高校人员聘用考试、简化进人程序、职称评审权下放至高校、由高校自主评审按岗聘任」（师德考点 p21），这是高校岗与中小学岗在制度上最常被考的差别。
3. 聘任合同必须明确「权利、义务、责任」三项，与 E47 义务栏「履行教师聘约」对接。
4. 资料包在《新时代职业道德建设实施纲要》与师德师风意见中反复出现「把好教师入口关，在教师招聘、引进时组织开展准则宣讲，将准则要求体现在教师聘用、聘任合同中」（师德考点 p16），可作为「资格—聘任—师德」链条的过渡句。

**【答题框架/落点】** 简答「教师资格与教师聘任的区别」按「性质（准入 vs 岗位）、主体（国家认定 vs 学校与教师）、形式（资格证书 vs 聘任合同）、依据」四点分层；论述「如何把好教师入口关」按「资格制度 → 招聘制度 → 准则宣讲与合同嵌入 → 师德考核一票否决」写。

**【易混辨析】** 「教师资格制度」不等于「教师聘任制度」；「学历要求」与「资格考试合格」在《教师法》中是选择关系（具备规定学历**或者**考试合格），不是并列累加；「高校自主评审职称」是评审权下放，不等于取消资格制度。

**【真题锚点】** 命题角度：选择「高校教师聘用与中小学教师聘用的制度差异」，或简答「教师聘任应遵循什么原则」；山东开放大学 2023、青岛工程职业学院 2023 涉及高校人事与教师管理类题型，可据此板块作答。

**【出处】** 法规核心 p1—p24（收录范围）；师德考点 p12、p16、p21；高频速记 p23—p27（资格条件原文见 E38、E39）。

### E49 · 申诉制度三条线：教师申诉·学生申诉·受教育者申诉 ★

**【必背原文】** 资料包收录三条申诉线：其一，教师对学校或者其他教育机构侵犯其合法权益的，或者对学校或者其他教育机构作出的处理不服的，可以向教育行政部门提出申诉（教师申诉，见 E39）；其二，受教育者对学校给予的处分不服，向有关部门提出申诉，对学校、教师侵犯其人身权、财产权等合法权益的，提出申诉或者依法提起诉讼（《教育法》第四十三条，见 E31）；其三，学生对学校的处理或者处分决定有异议，向学校学生申诉处理委员会提出书面申诉，对复查决定有异议再向学校所在地省级教育行政部门提出书面申诉（《普通高等学校学生管理规定》，五个时限见 E44）。

**【要点拆解】**

| 申诉线 | 申诉主体 | 受理机关 | 时限 | 对应编号 |
| --- | --- | --- | --- | --- |
| 教师申诉 | 教师 | 教育行政部门 | 见 E39（资料包法规核心收录，以原文为准） | E39 |
| 受教育者申诉 | 受教育者 | 有关部门 | 《教育法》第四十三条，见 E31 | E31 |
| 学生申诉（校内） | 高校学生 | 学校学生申诉处理委员会 | 10 日内提出、15 日内复查、复杂可延长 15 日 | E44 |
| 学生申诉（省级） | 高校学生 | 学校所在地省级教育行政部门 | 复查有异议 15 日内提出，省级部门 30 个工作日内处理并决定 | E44 |

1. 三条线互不通用：教师被侵权找教育行政部门，学生对处分不服先走校内申诉委员会，不能把「学生申诉处理委员会」答给教师用。
2. 学生申诉是「先校内、后省级」两级递进，五个时限单位不一致（前四个「日」、最后一个「工作日」），是选择题高频陷阱（见 E44 易混辨析）。
3. 「申诉」与「诉讼」不同：申诉是行政系统内部救济，诉讼是司法救济；《教育法》第四十三条对侵犯人身权、财产权写的是「提出申诉**或者**依法提起诉讼」，二选一或并用要按原文。
4. 重大处分（取消入学资格、取消学籍、退学、开除学籍等）须提交校长办公会或校长授权的专门会议研究决定并事先进行合法性审查，这是申诉之前必经的程序正当要求（见 E44）。

**【答题框架/落点】** 案例「处分程序是否正当、学生如何救济」按「处分五适当 → 决定书五项 → 重大处分合法性审查 → 送达 → 校内申诉 10 日 → 复查 15 日 → 省级申诉 15 日 → 处理 30 个工作日」逐步核对；简答「申诉制度有哪几条线」按上表四行作答。

**【易混辨析】** 「教师申诉」受理机关是教育行政部门，「学生申诉」第一级是学校内部委员会；「对处分不服」与「对侵权行为」在《教育法》第四十三条是两种不同事由；「申诉」不等于「复议」，资料包未收录行政复议专门条文，不得据此补写。

**【真题锚点】** 山东服装职业学院 2023 材料分析「侵犯了学生的什么权利」可延伸到申诉救济；命题角度：填空「学生对处理或处分决定有异议，应在＿＿日内向学校学生申诉处理委员会提出书面申诉」，或「省级教育行政部门应在接到书面申诉之日起＿＿个工作日内作出决定」。

**【出处】** 法规核心 p1—p24（收录范围）；高频速记 p26—p27；职教必背 p100—p101（条文原文见 E31、E39、E44）。

### E50 · 教育法律责任类型与法规版本差异辨析 ★

**【必背原文】** 资料包《教育法律法规核心考点》按法律责任类型整理《教育法》《教师法》《高等教育法》的责任条款：违反教育法规定，侵犯受教育者、教师、学校或者其他教育机构合法权益造成损失、损害的，依法承担民事责任（见 E32）；违反国家有关规定举办学校或者其他教育机构、违反国家规定招收学生、在招生考试中舞弊等，由教育行政部门或其他有关行政部门给予行政处罚、对直接负责的主管人员和其他直接责任人员依法给予处分，构成犯罪的依法追究刑事责任（见 E32、E39）。教师有「故意不完成教育教学任务给教育教学工作造成损失」「体罚学生经教育不改」「品行不良、侮辱学生影响恶劣」等情形的，由所在学校、其他教育机构或者教育行政部门给予行政处分或者解聘，情节严重构成犯罪的依法追究刑事责任（见 E39）。

**【要点拆解】**

| 责任类型 | 典型触发情形 | 承担方式 | 对应编号 |
| --- | --- | --- | --- |
| 行政法律责任（处分） | 教师故意不完成教学任务、体罚经教育不改、品行不良侮辱学生 | 行政处分、解聘 | E39 |
| 行政法律责任（处罚） | 违规举办学校、违规招生、招生考试舞弊 | 行政处罚、责令停止、没收违法所得 | E32 |
| 民事法律责任 | 侵犯受教育者、教师、学校合法权益造成损失损害 | 依法承担民事责任、赔偿损失 | E32 |
| 刑事法律责任 | 上述行为情节严重、构成犯罪 | 依法追究刑事责任 | E32、E39 |

1. 三类责任的判别口诀：「内部人员违规 → 处分」「社会主体违规办学 → 处罚」「造成损失损害 → 民事赔偿」「构成犯罪 → 刑事」。
2. 「处分」与「处罚」是两组不同法律后果：处分针对内部隶属人员，处罚针对外部行政相对人，选择题常混用。
3. 「解聘」与「撤销教师资格」不是一回事：解聘是聘任关系终止（E48），撤销资格是准入资格消灭，二者依据条款不同，答题不得互相替代。
4. **版本差异（本篇最关键的易混点）**：资料包「法规核心」收录《教育法》《高等教育法》现行修正版，「政策汇编第三篇」另收早期版本，两版条文序号与第五条等表述不一致。本文一律以现行修正版为准；若考场上题干引的是旧版表述，按「现行修正版为准、注明版本差异」作答，不硬背条文号。

**【答题框架/落点】** 案例「某行为应承担什么法律责任」按「定行为 → 定主体 → 定责任类型 → 定承担方式 → 看是否构成犯罪」五步；论述「依法治教」把「有法可依（法规体系，见 E45）+ 违法必究（三类责任）」写成两大部分。

**【易混辨析】** 「行政处分」≠「行政处罚」；「民事责任」以「造成损失、损害」为前提，无损害不谈赔偿；「情节严重构成犯罪」是刑事责任的门槛，不能把所有失范行为都写成「依法追究刑事责任」；现行修正版与早期版本的条文号差异见上文第 4 点，呼应「版本口径说明」。

**【真题锚点】** 日照工业学校 2023 选择含「教育法规和时政」；山东服装职业学院 2023 材料分析可延伸到责任承担；命题角度：选择「教师体罚学生经教育不改应承担的责任类型」，或辨析「处分与处罚的区别」。

**【出处】** 法规核心 p1—p24（收录范围）；高频速记 p23—p27；政策汇编 p1（目录，早期版本仅作版本差异提示）（条文原文见 E29、E32、E39）。

## 第七部分 · 2026 重点新政与教育时政（E51—E60）

新政层是所有论述题的「升华句」来源：前面六十个考点答完「是什么、怎么办」，最后一段几乎都要落到教育强国纲要、全国教育大会、教育科技人才一体推进上。资料包《1.教育类重要高频知识点（考点速记！）》与《2.高校招聘考试教育大类核心政策文件汇总》两册已收录本部分主干原文，以下逐条按原文整理；凡资料包未收录的 2026 年新文件与时政，统一在 E60 列明，不作补写。

### E51 · 教育强国建设规划纲要（2024—2035 年）：三大属性·六力·五大关系·八大体系 ★★★

**【必背原文】** 《教育强国建设规划纲要（2024—2035 年）》，资料包标注出台时间 **2025 年 1 月 19 日**。全面把握教育的**政治属性、人民属性、战略属性**；加快建设具有强大**思政引领力、人才竞争力、科技支撑力、民生保障力、社会协同力、国际影响力**的中国特色社会主义教育强国；正确处理**支撑国家战略和满足民生需求、知识学习和全面发展、培养人才和满足社会需要、规范有序和激发活力、扎根中国大地和借鉴国际经验**的重大关系；全面构建**八大体系**：固本铸魂的思想政治教育体系、公平优质的基础教育体系、自强卓越的高等教育体系、产教融合的职业教育体系、泛在可及的终身教育体系、创新牵引的科技支撑体系、素质精良的教师队伍体系、开放互鉴的国际合作体系。（高频速记 p4；政策汇编 p3）

**【要点拆解】**

| 提法 | 数量 | 逐项速记（首字口诀） |
| --- | --- | --- |
| 教育三大属性 | 3 | 政治、人民、战略（政·人·战） |
| 教育强国六力 | 6 | 思政引领、人才竞争、科技支撑、民生保障、社会协同、国际影响（思·人·科·民·协·国） |
| 五个重大关系 | 5 | 战略与民生、知识与全面、培养与社会需要、规范与活力、中国大地与国际经验 |
| 全面构建八大体系 | 8 | 思政·基础·高等·职教·终身·科技支撑·教师队伍·国际合作 |

1. 六力与三大属性是同一份文件的两组不同提法：三大属性回答「教育是什么性质」，六力回答「建成的教育强国强在哪」，选择题常互换设错。
2. 八大体系里与高职岗位直接相关的是「产教融合的职业教育体系」与「自强卓越的高等教育体系」「素质精良的教师队伍体系」三条，论述职教题优先引前两条。
3. 五个重大关系是「系统观念」的具体化，2024 年全国教育大会讲话里原样复述（见 E53），两处可互相印证。
4. 政策汇编另收录纲要「总体要求」完整表述，明确「坚持党对教育事业的全面领导，突出促进公平、提高质量，强化战略引领、支撑发展，深化改革创新、协同融合，坚持自主自信、胸怀天下」，以及「实现由大到强的系统跃升」，可作论述开头句。

**【答题框架/落点】** 简答「教育强国纲要的核心内容」按「出台时间 → 三大属性 → 六力 → 五个重大关系 → 八大体系 → 主要目标」六层默写；论述「如何理解教育强国建设」先写总体要求，再分属性与六力，最后落到高职教师怎么做（师德、双师型、产教融合）。

**【易混辨析】** 「三大属性」（政治·人民·战略）≠「六力」（六项能力）；「五个重大关系」≠「九个方面举措」（E52）；「八大体系」是体系清单，不是「一体两翼五重点」等职教改革任务（见职教必背 K05），不要跨篇混答。

**【真题锚点】** 日照工业学校 2023 选择含「教育法规和时政」；命题角度：选择「教育三大属性不包括下列哪一项」，或填空「教育强国六力中的＿＿＿＿力、＿＿＿＿力」，或简答「全面构建哪八大体系」。

**【出处】** 高频速记 p1（目录）、p4、p5；政策汇编 p1（目录）、p3。

### E52 · 2024 年全国教育大会（一）：教育是强国建设、民族复兴之基 ★

**【必背原文】** 2024 年全国教育大会，习近平在讲话中指出，**教育是强国建设、民族复兴之基**。党的十八大以来，我们坚持把教育作为**国之大计、党之大计**，全面贯彻党的教育方针，作出深入实施**科教兴国战略、加快教育现代化**的重大决策，确立**到 2035 年建成教育强国**的奋斗目标，加强党对教育工作的全面领导，不断推进教育体制机制改革，推动新时代教育事业取得**历史性成就、发生格局性变化**，教育强国建设迈出坚实步伐。习近平强调，我们要建成的教育强国，是**中国特色社会主义教育强国**，应当具有强大的**思政引领力、人才竞争力、科技支撑力、民生保障力、社会协同力、国际影响力**，为以中国式现代化全面推进强国建设、民族复兴伟业提供有力支撑。（高频速记 p5；政策汇编第二篇目录）

**【要点拆解】**

| 关键词 | 原文定位 | 易考点 |
| --- | --- | --- |
| 教育是强国建设、民族复兴之基 | 大会定调句 | 论述题首选开头 |
| 国之大计、党之大计 | 十八大以来定位 | 与「教育是国之大计、党之大计」师德考点 p3 同源 |
| 2035 年建成教育强国 | 奋斗目标 | 与纲要主要目标一致（E51） |
| 历史性成就、格局性变化 | 成效判断 | 选择题常改成「根本性变化」设错 |
| 六力 | 教育强国特质 | 与 E51 六力完全相同，可互相印证 |

1. 「教育是强国建设、民族复兴之基」是本轮时政最核心的一句判断，凡「谈谈对教育地位的认识」都可由此破题。
2. 「历史性成就、发生格局性变化」是固定搭配，不能写成「根本性」「转折性」。
3. 「中国特色社会主义教育强国」的限定词不能丢，问「建成什么样的教育强国」必须带「中国特色社会主义」。
4. 六力在大会讲话与纲要中两次出现，说明它是本轮政策的枢纽概念，务必闭卷写全六项。

## 附录 C · 六个万能答题框架

1. **概念解释题**：定义原文 → 内涵拆解（3—5 条）→ 意义或作用 → 落到高职教师怎么做。适用于「什么是教师职业道德」「什么是教育家精神」「什么是教育强国六力」。
2. **权利义务／案例定性题**：定主体（学校·教师·学生）→ 定法律 → 默条款 → 对照事实 → 定责任类型（处分·处罚·民事·刑事）。适用于 E46—E50 全部案例。
3. **「如何加强／如何建设」题**：现状与问题 → 分主体措施（国家·学校·教师·社会）→ 制度保障（考核、一票否决、长效机制）→ 升华（立德树人、教育强国、为党育人为国育才）。适用于师德师风、教育家精神、教师队伍建设。
4. **「关系／辨析」题**：分别给两个概念下定义 → 列共同点 → 列三点差异（主体·依据·后果）→ 各举一例。适用于附录 A 全部 20 组，尤其「十项准则与失范处理」「资格与聘任」「处分与处罚」。
5. **时政论述题**：定调句（教育是强国建设、民族复兴之基 / 国之大计党之大计）→ 政策依据（纲要三大属性·六力·八大体系）→ 教科人一体推进 → 落到职教与高职教师（产教融合、大国工匠、双师型）→ 收尾（2035 建成教育强国）。适用于 E51—E56。
6. **材料／案例分析题**：定性（涉及哪些 E 编号）→ 关键点逐条对应 → 程序核对（处分五适当、决定书五项、合法性审查、申诉时限）→ 措施分主体 → 升华。适用于学生权利、处分申诉、师德失范三类材料。
