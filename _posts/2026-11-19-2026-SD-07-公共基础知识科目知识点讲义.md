本系列《第一个月每日知识点讲义》讲的是「每天掌握哪些职教考点」，本篇与《政治理论知识点讲义》是它的**公共科目配套册**：公基是 B 高教型与 C 职教型两类自主招聘**完全重合**的科目，但拉不开差距，投入必须有上限。本篇把资料包《0公共基础知识笔记说明》给出的考情结论放在最前面，按它给每个板块定权重，再把法理学、宪法、行政法、民法、刑法、经济、马哲、公文、科技文史拆成 G01—G60 共 60 个可以直接背、可以直接判客观题的知识点；政治理论部分另见姊妹篇，两篇合起来覆盖公基全卷。

> **本篇开篇即引用考情结论（资料包《0公共基础知识笔记说明》p1 原文）**：高职院校在考查公基时，各板块内容都可能考到，考点平均，在复习时间有限的情况下，一定要抓住重点内容。公基的诸多板块中，**法律体量最大，内容最多，很难记忆，这部分建议不要花费过多时间，过一遍知识点即可，重点复习法理学、宪法、民法、刑法**，时间紧张的情况下，其他法律知识可直接不看。**公文管理等板块不容忽视，内容少，占比却不少。政治板块可以结合时政复习，文史除了过知识点以外，还需要通过做题积累。** 题型上，公基**主要以客观题为主，单选题、多选题、判断题**；**公文会考到简答和公文写作**。这四句话是本篇所有权重、所有 ★ 标记、所有附录的唯一依据。

## 第一部分 · 知识地图（先建立整体逻辑）

零散背 60 个考点效率极低。公基其实是一条「从抽象规范到具体责任、从国家制度到日常常识」的链条，理解这条链，判题时能自动调取：

```
规范层  法是什么、从哪来、管到谁、怎么生效
   ↓    G01 概念本质 / G02 特征与作用 / G03 法与道德政策 / G04 法律关系 / G05 效力与立法权限 / G06 法的实施
根本层  国家根本法与根本制度——所有部门法的上位依据
   ↓    G07 根本法 / G08 基本原则与宪法史 / G09 国体政体经济制度 / G10 选举与特别行政区 / G11 民族与基层自治
权利层  国家与公民之间：给什么权、收什么义务、谁来行使国家权力
   ↓    G12 公民权利 / G13 义务与特定主体 / G14 国家机构职权 / G15 监察司法与宪法修正案
行政层  权力怎么被约束、被侵犯了怎么救
   ↓    G16 行政法原则 / G17 行政行为效力 / G18 行政处罚 / G19 行政强制 / G20 行政复议 / G21 行政诉讼 / G22 国家赔偿 / G23 行政程序与受案排除
```

**一条通用答题主线**（后面每个考点都能套）：

简答与公文写作另用：`判明文种与行文方向 → 套格式要素 → 正文分层（依据／事项／要求）→ 落款与日期`。

## 第二部分 · 法理学与法的运行（G01—G06）

法理学是四册法律里最抽象、也最容易被「过一遍」带过的一册。但它是后面所有条文的语法：法律关系、效力层级、立法权限、法的实施，几乎每个部门法题都要借它定性。按考情结论，本册标 ★ 的点必须能闭卷写出条目，其余 ☆ 点认得即可。

### G01 · 法的概念与本质 ★

**【必背原文】**（`1.法理学.pdf p1`）：法是由**国家制定或认可**（产生方式）、由**国家强制力**（最后保障）保证实施的、由**特定物质生活条件所决定**（决定因素）的**统治阶级意志**（法的本质，在我国统治阶级是人民）的体现，以**权利和义务为内容**的**行为**（不调整思想）规范体系。资料把它压缩为四个抓手：权利义务、社会关系、行为规范。

**【要点拆解】**

1. 四个限定词必须逐字对应：制定或认可＝产生方式；国家强制力＝最后保障；物质生活条件＝决定因素；统治阶级意志＝本质。
2. 「在我国统治阶级是人民」是资料专门补的一句，判断题常把「统治阶级＝少数人」偷换进来。
3. 「以权利和义务为内容」「行为规范」「不调整思想」——法只管行为不管内心，这是与道德、宗教的分界线。
4. 法的概念可拆成「国家意志 + 国家强制力 + 物质决定性 + 权利义务」四层，缺一层即定义不完整。

**【答题框架/落点】**：客观题问「法的本质／决定因素／产生方式／最后保障」时，直接对四个限定词；问「法与思想的关系」答「只调整行为、不调整思想」；简答「什么是法」按「产生方式 → 本质 → 决定因素 → 内容 → 保障」五步写满。

**【易混辨析】**：**法的本质 vs 法的特征**——本质是「统治阶级意志 + 物质生活条件决定」，特征（见 G02）是规范性、国家意志性、普遍性、强制性；前者回答「法是什么」，后者回答「法长什么样」。**国家制定或认可 vs 国家强制力**——前者是「从哪来」，后者是「靠什么兜底」，多选题常把两者对调。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/1.法理学.pdf p1`

### G02 · 法的特征与法的作用 ★

**【必背原文】**（`1.法理学.pdf p1`）：特征四条——**规范性**（法是行为规范）、**国家意志性**（法由国家产生，体现国家意志）、**普遍性**（法律面前人人平等）、**强制性**（法由国家强制力保障）。法的作用分两类：**规范作用**＝指引（自己）、评价（他人）、预测（双方、相互之间、物或人）、强制（违法犯罪者）、教育（一般人、杀鸡儆猴）；**社会作用**＝维护统治（政治功能）、执行公共事务（社会功能）。

**【要点拆解】**

| 规范作用 | 作用对象（判题关键词） |
| --- | --- |
| 指引 | 本人、自己、自己的行为 |
| 评价 | 他人、以法为标准判断别人 |
| 预测 | 双方、相互之间、事先估计对方将如何行为 |
| 强制 | 违法犯罪者、制裁 |
| 教育 | 一般人、示范与警示（杀鸡儆猴） |

1. 五种规范作用**按「对象」区分**，这是资料给出的唯一判据，不要按「作用大小」猜。
2. 社会作用只有两条：政治功能（维护统治）+ 社会功能（执行公共事务）。
3. 法与经济：**经济决定法**；法与政治：**政治主导法，法服务于政治**；法与执政党政策：**党的政策指导法**。

**【答题框架/落点】**：单选题给一句情境（如「法官除了法律无别的上司」）问体现哪种作用／特征，先抓对象词再对表；「指引自己 / 评价他人 / 预测双方 / 强制违法者 / 教育一般人」五词背成口诀。

**【易混辨析】**：**指引 vs 评价**——作用对象是「自己」还是「他人」，一字之差即换答案。**规范作用 vs 社会作用**——前者作用于「人的行为」（五种），后者作用于「社会整体」（两条）。**评价 vs 强制**——评价是「判断」，强制是「制裁」。

**【真题锚点】**：山东开放大学 2023 单选「『法官除了法律无别的上司』，说明法具有？」——考法的特征／作用定性；同卷「礼已具备法的性质是在哪个朝代」考法的历史形态（属文史+法理交叉，见 G58 板块索引）。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/1.法理学.pdf p1`

### G03 · 法与道德、法与执政党政策 ☆

**【必背原文】**（`1.法理学.pdf p1—2`）：法与道德**区别**五条——生成方式不同（国家制定或认可 / 自发演进生成）、表现形式不同（法典、法条 / 内心、舆论或语言）、调整范围不同（调整范围较小 / 调整范围较大）、评价标准不同（标准明确 / 标准模糊）、**强制方式不同（最大区别）**（依靠国家强制力，外在强制力 / 依靠舆论和自觉，内在强制力）。法与政策**区别**四条——体现的意志不同（国家意志 / 全党意志）、表现形式不同（法典、法条 / 一般为决议、宣言、决定、声明、通知等）、实施方式不同（依靠国家强制力 / 依靠党纪制裁）、稳定性不同（稳定性较高、程序严格 / 灵活性较大）。补充：道德「自发形成、管言论和行为、评价不统一、调整广、依靠舆论和自觉」；宗教「同时控制思想」；党的政策「指导法」。

**【要点拆解】**

1. 法与道德的**最大区别是强制方式**（国家强制力 vs 舆论和自觉），这一句几乎必考。
2. 「调整范围」道德更广、法较窄；「评价标准」法明确、道德模糊——两栏不要对调。
3. 法与政策：意志（国家 / 全党）、形式（法条 / 决议通知）、实施（国家强制力 / 党纪制裁）、稳定性（高 / 灵活）四行成对背。
4. 共同点：法和道德**都是社会规范，都可以调整社会关系**——判断题常以「法与道德毫无关系」设错。

**【答题框架/落点】**：表格型多选题直接按五栏/四栏对齐；单选问「最大区别」答强制方式；问「法与政策的关系」答「党的政策指导法」。

**【易混辨析】**：**法 vs 道德**——强制方式（最大区别）、生成方式、表现形式、调整范围、评价标准五组。**法 vs 政策**——体现意志、表现形式、实施方式、稳定性四组。**道德 vs 宗教**——道德管言论和行为，宗教「同时控制思想」，多一层内心控制。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/1.法理学.pdf p1—2`

### G04 · 法律关系三要素与法律事实 ★

**【必背原文】**（`1.法理学.pdf p2`）：法律关系是**人们之间的权利义务关系**，由**主体、内容、客体**三要素构成。主体：自然人、法人、其他组织、国家（法人＝能独立承担责任的组织；非法人组织＝不能独立承担责任的组织）。客体：物、人身（人身利益）、行为结果（精神财富）、智力成果（行为）。内容：权利（可以享有，可以放弃；自主决定；主要、第一位）与义务（强制的，必须履行；必须做或者不做；次要、第二位；履行义务是为了享有权利）。形成、变更和消灭：**依据**是法律规范（民法典属于法律规范），**条件和中介**是法律事实＝法律事件 + 法律行为；法律事件不以当事人意志为转移（自然灾害、人的自然出生死亡、社会事件等），法律行为以当事人意志为转移（订立合同、婚姻、立遗嘱等）。

**【要点拆解】**

1. 三要素缺一不可，多选题常给四个选项让挑出「不属于要素」的那个。
2. 权利可放弃、义务必须履行——判断题最爱把「义务也可以放弃」设为错项。
3. 客体的四种写法按资料原样记：物 / 人身（人身利益）/ 行为结果（精神财富）/ 智力成果（行为）。
4. 法律事实二分：**事件＝不以意志为转移**（出生、死亡、灾害），**行为＝以意志为转移**（合同、婚姻、遗嘱）。

**【答题框架/落点】**：给情境问「引起法律关系产生的是事件还是行为」，先看有没有「人的意志」；问「法人 vs 非法人组织」只抓「能否独立承担责任」一条。

**【易混辨析】**：**法律事件 vs 法律行为**——是否以当事人意志为转移，前者如自然灾害、出生死亡，后者如订立合同、立遗嘱。**权利 vs 义务**——可放弃 / 必须履行、第一位 / 第二位。**法人 vs 非法人组织**——能否独立承担责任（资料举例：非法人组织如合伙，见民法册）。**法律规范 vs 法律事实**——前者是「依据」，后者是「条件和中介」。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/1.法理学.pdf p2`

### G05 · 法的效力层次、效力范围与立法权限排序 ★

**【必背原文】**（`1.法理学.pdf p2—3`）：**效力层次**四条——上位法的效力高于下位法；同一机关制定两法，**特别法优于一般法**；同一机关制定两法，**新法优于旧法**；根本法（宪法）优于普通法。**效力范围**：三分法＝对人、空间、时间；四分法＝对人、事、空间、时间。对人：以**属地主义为主，与属人主义、保护主义相结合（结合主义：我国）**；空间：主权、驻外使馆（视为本国领土的延伸）、船舶飞机（旗国主义）；时间：生效必须经公布，三种生效情形（一般自公布之日起生效 / 公布后由该法具体规定生效时间 / 公布后符合一定条件时生效），失效分明示和默示，**溯及力：原则上不溯及既往，从旧兼从轻原则，但新法更有利于当事人的除外**。**立法权（考制定机关）**：全国人大及人常＝法律（国家立法权）；国务院＝行政法规；国务院部门、直属机构＝部门规章；省级、设区市（自治州）人大人常＝地方性法规；省级、设区市（自治州）政府＝政府规章；自治地方人大＝自治条例和单行条例。**立法效力排序（考排序）**：上级 > 下级、同级人大 > 同级政府；①宪法＞法律＞行政法规＞地方性法规；②宪法＞法律＞行政法规＞部门规章；③本级地方性法规＞本级地方政府规章；④省级地方性法规＞设区的市地方性法规；⑤省级政府规章＞设区的市政府规章。**立法裁决**：地方性法规与部门规章→国务院提意见；政府规章与部门规章→国务院裁决。

**【要点拆解】**

| 制定机关 | 规范性文件 | 记忆锚 |
| --- | --- | --- |
| 全国人大及人常 | 法律 | 国家立法权 |
| 国务院 | 行政法规 | 最高行政机关 |
| 国务院部门、直属机构 | 部门规章 | 部委 |
| 省级、设区市人大人常 | 地方性法规 | 人大系统 |
| 省级、设区市政府 | 政府规章 | 政府系统 |
| 自治地方人大 | 自治条例、单行条例 | 自治地方 |

1. 排序题先分「人大系统 / 政府系统」，同级人大 > 同级政府，上级 > 下级。
2. 「宪法 > 法律 > 行政法规」是三段固定主干，后面接地方性法规或部门规章都对，但**地方性法规与部门规章冲突不由法院判，走国务院提意见**。
3. 溯及力只记「从旧兼从轻 + 新法更有利于当事人的除外」。
4. 生效三情形以「必须经公布」为前提；驻外使馆、船舶飞机属空间效力的两个特例。

**【答题框架/落点】**：排序题按「宪法—法律—行政法规—地方性法规 / 部门规章」先定大框架，再用「上级 > 下级、同级人大 > 同级政府」收口；问「特别法与一般法、新法与旧法」答「同一机关制定」这个前提，否则规则不适用。

**【易混辨析】**：**特别法优于一般法 vs 新法优于旧法**——两者都要求「同一机关制定」，前者看事项特别与否，后者看时间先后。**上位法 vs 根本法**——上位法优于下位法是层级规则，宪法优于普通法是根本法规则，别混成一条。**地方性法规 vs 部门规章冲突**（国务院提意见）**vs 政府规章 vs 部门规章冲突**（国务院裁决）——一个「提意见」、一个「裁决」，资料原文不可互换。**法律 vs 法规 vs 规章**——制定机关分别是全国人大及人常 / 国务院 / 部委与地方政府。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/1.法理学.pdf p2—3`

### G06 · 法的实施：执法、司法、守法与法律责任 ☆

**【必背原文】**（`1.法理学.pdf p3—4`）：法的生命在于法的实施。**执法（主动）**：主体是行政机关（政府及其部门），内容是全面管理，特征＝强制性、主动性、单方面性。**司法（被动）**：主体是司法机关（法院、检察院），内容是处理案件，特征＝强制性、被动性、程序性。**守法**：主体是所有人（一切人和组织），内容是依法行使权利和履行义务。法律责任产生的原因：违法、违约、法律规定；分类：民事、刑事、行政、违宪。法律渊源：以宪法为核心的制定法等。

**【要点拆解】**

| 环节 | 主体 | 内容 | 特征 | 主动/被动 |
| --- | --- | --- | --- | --- |
| 执法 | 行政机关 | 全面管理 | 强制性、主动性、单方面性 | 主动 |
| 司法 | 法院、检察院 | 处理案件 | 强制性、被动性、程序性 | 被动 |
| 守法 | 一切人和组织 | 依法行使权利、履行义务 | — | — |

1. 执法与司法最简判据：**主动 / 被动**；再加「单方面性 / 程序性」区分。
2. 守法主体是「所有人」，不是仅公民——判断题常把主体缩窄。
3. 法律责任四类：民事、刑事、行政、违宪；产生原因三条：违法、违约、法律规定。

**【答题框架/落点】**：给「工商局主动查处」「法院不告不理」这类情境，先定主动/被动，再定主体；问「法律责任产生原因」按三条原文列。

**【易混辨析】**：**执法 vs 司法**——行政机关主动全面管理 / 司法机关被动处理案件，且前者单方面性、后者程序性。**守法 vs 执法**——主体不同（一切人和组织 / 行政机关）。**违法 vs 违约**——同属法律责任产生原因，但一是违反法律、一是违反约定，资料把「法律规定」单列为第三类。

**【真题锚点】**：命题角度——山东开放大学 2023「把权力装进制度的笼子里需要推进权力运行？」可与「法无授权不可为」（见 G16 合法性原则）合并作答，属法理学与行政法交叉。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/1.法理学.pdf p3—4`

## 第三部分 · 宪法（G07—G15）

宪法是考情结论点名的四个重点之一，也是数字、机关职权、制度名称最密集的一册。按资料，`2.宪法.pdf` 共 7 页，本部分 9 个考点全部标 ★ 或 ☆，其中「特别行政区」一处必须写明中央保留国防与外交权。

### G07 · 宪法是根本法：三大特征、分类、渊源与结构 ★

**【必背原文】**（`2.宪法.pdf p1`）：宪法规定**根本制度：社会主义**；**根本任务：集中力量进行现代化建设**（沿着中国特色的社会主义道路，集中力量进行社会主义现代化建设）。宪法是根本法，体现为**内容上的根本性、效力上的最高性、制修程序上的严格性**。特征三条：根本法（内容上的根本性、效力上的最高性、制修程序上的严格性）、**权利保障书**、**民主事实法律化**。分类：我国是**成文宪法、刚性宪法、民定宪法、社会主义类型**的宪法（成文√不成文、刚性√柔性、钦定/协定/民定√、资本主义/社会主义√）。渊源：宪法典√、宪法性法律√、宪法惯例√、**宪法判例×（目前不是我国宪法的渊源）**、国际条约√。结构：序言√、正文√、附则；国家机构；国旗、国歌、国徽、首都（国家标志）。

**【要点拆解】**

1. 根本法「三性」＝内容根本性、效力最高性、制修程序严格性，三者缺一不可。
2. 我国宪法四个分类标签：成文、刚性、民定、社会主义类型。
3. 「宪法判例不是我国宪法渊源」是判断题高频错项（把英美做法搬过来即错）。
4. 国家标志四项：国旗、国歌、国徽、首都。

**【答题框架/落点】**：问「宪法为什么是根本法」答三性；问「我国宪法类型」答四个标签；问「渊源」逐项打勾并特别排除宪法判例。

**【易混辨析】**：**成文 vs 不成文**（有无统一法典）、**刚性 vs 柔性**（修宪程序是否严格）、**钦定/协定/民定**（制定主体）——三组分类标准不同，别把「民定」当成「成文」的同义词。**宪法典 vs 宪法性法律**——都是渊源，但位阶与形式不同；**宪法惯例 vs 宪法判例**——前者是我国渊源，后者不是。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/2.宪法.pdf p1`

### G08 · 宪法基本原则、新中国宪法史与宪法日 ★

**【必背原文】**（`2.宪法.pdf p1`）：基本原则四条——**人民主权原则、基本人权原则、权力制约原则、法治原则**。新中国宪法的历史：**共同纲领（宪法性文件）、1954 宪法（第一部宪法）、1982 宪法（现行宪法）**；**宪法日：12 月 4 日**。

**【要点拆解】**

1. 四原则按「主权归谁—保障什么—权力怎么摆—按什么治理」串记：人民主权 / 基本人权 / 权力制约 / 法治。
2. 三个时间节点：共同纲领是「宪法性文件」而非宪法；1954 是「第一部宪法」；1982 是「现行宪法」。
3. 宪法日 12 月 4 日，与现行宪法（1982 年 12 月 4 日通过）对应，属附录 B 必背数字。

**【答题框架/落点】**：单选问「现行宪法」答 1982；问「第一部宪法」答 1954；问「宪法性文件」答共同纲领；问「宪法日」答 12 月 4 日。

**【易混辨析】**：**人民主权 vs 基本人权**——前者讲权力来源（一切权力属于人民），后者讲权利保障。**权力制约 vs 法治原则**——前者讲权力之间的关系，后者讲依法治理。**1954 宪法 vs 1982 宪法**——「第一部」与「现行」是两个标签，最易互换；**共同纲领 vs 宪法**——共同纲领只是宪法性文件。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/2.宪法.pdf p1`

### G09 · 国家基本制度：国体、政体、国家结构与基本经济制度 ★

**【必背原文】**（`2.宪法.pdf p1—2`）：**根本制度：社会主义制度**；**国体（国家性质）：人民民主专政**；**政体、政权组织形式、根本政治制度：人民代表大会制度**；国家结构形式：**我国是单一制√、联邦制×**。中共领导多党合作：共产党实行政治领导（执政党），民主党派为参政党；爱国统一战线的组织形式：政协。经济制度：公有制为主体（全民、集体、混合制当中的全民和集体成分），非公有制是重要组成部分（个体、私营、三资）。补充：国有经济是国民经济的**主导力量**，国家保障国有经济的巩固和发展；对集体经济实行鼓励、指导和帮助；国家**鼓励、支持、引导**非公有制经济的发展，并依法实行监督和管理。自然资源：**矿藏、水流、城市的土地属于国家所有**；**宅基地和自留地、自留山属于集体所有**；森林、山岭、草原、荒地、滩涂等既可属国家所有，也可由法律规定属集体所有。

**【要点拆解】**

| 概念 | 资料原文定位 |
| --- | --- |
| 根本制度 | 社会主义制度 |
| 国体 | 人民民主专政 |
| 政体 / 根本政治制度 | 人民代表大会制度 |
| 国家结构形式 | 单一制（联邦制×） |
| 基本经济制度 | 公有制为主体、多种所有制经济共同发展 |
| 分配制度 | 按劳分配为主体、多种分配方式并存 |

1. 「国体 / 政体 / 根本制度 / 根本政治制度」四个词必须一一对号，这是本册最高频的配对题。
2. 自然资源归属三句要分层：国家专有（矿藏、水流、城市土地）、集体专有（宅基地、自留地、自留山）、两者皆可（森林山岭草原荒地滩涂）。
3. 非公有制政策动词是「鼓励、支持、引导 + 依法监督和管理」，不是「限制」。

**【答题框架/落点】**：配对题直接对表；问「国有经济地位」答「主导力量」；问「公有制主体地位还表现在」答自然资源归国家和集体所有。

**【易混辨析】**：**国体 vs 政体**——人民民主专政 / 人民代表大会制度，前者是「谁掌权」，后者是「怎么组织政权」。**根本制度 vs 根本政治制度**——社会主义制度 / 人民代表大会制度。**单一制 vs 联邦制**——我国是单一制。**国有经济（主导力量）vs 公有制（主体）**——一个讲主导、一个讲主体，资料用词不同。**城市土地（国家所有）vs 宅基地自留地自留山（集体所有）**——最易对调的一组。

**【真题锚点】**：命题角度——滨州职院 2024 单选「四个全面、五位一体」「现代化建设中处于核心地位」，同卷政治常识与本册「根本制度／根本政治制度」属同一配对题族；答题时勿把「五位一体」误答成根本制度。

### G10 · 选举制度与特别行政区制度 ★

**【必背原文】**（`2.宪法.pdf p2—3`）：选举制度四原则——**普遍性、平等、直接与间接并用、秘密投票**。享有选举权的基本条件：**中国公民、年满十八周岁、未被剥夺政治权利**。平等原则：每个选民在每次选举中只能在一个选区享有一个投票权；不承认也不允许任何选民因民族、职业、财产状况、家庭出身、居住情况的不同而享有特权；实行**同票同权**，每一代表所代表的城乡人口数相同。直接选举：不设区的市、市辖区、县、自治县（县级）、乡、民族乡、镇（乡）的人民代表大会代表由选民直接选出，受选民监督、对选民负责；间接选举：全国人民代表大会代表，省、自治区、直辖市、设区的市、自治州的人民代表大会代表由下一级人民代表大会选出，受原选举单位监督、对原选举单位负责。秘密投票＝无记名投票，可填同意、不同意、弃权、另选他人。**特别行政区制度：中央保留国防和外交**（补充知识：特别行政区**无国防、外交权**）。中央与特别行政区的关系：全国人大**决定特别行政区的设立及其制度**、制定并修改特别行政区基本法的专属权（基本法修改提案权属于全国人大常委会、国务院和特别行政区）；全国人大常委会**对基本法的解释权**、特区立法的备案审查权（特区立法会制定的法律只须报全国人大常委会备案，人大常委会认为有问题可以**发回但不能撤销**，被发回的法律自发回之日起立即失效，一般不具有溯及力）、**特区进入紧急状态的决定权**；国务院**负责管理与特区有关的外交事务、负责管理特区的防务、任命特区行政长官及其他主要行政官员**。

**【要点拆解】**

1. 选举权三条件：中国公民 + 年满 18 周岁 + 未被剥夺政治权利，缺一不可。
2. 直接 / 间接的分界：**县级、乡级直选；设区的市及以上、省级、全国间接选**。
3. 特别行政区一句话总纲：**中央保留国防与外交权，特别行政区无国防、外交权**；具体分属全国人大（设立、基本法）、全国人大常委会（解释、备案发回、紧急状态）、国务院（外交、防务、任命）。
4. 「发回但不能撤销」「立即失效、一般不溯及既往」是资料原文的两个精确限定，判断题高频。
5. 中国香港、中国澳门保持长期繁荣稳定，坚持「一国两制」和推进祖国统一（详见姊妹篇政治理论讲义相关条目）。

**【答题框架/落点】**：问「直接选举的范围」答「县、乡两级」；问「特别行政区的权力边界」先答「中央保留国防与外交」，再分述全国人大、人大常委会、国务院三项职权；问「基本法解释权」答全国人大常委会。

**【易混辨析】**：**直接选举 vs 间接选举**——县乡两级直选，设区的市及以上间接选；「代表受谁监督」也随之不同（选民 / 原选举单位）。**全国人大 vs 全国人大常委会（特区事务）**——前者「决定设立、制定修改基本法」，后者「解释基本法、备案发回、决定紧急状态」。**备案发回 vs 撤销**——人大常委会只能发回、不能撤销。**国务院（外交、防务、任命）vs 全国人大（设立与制度）**——一行政、一最高权力机关。**中国香港、中国澳门、中国台湾**——涉及三地一律写「中国香港」「中国澳门」「中国台湾」，特别行政区制度适用于中国香港、中国澳门，中央保留国防与外交权。

**【真题锚点】**：命题角度——宪法「特别行政区」常与政治理论「坚持『一国两制』和推进祖国统一」混考；判题时务必落到「中央保留国防与外交权」这一句，不要泛答「高度自治」。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/2.宪法.pdf p2—3`

### G11 · 民族区域自治制度与基层群众自治制度 ☆

**【必背原文】**（`2.宪法.pdf p3`）：**民族区域自治制度**：自治地方＝**自治区、自治州、自治县**；自治机关＝自治区、自治州、自治县的**人民代表大会和人民政府**；享有自治权。**基层群众自治制度**：村委会、居委会；与基层政权是**指导关系**（任期：**5 年**）。

**【要点拆解】**

1. 自治地方三级：自治区、州、县——**没有「自治市」「民族乡」**（民族乡不是自治地方）。
2. 自治机关只有「人大 + 政府」，**不含法院、检察院、监察委**。
3. 基层群众自治组织与基层政权是「指导关系」，不是「领导关系」——判断题最爱改成领导。
4. 村委会、居委会任期 5 年（资料原文），记入附录 B。

**【答题框架/落点】**：配对题按「自治地方三级 / 自治机关两类 / 基层两组织 / 指导关系」四格作答；问「村委会与乡镇政府关系」答指导关系。

**【易混辨析】**：**自治机关（人大+政府）vs 自治地方（区、州、县）**——一个是机关、一个是行政区划。**指导关系 vs 领导关系**——基层政权对村委会、居委会是指导；而监察机关上下级是领导（见 G15）。**民族乡 vs 自治县**——民族乡不是民族自治地方。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/2.宪法.pdf p3`

### G12 · 公民的基本权利 ★

**【必背原文】**（`2.宪法.pdf p3—4`）：**平等权**：不受不合理差别对待。**政治权利和自由**：选举、被选举；**六大自由**：言论、出版、集会、结社、游行、示威；**监督权**：批评权、建议权、控告、检举、申诉权。**宗教信仰自由**。**人身自由**：①生命权；②人身自由（禁止非法限制、搜查、拘留、逮捕）；③人格尊严（姓名权、肖像权、名誉权、荣誉权和隐私权）；④住宅权（禁止非法搜查或者非法侵入）；⑤通信自由和秘密。**经济文化权利**：①财产权（合法财产要保护，**征收征用要补偿**；注：**没有「私有财产神圣不可侵犯」**）；②劳动权和受教育权；③获得物质帮助权（**年老、疾病、丧失劳动能力**）；④休息权（劳动者）；⑤文化权利和自由。

**【要点拆解】**

| 权利族 | 条目 | 易设错点 |
| --- | --- | --- |
| 政治权利与自由 | 选举被选举、六大自由、监督权 | 「六大自由」不含「罢工」 |
| 人身自由 | 生命权、人身自由、人格尊严、住宅权、通信自由和秘密 | 五项须背全 |
| 经济文化权利 | 财产权、劳动权、受教育权、物质帮助权、休息权、文化权利 | 财产权无「神圣不可侵犯」表述 |
| 监督权 | 批评、建议、控告、检举、申诉 | 五个词别漏 |

1. 「六大自由」＝言论、出版、集会、结社、游行、示威，背成固定六字串。
2. 「征收征用要补偿」「没有私有财产神圣不可侵犯」是资料加注的两句，判断题高频。
3. 物质帮助权三情形：年老、疾病、丧失劳动能力；休息权主体是「劳动者」。

**【答题框架/落点】**：问「政治权利和自由包括」按「选举被选举 + 六大自由 + 监督权」三层答；问「人格尊严包括」按姓名、肖像、名誉、荣誉、隐私五项答；问「财产权」务必带「征收征用要补偿」。

**【易混辨析】**：**政治权利 vs 政治自由**——选举被选举是权利，六大自由是自由，监督权另列。**控告/检举/申诉**——同属监督权但对象不同，资料只要求能整体选出。**劳动权 vs 休息权**——后者主体限定「劳动者」。**人格尊严（宪法）vs 人格权（民法，见 G31）**——宪法列姓名、肖像、名誉、荣誉、隐私；民法另分生命权、身体权、健康权等，答题按题干问的是「宪法」还是「民法」选口径。

**【真题锚点】**：山东服装职院 2023 论述「材料分析侵犯了学生的什么权利」——需从宪法公民基本权利与民法人身权（G31）双口径定性，属跨册综合题。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/2.宪法.pdf p3—4`

### G13 · 公民的基本义务与特定主体权利 ☆

**【必背原文】**（`2.宪法.pdf p4`）：义务：**服兵役、纳税等**。**特定人权利**（也称特定主体的权利）：宪法除对所有公民普遍享有的权利和自由作出规定外，还对具有特定情况的公民设置专门规定、给予特别保护，主要内容四条——①保护妇女的权益；②保护婚姻、家庭、母亲、儿童和老人；③保护华侨、归侨和侨眷的权益；④保护军烈属的权益。

**【要点拆解】**

1. 义务资料只列「服兵役、纳税等」，答题不要自行扩写素材没有的义务条文。
2. 特定主体权利四条：妇女 / 婚姻家庭母亲儿童老人 / 华侨归侨侨眷 / 军烈属。
3. 「特定人权利」与「平等权」并不矛盾——它是对特定情况的专门保护。

**【答题框架/落点】**：多选「下列属于宪法规定的特定主体权利」直接对四条；简答「特定人权利」按四条 + 一句「给予特别保护」写满。

**【易混辨析】**：**公民基本义务 vs 特定主体权利**——前者是「必须做」（服兵役、纳税），后者是「受特别保护」；**华侨 / 归侨 / 侨眷**——三者并列，不可只答「华侨」；**特定主体权利 vs 普遍权利**——看题干是否出现「妇女」「儿童」「军烈属」等限定词。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/2.宪法.pdf p4`

### G14 · 国家机构：组织活动原则与主要机关职权 ★

**【必背原文】**（`2.宪法.pdf p4—5`）：组织和活动原则五条——**民主集中制原则（地位：根本组织原则）**、社会主义法治原则、责任制原则（**集体负责制**：全体人员集体讨论、按少数服从多数作出决定、集体承担责任，各级人大和常委会、监察委员会、人民法院和人民检察院等实行；**个人负责制**：首长个人决定问题并承担相应责任，国务院及其部委、地方政府和中央军委等实行）、密切联系群众为人民服务原则、精简和效率原则。**全国人大**：地位＝最高权力和最高立法机关；由省、自治区、直辖市、特别行政区和军队选出的代表组成，各少数民族都应有适当代表；**任期每届 5 年**，会议每年举行 1 次，由全国人大常委会召集。职权口诀「监督修宪制基本、三席三高三提名、计划预算战与和、改撤人常省建置」；资料列明：修改宪法、监督宪法的实施、制定和修改刑事民事国家机构的和其他的基本法律；选举主席、副主席、中央军事委员会主席（三席）；根据主席提名决定国务院总理人选、根据总理提名决定副总理等国务院组成人员（三提名）；选举国家监察委员会主任、最高人民法院院长、最高人民检察院检察长（三高）；改变或者撤销全国人大常委会不适当的决定；批准省、自治区、直辖市的建置；决定特别行政区的设立及其制度；决定战争与和平的问题。**人大代表权利**：言论免责权、人身受特别保护权（刑事获免权）。**全国人大常委会**：组成人员不得担任行政、司法机关职务；重点职权＝解释宪法和法律、监督宪法实施、制修非基本法律、监督军委与一府一委两院工作、撤销国务院及地方权力机关不适当的决定、决定特赦、宣布战争状态、动员、决定省以上紧急状态（口诀「督宪解释造非基、监督机关和撤销、特赦动员来开战、省国紧急找人常」）。**国务院**：地位＝最高行政机关；总理、副总理、国务委员**连续任职不得超过两届**；领导体制＝**总理负责制**；职权＝制定行政法规、管理国防等行政事务、改变或撤销下级不适当的决定、批准市县的建置和省市县的区域划分、决定省内进入紧急状态。**国家元首**：产生条件＝有选举权和被选举权 + **年满 45 周岁** + 中国公民；职权为礼节性职权。

**【要点拆解】**

| 机关 | 地位 | 任期/年限 | 领导体制 |
| --- | --- | --- | --- |
| 全国人大 | 最高权力、最高立法机关 | 每届 5 年 | 集体负责制 |
| 全国人大常委会 | 常设机关 | — | 集体负责制 |
| 国务院 | 最高行政机关 | 总理等连续任职不超两届 | 总理负责制 |
| 国家元首 | — | 年满 45 周岁 | — |

1. 「三席三高三提名」要把「选举」与「决定」分开：三席三高是选举，国务院组成人员是「提名—决定」。
2. 全国人大「批准省、自治区、直辖市的建置」，国务院「批准市县的建置和省市县的区域划分」——建置层级不同，最易混。
3. 紧急状态：全国人大常委会决定「省以上」，国务院决定「省内」。
4. 集体负责制（人大、常委会、监察委、法院、检察院）vs 个人负责制（国务院及部委、地方政府、中央军委）。

**【答题框架/落点】**：问「最高国家权力机关」答全国人大；问「解释宪法和法律」答全国人大常委会；问「制定行政法规」答国务院；问「根本组织原则」答民主集中制；问「国家元首任职年龄」答 45 周岁。

**【易混辨析】**：**修改宪法（全国人大）vs 解释宪法（全国人大常委会）**——一字之差、机关不同。**基本法律（全国人大）vs 非基本法律（人大常委会）**——制修主体不同。**建置（人大批省级、国务院批市县）vs 区域划分（国务院）**——层级与动词都要对。**集体负责制 vs 个人负责制**——按上表分机关。**言论免责权 vs 人身受特别保护权**——人大代表两项权利，前者针对发言表决、后者针对刑事拘留逮捕程序。

**【真题锚点】**：命题角度——「人民代表大会」是资料可检索的高频词，山东开放大学 2023 多选「教育组织形式」「六艺」等属文史教育交叉；本点常与 G09「政体＝人民代表大会制度」连考。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/2.宪法.pdf p4—5`

### G15 · 监察委员会、人民法院、人民检察院、宪法修正案与宪法宣誓 ★

**【必背原文】**（`2.宪法.pdf p5—6`）：**中央军委**：可连选连任；军委主席对全国人大和全国人大常委会负责，**但不报告工作**。**监察委员会**：职责＝**监督、调查、处置**；监察机关上下级是**领导**关系；独立行使监察权，与司法机关、执法部门互相配合、互相制约；国家监察委员会主任**连续任职不得超过两届**。**人民法院**：审判机关；最高人民法院院长任期与全国人大每届任期相同（**5 年**），连续任职不得超过两届；组织体系＝最高院、省高院、市中院、基层人民法院 + 专门法院；上下级是**监督关系**（独立审判）。**人民检察院**：法律监督机关；最高人民检察院检察长每届 5 年、连续任职不得超过两届；组织体系同法院；上下级是**领导**；职权＝立案侦查、批准逮捕、提起公诉，以及侦查监督、审判监督、执行监督。**宪法修正案**（资料列 6 条 + 口诀 7 句）：①贯彻新发展理念；②将「健全社会主义**法制**」修改为「健全社会主义**法治**」；③增加宪法宣誓规定：国家工作人员就职时应当依照法律规定公开进行宪法宣誓；④爱国统一战线扩展为「全体社会主义劳动者、社会主义事业的建设者、拥护社会主义的爱国者、拥护祖国统一和致力于中华民族伟大复兴的爱国者」；⑤**中国共产党领导是中国特色社会主义最本质的特征**；⑥删除了「连续任职不得超过两届」的规定。口诀：「科习思想新发展，党的领导最本质／社会生态和谐美，建设强国要复兴／设区市有立法权，宪法宣誓法治全／革命建设来改革，爱国战线来复兴／民族关系更和谐，和平互利共同体／正副主席无限制，核心价值要倡导／宪法法律委员会，监察机关入宪法」。

**【要点拆解】**

1. 「法制 → 法治」是宪法修正案原文用字，务必按资料写，判断题常以「法治 → 法制」反向设错。
2. 监察委上下级「领导」、法院上下级「监督」、检察院上下级「领导」——三组关系是本册第一易混点。
3. 军委主席「负责但不报告工作」，一句原文、一个特例。
4. 宪法宣誓：主体＝国家工作人员，方式＝依照法律规定公开进行。

**【答题框架/落点】**：问「法律监督机关」答人民检察院；问「审判机关」答人民法院；问「法院上下级关系」答监督、检察院答领导；问「宪法修正案把什么改成了什么」答「健全社会主义法制」→「健全社会主义法治」。

**【易混辨析】**：**法制 vs 法治**——宪法修正案把「法制」修改为「法治」，前者偏静态制度、后者偏治理方式；按资料原文只记「这次修改的方向」。**法院（监督）vs 检察院（领导）vs 监察委（领导）**——上下级关系三选一。**法院院长 / 检察院检察长（连任不超两届、每届 5 年）vs 军委主席（可连选连任、负责但不报告工作）**。**宪法修正案（2018 年内容）vs 宪法本身（1982 年现行）**——问「现行宪法」答 1982，问「增加宪法宣誓、监察机关入宪」答修正案。

**【真题锚点】**：山东政法学院 2022 思政课真题选择涉及「重要会议（十九届六中全会）」与马原著作，宪法修正案常与「党的领导是最本质特征」一起在党建常识题中出现；命题角度——「把权力装进制度的笼子里」（山东开放大学 2023）可引「权力制约原则」（G08）与监察委职责（本点）作答。

## 第四部分 · 行政法（G16—G23）

按考情结论，行政法属「其他法律知识」，标 ★★ 过一遍即可；但它贡献了全册最多的**判题口径数字**（14 周岁、50 元、1000 元、20 元、2 人、7 日、60 日、15 日、6 个月），且「复议 vs 诉讼」「处罚 vs 强制」是判题必考，所以本部分每一点都必须能当场判、能当场排除错项。

### G16 · 行政法概念与六项基本原则 ★

**【必背原文】**（`3.行政法.pdf p1`）：行政法是由于行政活动产生的行政关系法律规范的总和。基本原则六条——**合法性原则（地位：首要；法有规定不可为，法无授权不可为）**、**合理性原则（公平公正、比例原则）**、**程序正当原则（行政公开、公正参与）**、**高效便民原则（便民当事人、减轻程序负担）**、**诚实守信原则（行政行为不得随意撤销或变更）**、**权责统一原则（行政职权和职责的统一）**。行政主体＝行政机关和授权组织；相对人＝个人、组织。

**【要点拆解】**

| 原则 | 资料关键词 | 地位/落点 |
| --- | --- | --- |
| 合法性 | 法有规定不可为、法无授权不可为 | **首要原则** |
| 合理性 | 公平公正、比例原则 | 裁量适当 |
| 程序正当 | 行政公开、公正参与 | 程序层面 |
| 高效便民 | 便民当事人、减轻程序负担 | 效率层面 |
| 诚实守信 | 不得随意撤销或变更 | 信赖保护 |
| 权责统一 | 职权和职责的统一 | 有权必有责 |

1. 「首要原则」只有合法性一个，多选题常把合理性抬到首位设错。
2. 合法性两句口诀「法有规定不可为、法无授权不可为」是资料原文，区别于刑法「法无明文规定不为罪」（见 G36）。
3. 比例原则归在合理性之下，不要单列为第七个原则。

**【答题框架/落点】**：问「行政法首要原则」只答合法性；给「处罚明显过重」情境答合理性（比例原则）；给「不听取陈述申辩」情境答程序正当；给「出尔反尔撤回许可」答诚实守信。

**【易混辨析】**：**合法性 vs 合理性**——前者管「有没有授权」，后者管「裁量过不过分」；**程序正当 vs 高效便民**——一个讲公开参与、一个讲减轻负担；**诚实守信 vs 权责统一**——一个讲不得随意撤销变更、一个讲职权与职责对等；**行政主体 vs 行政相对人**——行政机关和授权组织 / 个人、组织。

**【真题锚点】**：山东开放大学 2023 单选「把权力装进制度的笼子里需要推进权力运行？」——标准落点是合法性原则「法无授权不可为」+ 权力制约，可与 G01、G08 串答；命题角度：本点常与宪法「权力制约原则」合并出多选。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/3.行政法.pdf p1`

### G17 · 行政主体、行政行为效力与分类 ★

**【必背原文】**（`3.行政法.pdf p1`）：行政行为是行政主体作出的能够产生行政法律效果的行为。**四效力**：**公定力（默认合法）、确定力（不得随意更改）、约束力（要遵守）、执行力（强制执行）**。分类七组：行政立法、执法、司法行为；内部和外部；羁束和自由裁量；依职权和依申请；要式和非要式；授益和负担；**具体（特定对象）和抽象（无特定对象）**。具体行政行为以行政处罚为代表（见 G18）。

**【要点拆解】**

1. 四效力按「默认合法 → 不得改 → 必须守 → 可强制」顺序背，各对应一个括号里的资料原注。
2. 「具体 vs 抽象」的唯一判据是**对象是否特定**，这是行政复议、行政诉讼受案范围的前置判断。
3. 依职权（主动）vs 依申请（被动）、授益（给好处）vs 负担（设义务）是两组常配对的分类。

**【答题框架/落点】**：问「行政行为被推定合法」答公定力；问「生效后不得任意变更」答确定力；问「复议/诉讼能不能告」先定具体还是抽象（抽象一般不可单独告，见 G23）。

**【易混辨析】**：**公定力 vs 确定力**——前者「默认合法」是推定，后者「不得随意更改」是存续力；**确定力 vs 约束力**——一个约束行政机关自己别改，一个约束相对人要遵守；**具体行政行为 vs 抽象行政行为**——特定对象 / 无特定对象；**羁束 vs 自由裁量**——有无选择余地。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/3.行政法.pdf p1`

### G18 · 行政处罚：种类、设定权、适用、程序与执行 ★

**【必背原文】**（`3.行政法.pdf p1`）：行政处罚是**事中制裁**。**种类四类**——声誉罚：**警告**；财产罚：**罚款、没收违法所得、没收非法财物**；行为罚：**责令停产停业、吊销或暂扣许可证执照**；人身自由罚：**行政拘留**。**设定权**：法律＝所有；行政法规＝除限制人身自由；地方性法规＝除限制人身自由、吊销企业营业执照；规章＝警告、一定数量罚款。管辖＝**行为发生地**。**适用**：不满 **14** 周岁、精神病人在不能辨认或控制自己行为时、情节轻微没后果、**2 年**内未被发现的不再处罚；**一事不能两次以上罚款**。**程序**：简易程序＝公民 **50 元以下**或警告、法人 **1000 元以下**或警告；一般程序＝**2 人**执法、集体决定、**7 日内**送达；听证程序＝**停业、吊销、较大罚款**。**执行**：原则**罚缴分离**；例外当场收缴＝**20 元以下**、事后难执行、交通不便当事人自己提出。

**【要点拆解】**

| 项目 | 资料原文数字 | 判题锚 |
| --- | --- | --- |
| 不处罚年龄 | 不满 14 周岁 | 与民法 8 周岁、刑法 14 周岁区分 |
| 处罚时效 | 2 年 | 「未被发现」 |
| 简易程序（公民） | 50 元以下或警告 | 法人 1000 元以下或警告 |
| 一般程序 | 2 人执法、7 日内送达 | 集体决定 |
| 当场收缴 | 20 元以下 | 罚缴分离的例外 |
| 听证 | 停业、吊销、较大罚款 | 三类情形 |

1. 设定权按「法律 > 行政法规 > 地方性法规 > 规章」逐级递减，每级排除项要背准：行政法规只排除「限制人身自由」，地方性法规多排除「吊销企业营业执照」，规章只剩「警告、一定数量罚款」。
2. 四类罚的归类题：警告＝声誉罚，罚款/没收＝财产罚，责令停产停业/吊扣证照＝行为罚，行政拘留＝人身自由罚。
3. 「一事不再罚」资料限定为「一事不能两次以上**罚款**」，不是「不能给两种处罚」。

**【答题框架/落点】**：给「吊销许可证」先定行为罚、再定可否设定；给「50 元罚款」定简易程序；给「责令停产停业」定听证；问「罚缴分离的例外」答 20 元以下等三项。

**【易混辨析】**：**罚款 vs 罚金**——罚款是行政处罚（行政法），罚金是刑罚附加刑（刑法 G41，资料刑法册明写「罚金 ≠ 罚款」）。**行政拘留 vs 拘役**——行政拘留是行政处罚（人身自由罚），拘役是刑罚主刑（G41），两者性质、机关、期限都不同。**行政处罚（事中制裁）vs 行政强制（事前控制/事后执行）**——见 G19。**简易程序 50 元 / 1000 元 vs 当场收缴 20 元**——前者是「决定程序」，后者是「收缴方式」，三数字不可互换。**2 年（处罚时效）vs 3 年（民事诉讼时效，G35）**——部门法不同。

**【真题锚点】**：命题角度——本点是全册数字最密的判断题源，10 份真题虽未直接出现「50 元以下」，但山东开放大学 2023「法的性质」「法官除了法律无别的上司」同属客观题定性族；按附录 B 数字表整组备考。

### G19 · 行政强制：措施与执行 ☆

**【必背原文】**（`3.行政法.pdf p1`）：**行政强制措施**＝**暂时性控制和限制（事前控制）**；**行政强制执行**＝**强制履行义务（事后执行）**。

**【要点拆解】**

1. 两者唯一判据是「事前控制 / 事后执行」+「暂时性 / 终局性」。
2. 措施是针对人身或财物的临时控制；执行是迫使已生效义务得到履行。
3. 与行政处罚（事中制裁）合起来构成「事前—事中—事后」三段，资料把行政处罚明标为「事中制裁」。

**【答题框架/落点】**：题干出现「暂时扣押、临时控制」答措施；出现「逾期不履行、强制划拨」答执行；三段式排序题按「强制措施 → 行政处罚 → 强制执行」。

**【易混辨析】**：**行政强制措施 vs 行政强制执行**——暂时性控制（事前）/ 强制履行义务（事后）。**行政强制 vs 行政处罚**——前者不以制裁为目的，后者是「事中制裁」；**行政强制 vs 行政诉讼执行**（G21 中「从账户划拨」）——后者是诉讼程序中的执行手段，资料分列两处，答题按题干问的是「行政机关强制」还是「法院执行」定口径。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/3.行政法.pdf p1`

### G20 · 行政复议 ★

**【必背原文】**（`3.行政法.pdf p1—2`）：概念＝依法向复议机关提出复议申请，复议机关审查**合法性和适当性**。**复议范围排除**：国防外交等、刑事侦查、内部行政、行政指导、行政调解；**部分抽象行政行为可附带审查**。**行政复议机关**：**原则是上一级，省部级找自己**。**复议程序**：提出申请 **60 日内**；复议机关审查＝**书面复议、原则不停止执行、被申请人承担举证责任**；结果＝**复议不加重**。

**【要点拆解】**

1. 复议审查「合法性 + 适当性」两项，比诉讼多一项「适当性」（诉讼只审合法性，见 G21）。
2. 「上一级管辖」是原则，「省部级找自己」是特例，判断题常把省部级也答成上一级。
3. 三个程序关键词：书面复议、不停止执行、被申请人（行政机关）举证。
4. 「复议不加重」＝不得因申请复议而加重对申请人的处罚。

**【答题框架/落点】**：问「复议申请期限」答 60 日内；问「复议期间是否停止执行」答原则不停止；问「谁举证」答被申请人；问「审查范围」答合法性和适当性。

**【易混辨析】**：**复议 vs 诉讼**——复议审「合法性 + 适当性」、原则书面、上级机关管辖；诉讼审「合法性」、公开审理、法院管辖、被告举证（见下表 G23）。**60 日（复议申请）vs 15 日（先复议后诉讼的起诉期）vs 6 个月（直接起诉）**——三个期限分属三个环节，绝不可混。**部分抽象行政行为可附带审查 vs 抽象行政行为不可单独起诉**——复议可附带、诉讼一般排除（G21 受案排除）。**省部级找自己 vs 原则是上一级**——特例与原则。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/3.行政法.pdf p1—2`

### G21 · 行政诉讼：原则、制度、受案排除、管辖与被告 ★

**【必背原文】**（`3.行政法.pdf p2—3`）：**原则**八条——依法受理、依法应诉；法院独立审判；以事实为根据，以法律为准绳；**合法性审查原则**；当事人法律地位平等；使用民族语言文字；当事人有权辩论；人民检察院实行法律监督。**基本制度**四项——**合议制**（三名以上单数人员组成合议庭，原则是合议制、例外是独任制）、**回避制**（有利害关系或者其他关系可能影响案件公正审判）、**公开审判**（国家秘密、个人隐私不公开；商业秘密申请后可以不公开）、**两审终审**。**受案范围排除**：国防外交等国家行为；行政法规、规章或者具有普遍约束力的决定、命令；内部行政行为；行政机关最终裁决的行政行为；依据刑事诉讼法授权实施的行为；调解、仲裁、不具有强制力的行政指导行为、没有实际影响的行为；驳回当事人对行政行为提出申诉的重复处理行为；不产生外部法律效力的行为；根据法院的生效裁判协助执行通知作出的行为；过程性行为；基于内部层级监督关系作出的行为；信访事项的受理登记等行为。**管辖**：级别（基层＝普通一审；中级＝海关处理、国务院部门或者县级以上地方政府、本辖区重大复杂；高级＝省重大复杂；最高院＝全国重大复杂）；地域（一般**原告就被告**，经复议的案件两机关所在地法院都可以；特殊＝不动产所在地、限制人身自由原告地或被告地）；指定管辖（特殊原因不能行使、有争议无法协商）；管辖权转移（上级可以审下级、下级往上须报请）。**被告**：一般＝作出行政行为的机关；经复议**维持＝两者共同被告**、**改变＝复议机关是被告**、未作出决定看原告意思；两个以上＝共同被告；A 委托 B＝**A 为被告**；被撤销或者职权变更＝继续行使职权的机关。

**【要点拆解】**

| 情形 | 被告 |
| --- | --- |
| 一般 | 作出行政行为的机关 |
| 复议维持 | 原机关 + 复议机关共同被告 |
| 复议改变 | 复议机关 |
| 复议未作决定 | 看原告的意思 |
| A 委托 B | A（委托机关） |
| 机关被撤销/职权变更 | 继续行使职权的机关 |

1. 「合法性审查原则」是行政诉讼独有的原则，与复议「合法性 + 适当性」对照记。
2. 复议维持后「两者共同被告」是资料明列的高频判题点。
3. 委托情形下被告是委托机关 A，不是受托组织 B——与国家赔偿「A 委托 B 由 A 赔偿」（G22）方向一致，可合并记。

**【答题框架/落点】**：问「中级法院一审管辖」答海关处理、国务院部门或县级以上地方政府、本辖区重大复杂三类；问「不动产纠纷管辖」答不动产所在地；问「复议维持谁当被告」答共同被告；问「不公开审理」答国家秘密、个人隐私（商业秘密须申请）。

**【易混辨析】**：**复议维持（共同被告）vs 复议改变（复议机关被告）**——一字之差定被告；**中级人民法院管辖 vs 基层**——看是否海关、国务院部门/县级以上政府、重大复杂；**地域管辖一般（原告就被告）vs 特殊（不动产所在地、限制人身自由原告地被告地）**；**A 委托 B：行政诉讼被告 A vs 国家赔偿义务机关 A**——两处结论一致，别与「A 授权 B 由 B 赔偿」混；**公开审判 vs 申请后可以不公开**——国家秘密个人隐私法定不公开，商业秘密须申请。

### G22 · 国家赔偿 ☆

**【必背原文】**（`3.行政法.pdf p3—4`）：**情形**＝违法行使职权。**赔偿义务机关**：机关侵害→机关赔偿；工作人员侵害→机关赔偿后**有追偿权**；**A 委托 B→A 来赔偿**；**A 授权 B→B 来赔偿**；被撤销的→找继续行使职权的机关或撤销决定机关；**复议机关加重的→加重的部分复议机关赔偿**。**赔偿方式**：主要方式为**支付赔偿金**；**预期损失不赔偿**。

**【要点拆解】**

1. 「委托→委托机关赔 / 授权→被授权组织赔」是本点最核心的一对，方向相反。
2. 工作人员个人侵权：先由机关赔，再向有故意或重大过失者追偿（资料表述为「机关赔偿后，有追偿权」）。
3. 复议加重：只就「加重的部分」由复议机关赔，原部分仍由原机关赔。
4. 「预期损失不赔偿」＝只赔直接损失，判断题常把「可得利益」设为应赔项。

**【答题框架/落点】**：问「主要赔偿方式」答支付赔偿金；问「委托与授权的区别」直接对 A/B 两句；问「复议加重」答加重部分由复议机关赔偿。

**【易混辨析】**：**A 委托 B（A 赔）vs A 授权 B（B 赔）**——全篇最易反的一组，务必成对背；**机关侵害 vs 工作人员侵害**——都先由机关赔，后者多一步追偿；**支付赔偿金（主要方式）vs 预期损失不赔偿**——方式与范围两个维度；**国家赔偿（违法行使职权）vs 行政补偿**——资料只列「违法行使职权」情形，答题按原文，不自行扩写补偿规则。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/3.行政法.pdf p3—4`

### G23 · 行政程序时限与受案排除总表（行政法收口）★

**【必背原文】**（`3.行政法.pdf p3`）：**起诉**：先复议后诉讼 **15 日**；直接诉讼 **6 个月**。**举证**：被告承担举证责任；例外＝起诉被告不作为、补偿赔偿案件。**一审**：原则公开审理、不停止执行、**不适用调解**；依据＝法律法规（自治条例和单行条例）。**二审**：当事人可以上诉，时间＝**判决 15 日、裁定 10 日**，效果＝**二审终审**。**再审**：当事人申请、法院启动、检察院可以抗诉。**执行**：从账户划拨、对负责人处罚款、公告、提出司法建议、拘留和依法追究刑事责任。

**【要点拆解】**

| --- | --- | --- |
| 复议申请 | 60 日内 | G20 |
| 先复议后诉讼起诉 | 15 日 | 本点 |
| 直接起诉 | 6 个月 | 本点 |
| 二审上诉（判决） | 15 日 | 本点 |
| 二审上诉（裁定） | 10 日 | 本点 |

## 第五部分 · 民法（G24—G35）

民法是考情结论点名的四个重点之一，`4.民法.pdf` 共 6 页却塞了从自然人到诉讼时效的完整链条。**铺垫（非编号点，出处 `4.民法.pdf p1`）**：民法调整平等主体的人身关系和财产关系；非法人组织如合伙。六项原则——**平等原则（地位、协商）、自愿原则（意思自治）、公平原则（合理均衡）、诚实信用原则（资料注「骗」「帝王」）、不得违反法律和公序良俗原则（道德底线）、有利于节约资源和保护生态环境的原则（绿色原则）**。其中诚实信用被称为「帝王条款」，绿色原则是资料单列的一项，判断题常问「哪一项是民法基本原则」而把「绿色原则」设为错项（它是，不能排）。

### G24 · 自然人：权利能力、行为能力、监护与宣告 ★

**【必背原文】**（`4.民法.pdf p1—2`）：**民事权利能力**：出生（独立呼吸）时起到死亡（生理死亡、宣告死亡）时止；出生时间、死亡时间以出生证明、死亡证明、户籍登记或者其他有效身份登记为准，**其他证据足以推翻以上记载时间的，以该证据证明的时间为准**；**胎儿**：涉及遗产继承、接受赠与等胎儿利益保护的，胎儿**视为具有民事权利能力**，但是胎儿娩出时为死体的，其民事权利能力**自始不存在**。**民事行为能力**：**完人**＝18 周岁以上；16 周岁以上不满 18 周岁，**以自己的劳动收入为主要生活来源**；**限人**＝8 周岁以上不满 18 周岁的、不能完全辨认自己行为的成年人（法定代理人代理；法定代理人同意、追认；纯获利；与年龄智力相适应）；**无人**＝不满 8 周岁、不能辨认自己行为的人。**监护**：代理被监护人实施民事法律行为，保护被监护人的权利；监护人应当按照**最有利于被监护人**的原则履行监护职责；监护人对被监护人的侵权行为承担民事责任；不履行监护职责或者侵害被监护人合法权益的，应当承担法律责任。**宣告失踪**：法定期间 **2 年**，利害关系人到法院申请，公告期 **3 个月**，效力＝财产代管，经申请撤销失踪宣告。**宣告死亡**：法定期间＝普通 **4 年**、意外 **2 年**、意外 + 经证明 **0 年**；申请时有的申请宣告死亡、有的申请宣告失踪，符合宣告死亡条件的，人民法院应当宣告死亡；公告期＝（4 年、2 年）**1 年**、（0 年）**3 个月**；死亡日期确定＝判决作出之日，意外事件下落不明的为意外事件发生之日；撤销后果＝配偶有再婚事实不能自行恢复，配偶未再婚但有书面声明不能自行恢复，配偶未再婚且无书面声明自行恢复；子女被他人依法收养的收养有效；财产返还。

**【要点拆解】**

| 档次 | 年龄/情形 | 行为效力 |
| --- | --- | --- |
| 完全民事行为能力人 | 18 周岁以上；16—18 周岁以自己劳动收入为主要生活来源 | 独立实施 |
| 限制民事行为能力人 | 8 周岁以上不满 18 周岁；不能完全辨认自己行为的成年人 | 法定代理人代理/同意追认；纯获利、相适应可独立 |
| 无民事行为能力人 | 不满 8 周岁；不能辨认自己行为的人 | 由法定代理人代理 |

1. 三个年龄锚：**8 周岁**（无人/限人分界）、**18 周岁**（成年/完人）、**16 周岁**（劳动收入视为完人）；另有刑法 14/16 周岁（G37）、行政法 14 周岁（G18）、宪法 18 周岁选举权（G10），务必按部门法对号。
2. 胎儿「视为有权利能力」但「娩出为死体则自始不存在」，两句必须一起背。
3. 宣告死亡三组期间：普通 4 年 / 意外 2 年 / 意外经证明 0 年；公告期 1 年（前两种）、3 个月（0 年）。
4. 监护四句：代理实施、最有利于被监护人、对被监护人侵权担责、失职担责。

**【答题框架/落点】**：给「7 岁儿童买手机」定无人→无效（G26）；给「10 岁儿童收压岁钱」定限人→纯获利有效；给「17 岁打工自养」定完人；给「下落不明 4 年」定普通宣告死亡、公告期 1 年。

**【易混辨析】**：**民事权利能力 vs 民事行为能力**——前者「始于出生终于死亡」人人平等，后者按年龄与辨认能力分三档；**8 周岁（民法无人/限人界）vs 14 周岁（行政法不处罚、刑法相对刑责起点）vs 16 周岁（刑法完全刑责、民法视为完人）**——部门法不同；**宣告失踪（2 年、公告 3 个月、财产代管）vs 宣告死亡（4/2/0 年、公告 1 年或 3 个月、人身财产全面处理）**——期间与效力都不同；**胎儿「视为有」vs「死体自始无」**——条件不同。

**【真题锚点】**：命题角度——「8 周岁」「18 周岁」「3 年诉讼时效」是资料可检索的高频数字，山东服装职院 2023 论述「材料分析侵犯了学生的什么权利」可与 G31 人身权合答。

### G25 · 法人分类与权利能力起止 ☆

**【必背原文】**（`4.民法.pdf p2`）：法人是组织。分类三类——**营利法人**（有限责任公司、股份有限公司和其他企业法人等）；**非营利法人**（事业单位、社会团体、基金会、社会服务机构等）；**特别法人**（机关法人、农村集体经济组织法人、城镇农村的合作经济组织法人、基层群众性自治组织法人）。法人的**民事权利能力、民事行为能力，从法人成立时产生，到法人终止时消灭**。

**【要点拆解】**

1. 三类法人的举例必须能归类：公司→营利，事业单位/基金会→非营利，机关法人/村委会居委会→特别法人。
2. 「基层群众性自治组织法人」归特别法人，与 G11 村委会、居委会（指导关系、任期 5 年）呼应。
3. 法人的权利能力与行为能力**同时产生、同时消灭**，与自然人「权利能力始于出生、行为能力分档」不同。

**【答题框架/落点】**：问「事业单位属于哪类法人」答非营利法人；问「机关法人」答特别法人；问「法人权利能力起止」答成立时产生、终止时消灭。

**【易混辨析】**：**法人 vs 非法人组织**——法人能独立承担责任，非法人组织（如合伙）不能独立承担责任（见 G04 法理学册、民法册「非法人组织：合伙」）；**营利 / 非营利 / 特别**——按设立目的与举例分；**法人权利能力（成立—终止）vs 自然人权利能力（出生—死亡）**——起止节点不同。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/4.民法.pdf p2`

### G26 · 民事法律行为的效力：无效、可撤销、效力待定 ★

**【必背原文】**（`4.民法.pdf p2`）：**无效民事法律行为**五类——无民事行为能力人实施的；行为人与相对人以虚假的意思表示实施的；行为人与相对人恶意串通，损害他人合法权益的；违背公序良俗的；违法的。**可撤销的民事法律行为**四类情形——**重大误解（行为人）、欺诈（受欺诈方）、胁迫（受胁迫方）、显示公平（受损害方）**（资料原文作「显示公平」）；**行使期限**——自知道或应当知道撤销事由之日起**一年**内；重大误解的当事人自知道或应当知道撤销事由之日起**三个月**内；当事人受胁迫，自胁迫行为终止之日起**一年**内；自民事法律行为发生之日起**五年**内。**效力待定的民事法律行为**三类——欠缺代理权的代理行为、限人实施的超能行为、无权处分行为。

**【要点拆解】**

| 效力状态 | 情形 | 关键词 |
| --- | --- | --- |
| 无效 | 无人实施、虚假意思表示、恶意串通、违背公序良俗、违法 | 自始无效 |
| 可撤销 | 重大误解、欺诈、胁迫、显失公平 | 撤销前有效、须在期限内行使 |
| 效力待定 | 欠缺代理权、限人超能、无权处分 | 待追认 |

1. 可撤销四类的「主张方」要对齐：重大误解是行为人，欺诈是受欺诈方，胁迫是受胁迫方，显失公平是受损害方。
2. 四个撤销期限：一般 1 年、重大误解 3 个月、胁迫自终止起 1 年、最长自行为发生之日起 5 年。
3. 「无效」与「可撤销」的判据：是否损害公共利益/违法（无效）还是仅意思表示瑕疵（可撤销）。

**【答题框架/落点】**：给「7 岁儿童签合同」答无效；给「因重大误解买错货」答可撤销、3 个月；给「被胁迫签字」答可撤销、自胁迫终止起 1 年；给「15 岁超能力大额消费」答效力待定。

**【易混辨析】**：**无效 vs 可撤销 vs 效力待定**——自始无效 / 撤销前有效且受期限限制 / 待追认；**重大误解 3 个月 vs 一般 1 年**——期限最短的是重大误解；**胁迫起算点（胁迫行为终止之日）vs 其他（知道或应当知道撤销事由之日）**——起算点不同；**可撤销婚姻「受胁迫 1 年」（G32）vs 可撤销民事法律行为「胁迫 1 年」**——数字相同但部门不同，别混用条文。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/4.民法.pdf p2`

### G27 · 代理 ★

**【必背原文】**（`4.民法.pdf p2`）：代理关系三方＝**被代理人（本人）、代理人、第三人（相对人）**。**代理权的行使原则**：在代理权限范围内行使代理权，不得无权代理；**亲自行使代理权，不得任意转托（同意、紧急）**；积极行使代理权，尽勤勉和谨慎义务。**滥用代理权的禁止**：自己代理、双方代理、代理人和第三人恶意串通损害被代理人利益。**无权代理**＝狭义无权代理（未授权之无权代理、越权之无权代理、代理权消灭后之无权代理）+ **表见代理**（以本人名义、无代理权、有证明文件〔盖有公章的空白合同、授权书、介绍信〕、相对人为善意〔不知情〕）。

**【要点拆解】**

1. 转托的两个例外：「同意」或「紧急」——资料原文括号，判断题常把「任意转托」设为合法。
2. 滥用代理权三种：自己代理、双方代理、恶意串通。
3. 表见代理四要件：以本人名义 + 无代理权 + 有证明文件 + 相对人善意，缺一不成立。
4. 狭义无权代理三种：未授权、越权、代理权消灭后。

**【答题框架/落点】**：给「拿着盖公章的空白合同签约、对方不知情」定表见代理；给「代理人自己买下被代理人的货」定自己代理（滥用）；给「擅自转委托」定违反亲自行使原则。

**【易混辨析】**：**狭义无权代理 vs 表见代理**——有无「证明文件 + 善意相对人」；**自己代理 / 双方代理 / 恶意串通**——滥用代理权三形态，别与无权代理混；**委托代理（民法）vs A 委托 B 的行政委托（G21/G22）**——前者产生代理关系，后者定行政诉讼被告与国家赔偿义务机关，属不同部门法；**亲自行使（原则）vs 同意/紧急转托（例外）**。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/4.民法.pdf p2`

### G28 · 物权 ★

**【必背原文】**（`4.民法.pdf p3`）：物权是权利人依法对特定的物享有**直接支配和排他**的权利。**原则**：物权法定原则、物权客体特定原则、公示公信原则、**物权效力优先原则（例外：买卖不破租赁）**。**所有权**：①**占有、使用、收益、处分（核心）**；②共有＝按份共有（**优先购买权**）、共同共有；③**相邻关系**：法定、必要便利、无偿；**地役权**：约定、约定便利、无偿或有偿；④变动方式＝**不动产登记、动产交付**。**用益物权**：土地承包经营权、建设用地使用权、宅基地使用权、地役权。**担保物权**：**抵押权不转移占有**（不得抵押的财产：土地所有权、集体土地使用权、公益设施、争议财产、查封扣押财产）；**质权转移占有**；**留置权**＝债务人逾期不履行债务，债权人可留置该财产。

**【要点拆解】**

1. 所有权四权能里「处分」是核心，判断题常把「占有」说成核心。
2. 相邻关系（法定、必要便利、无偿）vs 地役权（约定、约定便利、可有偿）是资料专门并列的一组。
3. 担保物权三分：抵押不转移占有、质权转移占有、留置权基于逾期不履行。
4. 物权变动：不动产看登记、动产看交付。

**【答题框架/落点】**：问「所有权核心权能」答处分；问「买卖不破租赁」答它是物权效力优先原则的例外；问「不动产所有权何时转移」答登记；问「不得抵押的财产」按五项原文列。

**【易混辨析】**：**抵押权（不转移占有）vs 质权（转移占有）vs 留置权（逾期不履行而留置）**——占有是否转移、产生原因不同；**相邻关系 vs 地役权**——法定/约定、必要便利/约定便利、无偿/可有偿；**用益物权 vs 担保物权**——前者用他人之物（含土地承包经营权等四项），后者担保债权（抵押、质押、留置）。**物权效力优先 vs 买卖不破租赁**——原则与例外。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/4.民法.pdf p3`

### G29 · 债权与合同 ★

**【必背原文】**（`4.民法.pdf p3`）：合同是（**财产性**）**协议**。**成立**：**要约**＝一方当事人向另一方当事人提出订立合同的条件；**要约邀请**＝寄送的价目表、拍卖公告、招标公告、招股说明书、商业广告；**要约与要约邀请的区别：明确具体**；**承诺**＝受要约人同意要约的条件以缔结合同的意思表示。**侵权行为**＝由于过错侵害他人财产或人身，应当承担的责任；法律特别规定＝被监护人致害监护人担责、狗咬人主人赔除非逗狗。**不当得利**＝没有法律或合同根据，一方利益增加、另一方利益减损，**要返还**。**无因管理**＝没有法定或约定义务，为避免他人利益受损进行管理和服务，**必要费用 + 直接损失由受益人承担**。**债的消灭**：清偿、抵销、提存、混同、免除。

**【要点拆解】**

1. 要约 vs 要约邀请的判据只有「明确具体」四个字；商业广告一般为要约邀请。
2. 债的四种发生原因：合同、侵权行为、不当得利、无因管理（资料分列四块）。
3. 不当得利「要返还」、无因管理「必要费用 + 直接损失由受益人承担」，两句效果不同。
4. 债的消灭五种：清偿、抵销、提存、混同、免除。

**【答题框架/落点】**：给「拍卖公告/商业广告」定要约邀请；给「内容明确具体的报价」定要约；给「错汇款项」定不当得利；给「替邻居修漏雨屋顶」定无因管理。

**【易混辨析】**：**要约 vs 要约邀请**——是否明确具体；**要约 vs 承诺**——提出条件 / 同意条件；**不当得利 vs 无因管理**——前者「没有根据而获利、要返还」，后者「没有义务而管理、必要费用由受益人承担」；**侵权（过错侵害）vs 违约（G34）**——违反法定义务 / 违反约定义务；**被监护人致害（监护人担责）vs 狗咬人（主人赔除非逗狗）**——资料并列的两条特别规定。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/4.民法.pdf p3`

### G30 · 知识产权 ★

**【必背原文】**（`4.民法.pdf p3—4`）：知识产权是民事主体对特定智力劳动成果依法享有的**专有权利**，包括**著作权、专利权、商标权**。**著作权**：①**自动保护**；②分类＝著作人身权（署名、修改、保护作品完整、发表）、著作财产权或其他；③保护期＝**署名权、修改权、保护作品完整权的保护期不受限制**；**发表权和财产权的保护期为作者终生及其死亡后 50 年**。**专利权**：发明、实用新型、外观设计；**发明 20 年；实用新型、外观设计 10 年，自申请日起计算，不能续期**。**商标权**：驰名商标＝所有商品，普通商标＝相同、类似商品；**有效期 10 年，自核准注册之日起计算，可以续展**。

**【要点拆解】**

| 权利 | 期限 | 起算/续展 |
| --- | --- | --- |
| 署名权、修改权、保护作品完整权 | 不受限制 | — |
| 发表权、著作财产权 | 作者终生 + 死亡后 50 年 | — |
| 发明专利权 | 20 年 | 自申请日起，不能续期 |
| 实用新型、外观设计专利权 | 10 年 | 自申请日起，不能续期 |
| 商标权 | 10 年 | 自核准注册之日起，可以续展 |

1. 著作权「自动保护」＝不需登记即产生，判断题常以「须登记才受保护」设错。
2. 专利权「不能续期」与商标权「可以续展」方向相反，是本点第一易混。
3. 三个起算点：专利权自**申请日**、商标权自**核准注册之日**、著作权保护期按**作者终生及死亡后**。

**【答题框架/落点】**：问「著作人身权哪些不受期限限制」答署名、修改、保护作品完整；问「发明专利期限」答 20 年；问「商标能否续展」答可以；问「专利能否续期」答不能。

**【易混辨析】**：**著作权自动保护 vs 专利权/商标权须申请核准**——产生方式不同；**发表权（有期限）vs 署名权（无期限）**——同属著作人身权但保护期不同；**专利权不能续期 vs 商标权可以续展**；**发明 20 年 vs 实用新型/外观设计 10 年**；**驰名商标（所有商品）vs 普通商标（相同、类似商品）**——保护范围不同。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/4.民法.pdf p3—4`

### G31 · 人身权 ☆

**【必背原文】**（`4.民法.pdf p4`）：**人格权**：自然人＝生命权、身体权、健康权、姓名权、肖像权、隐私权；法人、非法人组织＝**名称权**；自然人、法人、非法人组织共有＝**名誉权、荣誉权**。**肖像权**＝未经允许 + **营利目的**。**名誉权（假）vs 隐私权（真）**。**荣誉权**＝荣誉称号。**身份权**＝亲权、配偶权、亲属权。

**【要点拆解】**

1. 人格权按主体分三层：自然人独有（生命、身体、健康、姓名、肖像、隐私）、法人非法人组织独有（名称权）、共有（名誉权、荣誉权）。
2. 肖像权侵权两要件：未经允许 + 营利目的，缺营利目的一般不构成（资料口径）。
3. 名誉权与隐私权的判据资料用「假 / 真」两字：散布虚假事实损害名誉→名誉权；披露真实私密信息→隐私权。

**【答题框架/落点】**：问「法人有没有肖像权/隐私权」答没有、只有名称权（与自然人共有名誉权、荣誉权）；给「擅自用照片做广告」定侵犯肖像权；给「捏造事实诋毁」定名誉权、给「公开他人私密信息」定隐私权。

**【易混辨析】**：**名誉权（假）vs 隐私权（真）**——资料原文判据；**姓名权（自然人）vs 名称权（法人、非法人组织）**——主体不同；**肖像权（未经允许 + 营利目的）vs 名誉权（虚假事实）**——要件不同；**人格权 vs 身份权（亲权、配偶权、亲属权）**——前者与生俱来，后者基于特定身份关系；**宪法「人格尊严」五项（G12）vs 民法人格权**——见 G12 辨析。

**【真题锚点】**：山东服装职院 2023 论述「材料分析侵犯了学生的什么权利」——须在宪法公民基本权利（G12）与民法人身权（本点）之间选口径；命题角度：给「老师公开学生成绩/隐私」情境，按「隐私权（真）」定性。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/4.民法.pdf p4`

### G32 · 婚姻 ★

**【必背原文】**（`4.民法.pdf p4`）：**财产关系**：婚前归个人，婚后归共有；**个人财产**＝一方的婚前财产、一方用健康换来的、遗嘱或赠与合同中确定只归一方的、一方专用的生活用品、军人用健康换来的。**结婚**：必备条件＝男女自愿、**法定婚龄男 22、女 20**、一夫一妻；禁止条件＝直系血亲、三代以内旁系血亲、患病；**无效婚姻**＝未到法定婚龄、重婚、有禁止结婚的亲属关系、婚前患病婚后未愈；**可撤销婚姻**＝受胁迫、**1 年**。**离婚**：协议离婚、诉讼离婚；诉讼离婚**必经程序：调解**；特殊规定＝对军人的保护、对女方的保护（**怀孕期间、分娩后一年内或中止妊娠后六个月内**）；财产分割与债务清偿＝协议不成由人民法院判决；夫妻共同生活所欠债务应当共同偿还；共同签字或一方事后追认的为共同债务；以个人名义为家庭日常生活需要所负的债务为共同债务；以个人名义超出家庭日常生活需要所负的债务，债权人以属于夫妻共同债务为由主张权利的，人民法院不予支持，除非债权人能证明。

**【要点拆解】**

1. 法定婚龄 **男 22、女 20**——资料原文数字，不得改动。
2. 无效婚姻四项 vs 可撤销婚姻一项（受胁迫、1 年）：判断题最爱把「未到法定婚龄」塞进可撤销。
3. 对女方保护三个时段：怀孕期间、分娩后一年内、中止妊娠后六个月内。
4. 共同债务认定三条：共同签字/事后追认、家庭日常生活需要、超出部分债权人举证。

**【答题框架/落点】**：给「男 21 女 19 登记」答未到法定婚龄→无效婚姻；给「被胁迫结婚」答可撤销、1 年；给「诉讼离婚先做什么」答调解；给「一方以个人名义大额举债」答原则上不算共同债务、除非债权人能证明。

**【易混辨析】**：**无效婚姻 vs 可撤销婚姻**——四项无效情形 / 一项胁迫且限 1 年；**法定婚龄男 22 女 20 vs 选举权 18 周岁（G10）vs 民事行为能力 8/18 周岁（G24）**——三个部门法数字；**婚前个人财产 vs 婚后共有**；**协议离婚 vs 诉讼离婚（必经调解）**；**对女方保护 vs 对军人保护**——两类特殊规定并列。

### G33 · 继承 ☆

**【必背原文】**（`4.民法.pdf p4—5`）：**法定继承**：**第一顺序**＝配偶、子女（婚生子女、非婚生子女、养子女、形成抚养关系的继子女）、父母；**丧偶儿媳对公、婆，丧偶女婿对岳父、岳母尽了主要赡养义务的**，列为第一顺序；**第二顺序**＝兄弟姐妹、祖父母、外祖父母。**遗嘱继承和遗赠**：区别＝**遗嘱继承处分给法定继承人，遗赠处分给法定继承人以外的主体**；**遗嘱形式**＝自书、代书、录音、口头、公证；**多份遗嘱**＝有公证以公证为准、无公证以最晚为准；**默示效力**＝继承人**接受**、受遗赠人**放弃**；**遗赠抚养协议效力最高**。**遗产的分割**：划清遗产和共有财产（**夫妻共有财产先一分为二**）→ 确定继承方式（一般考法定继承）→ 胎儿的继承权 → 发挥遗产的效用（折价、适当补偿、共有）→ **清偿债务以遗产的实际价值为限**。

**【要点拆解】**

1. 第一顺序三类人 + 一个特例（丧偶儿媳/女婿尽主要赡养义务）；第二顺序三类人。
2. 「继承人默认接受、受遗赠人默认放弃」方向相反，是本点最易反的一组。
3. 效力层级：遗赠抚养协议 > 遗嘱/遗赠；多份遗嘱「有公证从公证、无公证从最晚」。
4. 分割五步：划清共有 → 定方式 → 胎儿份额 → 发挥效用 → 债务以实际价值为限。

**【答题框架/落点】**：问「第一顺序继承人」按配偶、子女、父母 + 丧偶儿媳女婿特例答；问「多份遗嘱」答有公证以公证为准、无公证以最晚为准；问「受遗赠人两个月内未表态」按资料「默示放弃」答（资料未列期限，不自行补数字）。

**【易混辨析】**：**遗嘱继承 vs 遗赠**——给法定继承人 / 给法定继承人以外的主体；**继承人（默示接受）vs 受遗赠人（默示放弃）**——方向相反；**第一顺序 vs 第二顺序**——有第一顺序时第二顺序不参与；**遗赠抚养协议（效力最高）vs 公证遗嘱**——资料明文「遗赠抚养协议效力最高」；**夫妻共有财产先一分为二 vs 清偿债务以遗产实际价值为限**——分割前两步不同环节。

### G34 · 民事责任：违约、侵权与缔约过失 ☆

**【必背原文】**（`4.民法.pdf p5`）：**违约责任**：构成＝一方违约造成对方损害、无免责事由；**法定免责事由**＝不可抗力、债权人过错、合理损耗；承担方式＝继续履行、采取补救措施、赔偿损失、违约金、**定金（罚则）：给付定金的一方不履行债务，无权要求返还定金；收受定金的一方不履行债务，应当双倍返还定金**。**侵权责任**：构成＝一方违法行为造成对方损害，行为人主观上有过错；**免责事由**＝不可抗力、受害人过错、正当防卫、紧急避险、受害人同意；承担方式＝停止侵害、排除妨碍、消除危险、返还财产、恢复原状、赔偿损失、赔礼道歉、消除影响、恢复名誉。**缔约过失责任**：假借订立合同恶意进行磋商；故意隐瞒与订立合同有关的重要事实或者提供虚假情况；泄露或不正当地使用商业秘密。

**【要点拆解】**

1. 违约免责三事由 vs 侵权免责五事由，两组清单不可混用。
2. 定金罚则两句对称：给付方违约→不返还；收受方违约→双倍返还。
3. 侵权责任八种承担方式按资料顺序背；缔约过失三种情形按「磋商—隐瞒虚假—泄密」串记。

**【答题框架/落点】**：给「合同签了不交货」定违约责任；给「打伤他人」定侵权责任；给「谈判中故意泄露对方商业秘密」定缔约过失责任；给「收了定金不发货」答双倍返还。

**【易混辨析】**：**违约责任 vs 侵权责任**——违反约定义务 / 违反法定义务，免责事由清单不同；**违约责任 vs 缔约过失责任**——合同已成立生效 / 合同订立阶段；**定金罚则（给付方不返还、收受方双倍）vs 违约金**——资料并列两种承担方式；**正当防卫/紧急避险（民法侵权免责事由）vs 刑法排除犯罪的行为（G38）**——同一组概念在两个部门法中的功能不同，别答串。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/4.民法.pdf p5`

### G35 · 民事诉讼时效 ★

**【必背原文】**（`4.民法.pdf p5—6`）：**不适用诉讼时效的规定**＝请求停止侵害、排除妨碍、消除危险；不动产物权和登记的动产物权的权利人请求返还财产；请求支付抚养费、赡养费或者扶养费。**类型及起算**：**一般 3 年**——自权利人知道或者应当知道权利受到损害**以及义务人**之日起计算；特殊＝**涉外 4 年、保险 5 年**；**最长 20 年**——自权利受到损害之日起。**其他特殊规定**：分期履行的，自最后一期履行期限届满之日起计算；无人或限人对其法定代理人的请求权自法定代理终止之日起计算；**未成年人遭受性侵害的自受害人年满 18 周岁之日起计算**。**中止、中断的区别**：时间不同＝**中止在最后 6 个月内**、**中断在整个诉讼时效期间**；事由不同＝中止（不可抗力；无人或限人没有法定代理人；继承开始后未确定继承人或者遗产管理人；权利人被控制），中断（权利人向义务人提出履行请求；义务人同意履行义务；权利人提起诉讼或者申请仲裁）；**效力不同＝中止暂停计算（不清零）补 6 个月；中断重新计算（重启、清零）**。

**【要点拆解】**

| 项目 | 中止 | 中断 |
| --- | --- | --- |
| 时间 | 最后 6 个月内 | 整个诉讼时效期间 |
| 事由 | 不可抗力、无法定代理人、未定继承人/遗产管理人、权利人被控制 | 提出履行请求、同意履行义务、提起诉讼或申请仲裁 |
| 效力 | 暂停计算（不清零），补 6 个月 | 重新计算（重启、清零） |

1. 一般 3 年、最长 20 年、涉外 4 年、保险 5 年——四个期限按资料原文，不得自行补充。
2. 起算点是「知道或应当知道权利受到损害**以及义务人**之日」，漏「义务人」即不完整。
3. 三类不适用诉讼时效的请求权按资料三行背。
4. 中止 vs 中断是全篇最高频的成对考点，从「时间、事由、效力」三行对齐背。

**【答题框架/落点】**：给「最后 6 个月内发生地震」答中止、补 6 个月；给「权利人起诉」答中断、重新计算；给「借钱不还超过 3 年」按一般时效 3 年判断；问「最长保护期」答 20 年。

**【易混辨析】**：**中止 vs 中断**——暂停不清零（补 6 个月）/ 重启清零，且发生时间、事由都不同（见上表）；**诉讼时效 3 年（民法）vs 复议申请 60 日 / 直接起诉 6 个月（行政法 G20、G23）vs 行政处罚追究 2 年（G18）**——三个部门法四组期限；**一般 3 年（自知道损害及义务人）vs 最长 20 年（自权利受到损害之日）**——起算点不同；**不适用诉讼时效的三类请求 vs 适用一般时效的请求**。

**【真题锚点】**：命题角度——「中止 vs 中断」几乎必考判断或单选；「3 年」「20 年」是资料可检索的高频数字，按附录 B 整组防守。

## 第六部分 · 刑法（G36—G43）

刑法同为考情结论点名的四个重点之一，`5.刑法.pdf` 共 7 页，是全册**数字与「一字之差」最多**的一册。复习时按「原则 → 构成 → 排除 → 形态 → 共犯 → 刑罚 → 量刑 → 罪名」八步走，每步只背资料原文口径。

### G36 · 刑法基本原则与适用范围 ★

**【必背原文】**（`5.刑法.pdf p1—2`）：刑法是规定**犯罪、刑罚**的法律。**基本原则 3 个**——**罪刑法定**、**平等适用刑法（＝人人平等）**、**罪责刑相适应（＝罪刑相适应＝罪刑相当＝罪刑均衡）**。**空间效力**：属地（主权、旗国主义；领域＝领陆、领水、领空、驻外使领馆、船舶、航空器；犯罪地＝行为地或结果地之一）、属人（国籍；最高刑 3 年以下可以不追究，国家工作人员、军人一律追究）、保护管辖（利益；且按照我国刑法最低刑 3 年以上、按照犯罪地法律也应受刑罚处罚）、普遍管辖（例：海盗、劫持航空器）。**时间效力**：**溯及力从旧兼从轻**——何时涉及＝犯罪在新法之前、判决在新法之后；原则上用旧法，除非新法判得更轻用新法；新法之前的有效判决继续有效。

**【要点拆解】**

| 原则 | 资料别名/关键词 |
| --- | --- |
| 罪刑法定 | 法无明文规定不为罪（资料未展开，按原则名记） |
| 平等适用刑法 | 人人平等 |
| 罪责刑相适应 | 罪刑相适应、罪刑相当、罪刑均衡 |

1. 三种「＝」别名是资料原文，多选题把「罪刑均衡」当第四种原则即错。
2. 四种空间管辖按「地域—国籍—利益—国际」串记；保护管辖有两个附加条件（最低刑 3 年以上 + 犯罪地法律也应处罚）。
3. 从旧兼从轻三句：原则用旧法、新法更轻用新法、旧判决继续有效。

**【答题框架/落点】**：问「刑法基本原则个数」答 3 个；给「中国公民在境外犯最高刑 2 年之罪」按属人管辖「最高刑 3 年以下可以不追究」判；给「新法判得更轻」答从旧兼从轻。

**【易混辨析】**：**罪刑法定（刑法）vs 合法性原则「法无授权不可为」（行政法 G16）**——部门法不同，但都强调「依法」；**属地 vs 属人 vs 保护 vs 普遍**——连接点分别是地域、国籍、利益、国际罪行；**从旧兼从轻（刑法）vs 法不溯及既往（法理学 G05「从旧兼从轻，但新法更有利于当事人的除外」）**——表述同源、适用领域不同；**罪责刑相适应 vs 平等适用刑法**——一个讲罚当其罪、一个讲人人平等。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/5.刑法.pdf p1—2`

### G37 · 犯罪构成与刑事责任能力 ★

**【必背原文】**（`5.刑法.pdf p1—2`）：**犯罪构成四要件**＝犯罪主体、犯罪主观方面、犯罪客体、犯罪客观方面。**犯罪三特征**＝严重的社会危害性、违反刑事法律规范、依法应当受刑罚处罚。**刑事责任能力**：**已满 16 周岁，完全刑责（一切都负）**；**不满 14 周岁的人，完全无刑责**；**相对无刑事责任能力＝已满 14 不满 16**（8 种，口诀「烧杀奸抢，伤贩爆头」：故意杀人、故意伤害致人重伤或者死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投毒罪）；**减轻刑事责任能力**＝未成年人、已满 75 周岁的人、又聋又哑的人、盲人、尚未完全丧失辨认或者控制自己行为能力的精神病人。自然人：精神病人清醒时、醉酒犯罪都算。**主观方面**：故意（直接故意＝希望、追求；间接故意＝放任、听之任之）、过失（疏忽大意＝应当预见由于疏忽大意而没有预见；过于自信＝已经预见但轻信能避免、最终没避免）、意外事件＝不可能预见、不应当预见。**客体**：客体（抽象）vs 犯罪对象（具体）；**所有的犯罪都有犯罪客体，但不一定都有犯罪对象**。**客观方面**：危害行为（作为＝积极的行为；不作为＝应为、能为、不为）、危害结果（实际损害、危险状态）、因果关系（引起与被引起）。

**【要点拆解】**

1. 三个年龄锚：**16 周岁**（完全刑责）、**14 周岁**（相对刑责起点与完全无刑责分界）、**75 周岁**（减轻）；与民法 8/18、行政法 14、宪法 18 一起记入附录 B。
2. 已满 14 不满 16 只对 8 种罪负责，口诀「烧杀奸抢，伤贩爆头」按资料原文（另一处口诀作「商贩抱头」，两种写法都指同一组）。
3. 醉酒的人犯罪负刑责；间歇性精神病人在正常时犯罪负刑责。
4. 「所有犯罪都有犯罪客体，但不一定都有犯罪对象」是判断题高频原句。

**【答题框架/落点】**：给「15 岁盗窃」答不负刑责（不在 8 种之列）；给「15 岁抢劫」答负刑责；给「醉酒驾车肇事」答负刑责；给「应当预见却没预见」答疏忽大意的过失。

**【易混辨析】**：**完全无（不满 14）vs 相对无（14—16，仅 8 种）vs 完全有（已满 16）**——三段年龄；**直接故意（希望追求）vs 间接故意（放任）vs 过于自信过失（轻信能避免）**——意志因素不同；**疏忽大意（没预见）vs 意外事件（不可能预见、不应当预见）**；**犯罪客体（抽象、必有）vs 犯罪对象（具体、不必有）**；**作为（积极）vs 不作为（应为能为不为）**。

**【真题锚点】**：命题角度——8 种罪与三个年龄几乎必以「给年龄定责任」单选出现；与 G24 民法 8/18 周岁、G18 行政法 14 周岁构成跨册数字组，按附录 B 防守。

### G38 · 正当防卫与紧急避险 ★

**【必背原文】**（`5.刑法.pdf p1、p3`）：**正当防卫**概念要点——他人（见义勇为）、**正在进行（当场性；反例：事前、事后）**、不法侵害（现实存在）、制止（意图；反例：互相斗殴、防卫挑拨）、不法侵害人（本人）；**防卫过当**＝超过必要限度，**无防卫过当罪**，**应当减轻或者免除处罚**；**无过当防卫**＝人身 + 暴力（行凶、杀人、抢劫、强奸、绑架等）。**紧急避险**概念要点——遇到危险（人、动物、自然界）、**不得已**、**保大放小**、**不适用于职务上、业务上有特定责任的人**；**避险过当：应当减轻或者免除处罚**。资料把两者概括为「排除犯罪的行为」，紧急避险口诀「保大放小」。

**【要点拆解】**

1. 正当防卫五要件按「他人 / 正在进行 / 不法侵害现实存在 / 制止意图 / 针对不法侵害人本人」背；「事前、事后」「互相斗殴、防卫挑拨」是资料给的反例。
2. 「无过当防卫」仅针对「人身 + 暴力」的严重犯罪（行凶、杀人、抢劫、强奸、绑架等）。
3. 紧急避险四要点：危险来源三类、不得已、保大放小、不适用职务业务特定责任人。
4. 防卫过当与避险过当的法律后果资料都写「应当减轻或者免除处罚」。

**【答题框架/落点】**：给「事后报复」答不属于正当防卫（事前/事后反例）；给「为救多人而损少数财产」答紧急避险；给「警察面对火灾不得以避免自身危险为由避险」答不适用于职务上业务上有特定责任的人。

**【易混辨析】**：**正当防卫 vs 紧急避险**——前者针对「不法侵害人本人」、后者「保大放小」可损害无辜第三人利益；危险来源前者只限人不法侵害，后者含人、动物、自然界。**防卫过当 vs 避险过当**——都「应当减轻或者免除处罚」，但触发条件不同。**正当防卫 vs 互相斗殴/防卫挑拨**——资料明列反例，缺「制止意图」即不成立。**无过当防卫（无限防卫）vs 一般防卫**——仅限人身 + 暴力的严重暴力犯罪。**刑法排除犯罪的行为 vs 民法侵权免责事由（G34 也列正当防卫、紧急避险）**——同一概念在两个部门法中的作用不同。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/5.刑法.pdf p1、p3`

### G39 · 故意犯罪形态：预备、未遂、中止、既遂 ★

**【必背原文】**（`5.刑法.pdf p1、p3`）：完成＝既遂；未完成＝**预备、未遂、中止**。**犯罪预备**（准备阶段 + 意志以外）：准备工具、制造条件；关键词＝买凶器、踩点、蹲点、尾随跟踪、出发前往犯罪地点；**可以比照既遂犯从轻、减轻或者免除处罚**。**犯罪未遂**（实行阶段 + 意志以外，欲而不能）：已经着手实行犯罪，由于犯罪分子意志以外的原因而未得逞；**可以比照既遂犯从轻或者减轻处罚**。**犯罪中止**（准备或实行 + 意志以内，能而不欲）：在犯罪过程中，自动放弃犯罪或者自动有效地防止犯罪结果发生；**事后补救的（如返还）不成立中止**；有效性；**没有造成损害的，应当免除处罚；造成损害的，应当减轻处罚**。

**【要点拆解】**

| 形态 | 阶段 | 停止原因 | 处罚口径 |
| --- | --- | --- | --- |
| 预备 | 准备阶段 | 意志以外 | 可以比照既遂从轻、减轻或免除 |
| 未遂 | 实行阶段 | 意志以外（欲而不能） | 可以比照既遂从轻或减轻 |
| 中止 | 准备或实行 | 意志以内（能而不欲） | 无损害应当免除、有损害应当减轻 |

1. 判据两步：先看阶段（准备 / 实行），再看停止原因（意志以外 / 意志以内）。
2. 「欲而不能＝未遂、能而不欲＝中止」是资料给的口诀，直接对应判题。
3. 处罚用词「可以」vs「应当」：预备、未遂用「可以」，中止用「应当」——判断题高频。
4. 中止要求「有效性」，事后返还赃物不成立中止。

**【答题框架/落点】**：给「买刀后未出门被抓」答预备；给「着手撬门被巡逻队抓获」答未遂；给「投毒后主动送医解毒」答中止；问「中止与未遂处罚区别」答「应当」与「可以」之别。

**【易混辨析】**：**预备 vs 未遂**——准备阶段 / 已着手实行；**未遂 vs 中止**——欲而不能（意志以外）/ 能而不欲（意志以内）；**「可以」从轻减轻（预备、未遂）vs「应当」免除或减轻（中止）**——助动词不同；**犯罪中止 vs 事后补救（返还）**——资料明说后者不成立中止；**中止（准备或实行阶段均可）vs 预备/未遂（各限一个阶段）**。

**【出处】**`04_公共基础知识/1_重点梳理（最精简）/5.刑法.pdf p1、p3`

### G40 · 共同犯罪 ★

**【必背原文】**（`5.刑法.pdf p1、p3—4`）：**成立条件**＝二人以上（至少 2 人）、共同故意、共同行为。**排除情形**＝同时犯、超出共同故意之外的犯罪、间接正犯（利用无刑事责任能力人、利用他人不知情）。**共犯分类**：**主犯**＝犯罪集团首要分子（犯罪集团至少 3 人），按照集团所犯全部罪行处罚；普通主犯。**从犯**＝次要、辅助，**应当从轻、减轻或者免除处罚**（资料注：2 主√、1 主 1 从√、2 从×）。**胁从犯**＝被胁迫参加且起较小作用，**应当减轻处罚或者免除处罚**。**教唆犯**＝按照他所起的作用处罚（主要作用→主犯，次要作用→从犯）；**教唆不满 18 周岁的，应当从重处罚**；被教唆的人没有犯被教唆的罪，教唆犯**可以从轻或者减轻处罚**。

**【要点拆解】**

1. 成立三条件缺一不可：「二人以上 + 共同故意 + 共同行为」；「同时犯」（各自作案、无意思联络）不成立共犯。
2. 犯罪集团「至少 3 人」，与共犯「至少 2 人」两个数字不同。
3. 四类共犯的处罚词：从犯「应当从轻、减轻或者免除」，胁从犯「应当减轻或者免除」，教唆犯按作用定、教唆未成年人从重。
4. 教唆未遂（被教唆者未犯）＝「可以从轻或者减轻处罚」。

**【答题框架/落点】**：给「两人共谋盗窃」定共同犯罪；给「各自同时在同一仓库偷东西、互不知情」答同时犯、不成立共犯；给「教唆 17 岁少年」答应当从重；给「被胁迫望风」答胁从犯。

**【易混辨析】**：**共同犯罪（≥2 人）vs 犯罪集团（≥3 人）**——人数门槛；**主犯 vs 从犯 vs 胁从犯**——作用大小与是否被胁迫；**从犯（应当从轻减轻免除）vs 胁从犯（应当减轻免除）**——从犯多一档「从轻」；**教唆犯按作用处罚 vs 教唆不满 18 周岁从重**；**间接正犯（利用无责任能力人/不知情者）vs 教唆犯**——前者被利用者不构成犯罪，资料列为共犯排除情形。

### G41 · 刑罚种类：主刑与附加刑 ★

**【必背原文】**（`5.刑法.pdf p1、p4—5`）：**主刑 5 种**（**独立适用**）＝**管制、拘役、有期徒刑、无期徒刑、死刑**；**附加刑 4 种**（**独立/附加适用**）＝**罚金、剥夺政治权利、没收财产、驱逐出境**。管制＝不关押、同工同酬、3-2-3；拘役＝短期剥夺自由、公安机关执行、拘役所/看守所、探亲假、酌量、1-6-1；有期徒刑＝6 个月以上 15 年以下，数罪并罚总和不满 35 年最高不能超过 20 年、总和 35 年以上最高不能超过 25 年；刑期折抵＝管制 1 天折 2 天、拘役/有期 1 天折 1 天、无期不折抵。**死刑限制**：犯罪时不满 18、审判时怀孕、审判时已满 75（以特别残忍手段致人死亡除外）；审判时怀孕＝从羁押到执行期间怀过；死刑分立即执行、死缓；核准＝死刑立即执行报最高院、死缓由省高院核准。**死缓**：没有故意犯罪减为无期徒刑；重大立功减为 **25 年**有期徒刑；故意犯罪情节恶劣报请最高人民法院核准后执行死刑；故意犯罪未执行死刑的，死缓期间重新计算。**罚金 ≠ 罚款**；遭遇不能抗拒的灾祸等原因缴纳确实有困难的，经人民法院裁定可以延期、减少或免除。**剥夺政治权利**内容＝选举权和被选举权、六大自由、国家机关职务、其他领导职务；适用＝危害国家安全的犯罪分子应当附加，故意杀人、强奸、放火、爆炸、投毒、抢劫等严重破坏社会秩序的可以附加，被判处死刑、无期徒刑的应当剥夺政治权利终身；期限＝管制附加与管制期限相等同时执行，死刑、无期徒刑剥夺终身，死缓或无期减为有期的改为 3 年以上 10 年以下，单处、拘役附加、有期附加 1 年以上 5 年以下。没收财产（没收非法财物）；驱逐出境适用于外国人。

**【要点拆解】**

| 类别 | 种类 | 适用方式 |
| --- | --- | --- |
| 主刑（5） | 管制、拘役、有期徒刑、无期徒刑、死刑 | 独立适用 |
| 附加刑（4） | 罚金、剥夺政治权利、没收财产、驱逐出境 | 独立或附加适用 |

1. 主刑只能独立、附加刑可独立可附加——判断题高频。
2. 「罚金 ≠ 罚款」（资料刑法册原句）与行政法「罚款」呼应，是跨册第一易混。
3. 死刑三类限制对象：犯罪时不满 18、审判时怀孕、审判时已满 75（有例外）。
4. 剥夺政治权利期限四档：与管制相等 / 终身 / 3—10 年 / 1—5 年。

**【答题框架/落点】**：问「主刑有几种」答 5 种并列举；问「附加刑能否独立适用」答能；问「罚金与罚款」答前者刑罚、后者行政处罚；问「死刑核准」答立即执行最高院、死缓省高院。

**【易混辨析】**：**罚金（刑罚）vs 罚款（行政处罚，G18）**——资料刑法册明写「罚金 ≠ 罚款」；**拘役（刑罚主刑，公安机关执行、1-6-1）vs 行政拘留（行政处罚，G18）**——性质、依据、期限都不同；**管制（不关押、同工同酬）vs 拘役（短期剥夺自由）vs 有期徒刑（6 个月—15 年）**——是否关押与期限；**死刑立即执行（最高院核准）vs 死缓（省高院核准）**；**主刑独立适用 vs 附加刑独立/附加适用**。

**【真题锚点】**：命题角度——「拘役 vs 拘留」「罚金 vs 罚款」是资料可检索的经典易混组，按附录 A 第 1、2 组整组防守。

### G42 · 量刑与刑罚的执行 ★

**【必背原文】**（`5.刑法.pdf p1、p5`）：**累犯**：一般累犯＝2 故意、2 有期、**5 年之内**；特殊累犯＝前后两罪均是危害国家安全罪、恐怖活动犯罪、黑社会性质的组织犯罪之一；**不满 18 周岁的人犯罪不成立累犯**；应当从重处罚，**不得缓刑、不得假释、可以减刑**。**自首**：一般自首＝犯了 A 罪自动投案、如实供述 A 罪；特别自首＝因犯 A 罪被抓，如实供述犯了 B 罪；**可以从轻或减轻处罚，犯罪较轻的可以免除处罚**。**立功**：揭发他人犯罪、提供重要线索侦破其他案件；可以从轻或者减轻，有重大立功的可以减轻或免除。**缓刑**：对象＝**拘役、3 年以下有期徒刑**；不满 18、怀孕的、已满 75 符合条件应当缓刑；**累犯、犯罪集团首要分子不适用缓刑**；结果＝遵纪守法原判刑罚不再执行、不遵守撤销缓刑执行原判刑罚、新罪/漏罪撤销缓刑数罪并罚。**减刑**：对象＝管制、拘役、有期、无期；限度＝管制拘役有期不少于原判刑期的 **1/2**，无期不能少于 **13 年**。**假释**：对象＝有期、无期；限度＝有期执行原判刑期 **1/2 以上**、无期实际执行 **13 年**；禁止＝累犯且因故意杀人、强奸、抢劫、绑架、放火、爆炸、投放危险物质或者有组织的暴力性犯罪、被判 10 年有期或无期；考验期＝有期徒刑剩余刑期、无期徒刑 **10 年**；结果＝考验期满视为原判刑罚执行完毕、不遵守撤销假释执行剩余刑期、新罪/漏罪撤销假释数罪并罚。

**【要点拆解】**

1. 累犯「不得缓刑、不得假释、可以减刑」三句方向不一致，是本点第一易混。
2. 一般自首与特别自首的区别：主动投案供述 A 罪 / 被抓后供述 B 罪。
3. 缓刑对象「拘役、3 年以下有期徒刑」，减刑/假释对象包含管制、无期。
4. 数字组：5 年（累犯）、1/2、13 年、10 年、3 年、25 年（死缓重大立功）——记入附录 B。

**【答题框架/落点】**：给「刑满 4 年又犯故意罪应判有期」定一般累犯、从重且不得缓刑假释；给「被抓后供出另案」定特别自首；给「判 2 年有期、怀孕」答应当缓刑；给「无期实际执行 13 年」答可假释。

**【易混辨析】**：**一般累犯（5 年内、2 故意 2 有期）vs 特殊累犯（三类罪之一、无 5 年限制表述）**；**自首（可以从轻减轻、较轻可免除）vs 立功（可以从轻减轻、重大立功可减轻免除）**；**缓刑（原判刑罚不再执行）vs 假释（考验期满视为执行完毕）vs 减刑（减轻原判刑罚）**；**不得缓刑 / 不得假释 / 可以减刑（累犯）**——三个动词别对调；**减刑限度 1/2、13 年 vs 假释限度 1/2、13 年**——数字相同但制度不同。

### G44 · 商品、劳动二重性与价值规律 ★

**【必背原文】**（`9.经济.pdf p1`）：商品经济的由来＝迄今为止两种经济形态：**自然经济（自给自足）、商品经济（交换为目的）、产品经济（共产主义）**。商品条件＝用于交换、劳动产品。**商品二重属性**：**使用价值**＝能满足人们某种需要的物品的效用，**自然属性（有用性）**；**价值**＝凝结在商品中的无差别的人类劳动，**社会属性（特有属性）**。**劳动二重性**：**具体劳动**＝各种形式的有用劳动，它生产使用价值；**抽象劳动**＝无差别的人类劳动，它形成价值的实体。商品价值量的决定因素＝**社会必要劳动时间**；结论＝社会必要劳动时间越长，价值量越高。**价值规律**：内容＝①价值量的决定因素是社会必要劳动时间；②商品交换的依据是**等价交换**；表现形式＝**价格围绕价值上下波动**；**价值决定价格，供求影响价格**（供 > 求→买方市场；供 < 求→卖方市场）；作用＝「**棒子**」调节资源配置、「**鞭子**」提高劳动生产率、「**筛子**」优胜劣汰。

**【要点拆解】**

| 对子 | A | B |
| --- | --- | --- |
| 商品二因素 | 使用价值（自然属性） | 价值（社会属性、特有属性） |
| 劳动二重性 | 具体劳动→生产使用价值 | 抽象劳动→形成价值 |
| 价格 | 价值决定价格 | 供求影响价格 |

1. 「货币最基本职能」这类真题问法，落点在商品/价值规律这一板块（价值尺度），按资料以「价值量由社会必要劳动时间决定」作答链追溯。
2. 价值规律三作用记成「棒子、鞭子、筛子」，多选题按三个词选。
3. 买方市场（供 > 求）与卖方市场（供 < 求）方向不能反。

**【答题框架/落点】**：问「价值的源泉」答抽象劳动；问「使用价值的源泉」答具体劳动；问「价格为何波动」答价值决定、供求影响；问「价值规律作用」答三工具。

**【易混辨析】**：**使用价值 vs 价值**——自然属性 / 社会属性（特有）；**具体劳动 vs 抽象劳动**——生产使用价值 / 形成价值；**价值决定价格 vs 供求影响价格**——决定与影响两个动词；**等价交换（价值规律内容）vs 价格围绕价值波动（表现形式）**——内容与形式。

**【真题锚点】**：山东开放大学 2023 单选「货币最基本职能？」——属商品与货币板块，按本点「价值量—等价交换」链条回溯；命题角度：本点与 G52「生产工具是生产力水平的主要标志」常在同一份卷的两道单选里分别出现。

### G45 · 资本主义经济制度：剩余价值与资本积累 ☆

**【必背原文】**（`9.经济.pdf p2`）：资本主义经济制度的**本质＝生产资料私有制**；**特征＝剥削剩余价值**（来源＝工人的**剩余劳动**；产生＝**生产阶段**；数量上**剩余价值＝利润**；1. 剩余价值是工人劳动的产物，2. 利润是资本家全部预付资本的产物）。资本分类（划分标准＝依据是否能够带来剩余价值）：**可变资本（V）**、**不变资本（C）**；**只有 v 才能生产剩余价值，工人的剩余劳动是剩余价值的唯一源泉**。获取方式＝**绝对剩余价值（加班）**、**相对剩余价值（提高劳动生产率）**、**超额剩余价值（个别企业提高劳动生产率）**。**资本积累**：含义＝剩余价值资本化；动力或目的＝赚取更多剩余价值；结果＝**两级分化（马太效应）**。

**【要点拆解】**

1. 「只有可变资本 v 生产剩余价值」是本点核心判据；不变资本 c 不生产剩余价值。
2. 三种剩余价值：绝对（加班/延长劳动时间）、相对（全社会提高劳动生产率）、超额（个别企业提高劳动生产率）。
3. 剩余价值「＝利润」是数量上的相等，但两者「产物」表述不同（工人劳动 / 全部预付资本）。

**【答题框架/落点】**：问「剩余价值的唯一源泉」答工人的剩余劳动；问「划分不变资本与可变资本的标准」答是否带来剩余价值；问「个别企业率先改进技术获得的是」答超额剩余价值。

**【易混辨析】**：**不变资本 C vs 可变资本 V**——是否生产剩余价值；**绝对剩余价值 vs 相对剩余价值 vs 超额剩余价值**——加班 / 全社会劳动生产率 / 个别企业劳动生产率；**剩余价值（工人劳动产物）vs 利润（全部预付资本产物）**——数量相等、来源表述不同；**资本积累（剩余价值资本化）vs 资本积聚/集中**（资料未列，不引申）。

**【真题锚点】**：山东政法学院 2022 思政课真题论述「为资本设置『红绿灯』的理解」——可与本点「生产资料私有制、剩余价值」及政治理论篇相关条目串答，属政治经济学与政治理论交叉。

### G46 · 社会主义市场经济：体制、所有制、分配与产业 ★

### G47 · 微观经济：需求、供给、弹性与市场类型 ☆

**【必背原文】**（`9.经济.pdf p5`）：**前提＝经济人假定**：每一行为主体都是自私自利的、追求自身利益最大化。**需求**：最主要影响因素＝价格；替代品（A or B，A 价格上涨→B 需求上涨）、互补品（C + D，C 价格上涨→D 需求下降）；**需求法则**＝价格越高需求越少、价格越低需求越高；**需求价格弹性**＝富有弹性（奢侈品）、缺乏弹性（必需品）；**需求收入弹性**＝正常品（收入增加需求增加；幅度大＝奢侈品、幅度小＝必需品）、劣等品（收入增加需求减少）。**供给**：最主要影响因素＝价格；**供给法则**＝价格提高供给增加。**相关名词**：总效用＝总的满足程度；边际效用＝新增满足程度；**边际效用递减规律**＝消费者新增满足感不断降低；机会成本＝放弃的最大潜在收益；**边际收益（产量）递减规律**＝产量先升后降的过程。**市场类型**：完全竞争＝最理想、不可能实现、产品无差别、极端市场不需要打广告；垄断竞争＝竞争性 > 垄断性；寡头垄断＝几个厂商垄断市场（差别寡头＝产品有差别、纯粹寡头＝产品无差别〔自然资源〕）；完全垄断＝一个厂商垄断整个行业、典型代表国企、极端市场不需要打广告。

**【要点拆解】**

| 市场类型 | 厂商数量 | 产品差别 | 广告 |
| --- | --- | --- | --- |
| 完全竞争 | 极多 | 无差别 | 不需要 |
| 垄断竞争 | 较多 | 有差别 | 需要 |
| 寡头垄断 | 几个 | 有差别/无差别 | — |
| 完全垄断 | 一个 | 无相近替代 | 不需要 |

1. 替代品与互补品的价格—需求联动方向相反，是本点第一判题点。
2. 「富有弹性＝奢侈品、缺乏弹性＝必需品」；「劣等品收入增加需求减少」。
3. 完全竞争与完全垄断都是「极端市场、不需要打广告」，别只答一个。

**【答题框架/落点】**：给「汽油涨价导致汽车需求下降」定互补品；给「茶叶涨价导致咖啡需求上升」定替代品；问「必需品需求价格弹性」答缺乏弹性；问「最理想但不可能实现的市场」答完全竞争。

**【易混辨析】**：**替代品（同向替代）vs 互补品（反向联动）**；**需求价格弹性（价格变动）vs 需求收入弹性（收入变动）**；**正常品 vs 劣等品**——收入增加时需求增 / 减；**边际效用递减（消费端满足感）vs 边际收益递减（生产端产量）**；**完全竞争 vs 完全垄断**——都属极端市场、都不需打广告，但厂商数量相反。

### G48 · 宏观经济：目标、政策与常见经济学名词 ★

**【必背原文】**（`9.经济.pdf p5—6`）：**宏观调控**＝凯恩斯（宏观经济学之父）提出，是一种宏观的间接的调控；**看不见的手＝靠市场＝亚当斯密**，**看得见的手＝靠政府＝凯恩斯**。**目标（口诀「两增一稳保平衡」）**：促进经济增长（最主要）、增加就业、稳定物价、保持国际收支平衡。失业四形式＝摩擦性失业（流动、跳槽、搬家）、结构性失业（产业结构调整、技能不匹配）、周期性失业（经济大环境—经济危机）、季节性失业（间歇性、淡旺季、农业）。稳定物价＝抑制住通货膨胀、避免通货紧缩、维持币值的稳定。**手段（最主要）**：经济手段（财政政策、货币政策）、行政手段（强制力）、法律手段（经济立法和经济司法）、计划手段、道德手段。**财政政策**：主体＝国家；工具＝国家预算、税收（强制性、无偿性、固定性）、国债、政府投资、补贴。**货币政策**：主体＝央行（职能＝国家的银行、银行的银行、发行的银行）；**三大法宝**＝公开市场业务（买卖有价证券）、法定存款准备金率（放在央行的钱）、再贴现率（央行扣的钱）；其他＝利率、汇率（本币贬值→促进出口、抑制进口）。**常见经济学名词**：**GDP**＝国内生产总值（地域概念；中华人民共和国领土范围内，中国人在中国 + 外国人在中国）；**GNP**＝国民生产总值（国民概念；具有中华人民共和国国籍的人，中国人在中国 + 中国人在外国）；**CPI**＝消费者物价指数（衡量通货膨胀的指标，**CPI > 3% 发生通货膨胀**）；**财政赤字**＝支出 > 收入，最佳弥补方式＝发行公债；**基尼系数**＝衡量收入分配差异，**警戒线 0.4**，结论＝基尼系数越小收入差异越小；**恩格尔系数**＝食物支出占总支出的比例，衡量人民生活水平，结论＝**恩格尔系数与生活水平成反比**。

**【要点拆解】**

1. 宏观调控四目标里「促进经济增长」是**最主要**目标，单选必考。
2. 货币政策三大法宝按资料三个括号记：买卖有价证券 / 放在央行的钱 / 央行扣的钱。
3. 四个指数/系数的结论：CPI > 3% 通胀、基尼 0.4 警戒且越小越平均、恩格尔与生活水平成反比、财政赤字支出 > 收入。
4. GDP 是地域概念、GNP 是国民概念——「中国人在中国 + 外国人在中国」vs「中国人在中国 + 中国人在外国」。

**【答题框架/落点】**：问「宏观经济学之父」答凯恩斯；问「最主要目标」答促进经济增长；问「三大法宝」答三个；问「GDP 与 GNP 区别」答地域 / 国民；问「衡量通胀的指标」答 CPI。

**【易混辨析】**：**财政政策（主体国家、工具预算税收国债投资补贴）vs 货币政策（主体央行、三大法宝 + 利率汇率）**；**GDP（地域）vs GNP（国民）**；**CPI（通胀）vs 基尼系数（收入分配）vs 恩格尔系数（生活水平）**——三个指标衡量对象不同；**摩擦性 / 结构性 / 周期性 / 季节性失业**——原因分别是流动、技能不匹配、经济危机、淡旺季；**经济手段（最主要）vs 行政手段（强制力）vs 法律手段**；**通货膨胀 vs 通货紧缩**——稳定物价要同时抑制前者、避免后者。

**【真题锚点】**：命题角度——「CPI > 3%」「基尼系数 0.4」是判断题改数设错的高频点，按附录 B 数字表整组防守；与政治理论篇「新质生产力」「高质量发展」构成经济类简答的升华句来源。

### G50 · 唯物辩证法：两大特征、三大规律、五对范畴 ★

**【必背原文】**（`10.马K思主义哲学.pdf p3—4`）：**两大特征**：**联系**＝事物内部诸要素之间以及事物之间的相互影响、相互作用和相互制约；特征＝**普遍性、客观性、条件性、多样性**；整体和部分＝整体居于主导地位统率着部分、关键部分对整体起决定作用、整体具有部分所没有的新功能。**发展**＝前进性质和上升性质的运动；实质＝**新事物的产生、旧事物的灭亡**；新旧事物区别的根本标志＝**是否同事物发展的必然趋势相符合**；方法论＝用发展的眼光看问题。**三大规律**：一、**对立统一规律**；二、**质量互变规律**（揭示了事物发展的**形式和状态**；量变＝渐进的、不显著的变化，质变＝根本性质的变化；区分标志＝是否超出一定限度；关系＝量变是质变的必要准备、质变是量变的必然结果、总的量变中有部分质变；方法论＝坚持适度原则、重视量的积累、创造条件促使事物向好的方向转化）；三、**否定之否定规律**（揭示了事物发展的**方向和道路**；辩证的否定实质＝**扬弃**；两次否定、三个阶段＝肯定→否定→否定之否定；方法论＝事物的发展是前进性和曲折性的对立统一）。**五对范畴**：内容和形式（内容决定形式）、现象和本质（现象有真象和假象之分；任何本质都会通过现象表现出来，任何现象都表示本质）、原因和结果（条件＝时间先后次序、引起与被引起的关系）、可能性和现实、偶然性和必然性。

**【要点拆解】**

1. 三大规律各配一个「揭示了什么」：对立统一（资料未展开）、质量互变＝形式和状态、否定之否定＝方向和道路。
2. 联系四特征：普遍性、客观性、条件性、多样性——简答「联系的含义和基本特点」按此答。
3. 量变与质变的区分标志是「是否超出一定限度」（度），方法论三条含「适度原则」。
4. 辩证否定实质「扬弃」、两次否定三个阶段是固定表述。

**【答题框架/落点】**：简答「联系的含义和基本特点」＝定义一句 + 四特征；给「水滴石穿」答质量互变；给「螺旋式上升」答否定之否定；问「辩证否定的实质」答扬弃。

**【易混辨析】**：**联系（普遍性客观性条件性多样性）vs 发展（前进上升、新替旧）**——两大特征；**量变（渐进不显著）vs 质变（根本性质）**——是否超出限度；**质量互变（形式和状态）vs 否定之否定（方向和道路）**——揭示内容不同；**现象（有真象假象）vs 本质**——任何本质都通过现象表现；**原因和结果（引起与被引起 + 时间先后）vs 偶然性和必然性**；**整体（统率部分、有新功能）vs 关键部分（对整体起决定作用）**。

**【真题锚点】**：山东政法学院 2022 思政课真题简答「**联系的含义和基本特点**」——直接命中本点「联系」的定义与四特征；命题角度：「质量互变」常以成语/俗语情境出单选。

### G51 · 辩证唯物主义认识论：实践、认识与真理 ★

**【必背原文】**（`10.马K思主义哲学.pdf p2—3`）：**实践**＝人类能动地改造世界的客观物质活动；特点＝**客观物质性、主观能动性、社会历史性、直接现实性**；基本形式＝**生产实践（最基本）、社会实践、科学实验**。**认识两阶段**：感性认识＝认识的低级阶段，形式＝**感觉、知觉、表象**；理性认识＝认识的高级阶段，形式＝**概念、判断、推理**；理性认识依赖于感性认识；感性认识有待于发展为理性认识，感性认识和理性认识相互渗透。**基本规律**：两次飞跃＝第一次感性认识到理性认识、第二次认识到实践；特点＝**反复性**（实践—认识—再实践）、**无限性**（没有终点）。**原理**：1. **实践决定认识**（实践是认识的来源、实践是认识发展的动力、实践是认识的目的和归宿、**实践是检验认识正确与否的唯一标准**）；2. **认识反作用于实践**（科学的认识促进、错误的认识阻碍）；方法论＝**避免本本主义和教条主义**。**真理**＝人们对于客观事物及其规律的**正确反映**；根本属性＝**客观性**；真理的具体性；真理和谬误＝一定范围内绝对对立、超出一定范围相互转化。

**【要点拆解】**

1. 实践四特点、三基本形式（生产实践最基本）按资料背。
2. 感性三形式（感觉知觉表象）vs 理性三形式（概念判断推理），判断题最易对调。
3. 实践决定认识四条 + 检验真理的唯一标准一句，是简答主干。
4. 两次飞跃：感性→理性、认识→实践（第二次更重要，资料未明示重要性，不引申）。

**【答题框架/落点】**：问「检验真理的唯一标准」答实践；问「认识的高级阶段形式」答概念判断推理；问「认识的来源/动力/目的归宿」按四条答；给「纸上得来终觉浅」定实践决定认识。

**【易混辨析】**：**感性认识（感觉知觉表象、低级）vs 理性认识（概念判断推理、高级）**；**实践是认识的来源 vs 动力 vs 目的归宿 vs 唯一标准**——四个定位别串；**第一次飞跃（感性→理性）vs 第二次飞跃（认识→实践）**；**真理（正确反映、客观性）vs 谬误**——一定范围内绝对对立、超出范围相互转化；**实践特点（客观物质性、直接现实性等）vs 认识特点（反复性、无限性）**。

**【真题锚点】**：命题角度——「实践是检验真理的唯一标准」是全系列最经典的判断/单选题；山东政法学院 2022 卷的马原著作题（《关于费尔巴哈的提纲》）与本点实践观同源，按本点口径作答。

### G52 · 历史唯物主义 ☆

**【必背原文】**（`10.马K思主义哲学.pdf p4—5`）：**历史观的基本问题＝社会存在和社会意识的关系问题**；两种对立的历史观＝**历史唯物主义、历史唯心主义**。**社会存在**＝地理环境、人口因素、**生产方式（决定性因素）**；**两者关系**＝社会存在决定社会意识、社会意识反作用于社会存在、**社会意识具有相对独立性**（表现＝不同步性）。**社会基本矛盾一**：**生产力**＝人类改造自然并从自然界获得生存和发展的物质资料的能力；实体性要素＝**劳动者（最活跃、起主导作用）、劳动资料（生产工具是社会生产力发展水平的主要标志）、劳动对象**；智能性要素＝**科学技术**。**生产关系**＝人们在物质生产过程中所结成的经济关系；静态构成＝**生产资料所有制形式（决定性作用）、人与人地位和相互关系、产品分配形式**；动态＝生产、分配、交换和消费；两者关系＝**生产力决定生产关系，生产关系反作用于生产力**。**社会基本矛盾二**：**经济基础**＝占统治地位的生产关系的总和；**上层建筑**＝政治上层建筑、思想上层建筑，**核心＝国家政权**；两者关系＝经济基础决定上层建筑、上层建筑反作用于经济基础。**人民群众是历史的主体和历史的创造者**：表现＝人民群众是社会物质财富的创造者、社会精神财富的创造者、实现社会变革的决定力量；群众路线。**人的本质和价值**：人的本质＝人的社会性质；人的价值＝**社会价值为第一位**、自我价值。

1. 「生产工具是社会生产力发展水平的主要标志」——直接对应山东开放大学 2023 真题单选。
2. 生产力三实体性要素里「劳动者最活跃、起主导作用」，「生产工具是主要标志」，两个「最」别混。
3. 生产关系静态构成中「生产资料所有制形式」起决定性作用。
4. 上层建筑核心＝国家政权；社会意识相对独立性表现＝不同步性。

**【易混辨析】**：**社会存在（地理环境人口因素生产方式）vs 社会意识**——决定与反作用；**生产力（劳动者、劳动资料、劳动对象）vs 生产关系（所有制、地位关系、分配形式）**——生产力决定生产关系；**劳动者（最活跃、主导）vs 生产工具（主要标志）**；**经济基础（生产关系总和）vs 上层建筑（核心国家政权）**；**历史唯物主义 vs 历史唯心主义**——是否承认社会存在决定社会意识；**社会价值（第一位）vs 自我价值**。

### G53 · 公文概述：概念、特点与文稿 ★

**【必背原文】**（`14.公文处理.pdf p1`）：公文＝**党政机关**在**处理公务**中形成的、具有**特定效力、规范体式**的文书。**特点**：**规范性**＝①格式；②语言＝准确、简洁、庄重、严谨；③文体＝说明、叙述、议论；**法定性**（资料注「错误表述：作者是撰稿人、撰写人」）；**时效性**＝及时有期限、时代性；**公务性、程序性、权威性**。**文稿**：**正本**（特殊形式＝**试行本、修订本、暂行本**）；**副本**（**仅复印无效、加盖章有效**）。

**【要点拆解】**

1. 公文作者是「发文机关」而非「撰稿人/撰写人」——资料专门标出这一错误表述，判断题高频。
2. 规范性三小项：格式、语言（准确简洁庄重严谨）、文体（说明叙述议论）。
3. 正本三种特殊形式：试行本、修订本、暂行本；副本「仅复印无效、加盖章有效」。
4. 特点五个词：规范性、法定性、时效性、公务性、程序性、权威性（资料并列，按资料列全）。

**【答题框架/落点】**：简答「公文的特点」按「规范性（含三小项）→ 法定性 → 时效性 → 公务性、程序性、权威性」写；判断题见「作者是撰稿人」即判错。

**【易混辨析】**：**公文作者（发文机关）vs 撰稿人**——资料明列错误表述；**正本 vs 副本**——副本仅复印无效、加盖章才有效；**试行本 / 修订本 / 暂行本**——都属正本的特殊形式，不是副本；**规范性（格式语言文体）vs 法定性（效力来源）**。

### G54 · 公文格式：版头、主体、版记三块 ★

**【必背原文】**（`14.公文处理.pdf p1`）：**版头**：**份号**＝6 位阿拉伯数字（涉密标）；**密级与保密期限**＝秘密、机密、绝密；**紧急程度**＝公文：特急、加急；电报：特提、特急、加急、平急；**发文机关标志**＝全称或规范化简称 + 文件（「文件」可省），联合行文＝主前协后或只写主办；**发文字号**＝年份标 4 位、用六角括号，顺序号不加「第」、不编虚位 0；**签发人**＝**仅上行文标**。**主体**：**标题**＝发文机关 + 事由 + 文种（**文种不可省**），**只有一个「关于」**；**主送机关**＝全称、规范化简称、统称（先高后低、先外后内），过多时移到版记，首页必须出现正文；**正文**＝层次序数「一、」「（一）」「1.」「（1）」；先引用标题、后发文字号；请示结语；**附件说明**＝附件名称后不加标点符号；**署名、日期、印章**＝日期右空 4 字，会议通过、负责人签发；印章**上不压正文、下压日期**，联合行文都盖章；**附注**＝说明印发传达范围。**版记**：**无「主题词」要素**；**抄送机关**＝需要知晓公文内容的机关。

**【要点拆解】**

| 区块 | 要素 | 精确限定 |
| --- | --- | --- |
| 版头 | 份号、密级与保密期限、紧急程度、发文机关标志、发文字号、签发人 | 份号 6 位；年份 4 位六角括号；签发人仅上行文 |
| 主体 | 标题、主送机关、正文、附件说明、署名日期印章、附注 | 三要素标题；只有一个「关于」；日期右空 4 字 |
| 版记 | 抄送机关 | 无「主题词」 |

1. 「文种不可省」「只有一个关于」「日期右空 4 字」「印章上不压正文下压日期」「无主题词」五句是格式判断题的送分点。
2. 发文字号三细节：年份 4 位、六角括号、顺序号不加「第」不编 0。
3. 签发人只在上行文标注；电报紧急程度比公文多「特提、平急」。
4. 主送机关排序「先高后低、先外后内」。

**【答题框架/落点】**：简答「公文格式包括哪些要素」按版头六项、主体六项、版记一项分层写；改错题按上表逐项核。

**【易混辨析】**：**版头 vs 主体 vs 版记**——三块要素不要串位；**密级（秘密机密绝密）vs 紧急程度（特急加急 / 电报特提特急加急平急）**；**发文机关标志（可省「文件」）vs 标题（文种不可省）**；**主送机关（需要办理）vs 抄送机关（需要知晓）**；**附件说明（名称后不加标点）vs 附注（印发传达范围）**；**签发人（仅上行文）vs 署名日期印章（主体）**。

### G55 · 公文种类：15 种法定公文与行文方向 ★

**【必背原文】**（`14.公文处理.pdf p1`）：资料册按 12 项编号列示——**1. 命令：嘉奖；2. 公告：国内外；3. 通告：一定范围；4. 通知：公文之王、轻骑兵，下级机关执行，批转、转发；5. 通报：表批情况；6. 请示：上行，事前，期复性；7. 报告：上行，事前中后；批复：下行文，针对请示；8. 意见：多向性；9. 函：不相隶属；10. 决定：奖惩；11. 决议：会议讨论事项；12. 公报：新闻性、报道性**。**按行文方向分为：上行文、平行文、下行文**。

**【要点拆解】**

| 文种 | 资料原文用途 | 行文方向 |
| --- | --- | --- |
| 命令 | 嘉奖 | 下行 |
| 公告 | 国内外 | 下行/周知 |
| 通告 | 一定范围 | 下行/周知 |
| 通知 | 公文之王、轻骑兵；下级机关执行、批转转发 | 下行（多向） |
| 通报 | 表批情况 | 下行 |
| 请示 | 上行、事前、期复性 | 上行 |
| 报告 | 上行、事前中后 | 上行 |
| 批复 | 下行文、针对请示 | 下行 |
| 意见 | 多向性 | 上行/平行/下行 |
| 函 | 不相隶属 | 平行 |
| 决定 | 奖惩 | 下行 |
| 决议 | 会议讨论事项 | 下行 |
| 公报 | 新闻性、报道性 | 下行/周知 |

1. 资料册按 **12 项编号**列示（第 7 项内含「批复」），法定公文通行口径为 **15 种**；资料册未逐一列全的其余文种，本篇只作提示、**不编写其定义**，考试作答一律以官方发布的公文处理条例原文与资料册列明的文种用途为准。
2. 「通知＝公文之王、轻骑兵」「函＝不相隶属」「意见＝多向性」「请示＝上行、事前、期复性」「批复＝针对请示」五句是判题锚。
3. 行文方向三分：上行文（请示、报告）、平行文（函）、下行文（命令、决定、决议、批复、通知、通报、公报、公告、通告等）；意见可多向。

**【答题框架/落点】**：给「向不相隶属单位商洽工作」答函；给「请求上级批准」答请示；给「答复下级请示」答批复；给「表彰先进、批评错误」答通报；给「公布重大会议事项」答公报。

**【易混辨析】**：**公告（国内外）vs 通告（一定范围）**——发布范围不同；**请示（上行、事前、期复、一文一事）vs 报告（上行、事前中后、不要求批复）**——是否期复、是否事前；**批复（下行、针对请示）vs 函（不相隶属、平行）**；**通知（公文之王、执行与批转转发）vs 通报（表批情况）**；**决议（会议讨论事项）vs 决定（奖惩）**；**意见（多向性）vs 其他单向文种**；**上行文 / 平行文 / 下行文**——按收文机关关系分。

**【真题锚点】**：东营职院 2023 写作「倡议书：注重文明礼仪，共创和谐校园」、济南幼儿师范 2024「三所高校文化建设情况的考察报告」——写作前先按本点判明文种与行文方向，再套附录 C 模板。

### G56 · 行文规则与公文拟制、办理流程 ★

**【必背原文】**（`14.公文处理.pdf p1—2`）：**行文规则**：**基本规则＝一般不越级**；**上行文规则**＝主送一个、不抄送下级、重大事项经党委政府同意、转报下级的请示要提倾向性意见、**请示一文一事**；**下行文规则**＝重要行文抄上级、办公厅室经同意可发指令性要求、涉及多部门先协商；**特殊规则**＝同级必要可联合。**公文拟制和办理**：**拟制**＝起草、审核、签发；**发文**＝复核、登记、印制、核发；**收文**＝签收、登记、初审、承办、传阅、催办、答复；**拟办**（初步拟定）、**批办**（领导批示）、**注办**（做标注）；**公文管理**＝绝密一般不得复制、汇编；汇编本按最高密级标；新机关要发文立户。

**【要点拆解】**

1. 「请示一文一事」「一般不越级」「主送一个、不抄送下级」是三条硬规则，判断题高频。
2. 三条流程按顺序背：拟制（起草审核签发）→ 发文（复核登记印制核发）→ 收文（签收登记初审承办传阅催办答复）。
3. 拟办 / 批办 / 注办三个「办」按资料括号区分：初步拟定 / 领导批示 / 做标注。
4. 汇编本按**最高密级**标注；绝密一般不得复制、汇编。

**【答题框架/落点】**：简答「公文拟制与办理流程」按三段流程 + 三办 + 管理三条写；改错「一文多事」「越级请示」「请示抄送下级」逐条判错。

**【易混辨析】**：**拟制（起草审核签发）vs 发文（复核登记印制核发）vs 收文（签收登记初审承办传阅催办答复）**——三段环节不可串；**拟办（初步拟定）vs 批办（领导批示）vs 注办（做标注）**；**上行文规则 vs 下行文规则**——主送一个不抄下级 / 重要行文抄上级；**请示一文一事 vs 报告可一文多事**（资料未明示后者，不引申）；**绝密不得复制汇编 vs 汇编本按最高密级标**。

### G57 · 公文写作题的写法（简答与全文模板）★

**【必背原文】**（格式依据 `14.公文处理.pdf p1`）：标题＝发文机关 + 事由 + 文种，文种不可省、只有一个「关于」；主送机关全称或规范化简称；正文层次「一、」「（一）」「1.」「（1）」；请示须有结语；署名、日期（右空 4 字）、印章（上不压正文、下压日期）；附件说明名称后不加标点；抄送机关列于版记。

**【要点拆解】**

1. **判文体**：先定文种（通知/请示/报告/倡议书/考察报告）与行文方向，再定格式要素取舍。
2. **套标题**：「××关于××的××」，只用一个「关于」，文种必须出现。
3. **写正文**：依据（为什么发）→ 事项（做什么）→ 要求（怎么做、何时做）三层；层次序数按「一、（一）1.（1）」。

**【答题框架/落点】**：客观题考格式要素按 G54 判；简答「如何写好一份请示」按「标题三要素 → 主送一个 → 一文一事 → 正文依据事项要求 → 期复结语 → 落款」六步写；公文写作按附录 C 模板直接默写。

### G58 · 科技常识速记：能源、信息技术与航天 ☆

**【必背原文】**（`17.科技.pdf p1—2`）：**能源分类**：按产生＝**一次能源**（自然界中以原有形式存在、未经加工转换；可再生〔太阳能、风能、地热能、生物质能〕/ 不可再生〔煤、石油、天然气、核能〕）、**二次能源**（经过加工或转换得到；汽油、柴油、沼气、电能）；按使用类型＝**常规能源**（已大规模生产和广泛利用：煤、石油、天然气）、**新能源**（刚开始开发利用、传统能源之外：太阳能、风能、地热能、生物质能、核能）。**核能**：核裂变（铀）、核能发电需要大量水冷却，**原子弹 1964 年我国爆炸成功**；核聚变（太阳内部），**氢弹 1967 年我国爆炸成功**；核衰变。**太阳能**＝光热转换（太阳能热水器、太阳灶）、光电转换（太阳能电池）、光化学转换（光合作用）。**风能**＝风形成原因是水平方向上气压的差异，风力发电＝荷兰。**海洋能**＝潮汐能（最成熟）、波浪能、海流能、海水温差能（最具潜力）、海水盐度差能。**生物质能**＝本质是太阳能转化。**地热能**＝地热发电、直接利用（供暖为主），浅层地热能利用规模最大在京津冀地区。**可燃冰**＝主要成分甲烷，主要分布陆地永久冻土、海洋深处，属一次能源、不可再生能源、新能源；乙醇汽油；第四代核能源（核聚变）。**纳米**＝长度单位，等于十亿分之一米；纳米材料尺度范围 1—100 nm。**生物工程**：遗传工程（基因工程）＝DNA（脱氧核糖核酸）、双螺旋、发现人沃森和克里克、绝大多数生物遗传信息的载体、转基因食品与抗虫棉，是现代生物技术的核心（建立标志）；细胞工程＝试管婴儿（有性繁殖）、克隆（供细胞核个体决定、无性繁殖）、克隆猴（世界首例非人灵长类动物）；微生物工程（发酵工程）＝馒头、酒、醋、酱油、红茶；酶工程＝绝大多数酶是蛋白质、加酶洗衣粉用温水洗涤去污好；生物反应器工程。**超导**＝温度降到绝对零度附近电阻减小到无法测量，超导状态能无损耗地传输电能。**信息技术**：三网融合＝电信网、广播电视网、互联网；大数据＝量大、特殊软件处理、处理速度快；物联网＝通过信息传感设备把任何物品与互联网连接起来实现智能化识别管理，核心为互联网，智能家居；5G＝高速率、大容量、低时延、低功耗；手机＝电磁波，雷雨天、加油站不宜打手机；光纤通信＝原理光的全反射、长短距离都可输送、信息损失小。**探月**：月球 1 号（苏联）人类首次月球非着陆、月球 2 号（苏联）人类首次月球着陆、月球 9 号（苏联）人类首次月球正面软着陆；嫦娥四号＝中继星鹊桥号、发射时间 2018 年 12 月 8 号、西昌卫星发射中心、长征三号乙、巡视器玉兔二号、登陆地点艾特肯盆地冯·卡门撞击坑（被命名为天河基地）、意义＝人类首次月球背面软着陆。

### G59 · 科技常识速记：生活物理、化学与生物 ☆

### 附录 C · 万能答题框架与公文格式模板

**框架 1 · 概念/原则类简答题**：`必背原文（定义或条目逐句写）→ 要点拆解（3—5 条，按资料原序）→ 意义或地位 → 落到判题/教师岗位`。适用于「什么是法」「行政法基本原则」「哲学基本问题」。

**框架 2 · 客观题判题四步**：`定性（板块 + 考定义还是考数字）→ 抓题干关键词 → 回原文对条目 → 排易混（查附录 A）→ 定选项`。给情境定制度（如「7 岁买手机」「复议维持谁当被告」）一律走这四步。

**框架 3 · 易混辨析类**：`先写两侧定义 → 再写唯一判据（资料给的那一个词）→ 各举一个资料原例 → 收在「一字之差定答案」`。适用于 22 组易混概念（附录 A）。

**框架 4 · 公文格式/改错类**：`按版头—主体—版记三块逐项核（G54 表）→ 标出「文种不可省、只有一个关于、日期右空 4 字、印章下压日期、无主题词、签发人仅上行文」→ 逐条说明错在哪、怎么改`。

**框架 5 · 公文写作四步**：`判文种与行文方向（G55）→ 套标题三要素 → 正文三层（依据 / 事项 / 要求）→ 落款（署名、日期、印章、抄送）`。倡议书、通知、请示、考察报告都套这一条。

**框架 6 · 材料/案例分析题**：`定性（这现象涉及哪几个 G 编号）→ 逐条对应原文 → 分主体给措施 → 升华（依法行政 / 依法治国 / 立德树人）`。如「材料分析侵犯了学生的什么权利」＝ G12 宪法权利 + G31 民法人身权双口径。
