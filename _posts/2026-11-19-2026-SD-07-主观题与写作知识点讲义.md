## 第一部分 · 知识地图（先建立整体逻辑）

主观题不是「文采题」，是「结构题 + 素材题」。十份山东真题里，写作几乎必考且分值最高：东营职院 2023 有 40 分作文与倡议书、济南幼儿师专 2024 有考察报告与议论文、日照工业学校 2023 有 800 字「职教如何突围」、济南工程职院 2023 有蔡元培学术自由写作题。框架决定不跑题，素材决定有话说，两者都要提前固化。

```
                    ┌─ 案例/材料题：定性 → 关键点 → 措施 → 反思（W01—W10）
题型判定 ───────────┼─ 结构化/综合分析：是什么 → 为什么 → 怎么办 → 升华（W11—W19）
                    ├─ 公文/应用文：文种 → 格式要素 → 正文模板 → 落款（W20—W30）
                    └─ 作文/申论：立意 → 标题 → 开头 → 分论点 → 结尾（W31—W38）
                                    ↓ 全部需要
        素材层  政策金句 / 人物案例 / 数据 / 反面现象 / 论证角度（W39—W48）
                                    ↓ 全部受制于
        评分层  观点准确 · 论据贴切 · 结构完整 · 语言流畅 · 卷面清晰（W49—W50）
```

**真题命中分布**：写作/作文 6/10 份卷（东营 40 分作文、倡议书；日照 800 字议论文；济南工程「学术自由」写作；济南幼儿师专考察报告 + 议论文；山东商业职院论述 2 题）；案例分析 4/10 份卷（东营 10 分案例、济南幼儿师专三校材料考察报告、山东服装职院材料分析侵权、滨州职院材料）；公文/应用文 3/10 份卷（倡议书、考察报告、报告类）；简答与论述 8/10 份卷。**结论：只背知识点不练笔会直接丢掉 40 分以上的写作分。**

**一条通用答题主线**（案例、结构化、论述、作文全部可套）：
`是什么（定性/立意）→ 为什么（原因/意义/背景）→ 有什么问题（现状痛点）→ 怎么办（分主体措施）→ 升华（教育强国 / 新质生产力 / 技能型社会）`

**第二条主线（写作专用）**：`引（政策金句或现象）→ 议（总论点）→ 联（三个分论点，各带例证/理证）→ 结（回扣 + 展望）`。

## 第二部分 · 案例分析题型与通用框架（W01—W10）

### W01 · 案例分析的题型判定与分值分布 ★

【必背原文/模板原文】资料包《案例分析范例》目录列七类：就业类、情感类、日常管理类、人际交流类、新生适应类、贫困生工作类、网络舆情工作类；《案例分析答题思路》按「突发事件 / 非突发事件」二分；专项班讲义专题一按「学习学业类、班级建设类、学生资助类、违纪处分类、人际关系类、心理健康类、恋爱情感类、就业指导类」分类并配例题。

【要点拆解】

| 真题 | 案例/写作题 | 分值/字数 |
| --- | --- | --- |
| 东营职院 2023 | 案例分析 + 倡议书 + 40 分作文「如何做好高职院校教育教学工作」 | 案例 10 分、作文 40 分 |
| 济南幼儿师专 2024 | 三所高校文化建设情况的考察报告 + 创新型人才培养议论文 | 大分值写作 |
| 山东服装职院 2023 | 材料分析侵犯了学生的什么权利 | 论述题 |
| 日照工业学校 2023 | 800 字「立足于人才培养，论述职教该如何突围」 | 800 字 |
| 济南工程职院 2023 | 蔡元培学术自由材料写作 + 高校毕业生体制改革趋势论述 | 写作 + 论述 |
| 青岛工程职院 2023 | 专业建设与改革、阶段性特点两份材料分析 | 材料分析题 |

【答题框架/落点】拿到题先判三件事：① 是突发事件还是非突发事件（决定用 T01 还是 T02）；② 是「怎么办」还是「怎么看/比较分析」（决定措施型还是评析型）；③ 字数与分值（300 字约 4—6 个采分点，600 字约 8—10 个，40 分作文需完整结构）。

【易混辨析】案例分析（给一段学生情境，问「你怎么办」）对材料分析（给政策/现象材料，问「如何理解/如何改革」）对考察报告（给多校材料，要求写成公文）；三者骨架不同，不可一律用「谈心谈话」开头。

【真题锚点】见上表，4/10 份卷直接命中。

【出处】案例范例 p1 目录；案例思路 p1、p3；专项讲义 p1—22；真题（东营职院 2023、济南幼儿师专 2024、山东服装职院 2023）。

### W02 · T01 突发事件五步框架 ★

【必背原文/模板原文】（**可直接默写**）**定性**：该案例是学生……（一句话概况凝练题干 who/when/where/what/how）的问题，属于校园危机事件应对工作范畴。**关键点**（面试时可省略）：作为辅导员，我会本着**由近及远、由急到缓**的原则，从以下几个方面展开工作。**具体措施**：1. **赶赴现场，稳定情绪/事态**——去现场、抛责任（途中汇报领导、听从指示）、找帮手（启动预案、组建应急工作小组、联系家长与保卫处医务室、视情况拨打 110/120）、救下他（生命第一，先安抚稳定情绪、倾听、确保安全）、看护他（带离危险区域、安排学生骨干 24 小时看护、联系校医院、决定是否送医）、稳事态（疏散围观、关注舆论动向）。2. **谈心谈话，了解情况**——侧面了解（同学、舍友、家长）、正面了解（情绪稳定后共情、了解深层原因、对症下药）。3. **多方合力，共同育人**——朋辈、家长、专业力量（心理健康老师测评与教育）、职能部门（宣传部门舆论缓释、一定范围内通告以正视听）。4. **重点关注，定期回访**——正面（人文关怀与心理疏导、定期交流）、建档案（建立学生档案持续关注）、侧面（学生信息员队伍、源头化解隐患）。5. **以点及面，群体教育**——心理疏导、摸排（一生一档、早发现早报告早研判早预防早控制）、主题班会（爱国主义、传统文化、安全、心理健康、挫折、恋爱观教育）、纪律教育（法律法规与校纪校规、底线红线）、校园文化。**总结反思**：树立闭环意识（不止于「知错」，要引导「能改」）、打造 1+n 育人模式、建立应急机制（事前预防、进宿舍进课堂进网络、案例总结整理成册）。

【要点拆解】
1. 五步顺序不可颠倒：**先稳现场与生命，再谈原因，再合力，再跟踪，最后群体教育**。
2. 六字诀「去现场、抛责任、找帮手、救下他、看护他、稳事态」是第一步的六个采分动作。
3. 「生命第一」「及时上报领导」「24 小时看护」「一生一档」「五早」是判卷关键词。
4. 总结反思三句（闭环意识、1+n 育人模式、应急机制）几乎可原样搬到任何突发事件题结尾。

【答题框架/落点】T01 用于：轻生/自杀倾向、失踪、突发疾病、聚众冲突、安全事故、网络舆情爆发。300 字题压缩为「定性 + 3 步措施 + 1 句反思」，600 字题五步全展开。

【易混辨析】突发事件框架（先控制事态、生命第一）对非突发事件框架（先谈心谈话、了解情况）；若在「学生挂科厌学」题里写「拨打 120」会被判定性错误。

【真题锚点】命题角度：山东服装职院 2023「材料分析侵犯了学生的什么权利」若含危机情境可套；济南幼儿师专 2024 案例材料为多校文化建设，属非突发，不用本框架。

【出处】案例思路 p1—2。

### W03 · T02 非突发事件六步框架 ★

【必背原文/模板原文】（**可直接默写**）**定性**：该案例是学生……（一句话概况凝练题干 who/when/where/what/how）的问题，属于 ××× 工作范畴。**关键点**：作为辅导员，我会本着由近及远、由急到缓的原则，从以下几个方面展开工作。**具体措施**：1. **谈心谈话，了解情况/批评教育/认真疏导**——以情感人（合适时间约谈、理解关怀、共情取得信任、了解前因后果、先肯定优良品质再批评错误行为）、以理服人（讲故事、摆数据、举案例，认识行为不当与思想偏差）、以法育人（援引校纪校规、说明严重性、承诺陪伴解决）、上报领导（及时上报、听从指示）。2. **沟通交流，积极处理**（视情况取舍）——涉及诈骗（报警、维权、反诈 APP）、涉及舆情（删帖澄清、客观理性看待信息）、涉及诉求（批评不当表达方式、引导校长信箱等正当渠道）、涉及被威胁（报警、情绪安抚）、涉及纠纷（陪同沟通、维护合法权益）。3. **多方合力/多措并举，共同育人**——朋辈力量、上级帮助、家长力量（先安抚家长、多关心少施压）、专业力量（心理测评）、宣传部门、报警、法律、专业教师（专家学者答疑解惑）。4. **动态调研，积极排查**——问题排查（学生干部全面摸排类似情况）、心理摸排（问卷、一生一档、五早）、座谈会（了解根源、公示举报电话、面对面回应急难愁盼）。5. **重点关注，定期回访**——正面（人文关怀、定期交流）、建档案、侧面（学生骨干关注动态）、舆情（网络舆情队伍）。6. **以点及面，群体教育**——举例（尊重意愿、保护隐私前提下讲明危害性）、主题班会、心理健康教育、纪律教育。**总结反思**：闭环意识、1+n 育人模式、防微杜渐（事前预防、进宿舍进课堂进网络）、占领网络思想政治教育主阵地（学生在哪思政就在哪、院系—班级—宿舍三级网络舆情监督机制）。

【要点拆解】
1. 第一步「以情感人 / 以理服人 / 以法育人 / 上报领导」四个小标题是标准采分点，务必写全。
2. 第二步按题干情境「视情况取舍」，不要五项全抄；写全反而显得套模板。
3. 第三步「多方合力」的八个主体（朋辈、上级、家长、心理、宣传、公安、法律、专业教师）按题干选 3—4 个。
4. 与 T01 的差别：本框架把「谈心谈话」放第一步（因为没有生命危险），把「赶赴现场」整步删除。

【答题框架/落点】T02 用于：学业困难/挂科、专业不感兴趣想转专业、慢就业待定族、奖学金助学金争议、学生干部辞职、恋爱情感、人际冲突、网络发帖、顶撞任课教师。

【易混辨析】「以情感人」对「以理服人」对「以法育人」顺序不可换；「上报领导」在第一步末，不要写成最后一步。

【真题锚点】专项讲义例题「学生服从志愿被招到某专业、要求转专业未果、逃课上网封闭自己」「迷恋网游多门挂科」；专项答案 p3—12 各类参考答案均按本框架。

【出处】案例思路 p3—5；专项讲义 p3—22；专项答案 p3—12。

### W04 · 案例「前置词」库 ☆

【必背原文/模板原文】（**可直接默写**）**了解信息的前置词**：1. 配合调查，了解详情；2. 仔细调查，了解详情；3. 调查了解，追根溯源；4. 调查了解，掌握详情；5. 全面了解，精确掌握信息；6. 详细了解情况，全面综合研判；7. 全面调查，了解情况；8. 准备信息，了解学生。**谈心谈话的前置词**：1. 谈心谈话，安抚情绪；2. 诚意沟通，以理服人；3. 谈心谈话，耐心疏导；4. 谈心谈话，教育引导；5. 谈心谈话，严重批评教育；6. 谈心谈话，因材施教。**长期关注的前置词**：1. 建立机制，长期关注；2. 动态关注，预防复发；3. 长期关注，加强服务；4. 持续关注，常态跟进；5. 闭环管理，长期教育；6. 引导保持持续跟进，树立闭环意识；7. 持续关注，双向闭环。

【要点拆解】
1. 每个措施段的**段首四字/六字小标题**就是采分点，判卷按小标题给分；同一份答案里不要重复用同一个前置词。
2. 三组分别对应「查」「谈」「跟」，与 T02 的第 1、4、5 步呼应。
3. 组合示例：「调查了解，追根溯源 → 谈心谈话，耐心疏导 → 对症下药，转变观念 → 加强指导，促进就业 → 以点及面，全面引导 → 长期关注，加强服务」（案例范例就业类第 1 题原答案）。

【答题框架/落点】写答案时先把 6 个小标题列在草稿纸上，再往每条下面填 1—2 句正文，保证不漏点、不重复。

【易混辨析】「安抚情绪」（情绪激动时用）对「严重批评教育」（违纪时用）对「因材施教」（学业/个性差异时用），按情境选，错用会显得不合分寸。

【真题锚点】案例范例 p2「一、案例分析思路」；专项答案各题均以小标题分段。

【出处】案例范例 p2；专项答案 p3—12。

### W05 · 专项班案例答题技巧六条 ★

【必背原文/模板原文】（**可直接默写**）【答题技巧】1. 调查研究事情的真相，确定事情的严重程度，具体问题具体分析。2. 考虑是否要向上级反映、汇报。3. 以学生为主体考虑问题，如何稳定学生情绪、有效与学生交流沟通？问题发生是否具有普遍性？利用时机加强对其他学生的教育和指导，让学生从一件事情中学会处理和解决问题的能力。4. 是否需要与家长联系沟通。5. 如果问题比较严重，是否需要请求心理咨询机构专业人员（公安人员，或保卫处，或学校学生部）等外力支持和援助。6. 事后如何总结，提高对学生事件（突发事件）的处理能力。

【要点拆解】
1. 六条是「审题检查表」：真相/严重程度 → 上报 → 学生主体与普遍性 → 家长 → 外力 → 总结。
2. 第 3 条的「问题发生是否具有普遍性」是「以点及面、群体教育」这一步的合法性依据，写答案时要点明。
3. 六条与 T01/T02 完全兼容：技巧是「想什么」，框架是「写什么」。

【答题框架/落点】开考后先用 1 分钟按六条在草稿纸打勾，再按 T01/T02 落笔，可避免漏掉「上报领导」「联系家长」「专业力量」三类高频采分点。

【易混辨析】「答题技巧六条」对「具体措施五步/六步」：前者是审题维度，后者是答案结构；不要把它当成段落标题写进答案。

【真题锚点】命题角度：任何案例题的审题环节；专项讲义 p3 原题照录。

【出处】专项讲义 p3。

### W06 · 专项班九类案例题型与例题 ☆

【必背原文/模板原文】专项班讲义专题一案例分类与例题：① 学习学业类（学生被调剂专业、思想消沉逃课上网封闭自己；迷恋网游、大二多门挂科补考未通过）② 班级建设类（上级领导来开职教现场会、学生质问「为什么老要我们搞卫生、算不算不真诚」；大一新生当选学生干部后因推诿现象递辞职申请）③ 学生资助类（抱怨评奖助学金制度不合理、往院长信箱写意见；获国家助学金后买新手机引发同学议论）④ 违纪处分类（学生趴桌、当场指责老师「教学内容太陈旧、看书都比听课有意思」、旁人起哄）⑤ 人际关系类（宿舍点香与少数民族风俗冲突；讲义气打人）⑥ 心理健康类（追求完美、高考失利、出现轻生念头；张某网络吵架后失联、情绪激动语言错乱上肢抽搐）⑦ 恋爱情感类（分手后不去上课、暗含轻生念头；学生爱慕已婚任课教师）⑧ 就业指导类（想做「待定族」、慢就业；大一是否要做生涯规划）⑨ 突发事件/材料分析论述题（心理危机干预全过程材料）。

【要点拆解】
1. 每类对应一个「标准处理组合」：学习学业＝调查 + 朋辈帮扶 + 专业课教师补课 + 家长；资助＝核实制度 + 政策宣讲 + 正确反映渠道 + 公示；违纪＝谈话认错道歉 + 学风教育 + 与任课教师沟通改进教法；心理健康＝生命第一 + 专业转介 + 长期跟踪。
2. 班级建设类第 1 题答案用「一屋不扫何以扫天下」「现代企业 6S 现场管理（整理、整顿、清扫、安全、清洁、素养）」「客人到家里也会搞卫生，这是礼节与尊重，与弄虚作假两码事」「职教现场会是对学校成绩的肯定」四句，是**可直接默写**的精彩话术。
3. 就业指导类用舒伯生涯发展理论：大一是生涯规划的**探索期**，自我探索 + 信息探索 + 决策技巧，到大三才能从容选择。

【答题框架/落点】按 W01 判定题型后，从本表调取该类的「标准处理组合」，再套 T01/T02 落笔。

【易混辨析】「学生资助类」（制度是否合理、助学金使用）对「贫困生工作类」（案例范例口径，含认定与帮扶）；「违纪处分类」对「人际关系类」：前者涉及校纪校规与处分，后者涉及双方调解。

【真题锚点】滨州职院 2024「兼职教师占全体教师比例」等选择同卷；山东服装职院 2023「职业院校如何开展学生道德教育」可借班级建设类话术。

【出处】专项讲义 p3—22；专项答案 p3—12。

### W07 · 《案例分析范例》七类题型与就业类完整答案 ☆

【必背原文/模板原文】《案例分析范例》目录七类：就业类、情感类、日常管理类、人际交流类、新生适应类、贫困生工作类、网络舆情工作类。**就业类第 1 题答案（可直接默写骨架）**：1. 定性——该案例是高校毕业生就业困难、就业意愿降低，出现「慢就业」和「待定族」现象，学生不愿意就业，属于辅导员工作职责中思想价值引领和职业规划与就业指导的工作范畴。2. 解决思路——解决思想问题与解决实际问题相结合；谈心谈话，了解问题本质，树立正确就业观念；加强就业指导，积极开展就业工作。3. 具体措施——① 调查了解，追根溯源；② 谈心谈话，耐心疏导；③ 对症下药，转变观念；④ 加强指导，促进就业；⑤ 以点及面，全面引导；⑥ 长期关注，加强服务。4. 反思总结——做好毕业生「一人一档」就业台账；利用网络信息技术定期问卷、一对一专属定制服务；向就业优秀辅导员和院系学习；就业工作在平时，把就业教育贯穿大一至大四。

【要点拆解】
1. 「定性 → 解决思路 → 具体措施 → 反思总结」是范例的四段式，比答题思路的「定性 → 关键点 → 措施 → 反思」多一段「解决思路」，题干若有「谈关键点/解决思路」就补这一段。
2. 「解决思想问题与解决实际问题相结合」是几乎万能的思路句，可迁移到学业、资助、心理各类。
3. 反思总结四条中「就业工作在平时，贯穿大一至大四」是升华句。

【答题框架/落点】就业类题整段套用；其他类把「具体措施」六条替换为对应类的标准处理组合（W06）。

【易混辨析】「慢就业/待定族」对「懒就业/不就业」：资料原文用「慢就业」「待定族」「特定族」，答题用原词；「一人一档」（就业台账）对「一生一档」（心理健康档案）。

【真题锚点】题库·主观 第 26 题「职业院校学生就业难、缓就业慢就业，你怎么看」；东营职院 2023 作文材料含「学生实践」。

【出处】案例范例 p1—16；题库·主观题目清单。

### W08 · 从辅导员岗迁移到专任教师岗（本篇关键）★

【必背原文/模板原文】资料包两份主观题材料**全部按辅导员岗编写**：定性句写「属于辅导员……工作范畴」，措施中大量出现「上报党委副书记」「启动危机预案」「学生骨干 24 小时看护」「一生一档」「进宿舍进课堂进网络」「主题班会」「院系—班级—宿舍三级舆情机制」。专任教师岗笔试若照抄，会出现身份错位。

【要点拆解】

| 维度 | 辅导员岗原表述 | 专任教师岗迁移表述 |
| --- | --- | --- |
| 身份定位 | 作为辅导员，我会…… | 作为专任教师/任课教师，我会…… |
| 定性句 | 属于辅导员思想价值引领和职业规划与就业指导的工作范畴 | 属于课堂教学、实训指导、课程思政与学业指导的工作范畴 |
| 上报对象 | 上报党委副书记、听从领导指示 | 及时与教研室、院系教学负责人、辅导员沟通，按学校规定报备 |
| 现场处置 | 启动危机预案、24 小时看护、联系保卫处医务室 | 第一时间保障课堂/实训安全，稳定秩序，配合辅导员与职能部门处置，不越权 |
| 育人合力 | 学生骨干、家长、心理老师、宣传部门 | 辅导员、专业带头人、企业导师、实训指导教师、家长（配合辅导员） |
| 群体教育 | 主题班会、纪律教育、班级活动 | 课程思政融入、课堂规则与实训规范、专业教育、学业预警帮扶、技能竞赛 |
| 跟踪闭环 | 一生一档、学生信息员队伍 | 学业过程性评价、学习情况跟踪与学情分析、课程达标与补考辅导 |
| 常见题眼 | 心理危机、舆情、宿舍矛盾、资助认定 | 学生顶撞教师、课堂玩手机、实训违规操作、挂科学业预警、实习不适应、专业认同低 |

【要点拆解（续）】
1. **三条迁移原则**：① 身份改为「任课教师/专业课教师/实训指导教师」；② 手段从「管理—处置」改为「教学—引导—协同」，凡涉及处分、危机干预、舆情、资助认定一律写「配合辅导员/职能部门，按学校规定报备」；③ 落点回到课堂、课程、实训、评价、专业认同，与《职业教育科目知识点讲义》V37 课程思政、V38 教学标准、V50 学生管理、V63 山东规范「一岗双责」「接诉即办」对齐。
2. 专任教师岗可**直接复用**的部分：由近及远由急到缓的原则、调查了解追根溯源、谈心谈话以情感人/以理服人/以法育人、多方合力、重点关注定期回访、以点及面群体教育、总结反思（闭环意识）。
3. 专任教师岗**必须改写**的部分：所有「辅导员」称谓、「主题班会」改为「课堂/专业教育」、危机处置的指挥权、资助认定与处分决定权。
4. 山东规范第二十六条「教师实行一岗双责，既教书又育人」是迁移后最有力的政策依据，可在定性句后引用。

【答题框架/落点】落笔前先在草稿纸写一句「我是专任教师，我的主阵地是课堂与实训」，然后按 T01/T02 逐条自检上表八项，把越权表述全部替换。

【易混辨析】「专任教师岗」对「辅导员岗」不是「少写几条」，而是「身份、权限、手段、落点」四项全换；把「上报党委副书记」改成「上报教研室」仍属生硬，应写「按学校规定报备并配合辅导员处置」。

【真题锚点】济南工程职院 2023 写作「蔡元培学术自由与高校改革启示」、东营职院 2023「如何做好高职院校教育教学工作」都是专任教师视角；专项讲义例题「学生顶撞专业课老师」本身就是最贴近专任教师岗的案例。

【出处】案例思路 p1—5；专项讲义 p3—22；鲁·规范 p4 第二十六条；真题（东营职院 2023、济南工程职院 2023）。

### W09 · T03 定性句与总结反思模板 ★

【必背原文/模板原文】（**可直接默写**）**定性句模板**：该案例是学生……（一句话凝练 who/when/where/what/how）的问题，属于 ××× 工作范畴。**关键点模板**：作为 ××（身份），我会本着由近及远、由急到缓的原则，从以下几个方面展开工作。**总结反思模板（三句）**：① 树立闭环意识——思想政治教育工作并非一蹴而就，批评教育和处理处分不能止于学生的「知错」，而要引导学生「能改」，对重点学生持续跟进，从根源入手，通过长期耐心的人文关怀和心理疏导，帮助其恢复正常学习生活状态。② 打造 1+n 育人模式——做好中介，充分调动校内校外、课堂内外各方面育人合力，整合学生骨干、家长、学校管理人员、专业人士、职能部门等多方力量，提升育人实效。③ 树立防微杜渐意识——在事前预防、发现化解上下功夫，加强进宿舍、进课堂、进网络，做到及时发现问题、及时解决问题；将案例总结反思整理成册，方便日后交流学习。

【要点拆解】
1. 定性句必须包含「一句话概括题干 + 归属范畴」，缺一即失分；概括句里要出现具体人物、事件、后果，不能只写「这是学生的问题」。
2. 突发事件的定性句末写「属于校园危机事件应对工作范畴」；非突发写「属于 ××× 工作范畴」（学习学业、思想价值引领、日常事务管理等）。
3. 三句反思可按题裁取 2—3 句，末句再加「占领网络思想政治教育主阵地」用于舆情类题。

【答题框架/落点】T03 与 T01/T02 拼装即为完整答案：定性 + 关键点 + 措施 + 反思。专任教师岗按 W08 替换身份与权限表述。

【易混辨析】「定性」对「解决思路」（W07 范例多一段）对「关键点」（答题思路中的原则句），三者不是同一句，按需选用。

【真题锚点】案例范例每道题均以「1. 定性：」「4. 反思总结：」起头；专项答案各题以「【答题要点】」起头，可对照练习。

【出处】案例思路 p1、p3、p5；案例范例 p2—16。

### W10 · 案例采分点分布与字数控制 ☆

【必背原文/模板原文】专项讲义例题标注分值字数：「毕业典礼……作答字数不超过 300 字」「心理健康宣传月策划方案，35 分，600 字左右」「面向毕业生写一篇 1000 字左右的主题发言稿」「撰写一篇网文，600 字以内」「针对给定材料 2 中的新生现状……300 字左右」「对刘老师、小高老师处理问题的做法进行比较分析，300 字左右」。

【要点拆解】

| 字数 | 建议结构 | 采分点数 |
| --- | --- | --- |
| 200—300 字 | 定性 1 句 + 措施 4—6 条（每条 1 句）+ 反思 1 句 | 6—8 个 |
| 600 字 | 定性 + 关键点 + 措施 6 条（每条 2 句）+ 反思 2—3 句 | 10—12 个 |
| 800—1000 字 | 完整四段式 + 每段展开例证/理证 | 结构分 + 内容分 |

【要点拆解（续）】
1. 判卷按「小标题 + 关键动词」给分：赶赴现场、上报领导、联系家长、谈心谈话、心理测评、建立档案、主题班会、以点及面、长期关注，写到一个给一分。
2. 每条措施写成「**动作 + 对象 + 目的**」三件套，例如「联系心理健康教育老师对该生进行心理测评，开展心理健康教育」。
3. 比较分析题（如「对刘老师、小高老师做法进行比较分析」）改用「分别定性 → 逐条对比（态度/程序/方法/效果）→ 得出启示」骨架，不用 T01/T02。

【答题框架/落点】先按字数定采分点数，再列小标题，最后填正文；宁可每条短，不要少一条。

【易混辨析】「字数不超过 300 字」不是「写满 300 字」，超字数可能扣分；「600 字左右」允许上下浮动，但结构必须完整。

【真题锚点】专项讲义 p23、p27、p31、p44、p46 各题标注；济南幼儿师专 2024 考察报告、东营职院 2023 案例 10 分。

【出处】专项讲义 p22—46；真题（东营职院 2023、济南幼儿师专 2024）。

### W12 · 教育理论类模板 ☆

【必背原文/模板原文】**表态**：题干中的理论/观点揭示了……，对高职专任教师的课堂教学与实训指导具有直接指导意义。**分析**：① 概念界定（该理论/人物思想的核心表述）；② 理论要点（3 条，按资料原文）；③ 职教场景印证（项目教学、理实一体、岗课赛证、课程思政）。**对策**：① 在教学设计上……；② 在课堂/实训实施上……；③ 在评价反馈上……。**收束**：把理论转化为可操作的教学行为，才是「学为人师、行为世范」的落点。

【要点拆解】
1. 可用理论清单（按 V68/V69 与教基补充核对原文）：黄炎培「手脑并用、做学合一、理论与实际并行、知识与技能并重」；陶行知「教学做合一」「捧着一颗心来，不带半根草去」；杜威「从做中学」；蔡元培「学术自由」；桑代克准备律/练习律/效果律；韦纳归因理论；班杜拉自我效能感；负迁移；过度学习 150%；舒伯生涯发展理论（大一是探索期）。
2. 「辨析题」变体：先判「片面/错误/正确」，再「肯定合理部分 → 指出片面之处 → 给出完整表述 → 落到教学」。
3. 教育理论类严禁编造人物原话；资料包未收录的完整定义按 `05_教育学·心理学` 与高教题库补，答题时只用有出处的表述。

【答题框架/落点】问「如何理解 ××」用四段；问「辨析 ××」先表态判断；问「对教学有何启示」只展开对策三条。

【真题锚点】山东服装职院 2023 论述「猎奇的、创新的教育是高质量教育，辨析」「课程实施是否应坚持创生取向」；日照工业学校 2023 简答「教学过程基本特点」；济南工程职院 2023 选择「杜威的教育思想」。

### W13 · 应急应变类模板 ★

【必背原文/模板原文】（**可直接默写**，由 T01 压缩）**表态**：面对这一突发情况，我会把学生生命安全与课堂/实训秩序放在第一位，沉着冷静、快速处置。**分析/处置**：① **第一时间到位**——赶赴现场、稳定情绪与事态，疏散无关人员；② **按程序上报协同**——途中向院系教学负责人报备、听从指示，配合辅导员、保卫处、医务室，视情况联系家长与 110/120；③ **生命/安全优先**——先安抚倾听、确保安全，安排专人看护，必要时送医；④ **控制影响**——关注舆论动向、一定范围内通报实情以正视听；⑤ **后续跟进**——谈心谈话了解深层原因，联系心理健康老师测评，建立跟踪档案。**收束**：事后复盘，完善课堂与实训应急预案，把「事前预防、发现化解」做在平时。

【要点拆解】
1. 三句判分词：「生命第一」「及时上报」「配合辅导员与职能部门」，专任教师岗不得写「我启动预案、我指挥处置」。
2. 实训车间的特有处置：立即停机断电、撤离危险区域、检查防护装备、按实训安全规程报告，比通用模板更贴岗。
3. 常见题眼：实训设备伤人、学生课堂突发疾病、学生当场顶撞/冲突、实习期间失联、网络舆情突发。

【答题框架/落点】T01 五步压缩为 5 条，每条 1—2 句；300 字题用本模板，600 字题回到 W02 全文。

【易混辨析】应急应变（被动、紧急、先控制）对计划组织（主动、预先、先方案）；「及时上报」对「越权处置」是专任教师岗最易失分处。

【真题锚点】案例范例情感类「女生与男朋友分手不去上课并暗含轻生念头」「室友失踪、有自杀倾向」；专项讲义心理健康类「张某网络吵架后失联、情绪激动语言错乱上肢抽搐」。

【出处】案例思路 p1—2；案例范例 p3—5；专项讲义 p13—22。

### W14 · 沟通协调类模板 ☆

【必背原文/模板原文】（**可直接默写**，由 T02 第 1—3 步与案例范例人际类整合）**表态**：出现分歧说明沟通不到位，我会本着尊重、真诚、解决问题的态度主动沟通。**分析/措施**：① **了解诉求**——找合适时间分别约谈，倾听、共情，弄清前因后果与各方的真实顾虑，做到心中有数；② **以理以法**——用讲故事、摆数据、举案例说明不当之处，援引校纪校规与教学管理制度，明确底线红线；③ **分对象沟通**——对同事（请教经验、明确分工、协同备课）、对学生（先肯定优良品质再批评错误行为）、对家长（先安抚、多关心少施压、家校合力）、对企业导师（明确实训标准与职责）；④ **达成共识**——形成书面或口头约定，明确各自责任与后续动作；⑤ **长效机制**——定期交流、信息互通、制度宣讲。**收束**：把一次分歧转化为改进教学管理的契机。

【要点拆解】
1. 万能思路句：「解决思想问题与解决实际问题相结合」（案例范例就业类原句）。
2. 班级建设类可用的四句精彩话术（专项答案 p4，**可直接默写**）：一屋不扫何以扫天下；现代企业 6S 现场管理（整理、整顿、清扫、安全、清洁、素养）是职业人必备劳动技能；上级来检查如同客人到家，会搞卫生换得体衣服，是礼节与尊重，与弄虚作假两码事；职教现场会是对学校过去成绩的肯定，也是树立职教品牌的最佳时机。
3. 专任教师岗高频沟通对象：学生、辅导员、教研室同事、企业兼职教师、家长（配合辅导员）、实训基地师傅。

【答题框架/落点】按「分别沟通 → 共同沟通 → 机制」三段写；涉及民族风俗、资助认定、处分等敏感事项一律写「尊重差异、按学校规定、请职能部门共同处理」。

【易混辨析】「沟通协调」对「应急应变」：前者无紧急危险、以谈话为主；「以情感人/以理服人/以法育人」三步不可少。

【真题锚点】专项讲义例题「学生顶撞专业课老师」「学生质问为什么要搞卫生」；案例范例人际交流类、日常管理类。

【出处】案例思路 p3—4；案例范例 p6—14；专项答案 p4、p6—7。

### W15 · 计划组织类模板 ☆

【必背原文/模板原文】（**可直接默写**，由专项讲义策划方案/倡议书/应急预案格式归纳）**表态**：组织好这次活动，对达成 ×× 目标、服务学生成长具有重要意义，我会周密筹划、闭环推进。**事前**：明确活动目的与主题 → 成立工作小组、确定时间地点参与对象 → 拟定方案（内容、流程、分工、经费、安全预案）→ 报批与宣传动员。**事中**：按流程实施，重点抓好（内容质量 / 学生参与 / 安全秩序 / 过程记录），及时处置临时情况。**事后**：收集反馈与成果、总结评估、宣传报道、材料归档、形成长效机制。**收束**：把单次活动沉淀为可复制的课程/活动品牌。

【易混辨析】「策划方案」（内部工作方案）对「通知」（对外告知）对「倡议书」（面向群体的号召）：三者文种、语气、格式都不同；「计划组织」对「应急应变」见 W13。

### W16 · T05 综合分析类模板与解题步骤 ★

【必背原文/模板原文】（**可直接默写**）**一、认识题型**：题干中出现「**理解、认识、评价、看法、分析、看待**」等词汇时，基本可以判定为综合分析题。【例题展示】① 谈谈你对「只要有 1%的希望就要尽 100%努力」这句话的理解；② 谈谈你对新时代高校辅导员工作的认识；③ 如何看待「复旦投毒案」事件。**二、答题思路**：解题步骤 → 总体思路 → 例题解析（如「毕业典礼是学生在校园中度过最后和最神圣时光……谈谈你对毕业典礼的看法，作答字数不超过 300 字」）。

【要点拆解】
1. 通用作答四段：**① 亮明观点**（这句话/这一现象说明了……，我认同/认为应辩证看待）→ **② 分层论证**（是什么：解释内涵；为什么：原因、意义、危害；怎么办：对策）→ **③ 联系岗位**（作为高职专任教师，落到课堂、实训、课程思政、学业指导）→ **④ 升华**（教育强国、技能型社会、立德树人）。
2. 辩证类题用「两面法」：先肯定合理一面，再指出局限/条件，最后给出全面表述；资料范例《1申论作文》p4 的「正面论证 / 反面论证」结构可借用。
3. 观点句经典句式（**可直接默写**，申论作文 p4）：……是……的根本、关键、基础、核心、前提；……是……之基、之源、之本、之依；……是……的重中之重、当务之急、必然要求；要……就要加强、加大、完善……；坚持……与……并重、相统一、相结合、相辅相成；……双管齐下、统筹并进。

【答题框架/落点】300 字题四段各 1—2 句；论述题四段各展开成一个自然段；辨析题先加一句「这一观点是片面的」。

【易混辨析】综合分析（谈看法）对教育理论类（谈概念，W12）对论述题（谈体系与措施，W18/W19）；「认识题型」六个判别词要背死。

【真题锚点】山东服装职院 2023 论述「猎奇的、创新的教育是高质量教育，辨析」；题库·主观 第 7 题「『以学生为本』或『以学生为主体』，你怎样理解」、第 13 题「国家加强和重视职业教育，对此你怎么看」、第 29 题「培养什么人、怎样培养人、为谁培养人」。

### W21 · 公文格式要素 ★

【必背原文/模板原文】（**可直接默写**，由公文模版 23 个模板归纳的通用要素）一份完整公文含：**标题**（发文单位 + 关于 + 事由 + 的 + 文种，如「×××× 公司关于 ×××××× 的决定」）→ **主送单位**（顶格写「××××（主送单位）：」）→ **正文**（依据/目的：「为了 ××××（目的），根据 ××××××（依据）」→ 事项：「经研究，决定 ××××××」→ 分条内容：「一、××××。二、××××。三、××××。」→ 希望要求）→ **结语**（请示用「妥否，请批示。」；报告用「特此报告。」；函用「请予审批」「请研究提出修改意见，于 ×××× 年 × 月 × 日前函告」；批复用「此复」类）→ **附件**（「附件：表彰名单」「附件：印模式样」）→ **发文机关署名** → **成文日期**（×××× 年 × 月 × 日）→ **印章**（模板以「(印章)」标注）→ **联系人及电话**（会议通知、请示、函常附）。

【要点拆解】

| 要素 | 模板写法 | 易错点 |
| --- | --- | --- |
| 标题 | ××××（单位）关于 ××××（事由）的 ××（文种） | 事由与文种不匹配、缺发文单位 |
| 主送单位 | ××××（主送单位）： | 多个主送混淆、请示多头主送 |
| 依据目的句 | 为了……，根据……，经研究，决定/现就……如下： | 缺依据、缺「经研究」 |
| 分条内容 | 一、…… 二、…… 三、…… | 层级混乱（一、/（一）/1. 混用） |
| 结语 | 妥否，请批示。/ 特此报告。/ 请予审批。 | 报告夹带请示事项、请示无结语 |
| 落款 | (印章) + ×××× 年 × 月 × 日 | 日期用汉字、缺印章、单位与日期倒置 |

【要点拆解（续）】
1. 会议纪要格式特殊：标题「会议纪要（第 × 期）」+ 制发单位 + 日期 → 会议概况（时间、主持人、参加人、传达/通报/听取/讨论/审议了什么）→ 「会议认为……会议强调……会议指出……会议经过审议，议定以下事项：」→ 参加会议人员名单；纪要**不写主送机关、不加印章**（按模板）。
2. 通知中的会议通知含「联系人：××× 电话：××××，邮箱：××××」与「请于 × 月 × 日前将参会人员名单报 ××××」，是采分细节。
3. 请示「一文一事」，主送一个上级机关，不可在报告中夹带请示事项。

【答题框架/落点】写公文先列九要素清单，逐项填；格式分往往占一半分值，宁可正文短也别漏落款与结语。

【易混辨析】「主送单位」对「抄送」；「附件说明」对「附件」本身；「成文日期」对「印发日期」；「印章」对「签发人」。

【真题锚点】东营职院 2023 倡议书（称呼、分条倡议、落款）；济南幼儿师专 2024 考察报告（标题、正文结构、落款）。

【出处】公文模版 p1—11；专项讲义 p24—37。

### W22 · T07 通知模板 ★

| 印发/转发性通知 | 「关于印发《××××××规定》的通知」：我们制定了……现印发给你们，请结合实际认真贯彻执行；贯彻执行中有何问题请及时反馈；转发式加「现将 ××（上级单位）《××××》（文号）转发给你们」 | 公文模版 p3 |

| --- | --- | --- |
| 文种误用 | 报告中夹带「请批准」；请示写成报告；不相隶属机关用请示 | 报告不夹带请示事项；求批复用请示；平行用函 |

1. 改错题作答格式：**先总说「本文存在 × 处错误」→ 逐条编号「错误 ×：……应改为……」→ 末条不漏落款与成文日期**。
2. 最常考的五个错误：文种误用、报告夹带请示、标题缺文种/事由、结语错配、落款缺项。
3. 通报与通知的判别：题干若出现「表彰/批评/事故情况」用通报；出现「请贯彻执行/现将有关事项通知如下」用通知。

【答题框架/落点】改错题按「标题 → 主送 → 正文依据 → 结语 → 附件 → 落款 → 文种」七步顺序逐项检查，保证不漏。

【易混辨析】「改错」对「写作」：改错只需指出并给出改法，不必重写全文；「格式错误」对「内容错误」：前者扣分点密集，优先全查一遍格式。

### W31 · 申论高分技巧五条与整体结构 ★

【必背原文/模板原文】（**可直接默写**）**一、高分技巧总结**：1. **观点**：准确（符合题干和材料）、全面（多用关键词，避免空洞）、明显（放在标题、开头、各段首句）、价值观正确。2. **论据**：贴切，丰富；材料之内的要改变表述，多用新闻热点、领导人讲话、名人名言与典故、自身实际（论据是用来论证观点的，要有材料外的素材，不能出现过度抄袭）。3. **结构**：清晰、完整、自然，分析对策都要有。4. **语言**：流畅、自然、多用短句、有风格（文采）。5. **注意字数要求，字迹要清晰**。**文章结构**：一般包括标题、开头、过渡、分析论证、结尾等基本构成部分；常见形式有以对策为主的文章结构，也有以分析内涵、原因、意义、关系等为主的文章结构；文章结构没有固定套路模式，要根据具体文章确定。

【要点拆解】
1. 主题与观点：主题即议论对象、写作对象；观点即写作过程中希望表达出来的所有重要信息。找准主题后，可从**阐释含义、分析原因或意义、危害、提出对策**等角度切入，围绕**关系、问题、原因、意义、危害、对策**等角度提出观点。
2. 确定主题与观点两步：**第一步剖析题干，定位关键信息；第二步梳理资料（背景、对策、含义、目标），挖掘具体观点**。
3. 「观点放在标题、开头、各段首句」是阅卷最实用的一条，分论点句必须写在段首。

【答题框架/落点】T11 全套：标题 → 开头（引 + 议）→ 过渡 → 三个分论段（观点 + 论据 + 分析 + 回扣）→ 结尾（总结 + 升华）。

【易混辨析】「主题」（写什么）对「观点」（主张什么）；「材料内改写」对「过度抄袭」：前者加分，后者扣分。

【真题锚点】东营职院 2023 40 分作文「如何做好高职院校教育教学工作」；济南幼儿师专 2024「以创新型人才培养为主题写一篇议论文」。

【出处】申论作文 p1—2；专项讲义 p38—43。

### W32 · 立意：两步定观点 ☆

【必背原文/模板原文】（**可直接默写**）第一步：剖析题干，定位关键信息。第二步：梳理资料（背景、对策、含义、目标），挖掘具体观点。总论点的确定：**题干主旨 + 看法**（专项讲义 p39）。分论点的确定：由总论点进行拆分，**一般三个**（示例：总论点「弘扬家风」→ 分论点「树立好家风 / 践行好家风 / 传承好家风」；总论点「以水为师」→「以水为师，师水之随境而适 / 师水之大道至简 / 师水之仁智兼备」）。

【要点拆解】
1. 职教作文常用总论点句式：「以 ×× 为抓手，推动职业教育高质量发展」「让职业教育与 ×× 紧密携手」「职业教育前途广阔、大有可为」「守教育报国初心，担筑梦育人使命」。
2. 分论点三种拆法：① 主体拆（政府 / 院校 / 教师 / 企业）；② 环节拆（夯实之基 / 锻造之魂 / 织就之网，见范文解析 p1）；③ 关系拆（最关键的是…… / 须着力在…… / 更加需要……，见范文解析 p2）。
3. 分论点句尽量用同一句式（排比），阅卷一眼可见结构完整。

【答题框架/落点】审题 3 分钟：圈题干关键词 → 从材料里挑 3 个支撑角度 → 写成 3 个对仗分论点 → 再动笔。

【易混辨析】「立意」对「标题」：立意先定，标题后取；「总论点」对「分论点」：分论点必须能支撑总论点，不能另起话题。

【真题锚点】日照工业学校 2023「立足于人才培养，论述职教该如何突围」（800 字）；济南幼儿师专 2024「创新型人才培养」议论文。

【出处】申论作文 p1；专项讲义 p39—40；范文解析 p1—15。

### W33 · 标题五型 ☆

【必背原文/模板原文】（**可直接默写**，申论作文 p2—3）**（1）常规型标题**：把安全发展摆在更突出的位置（把 XX 摆在 XX 的位置）／安全发展事关全局（XX 事关全局）／高质量就业需注重公平（XX 需注重 XX）／推进大学生就业要夯实制度基础（XX 要夯实 XX 基础）。**（2）比喻式标题**：推进依法行政开启法治政府「新航程」／用家庭教育破解财富观「密码」／用文化铸造新农村「脊梁」／以创新奏出时代「最强音」。**（3）警醒式标题**：莫让诗词「热」一时／莫让「土规定」伤害「异地办证」的善意／新闻，不要以伤害为代价／文化艺术，勿以传统反现代。**（4）对称式标题**：放慢脚步收获幸福／盘活老品牌焕发新生命／增强安全意识保障城市安全／完善党内法规体系夯实从严治党之基；动词 + 主题词：弘扬、树立、增加、加强、提升／涵养、托起、兜底、共话、打造、筑牢。**（5）主副式标题**：且把人文植心间 莫让科技失光泽 —— 科技与人文交融谱写美丽生活新篇章／岁月失语 惟石能言 —— 保护文化遗产传承中华文明／不患寡而患不均 —— 以制度建设保障教育公平。

【要点拆解】
1. 好标题应起画龙点睛效果，**一般应包含文章主题**；考场上最稳的是常规型与对称式，主副式对文采要求高但最出彩。
2. 职教主题可仿写：「把职业教育摆在更突出的位置」「以产教融合筑牢职教高质量发展之基」「莫让「唯学历」遮蔽技能之光」「职教之魂 存于匠心 —— 以工匠精神锻造技能良才」。
3. 范文标题库（**可直接借用句式**）：《推动现代职业教育迈上高质量发展新台阶》《让职业教育与劳动就业紧密携手》《职教之魂 存于匠心》《守教育报国初心，担筑梦育人使命》《打造现代化职业教育体系》《为高质量发展提供更多生力军》《职业教育高质量发展迎来新机遇》《在职业教育中启航奋进青春》《职业教育——让技能人才破圈》《职业教育为国锻造技能良才》《让职业技术教育之花开得更加绚丽多彩》。

【答题框架/落点】先定总论点 → 选一种标题型 → 套句式 → 检查是否含主题词。

【易混辨析】「比喻式」对「警醒式」：前者用引号强调新意象，后者用「莫让/勿以/不要」否定句式；主副式副标题前用破折号，不是冒号。

### W34 · 开头三式与两式补充 ★

【必背原文/模板原文】（**可直接默写**，申论作文 p3—4）**（1）阐释式**：文化学者冯骥才在贺兰山前，望着雄浑的石雕，感受着镶嵌在石缝之中的逝去岁月，不禁发出「岁月失语，惟石能言」的感慨。的确，中华民族在五千年的历史中创造了光辉的文化……**（2）评论式**：我们人为地把知识分成「文科」和「理科」……真正的科技是有灵魂、有生命、有温度、有情怀、有人性的……**（3）总结式**：交通运输业是事关国民经济的基础性、先导性、服务性行业……然而，目前车辆超限、超载的危险行驶行为似乎变成破不掉的魔咒……在这样的背景下，治理双超，加强执法，已经刻不容缓。**专项讲义两式**：**概括式**＝（铺垫背景）+ 罗列主要问题（与主题相关）+ 分析（原因、影响）+ 总论点；**转折递进式**＝好现象（名言、现象、意义等）+ 罗列主要问题 + 分析（原因、影响）+ 总论点。

### W35 · 分论点确定与结构布局 ☆

【必背原文/模板原文】（**可直接默写**）总论点＝题干主旨 + 看法；分论点由总论点拆分，一般三个；结构布局按「标题 → 开头 → 过渡 → 分析论证 → 结尾」。分论段两种论证结构：**例证法**＝分论点 + 例子 + 分析（启示）+ 回扣分论点（提对策）；**理证法**＝分论点 + 现状（好 + 坏）+ 影响（坏 + 好）/ 原因 + 回扣分论点（提对策）。

【要点拆解】
1. 论证的结构（申论作文 p4）：**论证 = 观点（段落开头）+ 论据（中间展开：问题原因 + 影响 + 对策，根据题干和资料实际各有侧重）**；常见形式：内涵式观点 + 论据、原因式观点 + 论据、意义式观点 + 论据、对策式观点 + 论据。
2. 纯说理论证（范文解析 p11 分析）：没有合适名言与例证时，可分层次展开，标志词为「一方面……另一方面……同时……」「从……看，……；从……看，……；从……看，……」。
3. 分论段每段建议 200 字左右（申论作文 p5 结尾模板标注「全文 1000 字左右」、正面/反面论证各 200 字左右）。

【答题框架/落点】三个分论段一律「段首分论点句 + 论据 + 分析 + 回扣」；三段之间用「首先/其次/再次」或同一句式排比衔接。

【易混辨析】「例证法」对「理证法」：前者必须有具体人物/事例，后者靠层次化说理；「分论点」对「论据」：论据不能另起一个观点。

【真题锚点】范文解析 p11—12 逐段标注「分论点 + 背景 + 对策」「分论点 + 对策 + 例证 + 意义」结构。

### W49 · 评分要点（观点·论据·结构·语言·字数）★

【必背原文/模板原文】（**可直接默写**，申论作文 p1 高分技巧总结）1. **观点**：准确（符合题干和材料）、全面（多用关键词，避免空洞）、明显（放在标题、开头、各段首句）、价值观正确。2. **论据**：贴切，丰富；材料之内的要改变表述，多用新闻热点、领导人讲话、名人名言与典故、自身实际；论据是用来论证观点的，要有材料外的素材，不能出现过度抄袭。3. **结构**：清晰、完整、自然，分析对策都要有。4. **语言**：流畅、自然、多用短句、有风格（文采）。5. **注意字数要求，字迹要清晰**。

【要点拆解】

| 维度 | 得分动作 | 失分动作 |
| --- | --- | --- |
| 观点 | 标题含主题词、开头亮总论点、分论点写在段首 | 观点藏在中段、跑题、价值观偏差 |
| 论据 | 每段 1 个材料内改写 + 1 个材料外素材 | 大段抄材料、通篇无例子 |
| 结构 | 标题—开头—三分论—结尾齐全，分析与对策都有 | 只有对策没有分析、缺结尾 |
| 语言 | 短句、排比、动词精准 | 长句套话、口号堆砌、错别字 |
| 字数 | 按要求写满（800/1000 字） | 不足或严重超出 |
| 卷面 | 字迹清晰、分段、序号规范 | 涂改、无段落、序号混乱 |

【要点拆解（续）】
1. 价值观正确是底线：不写政治敏感评论，不写未经资料收录的时政条文与数字（参见《职业教育科目知识点讲义》V70「需另行补充」）。
2. 「分析对策都要有」是资料原话：只写「要怎么做」不写「为什么」会被判结构不完整。
3. 案例/公文题另加格式分：小标题、结语、落款、主送、印章（W21/W30）逐项给分。

【答题框架/落点】写完按六维各打一个勾；优先补「分论点是否在段首」「结尾是否回扣」「字数是否达标」三项。

【易混辨析】「观点明显」对「观点正确」：明显是位置问题，正确是立场问题；「论据贴切」对「论据丰富」：宁可少而贴，不要多而离题。

【真题锚点】东营职院 2023 40 分作文、日照工业学校 2023 800 字、济南幼儿师专 2024 议论文均按此给分。

【出处】申论作文 p1；专项讲义 p38—43；范文解析逐篇【分析】批注。

### W50 · 卷面与考场执行要点 ☆

【必背原文/模板原文】资料包标注的字数与分值：倡议书（东营职院 2023）、40 分作文、800 字议论文、1000 字左右发言稿/议论文、600 字左右策划方案（35 分）、300 字左右比较分析、600 字以内网文、200 字以上请示。专项讲义 p44—46 网文写作例题要求「结合辅导员岗位工作撰写一篇网文（600 字以内）」并附「不负使命，做好辅导员工作」1000 字议论文题。

【要点拆解】

| 环节 | 执行要点 |
| --- | --- |
| 审题（3 分钟） | 圈题型动词、判文种/框架、定字数与身份（专任教师岗 → W08 迁移） |
| 列纲（5—10 分钟） | 草稿纸写：标题句 + 3 个分论点句 + 3 个论据 + 1 句结尾名言；公文则列九要素 |
| 写作 | 每段首句即观点；案例题先写小标题；公文先写标题与主送 |
| 收尾 | 必写结尾段（总结 + 升华）；必回落款/结语 |
| 检查（3 分钟） | 字数、错别字、序号层级、身份称谓（不得出现「作为辅导员」）、未收录时政 |

【要点拆解（续）】
1. 字迹与分段：一段不超过 6 行，分论点独立成段，序号用「一、二、三」或「首先/其次/再次」，全文层级统一。
2. 时间分配建议：40 分作文留足 40—50 分钟；案例 10 分题控制在 12 分钟内；公文题先保证格式再润色正文。
3. 专任教师岗最后自检一句：「我的答案里有没有越权写启动预案、处分决定、资助认定？有没有把身份写成辅导员？」——按 W08 表替换干净。

【答题框架/落点】把 W21 九要素表、W30 文种速查表、T01—T12 编号抄在草稿纸角落，全程按编号调取，不临场发明框架。

【易混辨析】「考场执行」对「平时积累」：素材按 W36 建议每主题备 2—3 例 2—3 句名言即可，不必整篇背范文；「写完检查」对「边写边改」：先一气写完再统一检查，避免打断结构。

【真题锚点】东营职院 2023（案例 + 倡议书 + 40 分作文同卷）、济南幼儿师专 2024（论述 + 案例 + 作文同卷）——多题同卷时时间分配本身即得分点。

【出处】专项讲义 p22—46（各题分值字数标注）；真题（东营职院 2023、济南幼儿师专 2024、日照工业学校 2023）；申论作文 p1。

### 附录 C · 七个万能答题框架

1. **T01 案例·突发事件**（W02）：定性 → 关键点 → 赶赴现场稳事态 → 谈心谈话 → 多方合力 → 重点关注回访 → 以点及面群体教育 → 总结反思（闭环 / 1+n / 应急机制）。
2. **T02 案例·非突发事件**（W03）：定性 → 关键点 → 谈心谈话（以情感人·以理服人·以法育人·上报领导）→ 沟通处理（按情境取舍）→ 多方合力 → 动态排查 → 重点关注 → 群体教育 → 反思。
3. **T04 结构化通用骨架**（W11）：表态 → 三条分析 → 三条对策 → 收束；六类按题干动词填入内容。
4. **通用主线**（W18）：是什么 → 为什么 → 有什么问题 → 怎么办（政府/企业/学校/教师）→ 升华；政策论述与作文通用。
5. **T06 四段式评析**（W19）：定性（含政策定位）→ 关键点/问题 → 具体措施（主体 + 动作 + 标准）→ 总结反思（三条规律 + 升华）。
6. **公文九要素框架**（W21）：标题 → 主送 → 依据目的句 → 分条事项 → 固定结语 → 附件 → 署名 → 日期 → 印章；改错按「标题—主送—正文—结语—附件—落款—文种」七步扫。
7. **T11 议论文框架**（W31—W38）：标题（含主题词）→ 开头（引 + 议 + 总论点）→ 三分论段（段首观点 + 论据 + 分析 + 回扣）→ 结尾（总结 + 名言 + 升华）。
